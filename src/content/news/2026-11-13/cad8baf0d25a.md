The point of this book is to expose you to ideas that you might otherwise never be exposed to. This book is about macros, that is programs that write programs. Macros are what make lisp the greatest programming language in the world. When used properly, macros enable amazing feats of abstraction, programmer productivity, and code efficiency and security that are unheard of elsewhere.

本书旨在让你接触到那些你可能永远无法接触到的思想。这本书是关于宏的，也就是编写程序的程序。宏使 Lisp 成为世界上最伟大的编程语言。当使用得当时，宏能够实现令人惊叹的抽象能力、程序员生产力，以及在其他地方闻所未闻的代码效率和安全性。

Macros let you do things you simply cannot do in other languages. If you are looking for a dry coding manual that re-hashes common-sense techniques in whatever langue du jour, this book is not for you. This book is about pushing the boundaries of what we know about programming. While this book teaches useful macro skills that can help solve your programming problems today and now, it has also been designed to be entertaining and inspiring.

宏让你能够做在其他语言中根本无法做到的事情。如果你正在寻找一本枯燥的编程手册，去重述那些时下流行语言中的常识性技术，那么这本书不适合你。这本书旨在拓展我们对编程认知的边界。虽然本书教授的实用宏技能可以帮助你解决当下的编程问题，但它也被设计得既有趣又富有启发性。

Installation macOS On macOS you can install the prebuilt IPA with Sideloadly or build the app directly with Xcode. Either way, the iPhone must be paired with the target Apple Watch, and the Watch must run a supported watchOS version.

安装 macOS 在 macOS 上，你可以使用 Sideloadly 安装预构建的 IPA，或者直接使用 Xcode 构建应用。无论哪种方式，iPhone 都必须与目标 Apple Watch 配对，且手表必须运行受支持的 watchOS 版本。

Install the IPA Known issue with Sideloadly 0.72: Issue #43 reports that this version may remove the embedded Watch app while signing. If the iPhone app installs but HermesEnabler2 is missing from the Watch, use Xcode instead. This report is specific to version 0.72; compatibility with other versions has not been confirmed. Download the IPA from Releases. Install Sideloadly on your Mac, connect your iPhone with a cable, and select it in Sideloadly. Drag the IPA into Sideloadly and enter your Apple ID. Turn off Use automatic bundle ID, set a fixed Bundle Identifier, and start signing. On the iPhone, open Settings → General → VPN & Device Management and trust your developer certificate. On the iPhone, open Settings → Privacy & Security → Developer Mode, turn it on, restart, and confirm. On the iPhone, open the Watch app, go to My Watch → Apps, and install HermesEnabler2 on the Watch. On the Apple Watch, open Settings → Privacy & Security → Developer Mode, turn it on, restart, and confirm. If the option is not shown, install the Watch app first and check again. Open HermesEnabler2 on your Apple Watch and follow the steps in the app.

安装 IPA Sideloadly 0.72 的已知问题：Issue #43 报告称该版本在签名时可能会移除嵌入的 Watch 应用。如果 iPhone 应用安装成功但手表上缺少 HermesEnabler2，请改用 Xcode。此报告仅针对 0.72 版本；与其他版本的兼容性尚未确认。从 Releases 下载 IPA。在 Mac 上安装 Sideloadly，用数据线连接 iPhone，并在 Sideloadly 中选中它。将 IPA 拖入 Sideloadly 并输入你的 Apple ID。关闭“Use automatic bundle ID”，设置一个固定的 Bundle Identifier，然后开始签名。在 iPhone 上，打开“设置”→“通用”→“VPN 与设备管理”并信任你的开发者证书。在 iPhone 上，打开“设置”→“隐私与安全性”→“开发者模式”，将其开启、重启并确认。在 iPhone 上，打开 Watch 应用，前往“我的手表”→“App”，在手表上安装 HermesEnabler2。在 Apple Watch 上，打开“设置”→“隐私与安全性”→“开发者模式”，将其开启、重启并确认。如果未显示该选项，请先安装 Watch 应用后再检查。在 Apple Watch 上打开 HermesEnabler2 并按照应用内的步骤操作。

使用 Xcode 构建 在 Xcode 中打开 HermesEnabler2.xcodeproj。选择你的 Apple Watch 作为运行目标并点击 Run。在 Apple Watch 上打开 HermesEnabler2 并按照应用内的步骤操作。

Windows Windows uses WatchBridge, a community tool that prepares Developer Mode and installs an IPA containing both an iPhone host app and a Watch app. It is not affiliated with Apple or with this project. Install Apple Mobile Device Service by installing iTunes or the Apple Devices app from the Microsoft Store. WatchBridge needs it for USB and Wi-Fi communication. WebView2 is built into Windows 11. Make sure your iPhone is paired with the target Apple Watch. WatchBridge supports only one paired Watch at a time; if more than one is paired, the preparation step stops instead of guessing. Download watchbridge-windows.zip from WatchBridge Releases, extract it, and run WatchBridge.exe. The executable is unsigned, so Windows SmartScreen may warn on first launch. Download the IPA from Releases. Use the original IPA that contains both the iPhone host and the Watch/*.app; Watch-only packages are not supported. Connect the paired iPhone over USB and select it in WatchBridge. Pair the Watch and confirm the trust prompt on the Watch. Request the Developer Mode switch, then on the Watch open Settings → Privacy & Security → Developer Mode, turn it on, restart, and confirm. Return to WatchBridge and click Check again. WatchBridge does not enable Developer Mode or restart the Watch for you. Sign in with your Apple ID, select the HermesEnabler2 IPA, and start signing and installation. WatchBridge installs the iPhone host app first, then the Watch app. Open HermesEnabler2 on your Apple Watch and follow the steps in the app. Developer-mode preparation requires a USB connection. After pairing over USB once, installs and renewals can use Wi-Fi.

Windows Windows 使用 WatchBridge，这是一个社区工具，用于准备开发者模式并安装包含 iPhone 主应用和 Watch 应用的 IPA。它与 Apple 或本项目无关。通过从 Microsoft Store 安装 iTunes 或 Apple Devices 应用来安装 Apple Mobile Device Service。WatchBridge 需要它进行 USB 和 Wi-Fi 通信。WebView2 已内置于 Windows 11 中。确保你的 iPhone 已与目标 Apple Watch 配对。WatchBridge 一次仅支持一个配对的手表；如果配对超过一个，准备步骤会停止，而不是进行猜测。从 WatchBridge Releases 下载 watchbridge-windows.zip，解压并运行 WatchBridge.exe。该可执行文件未签名，因此 Windows SmartScreen 在首次启动时可能会发出警告。从 Releases 下载 IPA。使用包含 iPhone 主应用和 Watch/*.app 的原始 IPA；不支持仅包含 Watch 的包。通过 USB 连接已配对的 iPhone，并在 WatchBridge 中选中它。配对 Apple Watch 并在手表上确认信任提示。请求切换开发者模式，然后在手表上打开“设置”→“隐私与安全性”→“开发者模式”，将其开启、重启并确认。返回 WatchBridge 并点击“Check again”。WatchBridge 不会为你开启开发者模式或重启手表。使用你的 Apple ID 登录，选择 HermesEnabler2 IPA，然后开始签名和安装。WatchBridge 会先安装 iPhone 主应用，然后再安装 Watch 应用。在 Apple Watch 上打开 HermesEnabler2 并按照应用内的步骤操作。开发者模式准备需要 USB 连接。通过 USB 配对一次后，安装和续期可以使用 Wi-Fi。

Cautions In Sideloadly, disable Use automatic bundle ID and use a fixed Bundle Identifier. Keep the same Bundle Identifier and Apple ID for every update so the app can retain its existing data and backup. Free Apple Personal Team provisioning profiles expire after seven days. When that happens, rebuild and reinstall the app, using the same Apple ID and Bundle Identifier. This project uses an App Groups entitlement, which a free Personal Team cannot provision. A paid developer team may be required; changing the Bundle Identifier does not remove this limitation. Do not assume that removing the entitlement is a complete fix, as the app's main functionality without it has not been confirmed. If the iPhone app installs but the Watch app does not appear, check the Sideloadly log for Watch apps will be stripped from the IPA. This means the embedded Watch app was removed; installing the iPhone app alone will not install it. Use Xcode to install the Watch app. Before deleting the app, always restore your MobileGestalt backup through the HermesEnabler2 app.

注意事项 在 Sideloadly 中，禁用“Use automatic bundle ID”并使用固定的 Bundle Identifier。每次更新时保持相同的 Bundle Identifier 和 Apple ID，以便应用保留其现有数据和备份。免费的 Apple 个人团队预置描述文件会在七天后过期。届时，请使用相同的 Apple ID 和 Bundle Identifier 重新构建并重新安装应用。本项目使用 App Groups 授权，免费的个人团队无法配置此项。可能需要付费开发者团队；更改 Bundle Identifier 无法消除此限制。不要假设移除该授权是完整的修复方案，因为在没有该授权的情况下，应用的主要功能尚未得到确认。如果 iPhone 应用安装成功但 Watch 应用未出现，请检查 Sideloadly 日志中是否有“Watch apps will be stripped from the IPA”的提示。这意味着嵌入的 Watch 应用已被移除；仅安装 iPhone 应用无法安装它。请使用 Xcode 安装 Watch 应用。在删除应用之前，请务必通过 HermesEnabler2 应用恢复你的 MobileGestalt 备份。

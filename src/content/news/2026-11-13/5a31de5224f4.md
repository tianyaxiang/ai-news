Daemon Mode Run Qwen Code as a long-lived service when you want browser, editor, SDK, and automation clients to share agent sessions without each starting a separate process. The daemon provides the built-in Web Shell and an HTTP + SSE API, supports multiple workspaces, and lets clients reconnect to active sessions. Start it in the foreground and open the Web Shell: qwen serve --open The default address is http://127.0.0.1:4170. To run and manage it in the background instead: qwen daemon start qwen daemon status qwen daemon logs -f qwen daemon stop

守护进程模式：当您希望浏览器、编辑器、SDK 和自动化客户端共享代理会话而无需各自启动独立进程时，可将 Qwen Code 作为长期运行的服务运行。该守护进程提供内置的 Web Shell 和 HTTP + SSE API，支持多个工作区，并允许客户端重新连接到活动会话。在前台启动并打开 Web Shell：qwen serve --open。默认地址为 http://127.0.0.1:4170。若要在后台运行和管理：qwen daemon start, qwen daemon status, qwen daemon logs -f, qwen daemon stop。

By default, the daemon listens on loopback without bearer authentication; any local process that can reach it can use the full API, including code execution. On shared or untrusted hosts, set QWEN_SERVER_TOKEN and use --require-auth. See the Daemon guide for workspaces, authentication, remote access, and the API.

默认情况下，守护进程在回环地址上监听且无需 Bearer 身份验证；任何可以访问它的本地进程都可以使用完整 API，包括代码执行。在共享或不受信任的主机上，请设置 QWEN_SERVER_TOKEN 并使用 --require-auth。有关工作区、身份验证、远程访问和 API 的详细信息，请参阅守护进程指南。

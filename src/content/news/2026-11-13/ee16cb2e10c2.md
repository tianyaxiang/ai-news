# Hello Baochip

Baochip is the latest open/trustable hardware venture by living legend Andrew "bunnie" Huang (wikipedia.org). Here’s the official website: https://www.baochip.com/ But I recommend bunnie’s write-ups on his blog as an introduction: Baochip-1x: A Mostly-Open, 22nm SoC for High Assurance Applications (bunniestudios.com) BIO: The Bao I/O Coprocessor (bunniestudios.com)

Baochip 是传奇人物 Andrew "bunnie" Huang（wikipedia.org）推出的最新开放/可信硬件项目。官方网站为：https://www.baochip.com/，但我建议阅读 bunnie 在其博客上的文章作为入门：Baochip-1x: A Mostly-Open, 22nm SoC for High Assurance Applications (bunniestudios.com) 以及 BIO: The Bao I/O Coprocessor (bunniestudios.com)。

What makes the Baochip1x special is that it is an SoC (system on chip) with: A RISC-V core An MMU (memory management unit, allows for hardware support of virtual memory, a feature normally reserved for "real" computers) I/O coprocessor (BIO) Hardware support for a bunch of security-focused features such as a TRNG (true random number generator), AES encryption, and a ton of cryptographic hashes It is intentionally inspectable with inexpensive infra-red cameras so you can visibly verify the structure of the chip yourself! (See Infra-Red, In Situ (IRIS) Inspection of Silicon (bunniestudios.com) It was made specifically to be able to run Xous, a microkernel OS written in Rust originally written for bunnie’s Precursor device. See Xous 0.10.0 - Introducing Baochip-1x Support (crowdsupply.com). More about Xous here: https://betrusted.io/xous-book/

Baochip1x 的特别之处在于它是一款 SoC（片上系统），具备：一个 RISC-V 内核、一个 MMU（内存管理单元，允许硬件支持虚拟内存，这是通常仅限于“真正”计算机的功能）、一个 I/O 协处理器（BIO），以及对一系列安全功能（如真随机数生成器 TRNG、AES 加密和大量加密哈希）的硬件支持。它被设计为可以使用廉价的红外摄像机进行检查，因此您可以亲自直观地验证芯片结构！（参见 Infra-Red, In Situ (IRIS) Inspection of Silicon (bunniestudios.com)）。它专为运行 Xous 而设计，这是一款最初为 bunnie 的 Precursor 设备编写的 Rust 微内核操作系统。参见 Xous 0.10.0 - Introducing Baochip-1x Support (crowdsupply.com)。关于 Xous 的更多信息请见：https://betrusted.io/xous-book/

I thought this was particularly insightful (from bunnie’s blog post about the BIO coprocessor linked above): "…​one of the key benefits of the Xous ecosystem being pure Rust is that we don’t have to maintain any tooling. We’d like to keep it so that the only tool required to build a Xous image is stable Rust. The moment a C compiler is introduced into the build process, we have to wade through a hodge-podge of distribution-specific C toolchains, greatly increasing developer friction and maintenance burden."

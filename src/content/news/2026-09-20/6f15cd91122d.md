# Kicking the tires on Jev (TypeSafe's System One model) with 2048
# 使用 2048 游戏测试 Jev（TypeSafe 的 System One 模型）

I finally got a chance to kick the tires on Jev (jev-1.13.0). I thought it'd do really well playing 2048. The strategy I used was: hand it the current board state and give it the option of up, down, left, right. I tried that 4 ways (the Jev rows in the table). Each row links to the request I sent.
我终于有机会试用一下 Jev (jev-1.13.0) 了。我原以为它在玩 2048 游戏时会有出色的表现。我采用的策略是：将当前的棋盘状态交给它，并提供上、下、左、右四个选项。我尝试了四种不同的方式（见下表中的 Jev 行）。每一行都链接到我发送的请求。

With just the board, it does about as well as making random moves. It does best when code works out what each move would do to the board and Jev picks from those; then it's about as good as a fixed rule (e.g., always left if that moves anything, else down, else right, else up). I didn't have long to spend on it, so I'm likely missing something.
仅提供棋盘状态时，它的表现与随机移动差不多。当代码预先计算出每一步移动对棋盘的影响，再让 Jev 从中选择时，它的表现最好；此时它的水平大约相当于一条固定规则（例如：如果向左能移动则始终向左，否则向下，再否则向右，最后向上）。我没有太多时间深入研究，所以很可能遗漏了一些关键点。

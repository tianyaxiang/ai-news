# Coder / Coder

**Coder is a self-hosted platform for cloud development environments and AI coding agents. Workspaces are defined with Terraform, connected through a secure Wireguard® tunnel, and automatically shut down when not used. Coder Agents runs a native AI coding agent whose loop executes in the control plane on your infrastructure, with no API keys in workspaces.**
Coder 是一个用于云开发环境和 AI 编码代理的自托管平台。工作区通过 Terraform 定义，通过安全的 Wireguard® 隧道连接，并在不使用时自动关闭。Coder Agents 运行原生的 AI 编码代理，其循环在您的基础设施控制平面上执行，工作区内无需存储任何 API 密钥。

**Define cloud development environments in Terraform EC2 VMs, Kubernetes Pods, Docker Containers, etc. Automatically shutdown idle resources to save on costs. Onboard developers in seconds instead of days. Delegate coding work to AI agents on your infrastructure. Bring any model (Anthropic, OpenAI, Google, Bedrock, self-hosted). No LLM credentials in workspaces, user identity on every action. Centralized model governance, cost tracking, and audit logging.**
通过 Terraform 在 EC2 虚拟机、Kubernetes Pod、Docker 容器等环境中定义云开发环境。自动关闭闲置资源以节省成本。让开发者在几秒钟内完成入职，而非几天。将编码工作委托给您基础设施上的 AI 代理。支持使用任何模型（Anthropic、OpenAI、Google、Bedrock 或自托管模型）。工作区内无需 LLM 凭据，每次操作均关联用户身份。提供集中的模型治理、成本跟踪和审计日志。

### Quickstart
### 快速入门

**Check out our install guides for other methods and a complete tutorial. Try Coder with the install script on Linux and macOS, or grab the latest binary or installer from GitHub Releases on Windows:**
查看我们的安装指南以获取其他方法及完整教程。在 Linux 和 macOS 上，您可以使用安装脚本尝试 Coder；在 Windows 上，请从 GitHub Releases 获取最新的二进制文件或安装程序：

`curl -L https://coder.com/install.sh | sh`

**Start the server and open http://localhost:3000 to create your initial user, create a Docker template, and provision your first workspace:**
启动服务器并打开 http://localhost:3000 以创建初始用户、创建 Docker 模板并配置您的第一个工作区：

`coder server`

**For a production deployment, add a PostgreSQL database (version 13 or later) and an external access URL, and see our validated architectures for sizing and infrastructure guidance:**
对于生产环境部署，请添加 PostgreSQL 数据库（13 或更高版本）和外部访问 URL，并查看我们的验证架构以获取规模调整和基础设施指导：

`coder server --postgres-url <url> --access-url <url>`

**Without these flags, Coder uses a built-in database and sets up a *.try.coder.app access URL for evaluation. Use coder --help for the full list of flags and environment variables.**
如果不使用这些标志，Coder 将使用内置数据库并设置一个 *.try.coder.app 访问 URL 以供评估。使用 `coder --help` 查看标志和环境变量的完整列表。

### Integrations
### 集成

**New integrations are always in progress. Open an issue to request one. Contributions are welcome in any official or community repository.**
新的集成工作一直在进行中。请提交 Issue 以请求新的集成。欢迎对任何官方或社区仓库做出贡献。

*   **Official Coder Registry:** Templates, modules, and integrations for common development environments.
    **官方 Coder 注册表：** 适用于常见开发环境的模板、模块和集成。
*   **Coding Agents:** Run agents like Claude Code, Codex, and OpenCode isolated in Coder workspaces.
    **编码代理：** 在 Coder 工作区中隔离运行 Claude Code、Codex 和 OpenCode 等代理。
*   **coderd Terraform Provider:** Declaratively manage your Coder deployment configuration as code.
    **coderd Terraform 提供程序：** 以代码形式声明式管理您的 Coder 部署配置。
*   **VS Code Extension:** Open any Coder workspace in VS Code with a single click.
    **VS Code 扩展：** 一键在 VS Code 中打开任何 Coder 工作区。
*   **JetBrains Toolbox Plugin:** Open any Coder workspace from JetBrains Toolbox with a single click.
    **JetBrains Toolbox 插件：** 一键从 JetBrains Toolbox 打开任何 Coder 工作区。
*   **Dev Containers:** Build development environments using devcontainer.json on Docker, Kubernetes, and OpenShift.
    **开发容器：** 在 Docker、Kubernetes 和 OpenShift 上使用 devcontainer.json 构建开发环境。
*   **Kubernetes Log Stream:** Stream Kubernetes Pod events to the Coder startup logs.
    **Kubernetes 日志流：** 将 Kubernetes Pod 事件流式传输到 Coder 启动日志中。
*   **Self-Hosted VS Code Extension Marketplace:** A private extension marketplace that works in restricted or airgapped networks integrating with code-server.
    **自托管 VS Code 扩展市场：** 一个私有扩展市场，可在受限或离线网络中工作，并与 code-server 集成。
*   **GitHub Actions:** An action to set up the Coder CLI in GitHub workflows.
    **GitHub Actions：** 在 GitHub 工作流中设置 Coder CLI 的 Action。

# makeplane / plane

Modern project management for all teams Website • Forum • X • Documentation Meet Plane, an open-source project management tool to track issues, run sprints cycles, and manage product roadmaps without the chaos of managing the tool itself. 🧘‍♀️

面向所有团队的现代项目管理工具 网站 • 论坛 • X • 文档。认识一下 Plane，这是一个开源项目管理工具，旨在帮助你跟踪问题、运行冲刺周期（sprints）并管理产品路线图，而无需陷入管理工具本身的混乱之中。🧘‍♀️

Plane is evolving every day. Your suggestions, ideas, and reported bugs help us immensely. Do not hesitate to join in the conversation on Forum or raise a GitHub issue. We read everything and respond to most. 🚀

Plane 每天都在进化。您的建议、想法和反馈的 Bug 对我们帮助巨大。请随时加入我们的论坛讨论或在 GitHub 上提交 Issue。我们会阅读每一条反馈，并回复其中的大部分。🚀

Installation Getting started with Plane is simple. Choose the setup that works best for you: Plane Cloud Sign up for a free account on Plane Cloud—it's the fastest way to get up and running without worrying about infrastructure. Self-host Plane Prefer full control over your data and infrastructure? Install and run Plane on your own servers. Follow our detailed deployment guides to get started. Installation methods Docs link Docker Kubernetes Managed hosting Instance admins can configure instance settings with God mode. 🌟

安装：开始使用 Plane 非常简单。选择最适合您的设置方式：Plane Cloud（注册 Plane Cloud 免费账户，这是无需担心基础设施即可快速上手的方式）；自托管 Plane（如果您更喜欢完全掌控数据和基础设施，可以在自己的服务器上安装并运行 Plane。请按照我们详细的部署指南开始操作）。安装方法：文档链接、Docker、Kubernetes、托管服务。实例管理员可以使用“上帝模式”（God mode）配置实例设置。🌟

Features: Work Items: Efficiently create and manage tasks with a robust rich text editor that supports file uploads. Enhance organization and tracking by adding sub-properties and referencing related issues.

功能：工作项：使用支持文件上传的强大富文本编辑器高效创建和管理任务。通过添加子属性和引用相关问题来增强组织和跟踪能力。

Cycles: Maintain your team’s momentum with Cycles. Track progress effortlessly using burn-down charts and other insightful tools.

周期：通过“周期”功能保持团队的动力。使用燃尽图和其他富有洞察力的工具轻松跟踪进度。

Modules: Simplify complex projects by dividing them into smaller, manageable modules.

模块：通过将复杂项目拆分为更小、更易于管理的模块来简化项目。

Views: Customize your workflow by creating filters to display only the most relevant issues. Save and share these views with ease.

视图：通过创建过滤器自定义工作流，仅显示最相关的问题。轻松保存并共享这些视图。

Pages: Capture and organize ideas using Plane Pages, complete with AI capabilities and a rich text editor. Format text, insert images, add hyperlinks, or convert your notes into actionable items.

页面：使用 Plane Pages 捕捉和组织想法，它配备了 AI 功能和富文本编辑器。您可以格式化文本、插入图片、添加超链接，或将笔记转换为可执行的任务项。

Analytics: Access real-time insights across all your Plane data. Visualize trends, remove blockers, and keep your projects moving forward.

分析：获取所有 Plane 数据的实时洞察。可视化趋势、消除障碍，并保持项目持续推进。

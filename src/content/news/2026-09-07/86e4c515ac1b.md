# Create Custom Windows 11 Notifications to Remind Yourself of Anything
# 在 Windows 11 中创建自定义通知，随时提醒自己任何事项

While there are plenty of ways to limit notifications on our digital devices and avoid distraction overload, there’s nothing inherently wrong with these alerts. They just need to be well managed and kept in their place.
虽然有很多方法可以限制数字设备上的通知并避免信息过载，但这些提醒本身并没有错。关键在于如何妥善管理并将其控制在合理的范围内。

Keeping notifications useful and timely can help you get more done in the day, not less, and Windows 11 comes with built-in tools for setting up custom notifications that run on a schedule you specify.
保持通知的实用性和及时性可以帮助你提高效率，而不是干扰工作。Windows 11 内置了相关工具，可以让你根据设定的时间表创建自定义通知。

You can use these scheduled notifications however you want. Maybe you need reminders to take breaks, or you want to make sure you devote specific blocks of time to certain projects, or you need alerts for when it’s time to go and pick the kids up.
你可以根据需要灵活使用这些定时通知。也许你需要休息提醒，或者想确保将特定的时间段投入到某些项目中，又或者需要提醒自己去接孩子。

However you want to use these custom notifications, here’s how to set them up—plus some extra apps that can help too.
无论你打算如何使用这些自定义通知，以下是设置方法，以及一些可以提供帮助的额外应用程序。

### Custom Notifications in Windows 11
### Windows 11 中的自定义通知

Task Scheduler gives you a clean, simple way of creating alerts.
任务计划程序（Task Scheduler）为你提供了一种简洁、简单的方式来创建提醒。

If you want to set up custom notifications in Windows 11 without turning to an app, the Task Scheduler is the utility you want. Type “task scheduler” into the search box on the taskbar or the Start menu, then select it when it appears.
如果你想在不借助第三方应用的情况下在 Windows 11 中设置自定义通知，任务计划程序就是你需要的工具。在任务栏或“开始”菜单的搜索框中输入“task scheduler”（任务计划程序），然后在搜索结果中将其打开。

Open the Action menu, choose Create Basic Task, and then give it a suitable name and description so you can identify it later. Click Next, and you can set the frequency of the notification: Your options are Daily, Weekly, Monthly, One time, When the computer starts, When I log on, and When a specific event is logged, so there’s a lot of flexibility.
打开“操作”（Action）菜单，选择“创建基本任务”（Create Basic Task），然后为其命名并添加描述，以便日后识别。点击“下一步”，你可以设置通知的频率：选项包括每天、每周、每月、一次、计算机启动时、登录时以及记录特定事件时，灵活性非常高。

Click Next again, and if you’ve chosen a recurring task then you can set exactly when it recurs—4 pm every afternoon, for example. Click Next, then choose Start a program, and select Next again. This opens up the dialog box screen for composing your notification.
再次点击“下一步”。如果你选择了重复任务，可以精确设置重复时间，例如每天下午 4 点。点击“下一步”，选择“启动程序”（Start a program），然后再次点击“下一步”。这将打开用于编写通知内容的对话框界面。

In the Program/script field, you need to enter “msg,” and in the Add arguments (optional) field, you put your actual notification text: “Reminder: get up and do some stretching” or whatever it happens to be. With another click on Next you can review your notification, and then choose Finish to confirm.
在“程序/脚本”（Program/script）字段中输入“msg”，在“添加参数（可选）”（Add arguments）字段中输入你实际的通知文本，例如：“提醒：起来做做伸展运动”或其他任何内容。再次点击“下一步”预览通知，最后点击“完成”进行确认。

Your notification is created, and will pop up at the specified time, whether or not Task Scheduler is open. If you ever need to edit or delete the task, you can head back to Task Scheduler to find it—it’ll be listed under the Task Scheduler Library heading, and you can right-click on the task to make changes.
通知创建完毕后，无论任务计划程序是否处于打开状态，它都会在指定时间弹出。如果你需要编辑或删除该任务，可以回到任务计划程序中查找——它会列在“任务计划程序库”（Task Scheduler Library）下，你可以右键点击该任务进行修改。

### Setting Notifications Through Apps
### 通过应用程序设置通知

The appeal of the Task Scheduler is that it’s built right into the Windows operating system, so you don’t need any other apps running to get your notifications, but there are ways to do this with apps as well. The Microsoft Clock app comes preinstalled with Windows, for example, and lets you set custom alarms.
任务计划程序的优势在于它内置于 Windows 操作系统中，因此无需运行其他应用程序即可接收通知。当然，你也可以通过应用程序来实现。例如，Windows 预装的“时钟”（Clock）应用就允许你设置自定义闹钟。

Once you’ve launched the app through the Start menu or taskbar search box, select Alarm to set one. Click on the + (plus) button in the lower right corner to create a new alarm, and you can give it a name—which is essentially the text you want for your notification. You can configure the time for the alarm, and when it should recur.
通过“开始”菜单或任务栏搜索框启动该应用后，选择“闹钟”（Alarm）进行设置。点击右下角的“+”号按钮创建新闹钟，并为其命名——这本质上就是你想要的通知文本。你可以配置闹钟的时间以及重复周期。

If that doesn’t do exactly what you want, another app that comes with Windows is Microsoft To Do—again, you can search for it from the taskbar or Start menu. As the name suggests, this is a fully fledged to-do app, but you can create custom notifications through it by attaching reminders to tasks.
如果这不能完全满足你的需求，Windows 自带的另一个应用是 Microsoft To Do——同样可以通过任务栏或“开始”菜单搜索到。顾名思义，这是一个功能齐全的待办事项应用，你可以通过为任务添加提醒来创建自定义通知。

Click Add a task to get started, and once you’ve given your new task a name, you can set the reminder details: What time and date you want the alert to appear, and whether or not you want the notification to repeat on a schedule. There's also the option to put your reminders into categories, if needed.
点击“添加任务”（Add a task）开始，为新任务命名后，即可设置提醒详情：包括提醒出现的日期和时间，以及是否需要按计划重复提醒。如果需要，还可以将提醒进行分类。

In terms of third-party apps, any clock, reminder, or to-do list app would do the job—something like TickTick, for instance—but these take you further away from the clean simplicity of just generating custom notifications and nothing else. Those apps will also come with extras you don’t necessarily need for this particular task.
至于第三方应用，任何时钟、提醒或待办事项应用（例如滴答清单 TickTick）都能胜任。但这些应用会让你偏离“仅生成自定义通知”的简洁初衷，且往往包含你在此任务中并不需要的额外功能。

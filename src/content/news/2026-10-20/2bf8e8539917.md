I’ve decided to archive the source code of my Ruby gems to make it clear that I’m no longer working on them; I’ve written this post to link from them in order to explain why.

我已决定将我的 Ruby gem 源代码归档，以明确表示我不再维护它们；我写这篇文章是为了在这些项目中添加链接，以解释其中的原因。

In an article published in 2000, Yukihiro Matsumoto (a.k.a. “Matz”), designer of Ruby, wrote, “For me, the purpose of life is, at least partly, to have joy. Programmers often feel joy when they can concentrate on the creative side of programming, so Ruby is designed to make programmers happy.” And as recently as a 2019 interview, he said, “I designed Ruby for humans, not for machines.”

在 2000 年发表的一篇文章中，Ruby 的设计者松本行弘（又名“Matz”）写道：“对我来说，人生的目的至少部分在于获得快乐。当程序员能够专注于编程的创造性一面时，他们往往会感到快乐，因此 Ruby 的设计初衷就是让程序员感到幸福。”而在 2019 年的一次采访中，他也曾表示：“我设计 Ruby 是为了人类，而不是为了机器。”

It was during that era, when Ruby was ostensibly for joy, for creativity, for humans, that I developed this code. But that age, of doing things for humans, has passed, and with it my enthusiasm for working on Ruby gems. I won’t say it was always great, but at least we were working with and for people.

正是在那个 Ruby 表面上为了快乐、为了创造力、为了人类而存在的时代，我开发了这些代码。但那个为人类做事的时代已经过去了，随之而去的是我开发 Ruby gem 的热情。我不会说那段时光总是美好的，但至少我们是在与人合作，并为人类服务。

The pre-eminent application of Ruby has been making web applications using Rails. Rails is open source software but it’s owned and controlled by a man whose views I find abhorrent, although there is an ongoing effort to fork it. To judge by his keynote at Rails World this year – the conference that he himself set up in pique after he wasn’t invited to RailsConf a couple of years ago – he is no longer particularly interested in Ruby, Rails, or even programming itself. (He’s now using LLM agents to churn out apps in Rust, a language which he compares to “pouring acid into [his] eyes”, but that’s apparently fine because he doesn’t even look at what they generate.)

Ruby 最主要的应用场景是使用 Rails 构建 Web 应用程序。Rails 虽然是开源软件，但它由一个我对其观点感到厌恶的人所拥有和控制，尽管目前有人正在尝试对其进行分叉（fork）。从他今年在 Rails World 大会上的主题演讲来看——那场会议是他几年前因未受邀参加 RailsConf 而赌气创办的——他似乎对 Ruby、Rails 甚至编程本身都不再特别感兴趣了。（他现在使用大语言模型代理来大量生产 Rust 应用程序，他曾将 Rust 比作“往眼睛里倒酸液”，但这显然没关系，因为他甚至根本不看这些代理生成了什么。）

But even beyond Rails, the Ruby language itself is now substantially developed using LLM agents. Matz is giving talks repositioning Ruby as a “Programming Language for AI age”, to be emitted by LLM agents, and stating that to be able to do that LLMs need to consume more good human-written Ruby code. You might already have seen the problem here.

即便抛开 Rails 不谈，Ruby 语言本身现在也主要通过大语言模型代理来开发。Matz 正在发表讲演，将 Ruby 重新定位为“人工智能时代的编程语言”，旨在由大语言模型代理来输出代码，并声称为了实现这一点，大语言模型需要消耗更多人类编写的优质 Ruby 代码。你可能已经看出这里的问题所在了。

In that context, I no longer feel inspired to contribute to a commons that’s being strip-mined by massive corporations to feed the very machines whose unthinking output pollutes it. When people claim that it’s no longer sustainable to write code by hand, they’re not entirely wrong, but only in the same way that it’s no longer sustainable to sleep in a bed once someone has taken a shit in it.

在这种背景下，我不再有动力为一个公共资源做出贡献，因为这些资源正被大型企业掠夺性地开采，以喂养那些其盲目输出正在污染公共资源的机器。当人们声称手工编写代码已不再可持续时，他们并非完全错误，但这就像有人在床上拉了屎之后，那张床就不再适合睡觉一样。

You want changes? Go ask your agent or something. I’m told that’s what you’re supposed to do now. I’m out.

你想要改动吗？去问你的代理或者什么东西吧。我被告知这就是你们现在应该做的事。我退出了。

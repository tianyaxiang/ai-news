# ReactOS reaches major milestone with NTFS install support

开源 Windows 替代系统 ReactOS 迎来了一个重要的里程碑：该操作系统现在可以直接安装在 NTFS（NT 文件系统）驱动器分区上。

As reported by Phoronix, the move to NTFS clears a long-standing hurdle for the project and brings it one step closer to finally reaching beta. Prior to this latest announcement, ReactOS required users to keep a FAT32 partition for installations.

据 Phoronix 报道，转向 NTFS 清除了该项目长期存在的一个障碍，使其距离最终进入测试阶段更近了一步。在此次公告发布之前，ReactOS 要求用户保留一个 FAT32 分区用于安装。

A proprietary Microsoft-developed filesystem, NTFS can trace its roots back through the Windows NT family lineage starting in 1993 with Windows NT 3.1. The variant introduced with Windows XP in 2001 remains the standard used by most Windows systems today.

NTFS 是微软开发的专有文件系统，其根源可以追溯到 1993 年 Windows NT 3.1 开始的 Windows NT 家族。2001 年随 Windows XP 引入的变体至今仍是大多数 Windows 系统使用的标准。

With ReactOS’s stated goal of reaching binary compatibility with Windows Server 2003, being confined to FAT32 partitions was a practical barrier to clear on the way to reproducing the Windows environment.

由于 ReactOS 的既定目标是实现与 Windows Server 2003 的二进制兼容，因此局限于 FAT32 分区是重现 Windows 环境过程中必须清除的一个实际障碍。

However, users looking to hop off the Windows train shouldn’t be grabbing their bags just yet. ReactOS wrote that the new driver still “lacks caching (which causes inferior performance), journaling and security support.”

然而，那些希望摆脱 Windows 的用户现在还不必急着行动。ReactOS 写道，新驱动程序仍然“缺乏缓存（这会导致性能较差）、日志记录和安全支持”。

So while the new driver is here, even the most intrepid of OS tinkerers should tread carefully. The ReactOS team warned in its announcement on X that there are still “potentially undiscovered bugs.”

因此，尽管新驱动程序已经发布，但即使是最勇敢的操作系统折腾者也应谨慎行事。ReactOS 团队在 X 上的公告中警告称，仍存在“潜在的未发现错误”。

The new driver closes a gap in development of nearly a decade. Read-only NTFS support was added to ReactOS all the way back in 2016, with boot support landing on FreeLoader in 2022. That meant that ReactOS’s bootloader could read from an NTFS partition, but the OS was unable to be directly installed there.

新驱动程序填补了近十年的开发空白。ReactOS 早在 2016 年就增加了只读 NTFS 支持，并于 2022 年在 FreeLoader 上实现了引导支持。这意味着 ReactOS 的引导加载程序可以从 NTFS 分区读取数据，但操作系统本身无法直接安装在上面。

ReactOS is a community-developed open source project that describes itself as “mostly driven by volunteers.” Development is coordinated through public channels like GitHub and the project’s forums. Those who might be interested in lending a hand to ReactOS’s development can visit the project website to learn more about how to contribute.

ReactOS 是一个社区开发的开源项目，自称为“主要由志愿者驱动”。开发工作通过 GitHub 和项目论坛等公共渠道进行协调。有兴趣协助 ReactOS 开发的人员可以访问项目网站，了解更多关于如何做出贡献的信息。

The project’s decades-long timeline underscores the scope and difficulty of reimplementing an operating system from scratch, and why the project has remained in alpha for so long. The ReactOS project may never be a truly viable alternative to Windows for most users, but this step forward means that at least now it can be installed on the same filesystem as the real thing.

该项目长达数十年的时间线凸显了从零开始重新实现操作系统的规模和难度，也解释了为什么该项目长期处于 Alpha 测试阶段。对于大多数用户而言，ReactOS 项目可能永远无法成为 Windows 的真正可行替代品，但这一进步意味着至少现在它可以安装在与 Windows 相同的文件系统上了。

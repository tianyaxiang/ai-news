**2. Azure Container Apps & AKS: Enhanced Autoscaling**
What it is: Azure Container Apps now offers autoscaling based on custom metrics, while Azure Kubernetes Service (AKS) has added support for Kubernetes version 1.28.
Why now: The updates (Azure Updates, 2026-10-07) provide developers with greater control over containerized applications, optimizing resource usage and performance.
Tutorial angle: Discover how to set up autoscaling for Azure Container Apps using custom metrics and deploy an AKS cluster with the latest Kubernetes version.
Difficulty: Intermediate
Start today: Install the Azure CLI and run az containerapp create to start experimenting with autoscaling.

它是什么：Azure Container Apps 现在提供基于自定义指标的自动缩放功能，而 Azure Kubernetes Service (AKS) 增加了对 Kubernetes 1.28 版本的支持。
为什么是现在：这些更新（Azure 更新，2026-10-07）为开发人员提供了对容器化应用程序的更大控制权，优化了资源使用和性能。
教程角度：了解如何使用自定义指标为 Azure Container Apps 设置自动缩放，并部署具有最新 Kubernetes 版本的 AKS 集群。
难度：中级
立即开始：安装 Azure CLI 并运行 az containerapp create 以开始尝试自动缩放。

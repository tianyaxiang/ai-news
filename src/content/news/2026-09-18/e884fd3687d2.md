# DualCount: Structurally Consistent Density and Point Modeling for Zero-Shot Object Counting
# DualCount：用于零样本目标计数的结构一致性密度与点建模

**Abstract:** Zero-shot object counting aims to estimate the number of objects specified by a text query without category-specific training. Recent approaches primarily rely on density regression or detection-style instance prediction. While effective, density-based models often suffer from spatial ambiguity and background leakage due to weakly regulated mass allocation, leading to fragmented or part-biased representations that increase counting error in complex scenes.

**摘要：** 零样本目标计数旨在无需特定类别训练的情况下，通过文本查询来估计目标对象的数量。目前的方法主要依赖于密度回归或检测式的实例预测。尽管这些方法行之有效，但基于密度模型的方法往往因质量分配（mass allocation）调节较弱，而面临空间模糊和背景泄露的问题，导致出现碎片化或偏向局部的表征，从而增加了复杂场景下的计数误差。

In this work, we propose an instance-aware dual-decoder framework that structurally couples density and point representations for zero-shot object counting. Instead of treating density estimation as independent pixel-wise regression, we interpret it as a structured mass allocation problem over a latent set of object instances. Predicted instance centers induce a soft instance-wise decomposition of the density map, upon which we enforce two geometric constraints: (1) per-instance mass conservation, ensuring each object contributes approximately one unit of density mass, and (2) center-of-mass alignment, encouraging each density component to concentrate around its corresponding predicted center.

在这项工作中，我们提出了一种实例感知的双解码器框架，将密度表征与点表征在结构上进行耦合，用于零样本目标计数。我们不再将密度估计视为独立的像素级回归，而是将其解释为在潜在目标实例集上的结构化质量分配问题。预测的实例中心引导了密度图的软实例分解，在此基础上，我们施加了两个几何约束：（1）实例级质量守恒，确保每个对象贡献大约一个单位的密度质量；（2）质心对齐，促使每个密度分量集中在其对应的预测中心周围。

These constraints introduce instance-level geometric consistency and lead to more accurate mass allocation, thereby reducing counting error. Extensive experiments on FSC-147, PUCPR+, and CARPK show that our approach consistently reduces counting error and establishes new state-of-the-art performance in zero-shot object counting.

这些约束引入了实例级的几何一致性，并实现了更精确的质量分配，从而降低了计数误差。在 FSC-147、PUCPR+ 和 CARPK 数据集上的大量实验表明，我们的方法能够持续降低计数误差，并在零样本目标计数领域建立了新的最先进（SOTA）性能表现。

# Beyond Static RAG: An Adaptive, Tri-Metric Routing Framework for Efficient Long-Context Inference on Commodity GPUs
# 超越静态 RAG：一种用于商用 GPU 高效长上下文推理的自适应三指标路由框架

**Abstract:** Deploying retrieval-augmented generation (RAG) on commodity GPUs such as the NVIDIA T4 (16 GB VRAM) exposes a practical failure mode we call the Compression Paradox: neural prompt compression can add key-value (KV) cache contention and preprocessing latency that outweigh generation-time savings, while skipping compression can cause out-of-memory (OOM) failures on long contexts.

**摘要：** 在 NVIDIA T4（16 GB 显存）等商用 GPU 上部署检索增强生成（RAG）时，会暴露出一种我们称之为“压缩悖论”（Compression Paradox）的实际故障模式：神经提示词压缩（neural prompt compression）可能会增加键值（KV）缓存争用和预处理延迟，其代价超过了生成阶段节省的时间；而跳过压缩则可能导致长上下文处理时的内存溢出（OOM）故障。

We identify two distinct failure mechanisms when a vLLM-served LLM and a PyTorch-based compressor are co-deployed under tight memory budgets, and introduce the Tri-Metric Router, a deterministic, training-free policy that selects among Raw, Neural (LLMLingua-2), and Lexical (BM25) pipelines.

当 vLLM 服务的大语言模型与基于 PyTorch 的压缩器在内存受限的情况下共同部署时，我们识别出了两种截然不同的故障机制，并引入了“三指标路由器”（Tri-Metric Router）。这是一种确定性的、无需训练的策略，可在原始（Raw）、神经（LLMLingua-2）和词法（BM25）流水线之间进行选择。

The router uses three CPU-side signals: spatial complexity ($L$), syntactic density ($\rho_{key}$), and type-token ratio (TTR). Unlike prior semantic-only adaptation, our dispatch signal is hardware-physical, based on VRAM headroom and a latency crossover point.

该路由器使用三个 CPU 端信号：空间复杂度 ($L$)、句法密度 ($\rho_{key}$) 和词汇丰富度（TTR）。与以往仅基于语义的自适应方法不同，我们的调度信号是硬件物理层面的，基于显存余量和延迟交叉点。

Thresholds are calibrated from profiling on LongBench qasper, yielding an operating crossover near 4,332 words on T4; our contribution is this calibration methodology rather than a hardware-specific constant.

阈值是通过对 LongBench qasper 进行性能分析校准得出的，在 T4 上得出的操作交叉点约为 4,332 个单词；我们的贡献在于这种校准方法论，而非某个特定的硬件常量。

On out-of-distribution holdouts, the method achieves 0% OOM failures, 88.5 $\pm$ 4.4% oracle alignment, and 49.3% Combined F1, improving over always-on lexical compression by 5.2 points without additional VRAM or training cost.

在分布外（OOD）测试集上，该方法实现了 0% 的 OOM 故障率、88.5 $\pm$ 4.4% 的预言机对齐率（oracle alignment）以及 49.3% 的综合 F1 分数，在无需额外显存或训练成本的情况下，比始终开启的词法压缩提升了 5.2 个百分点。

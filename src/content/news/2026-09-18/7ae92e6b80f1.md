# Disentangling Algorithmic Bias from Archival Artifacts: A Controlled Audit of Vision-Language Model Valuation in Metropolitan Museum Archives
# 厘清算法偏见与档案伪影：大都会艺术博物馆档案中视觉-语言模型评估的受控审计

**Abstract:** Auditing vision-language models (VLMs) for societal bias requires distinguishing direct algorithmic valuation disparities from confounders embedded within archival metadata. In this study, we audit Contrastive Language-Image Pretraining (CLIP) models using historical artwork metadata from the Metropolitan Museum of Art Open Access collection (N = 1,500 total objects; N = 743 attributed works: Male n = 534, Female n = 209; n = 618 anonymous).

**摘要：** 对视觉-语言模型（VLM）进行社会偏见审计时，需要将直接的算法评估差异与嵌入在档案元数据中的混杂因素区分开来。在本研究中，我们使用大都会艺术博物馆开放获取藏品中的历史艺术品元数据，对对比语言-图像预训练（CLIP）模型进行了审计（总计 N = 1,500 件藏品；N = 743 件有署名作品：男性 n = 534，女性 n = 209；匿名 n = 618）。

We establish a quantitative audit framework evaluating zero-shot CLIP logit differential scores across three semantic prompt pairs (masterpiece, quality, and influence). Unadjusted evaluations demonstrate high score convergence without a statistically significant main gender effect under OpenAI CLIP (mu_F = -0.0067 vs mu_M = -0.0035, p = 0.1829) or OpenCLIP (mu_F = 0.0171 vs mu_M = 0.0237, p = 0.1224).

我们建立了一个定量审计框架，评估了跨三个语义提示对（杰作、质量和影响力）的零样本 CLIP 对数几率差分得分。未经调整的评估显示，在 OpenAI CLIP（mu_F = -0.0067 对比 mu_M = -0.0035，p = 0.1829）或 OpenCLIP（mu_F = 0.0171 对比 mu_M = 0.0237，p = 0.1224）下，得分高度趋同，且不存在统计学意义上的主要性别效应。

Two One-Sided Tests (TOST) confirm statistical equivalence across Cohen's d >= 0.25 bounds (pTOST < 0.005). Multivariate OLS regression controlling for artwork medium, creation era, and aspect ratio (R^2 < 0.02) confirms that artist gender has no statistically significant conditional effect (p > 0.20).

双单侧检验（TOST）证实了在 Cohen's d >= 0.25 的界限内具有统计学等效性（pTOST < 0.005）。控制了艺术品媒介、创作时代和长宽比的多变量 OLS 回归（R^2 < 0.02）证实，艺术家性别没有统计学意义上的条件效应（p > 0.20）。

High residual embedding variance (R^2 < 2%) indicates that global zero-shot valuation metrics operate near an embedding noise floor, showing that broad zero-shot prompt logit differentials are a coarse measurement instrument rather than proving absolute model fairness.

较高的残差嵌入方差（R^2 < 2%）表明，全局零样本评估指标在嵌入噪声基准附近运行，这说明广泛的零样本提示对数几率差分是一种粗略的测量工具，并不能证明模型绝对公平。

We highlight two key caveats: (i) macro-level score equivalence reflects metric insensitivity to fine-grained visual-semantic features and does not preclude localized micro-level visual biases, and (ii) excluding 41.2% unattributed holdings reflects institutional survival bias. These results demonstrate the necessity of multivariate confound control, equivalence testing, and archival provenance auditing when assessing AI fairness in cultural heritage collections.

我们强调了两个关键注意事项：（i）宏观层面的得分等效性反映了指标对细粒度视觉-语义特征的不敏感，并不排除局部微观层面的视觉偏见；（ii）排除 41.2% 的无署名藏品反映了机构的生存偏差。这些结果表明，在评估文化遗产藏品中的人工智能公平性时，进行多变量混杂控制、等效性测试和档案来源审计是必要的。

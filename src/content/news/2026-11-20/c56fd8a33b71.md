### Pentaho Exposure Is a Repository Permission and Data-Connection Problem

Pentaho servers combine reports, transformations, schedules, and connection definitions. A reachable Pentaho endpoint can therefore reveal more about the data estate than one report page suggests.

Pentaho 服务器集成了报表、转换、调度和连接定义。因此，一个可访问的 Pentaho 端点所暴露的数据资产信息，可能远超单个报表页面所呈现的内容。

ZoomEye returned 3,251 matches for app="Pentaho" and 32,209 for title="Pentaho" on 2026-11-20, using sub_type=all, page 1, and pagesize 1. The title count is broad; the application count is a better starting point for validation. These are index matches, not confirmed vulnerable servers or internet-facing administration consoles.

2026 年 11 月 20 日，使用 sub_type=all、page 1 和 pagesize 1 的参数，ZoomEye 搜索到 app="Pentaho" 的结果为 3,251 条，title="Pentaho" 的结果为 32,209 条。标题统计范围较广；应用统计是验证的更好起点。这些仅为索引匹配结果，并非已确认的易受攻击服务器或面向互联网的管理控制台。

### Repository authority

Pentaho Server controls access to web resources and repository objects through users and roles. The Administration perspective manages security and can grant content permissions. A role that can read transformations but not their referenced database connections will encounter an error, showing that content access and connection access are related but distinct. Review administrator roles, repository permissions, and scheduled jobs separately. A user who can edit a transformation may be able to change the data source it references, even without direct database credentials.

Pentaho Server 通过用户和角色控制对 Web 资源和存储库对象的访问。管理视角（Administration perspective）负责安全管理并可授予内容权限。如果一个角色可以读取转换但无法读取其引用的数据库连接，则会遇到错误，这表明内容访问和连接访问虽然相关，但属于不同的权限范畴。请分别审查管理员角色、存储库权限和调度作业。即使没有直接的数据库凭据，能够编辑转换的用户也可能更改其引用的数据源。

### Triage workflow

Confirm the server version and owner. List administrators and roles with content or security-management rights. Review public or anonymous access, default sample users, and connections stored in the repository. Look for schedules that run as high-privilege identities. Inspect the last execution result and source revision for unexpected changes.

确认服务器版本和所有者。列出拥有内容或安全管理权限的管理员及角色。审查公共或匿名访问、默认示例用户以及存储在存储库中的连接。查找以高权限身份运行的调度任务。检查最近一次执行结果和源修订版本，查看是否存在异常更改。

### Monitoring

Alert on new administrators, role changes, connection changes, and modifications to scheduled jobs. Correlate repository activity with database authentication logs. ZoomEye narrows the public search. Pentaho repository permissions and database records determine the actual consequence.

针对新增管理员、角色变更、连接变更以及调度作业的修改设置警报。将存储库活动与数据库身份验证日志进行关联分析。ZoomEye 缩小了公共搜索范围，而 Pentaho 存储库权限和数据库记录则决定了实际的影响后果。

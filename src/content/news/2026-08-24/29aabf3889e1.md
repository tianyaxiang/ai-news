### Are there any decent programs for pdf viewing and editing for Linux that replace Adobe Acrobat?
### Linux 上有没有什么像样的 PDF 查看和编辑软件可以替代 Adobe Acrobat？

Are there any decent programs for pdf viewing and editing for Linux that replace Adobe Acrobat?
Linux 上有没有什么像样的 PDF 查看和编辑软件可以替代 Adobe Acrobat？

Alternate title: How is there still no decent Linux replacement for Adobe Acrobat (pdf viewing and editing)?
备选标题：为什么 Linux 上至今还没有一款像样的 Adobe Acrobat（PDF 查看与编辑）替代品？

There are plenty of viewing programs, some page editing programs, but simply nothing that also allows actual image editing, outline creation, etc.
市面上有很多查看软件和一些页面编辑程序，但就是找不到一款能够同时支持实际图像编辑、大纲创建等功能的软件。

PDF4QT does some of these but is not ideal.
PDF4QT 虽然能实现其中部分功能，但并不理想。

Anthropic is steering Claude away from re-creating specific titles, but users can still use it to make their own games.

Anthropic 正在引导 Claude 远离对特定游戏作品的复刻，但用户仍然可以使用它来制作自己的游戏。

Anthropic has updated Claude Code’s system prompt to prevent the AI tool from being used to re-create existing video games, as reported by Tom’s Hardware. Retro gaming is currently being overrun with AI-made decompilations, recompilations, and ports, but while Anthropic will still let people use Claude Code to make games, it doesn’t want people to use it for direct clones.

据 Tom’s Hardware 报道，Anthropic 已经更新了 Claude Code 的系统提示词，以防止该 AI 工具被用于复刻现有的电子游戏。目前，复古游戏领域充斥着 AI 生成的反编译、重编译和移植作品，尽管 Anthropic 仍允许人们使用 Claude Code 制作游戏，但该公司不希望人们将其用于直接克隆。

Last week, a user on X posted a screenshot allegedly showing two new sentences added to Claude Code’s system prompt: “Do build original games, games in a genre, and games from the user’s own designs and assets. Don’t build a recreation of a specific existing game, even if it is named or called original.”

上周，一位 X 用户发布了一张截图，据称显示 Claude Code 的系统提示词中增加了两句新话：“请制作原创游戏、特定类型的游戏，以及基于用户自身设计和素材的游戏。不要制作特定现有游戏的复刻版，即使它被命名或称为原创。”

Anthropic’s Addy Osmani, in a reply, didn’t confirm that specific language but did say that the company had updated the prompt in Claude Code on Opus 5.5: We added two sentences to Claude Code’s prompt on Opus 5.5 to steer it away from recreating someone else’s specific game because using Claude to infringe IP is against our usage policy.

Anthropic 的 Addy Osmani 在回复中并未确认具体的措辞，但确实表示公司已经在 Opus 5.5 版本的 Claude Code 中更新了提示词：“我们在 Opus 5.5 的 Claude Code 提示词中增加了两句话，旨在引导它避免复刻他人的特定游戏，因为使用 Claude 侵犯知识产权违反了我们的使用政策。”

Original games, genre games, and games built from your own designs and assets are meant to keep working. We’ll continue to iterate to ensure we’re striking the right balance. In the meantime, if Claude turns down something that’s yours, send it my way.

原创游戏、类型游戏以及基于您自身设计和素材构建的游戏仍可继续制作。我们将持续迭代，以确保实现正确的平衡。在此期间，如果 Claude 拒绝了属于您的内容，请发送给我。

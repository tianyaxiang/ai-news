About FreeToken is an edge-native Mixture-of-Experts (MoE) serving engine designed for running frontier-scale open-weight models on personal and consumer hardware. It treats heterogeneous edge resources—GPUs, CPUs, host memory, and interconnects—as a unified, elastic inference platform. Its core features include: Fast Edge-Native Runtime: Provides efficient MoE serving with bandwidth-adaptive CPU–GPU co-execution ($q^\star$ policy), full-layer double-buffered prefill streaming, global LRU expert caching, graph-compatible execution, and the FTW fast weight format. Semantic-Aware Caching: Features semantic anchor checkpoints for recurrent state and KV caches, allowing agentic context edits (e.g., tool calls, thinking blocks) to avoid redundant context recomputation. Elastic Memory Management: Supports dynamic, runtime VRAM re-allocation between expert caches and KV memory without engine restarts or weight reloading. Broad MoE & Ecosystem Support: Supports frontier open-weight MoE models (e.g., DeepSeek-V4-Flash, Qwen3.6-35B-A3B, GLM-5.2) across various parameter scales and quantization formats (e.g., MXFP4, NVFP4, FP8, BF16), with Anthropic/OpenAI-compatible APIs for seamless integration with real-world coding and tool-calling agents (e.g., Codex, Claude Code, OpenCode, OpenClaw, DeepSeek Harness). Diverse Consumer Hardware: Scales across consumer laptops, gaming desktops, and workstation GPUs, with native support for NVIDIA RTX 30, RTX 40, and RTX 50 series GPUs.

关于 FreeToken 是一款边缘原生混合专家（MoE）服务引擎，旨在个人和消费级硬件上运行前沿规模的开源权重模型。它将异构的边缘资源（GPU、CPU、主机内存和互连）视为一个统一的、弹性的推理平台。其核心功能包括：快速边缘原生运行时：提供高效的 MoE 服务，具备带宽自适应 CPU-GPU 协同执行（$q^\star$ 策略）、全层双缓冲预填充流式传输、全局 LRU 专家缓存、图兼容执行以及 FTW 快速权重格式。语义感知缓存：针对循环状态和 KV 缓存提供语义锚点检查点，允许智能体上下文编辑（如工具调用、思维块）以避免冗余的上下文重新计算。弹性内存管理：支持在专家缓存和 KV 内存之间进行动态的运行时显存重分配，无需重启引擎或重新加载权重。广泛的 MoE 与生态支持：支持各种参数规模和量化格式（如 MXFP4、NVFP4、FP8、BF16）的前沿开源权重 MoE 模型（如 DeepSeek-V4-Flash、Qwen3.6-35B-A3B、GLM-5.2），并提供与 Anthropic/OpenAI 兼容的 API，以便与实际的编码和工具调用智能体（如 Codex、Claude Code、OpenCode、OpenClaw、DeepSeek Harness）无缝集成。多样的消费级硬件：可扩展至消费级笔记本电脑、游戏台式机和工作站 GPU，并原生支持 NVIDIA RTX 30、RTX 40 和 RTX 50 系列 GPU。

Lots of porting work has happened this release. The Wasm feature is now enabled by default, so Wild can be used to link Wasm with the caveat that debug info isn't yet supported. Support for GNU linker scripts is greatly enhanced. Wild now supports enough of the linker script syntax that it can link Linux kernel modules and is close to being able to link the Linux kernel itself.

此版本进行了大量的移植工作。Wasm 功能现已默认启用，因此 Wild 可用于链接 Wasm，但需要注意的是尚不支持调试信息。对 GNU 链接器脚本的支持得到了极大增强。Wild 现在支持足够的链接器脚本语法，可以链接 Linux 内核模块，并且已接近能够链接 Linux 内核本身。

The Mac port has made significant progress. The feature isn't yet to the point where we're prepared to enable it by default, but Wild is able to link itself on Mac and at least one of the maintainers is now using Wild as their default linker for Rust on Mac. We've also fixed some performance issues that were affecting various filesystems and made a few general performance improvements.

Mac 移植版取得了重大进展。该功能尚未达到我们准备默认启用的程度，但 Wild 已经能够在 Mac 上链接自身，并且至少有一位维护者现在在 Mac 上将 Wild 作为 Rust 的默认链接器使用。我们还修复了一些影响各种文件系统的性能问题，并进行了一些常规的性能改进。

We also got a bit slower due to implementing proper ELF COMDAT support. We now cap the number of threads to at most 32 unless overridden by --threads. This avoids bad performance that occurs with larger numbers of threads due to contention on a Linux per-inode mutex. Our benchmarks have been expanded to include a wider range of scenarios such as different filesystems and whether the output file already exists. Build requirements Minimum rust version for building Wild is now 1.99.0

由于实现了适当的 ELF COMDAT 支持，我们的速度也稍微变慢了一些。除非通过 --threads 覆盖，否则我们将线程数限制为最多 32 个。这避免了由于 Linux 每个 inode 互斥锁上的争用而在线程数较多时出现的性能不佳问题。我们的基准测试已扩展到包括更广泛的场景，例如不同的文件系统以及输出文件是否已存在。构建要求：构建 Wild 的最低 Rust 版本现为 1.99.0。

Get Started in 15 Minutes Installation note: Starting in v2.1.113, Claude Code ships as a native per-platform binary (macOS/Linux/Windows). The recommended install is the native installer (curl -fsSL https://claude.ai/install.sh | bash); npm installation is deprecated in the official README; prefer the native installer, Homebrew (brew install --cask claude-code) or WinGet (winget install Anthropic.ClaudeCode). For reference, npm install -g @anthropic-ai/claude-code pulls the same native binary through a per-platform optional dependency at install time.

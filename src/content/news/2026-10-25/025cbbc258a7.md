# YouTube Opened Without Asking for the Login Password

YouTube 在没有要求输入登录密码的情况下打开了。视频已经播放了一秒钟。桌面上没有密码窗口，页面显示的是歌曲，而不是机器人验证。Savindu Thathsara, savithathsara.me。这是一条来自同一台 ThinkPad 的 Hearthlen 笔记。

A new browser looks like a stranger The assistant had been starting Chromium on its own, beside the desktop session. Chromium could not see the login keyring, so the desktop asked for the account password. A browser that starts that way also has no ordinary cookies, and YouTube answers a stranger with a check.

一个新的浏览器看起来像个陌生人。助手一直在桌面会话之外自行启动 Chromium。Chromium 无法识别登录密钥环，因此桌面要求输入账户密码。以这种方式启动的浏览器也没有常规的 Cookie，YouTube 会通过验证来应对陌生访问。

The fix is small. Links now open with the desktop’s own opener, in the session that is already logged in, so the tab belongs to the Chromium window already on screen. Chromium is also told to keep its saved data without the keyring (--password-store=basic). The assistant does not try to solve a robot check. It stops creating the kind of window that gets one. “Play shape of you on youtube” then returned in 3917 ms. Nothing named like a keyring prompt was running. The window title was the watch page, and the picture on screen was the video, playing.

修复方法很简单。链接现在使用桌面自带的打开程序，在已经登录的会话中打开，因此标签页属于屏幕上已有的 Chromium 窗口。Chromium 也被设置为在没有密钥环的情况下保存数据（--password-store=basic）。助手不会尝试解决机器人验证，它停止创建会导致此类验证的窗口。“Play shape of you on youtube”随后在 3917 毫秒内返回结果。没有任何类似密钥环提示的程序在运行。窗口标题是观看页面，屏幕上的画面是正在播放的视频。

A person, drawn with a few shapes When Hearthlen is in the conversation, a 200 by 248 window sits at the bottom right. It is a head, a ring, two eyes, and a mouth. No image, no video, no browser. The process measured 28,440 kB. A state change reached it in 0.1 ms, because the window is created at startup and only mapped when needed. Listening holds still. Thinking brightens the ring. Talking moves the mouth and shows the sentence. When the sentence ends, the window leaves. Speed stays with the skill path from Hey Hearthlen Opened YouTube Without a Cloud Model. The number still missing is the spoken wake, timed from a real “hey Hearthlen” at the laptop, which is the open check in the roadmap.

一个用几个形状勾勒出的人。当 Hearthlen 参与对话时，右下角会出现一个 200 乘 248 的窗口。它是一个头部、一个圆环、两只眼睛和一个嘴巴。没有图像，没有视频，没有浏览器。该进程占用 28,440 kB 内存。状态变化在 0.1 毫秒内传达给它，因为窗口在启动时创建，仅在需要时映射。聆听时保持静止。思考时圆环会变亮。说话时嘴巴会动并显示句子。句子结束时，窗口消失。速度保持在“Hey Hearthlen 在没有云模型的情况下打开 YouTube”的技能路径上。目前缺失的数据是语音唤醒时间，即从笔记本电脑上实际发出“hey Hearthlen”指令开始计时，这是路线图中的待办事项。

# Goldman Sachs is pulling Claude Code from its bankers and traders

Goldman Sachs has restricted Anthropic's Claude Code and Microsoft's GitHub to its engineers, cutting off traders and bankers who used the tools to track client flows and build market models. The bank barred its Hong Kong bankers from Claude in April and is now a lead underwriter on Anthropic's IPO.

高盛集团已限制其员工使用 Anthropic 的 Claude Code 和微软的 GitHub，仅允许工程师使用，从而切断了交易员和银行家利用这些工具追踪客户资金流和构建市场模型的使用权限。该行在 4 月份禁止其香港银行家使用 Claude，目前正担任 Anthropic 首次公开募股（IPO）的主承销商。

Most traders and bankers at Goldman Sachs can no longer use AI coding tools at work. Internal guidance updated in October restricts Anthropic's Claude Code and Microsoft's GitHub to the bank's engineers, Bloomberg News reported, following a review of productivity and risk concerns.

据彭博社报道，在对生产力和风险问题进行评估后，高盛于 10 月更新了内部指导方针，将 Anthropic 的 Claude Code 和微软的 GitHub 的使用权限限制在该行的工程师范围内，这意味着高盛的大多数交易员和银行家已无法在工作中使用人工智能编码工具。

Strats, who work across trading, quantitative research and software engineering, still have access, according to a second person familiar with the matter.

据第二位知情人士透露，横跨交易、量化研究和软件工程部门的策略师（Strats）仍保留访问权限。

The change has frustrated some traders, a person familiar with the matter told Bloomberg. They had been using the tools to monitor client trading flows, model market moves and positions, and put together written and graphic material. Goldman spokesperson Nick Carcaterra said the bank makes certain AI tools available to staff "to determine the best use cases" across the firm.

一位知情人士告诉彭博社，这一变动令一些交易员感到沮丧。他们此前一直使用这些工具来监控客户交易流、为市场走势和头寸建模，并整理书面和图形材料。高盛发言人尼克·卡卡泰拉（Nick Carcaterra）表示，该行向员工提供某些人工智能工具，旨在“确定公司内部的最佳用例”。

As recently as July, chief information officer Marco Argenti was talking up "vibe coding" by Goldman's non-technical employees. He told Bloomberg that traders and bankers had built tools with AI and passed them to the firm's engineers, of whom there are about 12,000, to be improved.

就在 7 月份，首席信息官马可·阿根蒂（Marco Argenti）还在大力推崇高盛非技术员工的“直觉编程”（vibe coding）。他告诉彭博社，交易员和银行家利用人工智能构建了工具，并将其交给公司约 1.2 万名工程师进行改进。

That arrangement let the people closest to a problem build a first version without waiting for engineering time. It also meant thousands of employees without engineering training were running software that writes and executes code, on the same machines they use to handle client information.

这种安排让最了解问题的人能够在无需等待工程排期的情况下构建出初步版本。这也意味着数千名未经工程培训的员工在处理客户信息的同一台机器上，运行着能够编写和执行代码的软件。

At a conference in Turin last month, Argenti described Goldman's AI adoption in waves and said developers, more than 12,000 of the bank's roughly 47,000 staff, had made up the first. The October guidance limits the coding agents to that group.

在上个月于都灵举行的一次会议上，阿根蒂将高盛的人工智能应用描述为分阶段进行，并表示开发人员（该行约 4.7 万名员工中的 1.2 万多人）构成了第一波。10 月份的指导方针将编码代理的使用限制在了这一群体中。

In April, Goldman removed Claude from its internal AI platform for bankers in Hong Kong. The Financial Times reported that the bank had read its contract with Anthropic strictly, and an Anthropic spokesperson said Claude had never been officially supported in Hong Kong. ChatGPT and Gemini remained available there. JPMorgan removed Claude from its Hong Kong approved list in June.

4 月份，高盛从其香港银行家的内部人工智能平台中移除了 Claude。《金融时报》报道称，该行严格解读了其与 Anthropic 的合同，而 Anthropic 发言人表示，Claude 从未在香港获得官方支持。ChatGPT 和 Gemini 在当地仍可使用。摩根大通于 6 月将 Claude 从其香港批准名单中移除。

The Hong Kong restriction was based on location and contract terms, and the new one is based on role. Goldman's in-house AI assistant, which uses models from several companies, is still available across the firm. The restriction applies to third-party agents that can write and run code by themselves.

香港的限制是基于地理位置和合同条款，而新的限制则是基于职位角色。高盛内部使用多家公司模型的人工智能助手在全公司范围内仍然可用。此次限制仅适用于能够自行编写和运行代码的第三方代理。

Earlier this year, Goldman said Anthropic engineers had spent six months at the bank helping build Claude-based agents for trade accounting and client onboarding. Those agents sit in the back office and are run by Goldman's engineering teams.

今年早些时候，高盛表示 Anthropic 的工程师曾在该行工作了六个月，协助构建用于交易会计和客户入职的基于 Claude 的代理。这些代理位于后台，由高盛的工程团队负责运行。

Goldman and Morgan Stanley are also the lead underwriters on Anthropic's IPO, according to the S-1 filed October 26. Anthropic is expected to list on Nasdaq under the ticker ANT before the end of November, as we reported last week. Over the next few weeks, Goldman's bankers will be marketing shares in a company whose coding agent most of them are no longer allowed to use.

根据 10 月 26 日提交的 S-1 文件，高盛和摩根士丹利也是 Anthropic 首次公开募股的主承销商。正如我们上周报道的那样，Anthropic 预计将在 11 月底前以股票代码“ANT”在纳斯达克上市。在接下来的几周里，高盛的银行家们将推销一家公司的股票，而这家公司的编码代理工具，他们中的大多数人已不再被允许使用。

Claude Code reads files, writes programs and runs them, typically with the same access as the person using it. Code an engineer writes with it usually goes through review, testing and deployment controls before it reaches anything important. A script a trader builds to watch client flows can end up in daily use without going through any of those.

Claude Code 可以读取文件、编写程序并运行它们，通常拥有与使用者相同的访问权限。工程师用它编写的代码在进入重要系统之前，通常会经过审查、测试和部署控制。而交易员为监控客户资金流而构建的脚本，可能在未经任何此类流程的情况下就投入日常使用。

Banks are also required to keep information barriers between groups, for example between bankers working on deals and traders who could profit from knowing about them. Goldman built its internal AI platform around controls like these. A tool a trader puts together with an agent wasn't designed with them in mind, and engineers can only check it if someone sends it their way.

银行还被要求在各部门之间保持信息隔离，例如在从事交易的银行家与可能因获悉交易信息而获利的交易员之间。高盛围绕这些控制措施构建了其内部人工智能平台。交易员利用代理工具构建的工具在设计时并未考虑到这些因素，工程师只有在有人将其发送过来时才能进行检查。

There is also the matter of whether anyone understands the code. Last month a Meta engineer said he now ships code he can't fully account for, and writing software is his job. A trader using an agent to model positions is less likely to know how that code handles unusual cases, which on a trading desk can mean losses.

此外，还有一个问题是是否有人能理解这些代码。上个月，一位 Meta 工程师表示，他现在发布的代码连他自己都无法完全解释，而编写软件本是他的工作。一名使用代理来模拟头寸的交易员，更不可能知道该代码如何处理异常情况，而在交易台，这可能意味着亏损。

Cost may also have played a part. Agent usage is billed by the token, and several companies that gave agents to everyone have seen spending climb. Amazon shut down an internal leaderboard after employees ran agents on pointless tasks to move up it, and Accenture now funds $29 a month of Claude per employee. Bloomberg's sources said productivity was part of Goldman's review.

成本可能也是一个因素。代理的使用按 Token 计费，几家向所有员工开放代理的公司已发现支出攀升。亚马逊在员工为了提升排名而让代理执行无意义任务后，关闭了一个内部排行榜；埃森哲现在为每位员工每月提供 29 美元的 Claude 使用额度。彭博社的消息来源称，生产力是高盛评估的一部分。

Barclays said in October that it expects half its developers to be using Claude Code by the end of the year, and three weeks later named developers among 5,000 job cuts. Like Goldman, it is giving coding agents to engineers. Unlike Goldman, it is also using them to reduce how many engineers it employs.

巴克莱银行在 10 月份表示，预计到今年年底其一半的开发人员将使用 Claude Code，但三周后，该行在 5000 人的裁员计划中提到了开发人员。与高盛一样，它正在向工程师提供编码代理。与高盛不同的是，它还利用这些工具来减少其雇佣的工程师数量。

Banks have tightened agent access in other places this fall. JPMorgan and Schwab are blocking outside agents from customer accounts, and Goldman has now set limits on which of its own employees can use them.

今年秋天，银行在其他方面也收紧了代理访问权限。摩根大通和嘉信理财正在阻止外部代理访问客户账户，而高盛现在也对其自身员工的使用权限设定了限制。

At State of AI, we think Goldman was right to restrict the tools and wrong in how it went about it.

在 State of AI，我们认为高盛限制这些工具的做法是正确的，但在执行方式上却有失妥当。

A trading floor is a bad place for unreviewed code written by people who can't read it, and the information barrier problem would be reason enough on its own. Requiring that agent-written code come from people trained to review it is a sensible rule for a regulated business.

交易大厅不适合存放由无法阅读代码的人编写且未经审查的代码，仅信息隔离问题就足以成为限制的理由。要求代理编写的代码必须由受过审查培训的人员处理，对于受监管的企业来说是一项明智的规则。

Goldman's own CIO was promoting traders' AI-built tools in July, though. Withdrawing access through a guideline update, with no replacement mentioned in Bloomberg's reporting, tells the traders who found good uses that they were the risk. Their complaints point to work the engineering team could take on, and Goldman would get more out of collecting them than out of waiting for them to fade.

然而，高盛自己的首席信息官在 7 月份还在推广交易员利用人工智能构建的工具。通过更新指导方针撤销访问权限，且彭博社的报道中未提及任何替代方案，这等于告诉那些找到了良好用途的交易员，他们本身就是风险所在。他们的抱怨指向了工程团队可以承担的工作，高盛从收集这些反馈中获得的收益，远比等待这些抱怨自行消退要多。

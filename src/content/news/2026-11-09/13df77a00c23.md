# anthropics / claude-quickstarts

Claude Quickstarts is a collection of projects designed to help developers quickly get started with building applications using the Claude API. Each quickstart provides a foundation that you can easily build upon and customize for your specific needs.

Claude Quickstarts 是一个项目集合，旨在帮助开发者快速上手使用 Claude API 构建应用程序。每个快速入门项目都提供了一个基础，你可以轻松地在其之上进行构建，并根据你的具体需求进行定制。

Getting Started: To use these quickstarts, you'll need an Claude API key. If you don't have one yet, you can sign up for free at console.anthropic.com.

入门指南：要使用这些快速入门项目，你需要一个 Claude API 密钥。如果你还没有，可以在 console.anthropic.com 免费注册。

Available Quickstarts: Customer Support Agent: A customer support agent powered by Claude. This project demonstrates how to leverage Claude's natural language understanding and generation capabilities to create an AI-assisted customer support system with access to a knowledge base. Go to Customer Support Agent Quickstart.

可用快速入门：客户支持代理：一个由 Claude 驱动的客户支持代理。该项目演示了如何利用 Claude 的自然语言理解和生成能力，创建一个能够访问知识库的 AI 辅助客户支持系统。前往客户支持代理快速入门。

Financial Data Analyst: A financial data analyst powered by Claude. This project demonstrates how to leverage Claude's capabilities with interactive data visualization to analyze financial data via chat. Go to Financial Data Analyst Quickstart.

金融数据分析师：一个由 Claude 驱动的金融数据分析师。该项目演示了如何结合 Claude 的能力与交互式数据可视化，通过聊天来分析金融数据。前往金融数据分析师快速入门。

Computer Use Demo: An environment and tools that Claude can use to control a desktop computer. This project demonstrates how to leverage the computer use capabilities of Claude, including support for the latest computer_toolset_20260801 toolset shape, where each computer action is a member tool the model calls by name. Go to Computer Use Demo Quickstart.

计算机使用演示：一个 Claude 可用于控制桌面计算机的环境和工具。该项目演示了如何利用 Claude 的计算机使用能力，包括对最新的 computer_toolset_20260801 工具集形态的支持，其中每个计算机操作都是模型按名称调用的成员工具。前往计算机使用演示快速入门。

Computer Use Best Practices: A pedagogical, native-macOS reference implementation of a computer-use agent. Unlike the containerized Computer Use Demo, this project runs directly against the macOS desktop (run it in a VM!) and demonstrates common patterns for building more reliable and cost-effective computer-use agents: explicit tool definitions, correct image sizing and pruning, prompt caching, server-side compaction, batched tool calls, a sandboxed shell, and trajectory recording. It pairs with Anthropic's computer-use best-practices guide. Go to Computer Use Best Practices Quickstart.

计算机使用最佳实践：一个教学性质的、原生 macOS 计算机使用代理参考实现。与容器化的“计算机使用演示”不同，该项目直接在 macOS 桌面上运行（请在虚拟机中运行！），并演示了构建更可靠、更具成本效益的计算机使用代理的常见模式：显式工具定义、正确的图像缩放与修剪、提示词缓存、服务端压缩、批量工具调用、沙盒 Shell 以及轨迹记录。它与 Anthropic 的计算机使用最佳实践指南配套使用。前往计算机使用最佳实践快速入门。

Browser Use Demo: A complete reference implementation for browser automation powered by Claude. This project demonstrates how to give Claude the ability to navigate websites, inspect and interact with DOM elements, extract content, and fill forms using a custom Playwright-backed browser tool. Go to Browser Use Demo Quickstart.

浏览器使用演示：一个由 Claude 驱动的浏览器自动化完整参考实现。该项目演示了如何通过自定义的 Playwright 支持的浏览器工具，赋予 Claude 浏览网站、检查并与 DOM 元素交互、提取内容以及填写表单的能力。前往浏览器使用演示快速入门。

Browser Toolset Quickstart: The minimal CDP example of Claude's browser toolset (browser_toolset_20260801), in Python and TypeScript. It has a small driver for one Chromium tab over the Chrome DevTools Protocol, a script that runs the driver with the tool runner, and a script that exercises it without a model. It shows the interface and is not production code. Go to Browser Toolset Quickstart.

浏览器工具集快速入门：Claude 浏览器工具集 (browser_toolset_20260801) 的最小 CDP 示例，提供 Python 和 TypeScript 版本。它包含一个通过 Chrome DevTools Protocol 控制单个 Chromium 标签页的小型驱动程序、一个使用工具运行器运行该驱动程序的脚本，以及一个无需模型即可测试它的脚本。它展示了接口，并非生产代码。前往浏览器工具集快速入门。

Computer Toolset Quickstart: The minimal VNC example of Claude's computer toolset (computer_toolset_20260801), in Python and TypeScript. It has a small driver for one desktop over VNC (the RFB protocol, no VNC library), a script that runs the driver with the tool runner, and a script that exercises it without a model. It shows the interface and is not production code. Go to Computer Toolset Quickstart.

计算机工具集快速入门：Claude 计算机工具集 (computer_toolset_20260801) 的最小 VNC 示例，提供 Python 和 TypeScript 版本。它包含一个通过 VNC（RFB 协议，无 VNC 库）控制单个桌面的小型驱动程序、一个使用工具运行器运行该驱动程序的脚本，以及一个无需模型即可测试它的脚本。它展示了接口，并非生产代码。前往计算机工具集快速入门。

Autonomous Coding Agent: An autonomous coding agent powered by the Claude Agent SDK. This project demonstrates a two-agent pattern (initializer + coding agent) that can build complete applications over multiple sessions, with progress persisted via git and a feature list that the agent works through incrementally. Go to Autonomous Coding Agent Quickstart.

自主编码代理：一个由 Claude Agent SDK 驱动的自主编码代理。该项目演示了一种双代理模式（初始化器 + 编码代理），可以在多个会话中构建完整的应用程序，通过 git 持久化进度，并根据功能列表逐步完成工作。前往自主编码代理快速入门。

Managed Agents: Chat SDK: A browser chat app powered by Claude Managed Agents and Vercel's Chat SDK. This project demonstrates how to pair a persistent Managed Agents session per conversation with a chat surface: a research analyst researches with web search and streams its brief token by token while a live feed shows the tool calls. The same handler runs on Slack, Teams, Discord, Telegram, or WhatsApp by swapping the Chat SDK adapter. Go to Managed Agents Chat SDK Quickstart.

托管代理：聊天 SDK：一个由 Claude 托管代理和 Vercel 聊天 SDK 驱动的浏览器聊天应用。该项目演示了如何将每个对话的持久化托管代理会话与聊天界面配对：研究分析师通过网络搜索进行研究，并逐个 token 流式传输其简报，同时实时显示工具调用情况。通过更换聊天 SDK 适配器，同一个处理程序可以在 Slack、Teams、Discord、Telegram 或 WhatsApp 上运行。前往托管代理聊天 SDK 快速入门。

Managed Agents with CopilotKit and AG-UI: A personal finance assistant chat app built on a Claude Managed Agent and rendered with CopilotKit. This project demonstrates how to bridge a managed-agent session to the AG-UI protocol, stream replies token by token with event deltas, and render agent tool calls as interactive generative UI components in the chat. Go to Managed Agents with CopilotKit Quickstart.

使用 CopilotKit 和 AG-UI 的托管代理：一个基于 Claude 托管代理构建并使用 CopilotKit 渲染的个人理财助手聊天应用。该项目演示了如何将托管代理会话桥接到 AG-UI 协议，通过事件增量逐个 token 流式传输回复，并将代理工具调用渲染为聊天中的交互式生成式 UI 组件。前往使用 CopilotKit 的托管代理快速入门。

Managed Agents: Daily Brief: A scheduled agent that reads your Slack channels and GitHub pull requests each weekday and posts one short brief to Slack, built on Claude Managed Agents. This project demonstrates a deployment defined entirely as files applied with ant apply (agent, environment, two memory stores, vault, cron deployment), a read-only preferences store next to a read-write state store, and run steps designed to fail well unattended: per-source bookmarks, a ledger against repeats, and a source that could not be read reported as unreadable rather than as a quiet day. Go to Managed Agents Daily Brief Quickstart.

托管代理：每日简报：一个基于 Claude 托管代理构建的定时代理，它会在每个工作日读取你的 Slack 频道和 GitHub 拉取请求，并向 Slack 发布一份简短的摘要。该项目演示了一种完全通过 ant apply 应用文件定义的部署方式（代理、环境、两个内存存储、保险库、定时任务部署），包含一个只读偏好设置存储和一个读写状态存储，以及旨在无人值守时也能良好处理失败的运行步骤：按来源书签、防止重复的分类账，以及将无法读取的来源报告为“不可读”而非“静默无事”。前往托管代理每日简报快速入门。

Managed Agents: Knowledge Wiki: A deal-room knowledge wiki built with Claude Managed Agents. This project demonstrates how to distill a document corpus once into a versioned memory-store knowledge wiki — using one dynamic workflow run that extracts, resolves, and consolidates — then answer repeated analyst questions from the wiki with provenance on every fact and a lower per-question cost than raw-document search. The worked example is a real M&A data room fetched from public SEC EDGAR filings. Go to Managed Agents Knowledge Wiki Quickstart.

托管代理：知识维基：一个使用 Claude 托管代理构建的交易室知识维基。该项目演示了如何将文档语料库一次性提炼为版本化的内存存储知识维基——使用一次提取、解析和整合的动态工作流运行——然后从维基中回答分析师的重复问题，并为每个事实提供来源证明，且单次问题的成本低于原始文档搜索。该示例是一个从公开的 SEC EDGAR 文件中获取的真实并购数据室。前往托管代理知识维基快速入门。

Managed Agents: Linear: An agent you can @mention or assign in Linear, backed by a Claude Managed Agent. This project demonstrates a stateless webhook bridge on Linear's Agent Platform: an AgentSessionEvent creates a Managed Agents session with the Linear session and organization IDs stored in session metadata, and the session.status_idled webhook reads that metadata back to post the reply as a comment. It installs through Linear OAuth with actor=app. Go to Managed Agents Linear Quickstart.

托管代理：Linear：一个由 Claude 托管代理支持的、可以在 Linear 中 @提及或分配任务的代理。该项目演示了 Linear 代理平台上的无状态 Webhook 桥接：AgentSessionEvent 创建一个托管代理会话，并将 Linear 会话和组织 ID 存储在会话元数据中，session.status_idled Webhook 会读取该元数据以将回复发布为评论。它通过 Linear OAuth 以 actor=app 的身份安装。前往托管代理 Linear 快速入门。

Like many of us who value the human side of the web, I am looking for ways to keep slop at bay. It seems like LLM detection technology works reasonably well nowadays, with Pangram as the main provider. It is expensive, though!

像许多重视网络人文一面的人一样，我正在寻找抵御垃圾内容的方法。目前看来，LLM 检测技术的效果相当不错，其中 Pangram 是主要的服务提供商。不过，它很昂贵！

Assuming pangram scans are trustworthy, and it seems they are, we could create a centralized index of pangram scans of articles. I have already set up a prototype where I publish results of my own pangram scans. I could create more users, each tied to its own API key, so others can contribute with scans as well. This is way more resource efficient than everyone running their own scans. What do you think?

假设 Pangram 的扫描结果是可信的（事实似乎也确实如此），我们可以创建一个文章 Pangram 扫描结果的集中索引。我已经建立了一个原型，用于发布我自己的扫描结果。我可以创建更多用户，每个用户绑定自己的 API 密钥，这样其他人也可以贡献扫描结果。这比每个人都各自运行扫描要高效得多。你们觉得呢？

Update: since this is receiving quite some attention, let me clarify one thing. I'm not proposing to change Lobste.rs itself. I'm wondering if there are enough people who'd like to join forces to maintain an independent index of pangram scans, for our own use, not intending to impose it on anyone (e.g., maybe we could have a browser extension that automatically shows the scan results for articles when browsing Lobste.rs or the orange site).

更新：由于这个提议引起了不少关注，我澄清一点。我并不是建议更改 Lobste.rs 本身。我只是想知道是否有足够多的人愿意联手维护一个独立的 Pangram 扫描索引供我们自己使用，并不打算强加给任何人（例如，我们或许可以开发一个浏览器扩展，在浏览 Lobste.rs 或“橙色网站”时自动显示文章的扫描结果）。

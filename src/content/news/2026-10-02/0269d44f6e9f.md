# Pidgin 3.0 Alpha 3 (2.97.0) 已正式发布

We are ecstatic to announce that we have released the third **alpha** version of Pidgin 3.0!!! This release has an official version number of 2.97.0. We will continue releasing in this fashion until we are ready for 3.0.0 which will be the release we consider ready for end users. You can read more about our development phases [here](https://discourse.imfreedom.org/t/pidgin-3-development-phases/369).

我们非常激动地宣布，Pidgin 3.0 的第三个 **Alpha** 版本现已发布！！！该版本的官方版本号为 2.97.0。我们将继续以这种方式进行发布，直到我们准备好 3.0.0 版本，届时该版本将被视为面向最终用户的正式版本。您可以[点击此处](https://discourse.imfreedom.org/t/pidgin-3-development-phases/369)了解更多关于我们开发阶段的信息。

The release can still be found on [SourceForge](https://sourceforge.net/projects/pidgin/files/Pidgin3/2.97.0/) but we have a new CDN thanks to [Fastly](https://fastly.com/) and the release can be found at [fastly.imfreedom.org](https://fastly.imfreedom.org/Pidgin3/2.97.0/). It will also show up on [Flathub Beta](https://docs.flathub.org/docs/for-users/installation) shortly.

该版本仍可在 [SourceForge](https://sourceforge.net/projects/pidgin/files/Pidgin3/2.97.0/) 上找到，但得益于 [Fastly](https://fastly.com/) 的支持，我们现在拥有了新的 CDN，您也可以在 [fastly.imfreedom.org](https://fastly.imfreedom.org/Pidgin3/2.97.0/) 获取该版本。它很快也会出现在 [Flathub Beta](https://docs.flathub.org/docs/for-users/installation) 上。

If you don’t want to use the [Flathub](https://flathub.org/) Beta method, there are build instructions in the `README.md` for building a [Flatpak](https://flatpak.org/) locally or installing into a [meson devenv](https://mesonbuild.com/Commands.html#devenv). Both methods avoid installing directly to your OS installation which is the preferred method as there is no easy way to uninstall the application at this time.

如果您不想使用 [Flathub](https://flathub.org/) Beta 方法，`README.md` 中提供了构建本地 [Flatpak](https://flatpak.org/) 或安装到 [meson devenv](https://mesonbuild.com/Commands.html#devenv) 的构建说明。这两种方法都避免了直接安装到您的操作系统中，这是目前推荐的做法，因为现阶段还没有简便的方法来卸载该应用程序。

## About
## 关于

Just like the previous releases, this is a timed release. It is a snapshot of what we currently have and is something we think other tinkerers and developers may want to start playing with. But again, it is **not** meant for *end users*.

与之前的版本一样，这是一个定时发布版本。它是我们当前开发进度的快照，我们认为其他技术爱好者和开发者可能会有兴趣尝试。但再次强调，它**不**适合*最终用户*使用。

Most things are not implemented, the user interface has had little to no polish, and there are so, so many bugs. As such we are asking packagers to please **not package** this for your users at this time as the potential support requests will be too much for us to handle.

大多数功能尚未实现，用户界面几乎没有经过润色，并且存在非常多的 Bug。因此，我们恳请软件包维护者目前**不要**将其打包提供给用户，因为由此产生的潜在支持请求将超出我们的处理能力。

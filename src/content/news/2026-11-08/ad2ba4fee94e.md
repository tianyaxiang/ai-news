Ruff aims to be orders of magnitude faster than alternative tools while integrating more functionality behind a single, common interface. Ruff can be used to replace Flake8 (plus dozens of plugins), Black, isort, pydocstyle, pyupgrade, autoflake, and more, all while executing tens or hundreds of times faster than any individual tool. Ruff is actively developed and used in major open-source projects like: Apache Airflow Apache Superset FastAPI Hugging Face Pandas SciPy Ruff is backed by Astral, the creators of uv and ty. Read the launch post, or the original project announcement.

Ruff 的目标是在提供比替代工具快几个数量级的速度的同时，通过单一的通用接口集成更多功能。Ruff 可以用来替代 Flake8（及其数十个插件）、Black、isort、pydocstyle、pyupgrade、autoflake 等工具，且执行速度比任何单一工具快几十倍甚至几百倍。Ruff 正在积极开发中，并被 Apache Airflow、Apache Superset、FastAPI、Hugging Face、Pandas 和 SciPy 等大型开源项目所使用。Ruff 由 uv 和 ty 的创建者 Astral 提供支持。请阅读发布博文或原始项目公告。

Installation Ruff is available as ruff on PyPI. Invoke Ruff directly with uvx: uvx ruff@0.17.4 check # Lint all files in the current directory. uvx ruff@0.17.4 format # Format all files in the current directory. Or install Ruff with uv (recommended), pip, or pipx: # With uv. uv tool install ruff@latest # Install Ruff globally. uv add --dev ruff # Or add Ruff to your project. # With pip. pip install ruff # With pipx. pipx install ruff

Usage To run Ruff as a linter, try any of the following: ruff check # Lint all files in the current directory (and any subdirectories). ruff check path/to/code/ # Lint all files in `/path/to/code` (and any subdirectories). ruff check path/to/code/*.py # Lint all `.py` files in `/path/to/code`. ruff check path/to/code/to/file.py # Lint `file.py`. ruff check @arguments.txt # Lint using an input file, treating its contents as newline-delimited command-line arguments. Or, to run Ruff as a formatter: ruff format # Format all files in the current directory (and any subdirectories). ruff format path/to/code/ # Format all files in `/path/to/code` (and any subdirectories). ruff format path/to/code/*.py # Format all `.py` files in `/path/to/code`. ruff format path/to/code/to/file.py # Format `file.py`. ruff format @arguments.txt # Format using an input file, treating its contents as newline-delimited command-line arguments.

用法：要将 Ruff 作为检查器运行，请尝试以下任一命令：`ruff check`（检查当前目录及子目录下的所有文件）、`ruff check path/to/code/`（检查指定路径下的所有文件）、`ruff check path/to/code/*.py`（检查指定路径下的所有 .py 文件）、`ruff check path/to/code/to/file.py`（检查指定文件）、`ruff check @arguments.txt`（使用输入文件进行检查，将其内容视为换行符分隔的命令行参数）。或者，要将 Ruff 作为格式化工具运行：`ruff format`（格式化当前目录及子目录下的所有文件）、`ruff format path/to/code/`（格式化指定路径下的所有文件）、`ruff format path/to/code/*.py`（格式化指定路径下的所有 .py 文件）、`ruff format path/to/code/to/file.py`（格式化指定文件）、`ruff format @arguments.txt`（使用输入文件进行格式化，将其内容视为换行符分隔的命令行参数）。

Ruff can also be used as a pre-commit hook via ruff-pre-commit: - repo: https://github.com/astral-sh/ruff-pre-commit # Ruff version. rev: v0.17.4 hooks: # Run the linter. - id: ruff-check args: [ --fix ] # Run the formatter. - id: ruff-format Ruff can also be used as a VS Code extension or with various other editors. Ruff can also be used as a GitHub Action via ruff-action: name: Ruff on: [ push, pull_request ] jobs: ruff: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: astral-sh/ruff-action@v3

Ruff 还可以通过 ruff-pre-commit 用作预提交钩子（pre-commit hook）：配置包括仓库地址、版本号以及运行检查器（带 --fix 参数）和格式化工具的钩子。Ruff 还可以作为 VS Code 扩展或在其他各种编辑器中使用。Ruff 还可以通过 ruff-action 作为 GitHub Action 使用，配置包括名称、触发条件（push, pull_request）以及在 ubuntu-latest 上运行的作业步骤。

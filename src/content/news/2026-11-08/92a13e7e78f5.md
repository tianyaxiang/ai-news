# Running a law firm on Free software

I started running decoded.legal - a small English law firm, focussing on Internet, telecoms, and tech law - on Free software, both client and server side, around five years ago. I have used Free software in my personal life for a lot longer than that.

大约五年前，我开始使用自由软件（包括客户端和服务器端）来运营我的小型英国律师事务所 decoded.legal，该事务所专注于互联网、电信和科技法律。在个人生活中，我使用自由软件的时间则要长得多。

Back in 2022, I wrote about my experiences after the first year or so. I wrote an update in 2024. Someone asked me recently what I am doing now, and, while it is mostly the same, some bits have changed. So here is the 2026 update.

早在 2022 年，我就写过关于运营一年左右后的心得体会。2024 年，我又写了一篇更新。最近有人问我现在的状况，虽然大体上没变，但有些细节已经调整了。所以，这就是 2026 年的更新。

I am still using Debian, with GNOME, and it works well for me. I’m using it on a ThinkPad X1 Yoga Gen 6, as my primary machine, and, being a “Yoga” version, I rather like being able to fold the screen back and write on it to mark up documents. (Here are my thoughts on the different “Active Pens” available for it.)

我依然在使用 Debian 和 GNOME，它们对我来说运行良好。我将 ThinkPad X1 Yoga Gen 6 作为主力机，由于它是“Yoga”版本，我很喜欢将其屏幕翻转过来，在上面书写以标注文档。（这是我对该设备可选的各种“主动式触控笔”的看法。）

However, the machine itself seems to have a hardware problem with the Thunderbolt / USB-C ports (fine for power, very flaky for data), and so I might need to replace it. And I have no idea what laptop I might get.

然而，这台机器本身的 Thunderbolt / USB-C 接口似乎存在硬件问题（充电没问题，但数据传输非常不稳定），所以我可能需要更换它。至于下一台笔记本电脑买什么，我还没什么头绪。

Email (MUA): Thunderbird and mutt, depending on what I am doing. Document production: LibreOffice’s Writer if I want a “Word” document (e.g. I am exchanging documents with other lawyers), and I am using pandoc and typst to convert Markdown files that I tend to write in vim for some other bits. I’d like to explore tex at some point, as I have a client who likes diffs to their .tex files, and that looks rather neat.

电子邮件 (MUA)：Thunderbird 和 mutt，取决于我正在处理的任务。文档制作：如果需要“Word”文档（例如与其他律师交换文件），我会使用 LibreOffice 的 Writer；对于其他部分，我倾向于在 vim 中编写 Markdown 文件，并使用 pandoc 和 typst 进行转换。我打算在某个时候研究一下 tex，因为我有一位客户喜欢查看其 .tex 文件的差异对比，看起来相当整洁。

Presentations: reveal.js. File manager: Nautilus. PDFs: evince for most reading; Xournal++ for marking up PDFs; PDFarranger and pdftk for interfering with PDFs. Text expansion: espanso. Browser: Firefox or links. Local wiki / knowledge management: vimwiki. Disk encryption: LUKS. Client-side encryption of files before syncing them with Syncthing: Cryptomator.

演示文稿：reveal.js。文件管理器：Nautilus。PDF：evince 用于日常阅读；Xournal++ 用于标注 PDF；PDFarranger 和 pdftk 用于处理 PDF。文本扩展：espanso。浏览器：Firefox 或 links。本地维基/知识管理：vimwiki。磁盘加密：LUKS。在通过 Syncthing 同步文件前的客户端加密：Cryptomator。

Fediverse: I tend to use the Mastodon advanced web UI or, when I want fewer images, the TUI toot. Password manager: Bitwarden, using the vaultwarden server, with YubiKeys for managing more sensitive credentials. Markdown editor (for blogposts; I do presentations in vim or gedit): Apostrophe. Scanning: paperless-ngx. Label printing: there’s a great FOSS web UI for Brother (and perhaps other) label printers. I don’t print many labels, as we aim to be paperless, but it’s convenient when I need to do so.

联邦宇宙 (Fediverse)：我倾向于使用 Mastodon 的高级网页界面，或者在想要减少图片显示时使用 TUI 工具 toot。密码管理器：Bitwarden，使用 vaultwarden 服务器，并配合 YubiKeys 来管理更敏感的凭据。Markdown 编辑器（用于博客文章；演示文稿我用 vim 或 gedit 制作）：Apostrophe。扫描：paperless-ngx。标签打印：有一个很棒的自由开源网页界面，适用于 Brother（或许还有其他品牌）的标签打印机。由于我们力求无纸化，我打印的标签不多，但在需要时非常方便。

Why so many terminal-based tools? The simple answer is that I am very comfortable in a terminal, and I like them. They have fewer distractions and, when compared with most GUI software, are just - IMHO - easier to use, especially when I don’t need to move my hands away from the keyboard. So, while I don’t use them exclusively, I use mutt, vim, ikhal, ncmpcpp, newsboat, toot, links, and various other TUIs, frequently.

为什么使用这么多基于终端的工具？简单的回答是，我在终端里感到非常舒适，而且我喜欢它们。它们干扰更少，而且与大多数图形界面软件相比，在我看来它们更容易使用，尤其是当我不需要把手从键盘上移开时。因此，虽然我并非只用这些工具，但我经常使用 mutt、vim、ikhal、ncmpcpp、newsboat、toot、links 以及其他各种终端用户界面 (TUI)。

Everything here - other than Signal - is self-hosted, and I’m mostly using Intel NUCs now. I still have some Raspberry Pi devices, but fewer than I did. (Again, this doesn’t list everything; just the main applications.)

除了 Signal 之外，这里的所有东西都是自托管的，我现在主要使用 Intel NUC。我还有一些树莓派设备，但比以前少了。（再次说明，这并没有列出所有内容，仅列出了主要应用程序。）

Email (MTA): postfix / dovecot. File synchronisation: Syncthing. Video conferencing: Signal. Invoicing and tracking payments: InvoicePlane, just for generating PDF invoices. Clients don’t interact with it. “Case management” / “Matter management”: EspoCRM. VPN: WireGuard, using trailofbit’s algo ansible scripts on one machine, and PiVPN on another (albeit not on a Pi).

电子邮件 (MTA)：postfix / dovecot。文件同步：Syncthing。视频会议：Signal。发票与付款跟踪：InvoicePlane，仅用于生成 PDF 发票。客户不会直接与其交互。“案件管理”/“事务管理”：EspoCRM。VPN：WireGuard，在一台机器上使用 trailofbit 的 algo ansible 脚本，在另一台机器上使用 PiVPN（尽管不是在树莓派上运行）。

Vulnerability scanning: greenbone/OpenVAS. Monitoring: Uptime Kuma. Forge / hosted git repository: Forgejo. Password manager: vaultwarden. Website: it is a static site built via mkdocs, hosted on apache2. Fediverse: I am using the *glitch-soc Mastodon** fork. Knowledge management, and managing our law firm’s (numerous) policies and procedures: dokuwiki with the Markdown plugin. DNS: unbound, with Pi-Hole in front of it. Backups: restic and rsync. Collaborative document editing: I don’t. None, for various reasons.

漏洞扫描：greenbone/OpenVAS。监控：Uptime Kuma。代码托管/Git 仓库：Forgejo。密码管理器：vaultwarden。网站：这是一个通过 mkdocs 构建的静态网站，托管在 apache2 上。联邦宇宙：我使用的是 *glitch-soc Mastodon** 分支。知识管理以及管理我们律所（众多）的政策和程序：dokuwiki 配合 Markdown 插件。DNS：unbound，前端配有 Pi-Hole。备份：restic 和 rsync。协作文档编辑：我不使用。出于各种原因，目前没有使用任何此类工具。

I’m using a Pixel running GrapheneOS for my mobile device. I use F-Droid as the main app store. Using Android doesn’t thrill me, especially given Google’s direction of travel, but at the moment - despite trying quite a lot of different OSs and devices, including postmarketOS and Ubuntu Touch, as well as SailfishOS previously - I have not found something that does what I need better than GrapheneOS.

我的移动设备是一台运行 GrapheneOS 的 Pixel 手机。我主要使用 F-Droid 作为应用商店。使用 Android 并没有让我感到兴奋，尤其是考虑到 Google 的发展方向，但目前为止——尽管我尝试过许多不同的操作系统和设备，包括 postmarketOS、Ubuntu Touch 以及之前的 SailfishOS——我还没有发现比 GrapheneOS 更能满足我需求的方案。

No change here: zero problems. Many of my clients use Microsoft’s software, or Apple’s software.

这方面没有变化：零问题。我的许多客户都在使用微软或苹果的软件。

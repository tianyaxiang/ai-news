Meridian is a web-browser for MacOS built on GPUI and Servo. Meridian is already quite useful to browse websites that are light on javascript and layouting features. The browser is highly configurable: fonts, keybinds, colors, tabs and all.

Meridian 是一款基于 GPUI 和 Servo 构建的 MacOS 网络浏览器。对于那些对 JavaScript 和布局功能要求较低的网站，Meridian 目前已经相当好用。该浏览器具有高度的可配置性，包括字体、快捷键、颜色、标签页等各项设置。

To try Meridian, you can use nix: nix run git+https://tangled.org/oppi.li/meridian The project is developed on Tangled, all contributions are welcome, please do browse the list of open issues if you are looking to contribute!

若要尝试 Meridian，可以使用 nix 命令：nix run git+https://tangled.org/oppi.li/meridian。该项目在 Tangled 上开发，欢迎所有贡献；如果您有意参与贡献，请浏览待处理问题列表！

Meridian supports the following features: Address bar with typeahead, Vertical and horizontal tabs, Bookmarks and history, Per-site zoom, Audio and video playback, Reader mode, Tab previews, Typeahead from bookmarks and history, Context menu, Dark mode, Reader view.

Meridian 支持以下功能：带有预输入功能的地址栏、垂直和水平标签页、书签和历史记录、针对特定站点的缩放、音频和视频播放、阅读模式、标签页预览、来自书签和历史记录的预输入、上下文菜单、深色模式以及阅读视图。

Under the hood, Meridian is written in Rust and built on GPUI and Servo. Web pages and browser state is managed by Servo. The browser's chrome is drawn by gpui, the UI framework behind the Zed editor. The glue code to interface servo with gpui lives in separate library, gpui-servo, which exposes Servo as an ordinary gpui component, so anybody can now write a servo-based browser in GPUI!

在底层技术上，Meridian 使用 Rust 编写，并基于 GPUI 和 Servo 构建。网页和浏览器状态由 Servo 管理。浏览器的界面由 GPUI 绘制，这是 Zed 编辑器背后的 UI 框架。用于连接 Servo 和 GPUI 的粘合代码位于独立的库 gpui-servo 中，它将 Servo 作为一个普通的 GPUI 组件公开，因此现在任何人都可以使用 GPUI 编写基于 Servo 的浏览器！

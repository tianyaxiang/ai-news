### NVIDIA / SkillEvaluator

评估并改进 AI 代理技能和插件：涵盖质量、安全性、重叠度、兼容性以及在代理中的实际影响。📺 直播：专家问答：评估代理技能。SkillEvaluator 用于检查 AI 代理技能和插件，并衡量技能对任务结果的影响：从质量检查开始，然后比较使用与不使用该技能的运行结果。代理技能是由“代理技能规范”定义的指令和支持文件文件夹。SkillEvaluator 是 NVIDIA 验证技能流水线的一部分。

**Get started**
Check skills from your terminal, CI, or agent. 1. Run the CLI directly 2. Add it to your repo via CI 3. Wire it to your agent. Install with pip: `pip install skillevaluator` Or install with uv: `uv tool install skillevaluator`. Then check your skill, no key: `skillevaluator validate ./my-skill --tiers 1`. Other tiers: installation guide.

**入门指南**
通过终端、CI 或代理检查技能。1. 直接运行 CLI；2. 通过 CI 添加到你的仓库；3. 连接到你的代理。使用 pip 安装：`pip install skillevaluator`，或使用 uv 安装：`uv tool install skillevaluator`。然后检查你的技能（无需密钥）：`skillevaluator validate ./my-skill --tiers 1`。其他层级请参考安装指南。

**Our CI template checks every skill change. No evaluation code to maintain. Run this in your GitHub repository. It opens a setup PR: `skillevaluator ci init`. GitLab details: repository guide. Add the skill to Claude Code, Codex or another agent: `npx skills add NVIDIA/SkillEvaluator`. Then ask: "Is my skill any good?" See the agent guide.**

我们的 CI 模板会检查每一次技能变更，无需维护评估代码。在你的 GitHub 仓库中运行此命令，它会打开一个设置 PR：`skillevaluator ci init`。GitLab 详情请参考仓库指南。将技能添加到 Claude Code、Codex 或其他代理：`npx skills add NVIDIA/SkillEvaluator`。然后询问：“我的技能好用吗？”请参阅代理指南。

**⚡ Harness check: will your agent load your skill? Know in seconds. No LLM inference · No model key · No agent run. `skillevaluator harness-check ./my-skill`**

⚡ 兼容性检查：你的代理能加载你的技能吗？几秒钟内即可知晓。无需 LLM 推理，无需模型密钥，无需运行代理。`skillevaluator harness-check ./my-skill`

**Quickstart: Both use bundled text-analyzer. Start here. Requires Git and uv. First result: Run without an LLM. A deterministic quality score and findings. Use NVIDIA Build: Git, uv, and a Build API key. Model-backed rubric scores and feedback.**

快速入门：两者均使用捆绑的 text-analyzer。从这里开始。需要 Git 和 uv。第一个结果：无需 LLM 运行。获得确定性的质量评分和发现。使用 NVIDIA Build：需要 Git、uv 和 Build API 密钥。获得基于模型的准则评分和反馈。

**Install uv and Git, then get the example: `git clone --depth 1 https://github.com/NVIDIA/SkillEvaluator.git`, `cd SkillEvaluator`. uv provisions Python 3.13 and dependencies. Run without an LLM: `uv run --python 3.13 skillevaluator quality-check src/skillevaluator/tier3/reference_skills/text-analyzer -r cli -r json -o reports/first-quality`. No API key, scanner, GPU or Docker is needed. The example scores 88.8/100 (B), exits 0 and saves reports/first-quality/skillevaluator-quality.json. The passing threshold defaults to 70. This checks static quality; publication evidence stays INCOMPLETE. Security needs scanners; agent impact needs live evaluation. Replace the example path with your skill directory. See the keyless walkthrough.**

安装 uv 和 Git，然后获取示例：`git clone --depth 1 https://github.com/NVIDIA/SkillEvaluator.git`，`cd SkillEvaluator`。uv 会配置 Python 3.13 和依赖项。无需 LLM 运行：`uv run --python 3.13 skillevaluator quality-check src/skillevaluator/tier3/reference_skills/text-analyzer -r cli -r json -o reports/first-quality`。无需 API 密钥、扫描器、GPU 或 Docker。该示例得分为 88.8/100 (B)，退出代码为 0，并保存了 `reports/first-quality/skillevaluator-quality.json`。通过阈值默认为 70。这检查的是静态质量；发布证据仍为“不完整”。安全性需要扫描器；代理影响需要实时评估。将示例路径替换为你的技能目录。请参阅无密钥演练。

**Use NVIDIA Build: Eligible NVIDIA Developer Program members can use NVIDIA-hosted endpoints for free prototyping, subject to access terms and rate limits. Sign in at build.nvidia.com and complete enrollment. Open a model page, select Get API Key, and generate your key. Set the provider and key in the same terminal, then run the rubric check: `export SKILL_EVAL_LLM_PROVIDER=nv_build`, `export NVIDIA_API_KEY='nvapi-...'`, `uv run --python 3.13 --extra llm skillevaluator rubric-eval src/skillevaluator/tier3/reference_skills/text-analyzer -r cli -r json -o reports/first-build`. The command sends skill documentation to the model and saves feedback in reports/first-build/skillevaluator-rubric.json. No agent runtime or Docker is needed. Completed evaluations can still fail rubric thresholds. The same key supports Tier 2 embeddings and supported Tier 3 agents. See the Build walkthrough or provider configuration.**

使用 NVIDIA Build：符合条件的 NVIDIA 开发者计划成员可以使用 NVIDIA 托管的端点进行免费原型设计，受访问条款和速率限制约束。在 build.nvidia.com 登录并完成注册。打开模型页面，选择“获取 API 密钥”并生成你的密钥。在同一终端中设置提供商和密钥，然后运行准则检查：`export SKILL_EVAL_LLM_PROVIDER=nv_build`，`export NVIDIA_API_KEY='nvapi-...'`，`uv run --python 3.13 --extra llm skillevaluator rubric-eval src/skillevaluator/tier3/reference_skills/text-analyzer -r cli -r json -o reports/first-build`。该命令将技能文档发送给模型，并将反馈保存在 `reports/first-build/skillevaluator-rubric.json` 中。无需代理运行时或 Docker。完成的评估仍可能未达到准则阈值。同一密钥支持第 2 层嵌入和受支持的第 3 层代理。请参阅 Build 演练或提供商配置。

**Three-tier overview: Each tier is independent. Add its extra to your command.**

三层概述：每一层都是独立的。在你的命令中添加相应的额外参数。

| Tier | Question | Example after setup | Additional setup |
| :--- | :--- | :--- | :--- |
| Tier 1: Validation | Is the skill safe, well-formed and harness-compatible? | `uv run skillevaluator tier1 ./my-skill --no-llm` | External scanners for full static coverage; a provider and model clients enable LLM checks |
| Tier 2: Deduplication | Does guidance repeat or overlap? | `uv run --extra tier2 skillevaluator tier2 ./my-skill` | Embeddings and chat; add --catalog ./skill-catalog.json for inter-skill comparison |
| Tier 3: Live Evaluation | Does the skill help the agent? | `uv run --extra tier3 skillevaluator tier3 ./my-skill` | Provider access, a supported agent, and a running sandbox (Docker by default) |

| 层级 | 问题 | 设置后的示例 | 额外设置 |
| :--- | :--- | :--- | :--- |
| 第 1 层：验证 | 技能是否安全、格式规范且兼容？ | `uv run skillevaluator tier1 ./my-skill --no-llm` | 用于全面静态覆盖的外部扫描器；提供商和模型客户端启用 LLM 检查 |
| 第 2 层：去重 | 指导是否存在重复或重叠？ | `uv run --extra tier2 skillevaluator tier2 ./my-skill` | 嵌入和聊天；添加 --catalog ./skill-catalog.json 以进行技能间比较 |
| 第 3 层：实时评估 | 技能对代理有帮助吗？ | `uv run --extra tier3 skillevaluator tier3 ./my-skill` | 提供商访问权限、受支持的代理以及运行中的沙箱（默认为 Docker） |

**Tier 1 fetches pinned, verified SkillSpector and Gitleaks releases when they are missing; Semgrep is optional. See scanners. --no-llm does not remove scanner requirements; a scanner that cannot run is INCOMPLETE and exits nonzero. SkillSpector provides specialized skill security scanning; Harbor, the open-source agent evaluation framework, powers sandboxed agent runs. Tier 2 reports when inter-skill comparison did not run. Tier 3 autopilot reuses sources or creates one skill-grounded case with limited coverage. See tier guides.**

第 1 层在缺失时会获取已固定、已验证的 SkillSpector 和 Gitleaks 版本；Semgrep 是可选的。请参阅扫描器。--no-llm 不会移除扫描器要求；无法运行的扫描器会被标记为“不完整”并以非零状态退出。SkillSpector 提供专业的技能安全扫描；Harbor（开源代理评估框架）为沙箱代理运行提供支持。第 2 层会在技能间比较未运行时报告。第 3 层自动驾驶模式会重用源或创建一个覆盖范围有限的技能基础案例。请参阅层级指南。

**Run the combined pipeline: After setting up the provider, scanners, and agent sandbox, run all three tiers: `uv run --python 3.13 --extra all skillevaluator doctor --env-mode docker`, `uv run --python 3.13 --extra all skillevaluator validate ./my-skill`. doctor checks readiness, not inference success. validate runs all tiers with autopilot for skills. Use --tiers 1,2 to skip live evaluation or --tiers 1 for static checks. --no-autopilot requires an existing source. Other artifact types retain their applicable stages. Tier 1 gates validate. Tier 2 gates unless --no-block-on-dedup is set; Tier 3 gates only with --block-on-agent-eval. Model and managed-sandbox usage can incur charges; see runtime and cost. Standalone generation needs substantive evals/EVAL.md guidance, a --prompt file with task requests and outcomes, or matching retained traces. --force below replaces the autopilot starter; --refine refines it. Explicit --groun**

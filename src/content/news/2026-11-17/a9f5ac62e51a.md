Computer Science > Artificial Intelligence arXiv:2611.17341 (cs) [Submitted on 1 Sep 2026] Title: Tabular Population Priors as Structured Retrieval for EHR Medication Set Prediction Authors: Animesh Agarwal, Meysam Ghaffari, Nina Fatehi, Carlos Morato.

计算机科学 > 人工智能 arXiv:2611.17341 (cs) [提交于 2026 年 9 月 1 日] 标题：作为电子健康记录药物集预测结构化检索的表格化群体先验 作者：Animesh Agarwal, Meysam Ghaffari, Nina Fatehi, Carlos Morato。

Abstract: Medication prediction from electronic health records is a fixed vocabulary structured prediction problem, yet recent clinical RAG systems often treat it like open-ended case-based reasoning: retrieve similar patient admissions and ask an LLM to infer a medication set. This retrieval object is indirect—the model receives retrieved patient records while the target is a discrete set of medication class labels.

摘要：基于电子健康记录的药物预测是一个固定词汇表的结构化预测问题，然而近期的临床检索增强生成（RAG）系统通常将其视为开放式的基于案例的推理：检索相似的患者入院记录并要求大语言模型（LLM）推断药物集。这种检索对象是间接的——模型接收的是检索到的患者记录，而目标却是离散的药物类别标签集。

We propose a more task-aligned retrieval object: a tabular population prior—ranked medication class candidates from a sparse condition-medication co-occurrence table estimated from training admissions. Using PACERAG as a fixed downstream pipeline and replacing only its patient retriever, this drop-in swap improves F1 from 0.303 to 0.338 (+11.5% relative) and Jaccard from 0.218 to 0.237 on 1,004 heldout MIMIC-IV admissions, with no additional LLM calls and no inference time patient index.

我们提出了一种更符合任务要求的检索对象：表格化群体先验——即从训练入院记录中估计出的稀疏病情-药物共现表中排名的药物类别候选者。使用 PACERAG 作为固定的下游流水线，仅替换其患者检索器，这种直接替换在 1,004 例留出的 MIMIC-IV 入院记录上将 F1 分数从 0.303 提高到 0.338（相对提升 11.5%），Jaccard 系数从 0.218 提高到 0.237，且无需额外的 LLM 调用，也无需推理时的患者索引。

A non-LLM top-k baseline reaches F1=0.248, confirming the prior is predictive before LLM integration. Aggregate population statistics can provide a more task-aligned, efficient, and auditable retrieval source than patient-level nearest neighbors for fixed vocabulary EHR set prediction.

一个非 LLM 的 top-k 基准达到了 F1=0.248，证实了该先验在集成到 LLM 之前就具有预测性。对于固定词汇表的电子健康记录集预测，汇总的群体统计数据可以提供比患者级最近邻更符合任务要求、更高效且可审计的检索源。

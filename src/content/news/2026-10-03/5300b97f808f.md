# DeepSeek Harness Desktop for macOS and Windows

**Everything is a plugin**
Install plugins, or create them through chat in “Creator mode”, to extend tools, skills, and the interface.

**一切皆为插件**
安装插件，或通过“创建者模式”（Creator mode）在对话中直接创建插件，以扩展工具、技能和界面功能。

**Adapt to your workflow**
Enable the Scheduled tasks plugin to start tasks anytime and run recurring work on schedule. Stay on top of progress and inspect tool call details when needed. (e.g., "Every Friday at 17:00 Beijing time, summarize this week's project notes in a weekly report.")

**适配您的工作流**
启用“定时任务”（Scheduled tasks）插件，可随时启动任务并按计划运行重复性工作。随时掌握进度，并在需要时检查工具调用的详细信息。（例如：“每周五北京时间 17:00，将本周的项目笔记总结为周报。”）

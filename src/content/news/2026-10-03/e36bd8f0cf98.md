# K-Dense BYOK: An Open-Source AI Research Assistant That Runs Locally and Keeps a Hash-Chained Lab Notebook
# K-Dense BYOK：一款本地运行并维护哈希链式实验记录的开源 AI 研究助手

K-Dense BYOK (bring your own keys) is a free, open-source AI research assistant for scientists in any field that runs on the researcher's own computer. The researcher supplies access to a model of their choice, hosted or running locally, and the application supplies everything else: a place for the work to run, a layer of scientific scaffolding, and a complete record. Each project is an ordinary folder, so the data, the code, the results, and the record stay on a machine the researcher administers and can be read years later without the application.

K-Dense BYOK（自带密钥）是一款免费的开源 AI 研究助手，适用于各领域的科学家，且直接在研究人员的个人电脑上运行。研究人员只需提供其选择的模型访问权限（无论是托管模型还是本地运行模型），应用程序即可提供其余一切所需：工作运行环境、科学框架层以及完整的记录。每个项目都是一个普通的文件夹，因此数据、代码、结果和记录都保存在研究人员管理的机器上，即便多年后无需该应用程序，这些内容依然可读。

Three things separate it from a chat assistant or a general-purpose coding agent. It ships a library of written scientific procedures, guided workflow templates, catalogs of where research data can be found, and reviewer and writer roles the agent can hand work to. It keeps a Living Lab Notebook whose entries link into an argument and are added to but never erased. And it records what happened by watching what the agent does rather than by taking the agent's word for it, in a log the agent has no tool that can write to.

它与聊天助手或通用编程代理有三个显著区别。首先，它内置了一个科学程序库、引导式工作流模板、研究数据来源目录，以及代理可以分配任务的“审稿人”和“撰稿人”角色。其次，它维护着一本“动态实验记录本”（Living Lab Notebook），其中的条目相互关联形成论证，且只增不删。最后，它通过观察代理的行为来记录过程，而不是听信代理的自述；记录日志存储在代理无法写入的受限区域。

That choice targets the most common failure, model overclaiming, in our earlier benchmark of nine frontier models, by making claims checkable rather than preventing them. On twenty interdisciplinary research prompts, scored under a rubric fixed in advance, K-Dense BYOK led two managed platforms on both scientific quality and research execution. Its deliverables were the only ones that recorded the software they ran in, and the only ones that usually arrived with a command that regenerates the results. One of the managed platforms ran the same frontier model and supplied neither. Those environment records were files the agent wrote, not part of the observed log, which does not yet capture the software environment itself. The code is available under the MIT license at this https URL.

这一设计旨在解决我们在之前对九个前沿模型进行基准测试时发现的最常见问题——模型过度宣称（model overclaiming）。通过使声明可验证而非单纯限制声明，该系统提高了透明度。在二十个跨学科研究提示词的测试中，按照预设标准评分，K-Dense BYOK 在科学质量和研究执行力方面均领先于两个托管平台。它是唯一能够记录运行软件环境的系统，也是唯一通常附带可复现结果命令的系统。其中一个托管平台虽然运行了相同的模型，但未能提供上述任何一项。那些环境记录仅是代理写入的文件，而非观察日志的一部分，因为目前的观察日志尚未捕获软件环境本身。代码已在 MIT 许可下发布，详情请见此链接。

# Apple Pass Designer

**Introducing Pass Designer**
Whether you’re creating passes for a local fitness center, a small music venue, a global airline, or a national coffee chain, Pass Designer makes it easy to craft and preview passes that reflect your business.

**介绍 Pass Designer**
无论您是为当地健身中心、小型音乐场所、全球航空公司还是全国性连锁咖啡店创建票证，Pass Designer 都能让您轻松制作并预览能够体现您品牌形象的票证。

**Building passes made easy**
Start with templates provided by Apple or your own to capture the personality of your brand. You can use your preferred design tool to create images for passes — such as logos, backgrounds, or strip images — then bring them into Pass Designer to complete a pass design. As you edit, Pass Designer updates the preview in real time to show how a pass will appear on iPhone and Apple Watch. The preview uses the same rendering as iOS and watchOS, so what you see in Pass Designer is exactly what customers will see on their device.

**轻松构建票证**
您可以从 Apple 提供的模板或您自己的模板开始，以捕捉您品牌的个性。您可以使用自己偏好的设计工具为票证创建图像（例如徽标、背景或条状图像），然后将其导入 Pass Designer 以完成票证设计。在您编辑时，Pass Designer 会实时更新预览，展示票证在 iPhone 和 Apple Watch 上的显示效果。该预览使用与 iOS 和 watchOS 相同的渲染方式，因此您在 Pass Designer 中看到的内容与客户在其设备上看到的内容完全一致。

**Colors and appearance**
Easily adjust a pass’s background, foreground, and label colors.

**颜色与外观**
轻松调整票证的背景、前景和标签颜色。

**Adaptable layouts**
Pass Designer supports designs that take full advantage of the latest advances in Apple Wallet, as well as backward-compatible passes.

**适配布局**
Pass Designer 支持充分利用 Apple Wallet 最新功能的各种设计，同时也支持向后兼容的票证。

**Standard fields**
Each pass type includes standard fields for displaying information, and you can edit each field’s content directly in Pass Designer.

**标准字段**
每种票证类型都包含用于显示信息的标准字段，您可以直接在 Pass Designer 中编辑每个字段的内容。

**Validation**
Pass Designer validates your pass as you work and alerts you to any issues such as missing required key values and unexpected definitions.

**验证**
Pass Designer 会在您工作时验证您的票证，并提醒您注意任何问题，例如缺少必要的键值或出现意外的定义。

**Semantic tags**
For boarding passes and event tickets, semantic tags add structured data — such as event dates, venue locations, or flight details — that the system uses to enable features like Siri Suggestions, Calendar integration, and Maps directions. Pass Designer lets you edit semantic tags directly in the UI, and you can view a semantic and non-semantic pass side by side. It can also automatically generate a backward-compatible pass structure from your semantic data that doesn’t require semantic tags, ensuring your pass works where they may not be supported.

**语义标签**
对于登机牌和活动门票，语义标签可以添加结构化数据（例如活动日期、场地位置或航班详情），系统利用这些数据来启用 Siri 建议、日历集成和地图导航等功能。Pass Designer 允许您直接在界面中编辑语义标签，并且您可以并排查看带有语义标签和不带语义标签的票证。它还可以根据您的语义数据自动生成无需语义标签的向后兼容票证结构，确保您的票证在不支持语义标签的环境中也能正常工作。

**下载测试版**
Pass Designer 测试版需要 macOS 27 或更高版本。如需下载，请使用您的 Apple 账户登录。如果出现提示，请完成免费注册并接受《Apple 开发者协议》。

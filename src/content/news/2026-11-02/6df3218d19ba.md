Introduction to Programming in ATS
Hongwei Xi ATS Trustful Software, Inc. Copyright © 2010-201? Hongwei Xi

《ATS 编程入门》
Hongwei Xi，ATS Trustful Software, Inc. 版权所有 © 2010-201? Hongwei Xi。

As a programming language, ATS is both syntax-rich and feature-rich. This book introduces the reader to some core features of ATS, including basic functional programming, simple types, (recursively defined) datatypes, polymorphic types, dependent types, linear types, theorem-proving, programming with theorem-proving (PwTP), and template-based programming.

作为一种编程语言，ATS 既拥有丰富的语法，也具备强大的功能。本书向读者介绍了 ATS 的一些核心特性，包括基础函数式编程、简单类型、（递归定义的）数据类型、多态类型、依赖类型、线性类型、定理证明、基于定理证明的编程（PwTP）以及基于模板的编程。

Although the reader is not assumed to be familiar with programming in general, the book is likely to be rather dense for someone without considerable programming experience. All rights are reserved. Permission is granted to print this document for personal use.

尽管并不要求读者具备通用的编程基础，但对于缺乏丰富编程经验的人来说，本书的内容可能会显得相当晦涩。保留所有权利。允许打印本文档供个人使用。

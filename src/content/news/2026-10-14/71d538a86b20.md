Solving complex engineering tasks: At Google, we’ve been using Argon on our hardest engineering problems. Over the past few weeks, software engineers have been shipping high-quality code faster than ever. Argon in Antigravity has helped teams increase agentic code submissions by more than 35% while reducing code rollbacks by nearly a third.

解决复杂的工程任务：在 Google，我们一直使用 Argon 来处理最棘手的工程问题。在过去几周里，软件工程师交付高质量代码的速度比以往任何时候都快。Antigravity 中的 Argon 帮助团队将智能体代码提交量提高了 35% 以上，同时将代码回滚率降低了近三分之一。

Untangling browser feature code in Chrome: Argon helped the Chrome team separate core webpage handling from a ~6 million line legacy folder of browser features held within Chromium’s 40 million-line codebase. Piping multiple clean code changes at a time, Argon helped the team finish an architectural refactor across hundreds of files, completing months of work in weeks. For Chrome's billions of global users, this will unlock the ability for live webpages to move fluidly between tabs, side panels, and floating windows without reloading, eliminating an entire category of browser crashes.

梳理 Chrome 浏览器功能代码：Argon 帮助 Chrome 团队将核心网页处理功能从 Chromium 4000 万行代码库中约 600 万行的遗留浏览器功能文件夹中分离出来。通过一次性导入多个整洁的代码更改，Argon 帮助团队完成了跨数百个文件的架构重构，在几周内完成了原本需要数月的工作。对于 Chrome 的数十亿全球用户而言，这将使实时网页能够在标签页、侧边栏和浮动窗口之间流畅切换而无需重新加载，从而消除了一整类浏览器崩溃问题。

Optimizing a production Python codebase in hours: Argon in Antigravity is helping the team behind Google's open-source Agent Development Kit (ADK), a framework powering enterprise agents, push their performance engineering further. The team gave Argon their .agents/skills rulebook and a one-paragraph goal to eliminate framework overhead without breaking existing apps. Working autonomously overnight, Argon surfaced optimizations, now live in google/adk-python, that cut in-memory session prep time by 40% in long sessions and sped up cold imports by 21%. 在数小时内优化生产环境 Python 代码库：Antigravity 中的 Argon 正在帮助 Google 开源 Agent Development Kit (ADK)（一个为企业智能体提供支持的框架）背后的团队进一步提升其性能工程。团队向 Argon 提供了 .agents/skills 规则手册和一个简短的目标，即在不破坏现有应用的前提下消除框架开销。Argon 在夜间自主工作，发现了多项优化方案，现已在 google/adk-python 中上线，将长会话中的内存会话准备时间缩短了 40%，并将冷导入速度提高了 21%。阅读工程深度解析以了解更多信息。

Quantum chemistry open-source package optimization: xTB (Semiempirical Extended Tight-Binding) is one of the most-cited open-source quantum chemistry packages for molecules. Scientists use it to predict molecules' 3D shapes and to screen large numbers of drug and materials candidates. Using Argon in Antigravity, our researchers made xTB up to 2.3x faster at predicting molecular structures and 1.8x faster at conformer search. The changes have been contributed to the official xTB repository on GitHub.

量子化学开源包优化：xTB（半经验扩展紧束缚）是分子领域引用率最高的开源量子化学软件包之一。科学家利用它来预测分子的 3D 形状并筛选大量的药物和材料候选物。通过在 Antigravity 中使用 Argon，我们的研究人员使 xTB 在预测分子结构方面的速度提高了 2.3 倍，在构象搜索方面的速度提高了 1.8 倍。这些更改已贡献给 GitHub 上的官方 xTB 存储库。

Making our open Gemma models nearly three times as fast: Using Argon, we achieved a 2.85x end-to-end inference speedup on an A100 via vLLM (accelerating throughput from ~37,900 to over 108,000 tokens per second on Gemma 4 E2B) with 100% token parity and zero quality drop in just a few days, a process that would usually take months. Check out the upstream pull requests (optimizing everything from attention tuning to speculative decoding) to see the exact changes.

使我们的开源 Gemma 模型速度提升近三倍：使用 Argon，我们在几天内通过 vLLM 在 A100 上实现了 2.85 倍的端到端推理加速（在 Gemma 4 E2B 上将吞吐量从约 37,900 token/秒提升至超过 108,000 token/秒），且保持了 100% 的 Token 一致性，质量零下降，而这一过程通常需要数月时间。查看上游 Pull Request（涵盖从注意力调优到推测解码的所有优化）以了解具体更改。

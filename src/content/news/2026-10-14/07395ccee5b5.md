# xtool-org / xtool

xtool Cross-platform Xcode replacement. Build and deploy iOS apps with SwiftPM on Linux, Windows, and macOS.

xtool 是一个跨平台的 Xcode 替代品。它支持在 Linux、Windows 和 macOS 上使用 SwiftPM 构建并部署 iOS 应用。

Overview xtool is a cross-platform (Linux/WSL/macOS) tool that replicates Xcode functionality with open standards. ✅ Build a SwiftPM package into an iOS app ✅ Sign and install iOS apps ✅ Interact with Apple Developer Services programmatically

概述：xtool 是一款跨平台（Linux/WSL/macOS）工具，通过开放标准复制了 Xcode 的功能。✅ 将 SwiftPM 包构建为 iOS 应用 ✅ 签名并安装 iOS 应用 ✅ 以编程方式与 Apple 开发者服务进行交互。

Getting Started Follow the guide to install xtool Installation (Linux/Windows) Installation (macOS) Create and run your first xtool-powered app by following the tutorial! Examples Screenshot

入门：请按照指南安装 xtool。安装（Linux/Windows）、安装（macOS）。按照教程创建并运行您的第一个由 xtool 驱动的应用！示例、截图。

Command line interface $ xtool --help OVERVIEW: Cross-platform Xcode replacement USAGE: xtool <subcommand> OPTIONS: -h, --help Show help information. CONFIGURATION SUBCOMMANDS: setup Set up xtool for iOS development auth Manage Apple Developer Services authentication sdk Manage the Darwin Swift SDK DEVELOPMENT SUBCOMMANDS: new Create a new xtool SwiftPM project dev Build and run an xtool SwiftPM project ds Interact with Apple Developer Services DEVICE SUBCOMMANDS: devices List devices install Install an ipa file to your device uninstall Uninstall an installed app launch Launch an installed app See 'xtool help <subcommand>' for detailed help.

命令行界面：$ xtool --help。概述：跨平台 Xcode 替代品。用法：xtool <子命令>。选项：-h, --help 显示帮助信息。配置子命令：setup 设置 iOS 开发环境，auth 管理 Apple 开发者服务认证，sdk 管理 Darwin Swift SDK。开发子命令：new 创建新的 xtool SwiftPM 项目，dev 构建并运行 xtool SwiftPM 项目，ds 与 Apple 开发者服务交互。设备子命令：devices 列出设备，install 将 ipa 文件安装到设备，uninstall 卸载已安装的应用，launch 启动已安装的应用。查看 'xtool help <子命令>' 获取详细帮助。

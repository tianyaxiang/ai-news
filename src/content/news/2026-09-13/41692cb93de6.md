# xkcd-font: The xkcd font
# xkcd-font：xkcd 字体

xkcd-font Fonts derived from the handwriting of @randallmunroe, the xkcd webcomic author. Yes, it really is his handwriting, and he hopes we fix the pesky kerning: [Credit to xkcd] This repository contains two fonts, xkcd Script and xkcd, each with their own characteristics (and limitations):
xkcd-font 是源自 xkcd 网络漫画作者 @randallmunroe 手迹的字体。没错，这确实是他的笔迹，他也希望我们能修复那些恼人的字距问题：[致谢 xkcd]。该仓库包含两款字体：xkcd Script 和 xkcd，它们各自拥有不同的特点（以及局限性）：

Font: xkcd Script
字体：xkcd Script

xkcd Script is a font derived from a handwriting sample provided by Randall. It is far less uniform than xkcd, and we think it is therefore more like a true script font. You can see the font as a live preview, or for more information about the font and how it is constructed see the xkcd-script/README. Pre-built font files are available directly in this repository: xkcd-script.ttf | xkcd-script.woff
xkcd Script 是一款源自 Randall 所提供手写样本的字体。它比 xkcd 字体更不规整，因此我们认为它更像是一款真正的连笔手写体。你可以查看该字体的实时预览，或参阅 xkcd-script/README 以获取关于该字体及其构建方式的更多信息。预构建的字体文件可直接在本仓库中获取：xkcd-script.ttf | xkcd-script.woff

Font: xkcd
字体：xkcd

The xkcd font was originally created by Randall, and was used in xkcd "The Pace of Modern Life" (April 1st, 2013). It is considerably more uniform than xkcd Script, which can result in more legibility at the cost of being slightly less like the actual xkcd comic. The pre-built font file is available directly in this repository: xkcd.otf
xkcd 字体最初由 Randall 创建，并曾用于 xkcd 的漫画《The Pace of Modern Life》（2013 年 4 月 1 日）。它比 xkcd Script 规整得多，这虽然提高了可读性，但代价是看起来与真实的 xkcd 漫画略有出入。预构建的字体文件可直接在本仓库中获取：xkcd.otf

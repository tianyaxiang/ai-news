# Vim Classic

Vim Classic - long term support for Vim. Vim Classic is a fork of Vim 8.x for long-term maintenance, providing a stable, dependable editor — maintained entirely by humans.

Vim Classic - Vim 的长期支持版本。Vim Classic 是 Vim 8.x 的一个分支，旨在进行长期维护，提供一个稳定、可靠的编辑器——完全由人类维护。

Documentation: Browse online or read :help in Vim Classic. Source code: See SourceHut. Mailing lists: vim-classic-announce, vim-classic-discuss, vim-classic-devel. IRC: #vim-classic on irc.libera.chat.

文档：在线浏览或在 Vim Classic 中阅读 :help。源代码：查看 SourceHut。邮件列表：vim-classic-announce, vim-classic-discuss, vim-classic-devel。IRC：irc.libera.chat 上的 #vim-classic。

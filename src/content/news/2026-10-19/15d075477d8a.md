# QML for C & Zig

QML for C & Zig Hi all, Following up on the previous update (Build System Improvements, Centralized Overview, etc.), QML is now available. For those unfamiliar, this introduces a more declarative paradigm that leverages the existing breadth of each library.

C 与 Zig 的 QML 大家好，继之前的更新（构建系统改进、集中概览等）之后，QML 现已发布。对于不熟悉的人来说，这引入了一种更具声明性的范式，利用了每个库现有的广度。

Importantly, this additional paradigm can coexist in a single application so developers still have full control. One of the areas that this enhances is development for portable devices such as the Steam Deck.

重要的是，这种额外的范式可以在同一个应用程序中共存，因此开发人员仍然拥有完全的控制权。它增强的领域之一是针对 Steam Deck 等便携式设备的开发。

Speaking more to the development experience, as the examples demonstrate, much of the expected functionality for QML is available. In addition to leveraging the bindings for private Qt classes, some advanced metaprogramming can also be had.

谈到开发体验，正如示例所展示的那样，QML 的大部分预期功能都已可用。除了利用私有 Qt 类的绑定外，还可以进行一些高级元编程。

For typical usage, if simpler options exist, those are encouraged. Some portions of the API can be very low level. Over time, more common operations can probably be augmented by helper functions if enough need emerges.

对于典型用法，如果存在更简单的选项，则鼓励使用这些选项。API 的某些部分可能非常底层。随着时间的推移，如果出现足够的需求，更常见的操作可能会通过辅助函数来增强。

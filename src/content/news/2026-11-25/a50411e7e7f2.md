# GTA VI PC recompilation project shut down by Take-Two

游戏模组社区正竞相让《侠盗猎车手 VI》（GTA VI）在 PC 上运行，但其中一项重大努力已于今日被 Take-Two 叫停。由 15 岁的“NotRexed”发起的粉丝项目“Leonida”，在收到《GTA VI》发行商 Take-Two 的数字千年版权法案（DMCA）下架通知后已销声匿迹。

Leonida was designed to translate a leaked GTA VI Xbox build to run natively on Windows. Cyberleek, the leaker who posted multiple GTA VI gameplay videos over the summer, published a full Xbox build of the game earlier this week. The leak has kicked recompilation efforts up a notch, as modders race to reverse-engineer the game’s code and rebuild it into native PC code.

Leonida 的设计初衷是将泄露的《GTA VI》Xbox 版本转换为在 Windows 上原生运行。曾在夏季发布多个《GTA VI》游戏视频的泄密者 Cyberleek 于本周早些时候发布了该游戏的完整 Xbox 版本。此次泄露加速了重新编译的工作，模组制作者们正竞相逆向工程游戏代码，并将其重构为原生 PC 代码。

Some have managed to get the game to boot on PC, but recompiling the full game won’t be easy — even with help from AI tools like Claude. Take-Two is trying to slow this progress, and its IP enforcement team targeted the main GitHub repository for Leonida and more than 2,900 forks of it, claiming that it “infringes upon Take-Two’s copyrighted works and facilitates copyright infringement of Rockstar Games title, Grand Theft Auto VI.”

一些人已经成功让游戏在 PC 上启动，但要重新编译整个游戏绝非易事——即使有 Claude 等人工智能工具的辅助。Take-Two 正试图减缓这一进程，其知识产权执法团队针对 Leonida 的主 GitHub 存储库及其 2,900 多个分支采取了行动，声称其“侵犯了 Take-Two 的版权作品，并助长了对 Rockstar Games 旗下作品《侠盗猎车手 VI》的版权侵权行为。”

PortWatch VI is tracking the efforts to recompile, emulate, or port the leaked Xbox build over to PC. At the time of publishing, the VIctory project and forks of it are leading the way. People are also trying to use XCL, a compatibility layer that runs Xbox Series X games on a Windows PC, to get GTA VI running.

PortWatch VI 正在追踪将泄露的 Xbox 版本重新编译、模拟或移植到 PC 上的工作。截至本文发布时，VIctory 项目及其分支处于领先地位。人们也在尝试使用 XCL（一种在 Windows PC 上运行 Xbox Series X 游戏的兼容层）来让《GTA VI》运行起来。

At this point, it seems like Take-Two might not be able to avoid the inevitable here. The clock started ticking down to the release of the PC version last week, and if recent reports are true, we might see it in a few months. If GTA VI is close to being officially ready for PC, we could hear about a release before modders manage to get the game running on PC unofficially.

目前看来，Take-Two 可能无法避免这一必然结果。PC 版本的发布倒计时已于上周开始，如果近期的报道属实，我们可能在几个月内就能见到它。如果《GTA VI》的 PC 官方版本即将准备就绪，我们或许会在模组制作者成功实现非官方 PC 运行之前，就听到有关正式发布的消息。

**Introduction A walking policy can keep Microduck balanced, but it does not tell the robot how to steer around an obstacle in its path. In this workflow, we reuse the walking policy from our first Microduck tutorial and keep its weights fixed. This follow-up trains a separate avoidance controller using time-of-flight (ToF) sensing. You choose a direction with a gamepad; the controller adjusts the velocity command before passing it to the walking policy.**

简介：行走策略可以保持 Microduck 的平衡，但它无法告诉机器人如何绕过路径上的障碍物。在此工作流中，我们复用了第一个 Microduck 教程中的行走策略，并保持其权重不变。本后续教程通过飞行时间（ToF）传感训练一个独立的避障控制器。用户通过游戏手柄选择方向，控制器在将速度指令传递给行走策略之前对其进行调整。

**NVIDIA Isaac Lab is an open-source framework for training policies across thousands of GPU-parallel simulations and it provides the robot-learning environment. Newton simulates physics and the sensor’s depth measurements. We will cover the control architecture, train on varied obstacle layouts, evaluate the resulting policies, and prepare the interface for hardware testing.**

NVIDIA Isaac Lab 是一个开源框架，用于在数千个 GPU 并行仿真中训练策略，并提供机器人学习环境。Newton 则负责模拟物理环境和传感器的深度测量。我们将涵盖控制架构、在不同障碍物布局上进行训练、评估所得策略，并为硬件测试准备接口。

**1. Set Microduck obstacle avoidance in Isaac Lab For simulation and training, prepare: A Linux system with a compatible NVIDIA GPU and driver. See the Isaac Lab installation guide for platform requirements. Git with Git LFS, and the uv package manager. For physical-robot testing, prepare: A configured Microduck. Load the same backlash walking-policy export used by the navigation task. A supported ToF sensor with its configuration recorded. A paired gamepad and a level test area with obstacles.**

1. 在 Isaac Lab 中设置 Microduck 避障。仿真与训练准备：一台配备兼容 NVIDIA GPU 和驱动程序的 Linux 系统（平台要求请参阅 Isaac Lab 安装指南）、安装 Git（含 Git LFS）以及 uv 包管理器。物理机器人测试准备：一台已配置好的 Microduck、加载与导航任务相同的反冲行走策略导出文件、一个已记录配置的受支持 ToF 传感器、一个已配对的游戏手柄以及一个带有障碍物的平坦测试区域。

**Quick install Install uv if it is not already installed. Then clone the exp/microduck branch of the Isaac Lab repository and install its dependencies: git lfs install git clone --branch exp/microduck https://github.com/isaac-sim/IsaacLab.git cd IsaacLab uv sync --frozen Once setup is complete, list the available Microduck environments and presets: uv run isaaclab list_envs --keyword MicroDuck --show_presets**

快速安装：如果尚未安装 uv，请先安装。然后克隆 Isaac Lab 仓库的 exp/microduck 分支并安装依赖项：`git lfs install`、`git clone --branch exp/microduck https://github.com/isaac-sim/IsaacLab.git`、`cd IsaacLab`、`uv sync --frozen`。设置完成后，列出可用的 Microduck 环境和预设：`uv run isaaclab list_envs --keyword MicroDuck --show_presets`。

**Download the walking policy Download and export the upstream backlash walking checkpoint once before training. The obstacle avoidance task loads the exported walking policy automatically. uv run isaaclab play \ --task IsaacContrib-Velocity-Rough-MicroDuck \ --rl_library rsl_rl --checkpoint pretrained \ --num_envs 1 --visualizer none \ --video newton_gl --video_length 1 \ presets=backlash**

下载行走策略：在训练前，先下载并导出上游的反冲行走检查点。避障任务会自动加载导出的行走策略。运行命令：`uv run isaaclab play --task IsaacContrib-Velocity-Rough-MicroDuck --rl_library rsl_rl --checkpoint pretrained --num_envs 1 --visualizer none --video newton_gl --video_length 1 presets=backlash`。

**At each episode reset, the environment code automatically samples a layout, shuffles the props, and varies their placement and rotation. Most courses scatter obstacles ahead of the duck, with a smaller mix of clear paths, barriers and passages. The code also mirrors layouts and mixes aligned and staggered rows. Goals start ahead of the duck. Movement commands guide it toward the goal while the policy adjusts them around obstacles.**

在每次剧集重置时，环境代码会自动采样布局、打乱道具，并改变它们的位置和旋转角度。大多数路线将障碍物散布在机器鸭前方，并混合了少量清晰路径、屏障和通道。代码还会镜像布局，并混合对齐和交错的行。目标设置在机器鸭前方。移动指令引导它朝目标前进，同时策略会根据障碍物对指令进行调整。

**3. Understand how ToF sensing guides the walking policy The IsaacContrib-ObstacleAvoidance-Flat-MicroDuck task separates obstacle avoidance from balance. A navigation policy uses ToF sensing to adjust forward, lateral, and yaw commands at 50 Hz. The frozen walking policy then converts those commands into joint actions, allowing the robot to learn obstacle avoidance without retraining its walking behavior.**

3. 理解 ToF 传感如何引导行走策略：`IsaacContrib-ObstacleAvoidance-Flat-MicroDuck` 任务将避障与平衡分离开来。导航策略使用 ToF 传感以 50 Hz 的频率调整前进、横向和偏航指令。冻结的行走策略随后将这些指令转换为关节动作，使机器人能够在无需重新训练行走行为的情况下学习避障。

**During training, the navigation policy’s actor receives ToF history and body and controller state available on the real robot. Its critic has access to additional simulation state to guide learning, but is not needed for deployment. Rewards encourage progress toward the goal, safe arrivals, and movement around obstacles. Following a movement command earns credit only when the robot makes progress with sufficient clearance; risky approaches reduce that credit. Penalties discourage fast approaches, abrupt command changes, collisions, and falls.**

在训练期间，导航策略的执行器（actor）接收真实机器人上可用的 ToF 历史记录以及身体和控制器状态。其评价器（critic）可以访问额外的仿真状态以指导学习，但在部署时不需要。奖励机制鼓励向目标前进、安全到达以及绕过障碍物。只有当机器人在保持足够间隙的情况下取得进展时，遵循移动指令才会获得奖励；危险的接近方式会减少奖励。惩罚机制则用于抑制快速接近、突兀的指令变化、碰撞和跌倒。

**The obstacle-avoidance task lives in isaaclab_tasks.contrib.microduck_obstacle. Its configuration is in obstacle_avoidance_env_cfg.py, ToF sensing is in sensors.py, and actions, commands, observations and rewards are organized under mdp/.**

避障任务位于 `isaaclab_tasks.contrib.microduck_obstacle` 中。其配置在 `obstacle_avoidance_env_cfg.py` 中，ToF 传感在 `sensors.py` 中，而动作、指令、观测和奖励则组织在 `mdp/` 下。

**Model the ToF sensor MicroDuckToFCamera extends Newton’s LegacyMultiMeshRayCasterCamera to model the VL53L5CX—a compact time-of-flight (ToF) sensor on the microduck that measures distance across an 8×8 grid at 15Hz. The simulated sensor has a 45° field of view and a 0.12–4 m range. It follows the duck’s head, with placement similar to the sensor on the real duck. Real recordings informed the sensor placement and floor readings in simulation. Training adds noise, delays and missing measurements—including near the grid’s edges—to expose the policy to imperfect data.**

模拟 ToF 传感器：`MicroDuckToFCamera` 扩展了 Newton 的 `LegacyMultiMeshRayCasterCamera`，用于模拟 VL53L5CX——这是一种安装在 Microduck 上的紧凑型飞行时间（ToF）传感器，能以 15Hz 的频率测量 8×8 网格的距离。模拟传感器具有 45° 的视场角和 0.12–4 米的量程。它跟随机器鸭的头部，放置位置与真实机器鸭上的传感器相似。真实的记录数据为仿真中的传感器放置和地面读数提供了参考。训练过程中加入了噪声、延迟和缺失测量（包括网格边缘附近的测量），以使策略能够适应不完美的数据。

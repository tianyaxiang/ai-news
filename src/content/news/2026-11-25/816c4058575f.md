# How to Find Any Substack Newsletter's Best Posts with Python (2026)

每个 Substack 时事通讯都有一些文章获得的赞、评论和转发远超其他内容。这些文章揭示了读者真正想要的东西。在本教程中，你将通过大约 15 行代码，将任何时事通讯的所有文章提取到 Python 中并进行排名。你将获得每篇文章的以下信息：标题、副标题、日期和作者；点赞数、评论数、转发数和字数；是否为付费内容；免费文章的全文（非常适合研究或大语言模型数据集）。免责声明：本文使用的爬虫由我开发。它读取的是 Substack 的公开数据，因此你不需要登录，也不需要 Substack 的 API 密钥。

### Get the top posts of a newsletter
This gets the 20 most popular posts of Lenny's Newsletter. It works with name.substack.com addresses and with custom domains.
```python
import os
from apify_client import ApifyClient
client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("neronbaez/substack-scraper").call(run_input={
    "publications": ["lennysnewsletter.com"],
    "sort": "top", # "top" = most popular, "new" = latest
    "maxPostsPerPublication": 20,
    "includeContent": True, # full text of free posts
})
posts = list(client.dataset(run.default_dataset_id).iterate_items())
for p in posts:
    print(f'{p["likes"]:>5} likes | {p["comments"]:>3} comments | '
          f'{p["wordCount"]:>5} words | {p["title"]}')
```

### Find what works: free vs paid, short vs long
With the posts in a list, two quick questions are one line each:
```python
from statistics import mean
free = [p["likes"] for p in posts if not p["isPaid"]]
paid = [p["likes"] for p in posts if p["isPaid"]]
print("avg likes free:", round(mean(free)) if free else "-")
print("avg likes paid:", round(mean(paid)) if paid else "-")

long_posts = [p["likes"] for p in posts if p["wordCount"] > 2500]
short_posts = [p["likes"] for p in posts if p["wordCount"] <= 2500]
print("avg likes long:", round(mean(long_posts)) if long_posts else "-")
print("avg likes short:", round(mean(short_posts)) if short_posts else "-")
```
Run it on two or three newsletters in your niche and you will quickly see which formats and topics get the most engagement.

### 找出有效内容：免费与付费，短文与长文
将文章放入列表后，只需一行代码即可回答两个快速问题：
```python
from statistics import mean
free = [p["likes"] for p in posts if not p["isPaid"]]
paid = [p["likes"] for p in posts if p["isPaid"]]
print("免费平均点赞数:", round(mean(free)) if free else "-")
print("付费平均点赞数:", round(mean(paid)) if paid else "-")

long_posts = [p["likes"] for p in posts if p["wordCount"] > 2500]
short_posts = [p["likes"] for p in posts if p["wordCount"] <= 2500]
print("长文平均点赞数:", round(mean(long_posts)) if long_posts else "-")
print("短文平均点赞数:", round(mean(short_posts)) if short_posts else "-")
```
在你的领域中选择两到三个时事通讯运行此代码，你很快就能看出哪些格式和主题获得的互动最多。

### Going further
Read the comments. Set "includeComments": True and each comment comes back as its own item with text, author, likes and date. That is the fastest way to learn what readers ask for. Compare newsletters. Put several in "publications" (for example ["lennysnewsletter.com", "astralcodexten.com"]) and group the results by the publication field. Build a dataset. With "sort": "new" and a higher maxPostsPerPublication, you get a clean archive of full-text posts for search or RAG. Only free posts include the full text; paid posts include a preview. Cost. You pay per result: $0.002 per post and $0.0005 per comment, so the latest 100 posts of a newsletter cost $0.20.

### 深入探索
阅读评论。设置 "includeComments": True，每条评论都会作为单独的项目返回，包含文本、作者、点赞数和日期。这是了解读者需求最快的方法。比较时事通讯。在 "publications" 中放入多个地址（例如 ["lennysnewsletter.com", "astralcodexten.com"]），并按 publication 字段对结果进行分组。构建数据集。通过设置 "sort": "new" 和更高的 maxPostsPerPublication，你可以获得用于搜索或 RAG 的全文文章存档。只有免费文章包含全文；付费文章仅包含预览。成本。按结果付费：每篇文章 0.002 美元，每条评论 0.0005 美元，因此获取某时事通讯的最新 100 篇文章仅需 0.20 美元。

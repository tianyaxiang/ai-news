# Your Claude Plan Could Be Worth $11,000 a Month

The most expensive Claude plan costs $200 a month. At API prices, the usage it allows could be worth about $11,000 a month. I did not measure that plan. I measured mine. I pay $100 a month for Max 5x, and in the last 30 days my Claude Code usage would have cost about $5,000 at API prices.

最昂贵的 Claude 方案每月收费 200 美元。按 API 价格计算，其允许的使用量价值约为每月 11,000 美元。我没有测量那个方案，我测量的是我自己的。我每月支付 100 美元购买 Max 5x 方案，在过去 30 天里，我的 Claude Code 使用量按 API 价格计算约为 5,000 美元。

The weekly limit stopped me twice, and those stops let me put a dollar value on the plan: about $5,500 a month. The $200 plan allows twice as much usage per week, so it is worth about twice as much. Anthropic sells its plans in "times Pro usage", not in dollars, so the plan page does not show these numbers.

每周限额曾两次限制了我的使用，这些限制让我能够为该方案估算出一个美元价值：每月约 5,500 美元。200 美元的方案每周允许的使用量是前者的两倍，因此其价值也约为前者的两倍。Anthropic 以“Pro 使用量的倍数”而非美元来销售其方案，因此方案页面并未显示这些数字。

I calculated them from the transcripts that Claude Code keeps on my disk. In this article I'll show how I measured it, what each plan is worth in API dollars, where the tokens went, and why your own number is probably smaller. The case: one developer (me), one machine, Claude Code on the Max 5x plan, from October 4 to November 3, 2026.

我根据 Claude Code 保存在我磁盘上的记录计算出了这些数值。在本文中，我将展示我是如何进行测量的、每个方案按 API 美元计算的价值、Token 的去向，以及为什么你自己的数字可能更小。案例背景：一名开发者（我）、一台机器、使用 Max 5x 方案的 Claude Code，时间跨度为 2026 年 10 月 4 日至 11 月 3 日。

Most of the work was coding with agents on Claude Opus 5.5. Every number in this article is an estimate from my own usage, and the $11,000 is an extrapolation from my plan to the $200 one. Anthropic does not publish its limits in dollars, and I have no data on what my usage costs Anthropic.

大部分工作是使用 Claude Opus 5.5 上的智能体进行编码。本文中的每个数字都是根据我个人使用情况的估算值，而 11,000 美元是从我的方案推算到 200 美元方案的结果。Anthropic 并未以美元形式公布其限额，我也没有关于我的使用量对 Anthropic 造成多少成本的数据。

And my real month on Max 5x: I paid $100 and used ~$5,000 at API prices. That is $3.30 a day against $160 a day, a 98% discount.

我在 Max 5x 方案上的真实一个月情况是：我支付了 100 美元，使用了价值约 5,000 美元的 API 额度。这相当于每天 3.30 美元对比每天 160 美元，享受了 98% 的折扣。

How I Measured It: Claude Code writes every session to a JSONL file under ~/.claude/projects/. Each answer from the model carries a usage block with four counts: input tokens, cache writes, cache reads and output tokens. I summed every answer of the 30 days, from the main sessions and from the subagents, and priced each one with the public API price table.

我是如何测量的：Claude Code 会将每次会话写入 ~/.claude/projects/ 下的一个 JSONL 文件中。模型给出的每个回答都包含一个使用情况块，其中有四个计数：输入 Token、缓存写入、缓存读取和输出 Token。我汇总了 30 天内所有来自主会话和子智能体的回答，并使用公开的 API 价格表为每一项定价。

--- | --- | --- | --- | ---

Claude Sonnet 5.5 | $2 | $2.50 / $4 | $0.10 | $10

What My Plan Is Worth: The Max 5x plan has two limits: one per 5 hours and one per week. I hit both. Each stop shows a message with the time of the reset, so I summed the API-equivalent usage inside each window, up to the stop.

我的方案价值几何：Max 5x 方案有两个限额：一个是每 5 小时限额，一个是每周限额。我两个都触发了。每次停止时都会显示一条包含重置时间的消息，因此我汇总了每个窗口内直到停止时的 API 等效使用量。

Limit | Times I hit it | API-equivalent at the stop
--- | --- | ---
Weekly | 2 | ~$1,250
5 hours | 3 | ~$150 to ~$180

限额 | 触发次数 | 停止时的 API 等效价值
--- | --- | ---
每周 | 2 | ~1,250 美元
5 小时 | 3 | ~150 美元至 ~180 美元

A week has 33.6 windows of 5 hours, and the weekly limit runs out after 7 or 8 full ones. So for heavy work, the weekly limit is the one that stops you. Both times, it stopped me on a Saturday, about one day before the weekly reset. From the weekly limit, the monthly ceiling is about $1,250 × 4.35 ≈ $5,500 of API usage for $100, about 55 times the price. In these 30 days, I used about 90% of it.

一周有 33.6 个 5 小时窗口，而每周限额在用满 7 或 8 个窗口后就会耗尽。因此对于繁重的工作，每周限额才是限制你的那个。两次触发时，都是在周六，大约在每周重置前一天。根据每周限额，月度上限约为 1,250 美元 × 4.35 ≈ 5,500 美元的 API 使用量，而费用仅为 100 美元，约为价格的 55 倍。在这 30 天里，我使用了大约 90% 的额度。

What the $200 Plan Is Worth: The Ultra plan costs $200. It gives "10x Pro usage" per week instead of "5x", and it has no 5-hour limit for verified accounts. If 10x is exactly twice 5x, its weekly ceiling is about $2,500 of API usage, and its monthly ceiling is about $11,000. Both plans also include API credits for the Claude Platform: $100 a month on Max and $200 on Ultra. I did not count them here. The ratio stays at about 55×.

200 美元的方案价值几何：Ultra 方案收费 200 美元。它每周提供“10 倍 Pro 使用量”而非“5 倍”，且对于已验证账户没有 5 小时限额。如果 10 倍正好是 5 倍的两倍，那么其每周上限约为 2,500 美元的 API 使用量，月度上限约为 11,000 美元。这两个方案还包含用于 Claude 平台的 API 额度：Max 方案每月 100 美元，Ultra 方案每月 200 美元。我在此处未计入这些额度。倍数保持在约 55 倍左右。

The $200 plan does not make a token cheaper. It buys twice the room, and it removes the 5-hour stop. I don't have Ultra, so this number is an extrapolation from my measurements, not a measurement.

200 美元的方案并不会让 Token 变得更便宜。它购买的是两倍的空间，并移除了 5 小时的停止限制。我没有 Ultra 方案，所以这个数字是我根据测量结果进行的推算，而非实际测量值。

98% of my tokens were cache reads. An agent sends the whole conversation again on every call: the instructions, the files it read, the tool results. I made about 56,000 calls, and each one read a large context again. The prompt cache makes that cheap. On Opus 5.5, a cache read costs $0.20 per million tokens, 5% of the input price. Even so, the context is most of the bill: cache reads and cache writes together are 82% of the cost. The output, which includes all the code the model wrote, is only 18%.

我 98% 的 Token 是缓存读取。智能体在每次调用时都会重新发送整个对话：指令、它读取的文件、工具结果。我进行了大约 56,000 次调用，每一次都重新读取了大量上下文。提示词缓存（Prompt Cache）让这变得很便宜。在 Opus 5.5 上，缓存读取的价格是每百万 Token 0.20 美元，仅为输入价格的 5%。即便如此，上下文仍占据了账单的大部分：缓存读取和缓存写入合计占成本的 82%。包含模型编写的所有代码的输出部分仅占 18%。

Why Your Number Is Probably Smaller: A plan is worth what you actually use, and I am a heavy user. Anthropic's Claude Code documentation says that across enterprise deployments, the average developer costs about $13 per active day and $150 to $250 per month at API prices. On the $100 plan, that is a discount of about 35% to 60%. That is still a good deal, but it is far from 98%. To use $11,000 a month on the $200 plan, you would need about 45 to 75 times the usage of that average developer. My usage was 20 to 30 times that average, and it filled about 90% of my $100 plan.

为什么你的数字可能更小：一个方案的价值取决于你的实际使用量，而我是一个重度用户。Anthropic 的 Claude Code 文档显示，在企业部署中，普通开发者按 API 价格计算，平均每天花费约 13 美元，每月花费 150 至 250 美元。对于 100 美元的方案，这大约是 35% 到 60% 的折扣。这仍然很划算，但远达不到 98%。要在 200 美元的方案上每月使用 11,000 美元，你需要达到普通开发者使用量的 45 到 75 倍。我的使用量是该平均值的 20 到 30 倍，并且已经填满了我的 100 美元方案约 90% 的额度。

Is Anthropic Losing Money on Me? I don't know. The API price is a list price, not a cost. Anthropic itself sells the same tokens at different prices: the Batch API costs 50% of the normal price, and a cache read costs 5% of an input token. 98% of my tokens were the cheapest kind. Many subscribers also use much less than the ceiling. I found analyst estimates of Anthropic's margins, but they disagree with each other and I could not verify them, so I don't quote them here. What I can say is narrower: my subscription price is not a cost, and the API price is not a cost either.

Anthropic 在我身上亏钱吗？我不知道。API 价格是标价，而不是成本。Anthropic 自己以不同的价格销售相同的 Token：批量 API（Batch API）的成本是正常价格的 50%，而缓存读取的成本是输入 Token 的 5%。我 98% 的 Token 都是最便宜的那种。许多订阅者的使用量也远低于上限。我找到了一些分析师对 Anthropic 利润率的估算，但他们各执一词，我无法核实，因此不在此引用。我能说的是更具体的一点：我的订阅价格不是成本，API 价格也不是成本。

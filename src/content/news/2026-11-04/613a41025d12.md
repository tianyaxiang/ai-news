# anomalyco / hex

Hex is local voice dictation for Mac, Windows and Linux. Hold a key, speak, and it pastes.

Hex 是一款适用于 Mac、Windows 和 Linux 的本地语音听写工具。按住按键，说话，它就会自动粘贴。

How it works: hold the shortcut, speak, then let go. Hex transcribes on your device and pastes into whatever app you're in. The first run downloads a speech model; after that, nothing leaves your machine.

工作原理：按住快捷键，说话，然后松开。Hex 会在你的设备上进行转录，并粘贴到你当前使用的任何应用程序中。首次运行时会下载语音模型；此后，没有任何数据会离开你的机器。

Experimental features live in Labs, at the bottom of the sidebar. Downloads: Stable is the current release. Dev is the newest build of dev and updates itself from the dev channel.

Or install with: Homebrew: `brew install --cask anomalyco/tap/hex`, AUR: `yay -S hex-bin`, install script (Linux): `curl -fsSL https://anoma.ly/hex/install-linux.sh | sh`, Nix: `nix profile add github:anomalyco/hex`. More docs are in docs/.

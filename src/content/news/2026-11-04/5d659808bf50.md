Introduction The NetBSD Project is pleased to announce NetBSD 11.1, the first point release of the NetBSD 11 stable branch.

简介：NetBSD 项目很高兴地宣布 NetBSD 11.1 的发布，这是 NetBSD 11 稳定分支的第一个点版本。

Upgrade instructions An existing installation can be upgraded by booting an installation image and selecting the Upgrade option. If you are using other update methods, update the kernel and modules first, then reboot and update your userspace.

升级说明：现有的安装可以通过引导安装镜像并选择“升级”（Upgrade）选项来进行升级。如果您使用其他更新方法，请先更新内核和模块，然后重启并更新您的用户空间。

Changes since NetBSD 11.0 This release primarily focuses on security and bug fixes, since our aim was to get it released as soon as possible to address certain security issues.

自 NetBSD 11.0 以来的变更：此版本主要侧重于安全性和错误修复，因为我们的目标是尽快发布该版本以解决特定的安全问题。

Ports alpha: Fixed a boot hang occurring on unpatched QEMU. alpha: Fixed kernel stack pointer alignment leading to panics during test suite runs. (PR 60865) amd64, i386: Reduced the strictness of the "WARNING: no TOD clock present" check. amd64, i386: Fixed a panic on the Zhaoxin KX-7000 and other late-model CPUs from VIA/Zhaoxin.

移植版：alpha：修复了在未打补丁的 QEMU 上发生的引导挂起问题。alpha：修复了导致测试套件运行期间内核栈指针对齐引发的内核恐慌（PR 60865）。amd64, i386：降低了“警告：未检测到 TOD 时钟”（WARNING: no TOD clock present）检查的严格程度。amd64, i386：修复了在兆芯 KX-7000 及其他 VIA/兆芯新款 CPU 上发生的内核恐慌。

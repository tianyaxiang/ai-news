# The "$60 Gaming PC" – AMD BC-250 (2025)
# “60美元游戏PC”——AMD BC-250 (2025)

Ok it’s not exactly $60 but you can get the board itself for that amount of money on eBay if you’re lucky, but on average the price is around $70-$100 (as of November 2025) which is still very cheap considering you can play Cyberpunk 2077 on this.
虽然它并不完全是60美元，但如果你运气好，在eBay上确实能以这个价格买到主板本体。平均价格通常在70到100美元之间（截至2025年11月），考虑到它能运行《赛博朋克2077》，这个价格依然非常便宜。

What is this? The BC-250 began life not as a gaming board, but as part of a crypto-mining rig. The “trick” behind it: the BC-250 uses a cut-down version of the APU from a PlayStation 5 (PS5) — a repurposed SoC (system-on-chip). Specifically: many PS5 APUs that didn’t meet console spec (“binned” or “defective” for console use) got repurposed. Instead of being discarded, these chips were re-used for mining/higher-density hardware.
这是什么？BC-250最初并非作为游戏主板设计，而是加密货币挖矿设备的一部分。其背后的“玄机”在于：BC-250使用的是PlayStation 5 (PS5) APU的精简版——一种重新利用的SoC（片上系统）。具体来说，许多未达到主机规格（被视为“分级筛选”或“缺陷”）的PS5 APU被重新利用。这些芯片没有被丢弃，而是被用于挖矿或高密度硬件设备中。

The original deployment: there was a rack-mount mining “server” build from ASRock that used 12 BC-250 cards, targeted at miners — sold as a “barebone” 4U server chassis. As mainstream GPU mining lost favor, many BC-250 units started circulating second-hand — offering hardware enthusiasts an opportunity to experiment. “BC-250 is basically a Playstation 5 chip that didn’t make the cut, and was released as a crypto-mining board.”
最初的部署方式是：华擎（ASRock）推出过一款机架式挖矿“服务器”，内置12块BC-250卡，主要面向矿工销售，以“准系统”4U服务器机箱的形式提供。随着主流GPU挖矿热潮的消退，许多BC-250开始在二手市场流通，为硬件爱好者提供了实验的机会。“BC-250本质上就是没能通过PS5质检的芯片，被重新包装成了加密货币挖矿板。”

### Key Specs & Hardware Details
### 关键规格与硬件细节

From public teardowns, benchmarks, and community experiments, BC-250 hardware specs are roughly:
根据公开的拆解、基准测试和社区实验，BC-250的硬件规格大致如下：

*   **CPU:** 6 × Zen 2 cores (12 threads) — a cut-down PS5 APU.
*   **CPU：** 6核Zen 2架构（12线程）——精简版的PS5 APU。
*   **GPU / iGPU:** RDNA 2 architecture, 24 Compute Units (CUs) — reduced from the 36 CUs of a full PS5 APU.
*   **GPU / 核显：** RDNA 2架构，24个计算单元（CU）——相比完整版PS5 APU的36个CU有所缩减。
*   **Memory:** 16 GB GDDR6 memory shared between CPU and GPU — there are no DDR4/DDR5 slots in a typical BC-250 board.
*   **内存：** 16GB GDDR6内存，由CPU和GPU共享——典型的BC-250主板上没有DDR4/DDR5插槽。
*   **I/O & connectivity:** Even though it looks like a “GPU card,” it works as a single-board PC — includes DisplayPort, USB (2.0/3.0), Ethernet, M.2 NVMe slot (for storage), power header (8-pin PCIe), CMOS battery, and backplate I/O shield.
*   **I/O与连接性：** 尽管它看起来像一张“显卡”，但它实际上是一台单板电脑——包含DisplayPort接口、USB (2.0/3.0)、以太网口、M.2 NVMe插槽（用于存储）、电源接口（8-pin PCIe）、CMOS电池以及背板I/O挡板。

### Performance benchmarks & real-world behavior
### 性能基准测试与实际表现

Earlier reports suggested some instability with drivers, but recent community patches and updated drivers have improved support. Community tests showed surprising results: e.g. one test rig running BC-250 reportedly ran games like Cyberpunk 2077, GTA V, Counter-Strike 2, Hitman 3 — at playable framerates (not high-end, but enough for a budget build). Given enough power (cooling + PSUs) and tuning (BIOS tweaks, Linux driver config), some people report a gaming experience “close to an entry-level modern GPU.”
早期的报告指出驱动程序存在一些不稳定性，但最近社区发布的补丁和更新的驱动程序改善了支持情况。社区测试显示了令人惊讶的结果：例如，一台运行BC-250的测试机据称可以以可玩的帧率运行《赛博朋克2077》、《GTA V》、《反恐精英2》、《杀手3》等游戏（虽然不是高端体验，但对于预算有限的装机方案来说已经足够）。在提供充足的电力（散热+电源）和调优（BIOS调整、Linux驱动配置）后，一些用户反馈其游戏体验“接近入门级现代显卡”。

**Cooling**
**散热**
The BC-250 comes with a server-style closed finstack. It’s possible to use a blower fan to cool it, and there are even 3D-printed case designs that keep the original heatsink untouched (you’ll find these in my how-to repo linked below). However, for good cooling performance, you’ll need to modify the finstack and open it up. This allows you to use one or two 120 mm fans for proper airflow. Be aware that this is a destructive modification — I’ve explained one method for doing it in the how-to repository. Additionally, I refreshed the thermal pads and thermal paste for optimal cooling performance.
BC-250自带服务器风格的封闭式散热鳍片。使用涡轮风扇进行散热是可行的，甚至有3D打印的机箱设计可以保留原始散热器（你可以在我下方链接的教程仓库中找到这些设计）。然而，为了获得良好的散热性能，你需要对鳍片进行改造并将其打开，这样就可以使用一个或两个120mm风扇来获得更好的气流。请注意，这是一种破坏性改造——我在教程仓库中解释了其中一种方法。此外，我还更换了导热垫和导热膏，以达到最佳散热效果。

**The unified memory**
**统一内存**
The BC-250 has 16 GB of unified memory, but by default it’s split between the CPU and GPU—typically 8 GB/8 GB (or in some cases 4 GB/12 GB). To use the device for gaming, you need to modify this and force a 512 MB allocation as VRAM. This may sound counterintuitive, but remember that this is an APU, not a traditional CPU/GPU setup. To change these settings, the BIOS must be flashed to a custom 3.00 BIOS version that unlocks the Chipset configuration menu. This used to require an EEPROM programmer—at least according to documentation from about a year ago. Fortunately, there is now a bootable BIOS Flasher image that can handle the job much more easily.
BC-250拥有16GB统一内存，但默认情况下会在CPU和GPU之间分配——通常是8GB/8GB（有时是4GB/12GB）。为了将其用于游戏，你需要修改此设置，强制分配512MB作为显存（VRAM）。这听起来可能有些反直觉，但请记住，这是一个APU，而不是传统的CPU/GPU组合。要更改这些设置，必须将BIOS刷入解锁了芯片组配置菜单的自定义3.00版本。根据大约一年前的文档，这曾经需要EEPROM编程器。幸运的是，现在有了可引导的BIOS刷写镜像，可以更轻松地完成这项工作。

**OS**
**操作系统**
You can install Windows, but because this isn’t typical hardware, you won’t have proper graphics drivers. Most users run Arch-based Linux distributions instead. I went with Manjaro Linux, which works flawlessly. The Linux version of Steam works out of the box.
你可以安装Windows，但由于这不是典型的硬件，你将无法获得合适的显卡驱动。大多数用户选择运行基于Arch的Linux发行版。我选择了Manjaro Linux，它运行得非常完美。Linux版本的Steam可以直接开箱即用。

**机箱**

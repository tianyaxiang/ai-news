Meta has launched what it calls the “most capable” open-weight model in the United States. Dubbed Muse Spark Open, the model also has the distinction of having been designed to work with Macs.

Meta 推出了其在美国所谓的“最强”开放权重模型。该模型被称为 Muse Spark Open，其独特之处在于专为 Mac 电脑设计。

The new model, which leverages 816 billion parameters and a 1 million token context window, claims to offer superior performance to other popular open-weight models, according to evaluation results released by Meta on Thursday. Muse Spark Open is natively multimodal and built for complex coding tasks and agentic labor.

根据 Meta 周四发布的评估结果，这款拥有 8160 亿参数和 100 万 token 上下文窗口的新模型，声称比其他流行的开放权重模型具有更优越的性能。Muse Spark Open 原生支持多模态，专为复杂的编码任务和代理工作而构建。

It has also been designed to run locally on Apple’s computers. However, you will still need a lot of power to run the model locally, with a requirement of at least 1 terabyte of RAM, per Engadget. The model will run best via the Mac Studio that comes equipped with the M5 Ultra chip.

它还被设计为可以在苹果电脑上本地运行。然而，据 Engadget 报道，在本地运行该模型仍需要强大的算力，且至少需要 1TB 的内存。该模型在配备 M5 Ultra 芯片的 Mac Studio 上运行效果最佳。

Still, if you can muster the memory, Muse Spark Open may prove a significant work horse for coding and other desktop tasks. Meta says that it paired the model with Muse Code, its AI coding terminal, and deployed it to various agentic workflows, including coding fixes for a Mastodon client that included “bug fixes, new features, [and] full build.”

尽管如此，如果你能满足内存要求，Muse Spark Open 可能会成为编码和其他桌面任务的重要主力。Meta 表示，他们将该模型与 AI 编码终端 Muse Code 配对，并将其部署到各种代理工作流中，包括为 Mastodon 客户端进行编码修复，涵盖了“错误修复、新功能 [以及] 完整构建”。

The company says it also deployed it in the service of running DaVinci Resolve, the high-end video editing software, revealing that the model was capable of reviewing and cropping footage. Open-weight models provide a number of distinct industry advantages that aren’t afforded by closed and proprietary models.

该公司还表示，已将其部署用于运行高端视频编辑软件 DaVinci Resolve，并展示了该模型具备审阅和剪辑素材的能力。开放权重模型提供了封闭式专有模型所不具备的多种独特行业优势。

Open-weight models can be significantly more cost-efficient and can also offer transparency and flexibility that closed source models don’t allow. Meta is making the new model available now through a number of different API platforms.

开放权重模型在成本效益上可以显著更高，并能提供闭源模型所不允许的透明度和灵活性。Meta 目前已通过多个不同的 API 平台提供该新模型。

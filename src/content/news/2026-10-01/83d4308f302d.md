# Reddit says it has to cut back access to ‘Old Reddit’ because of AI bots
# Reddit 表示，为应对 AI 机器人，将进一步限制“旧版 Reddit”的访问权限

Reddit is further limiting who can use the “Old Reddit” experience as part of its efforts to combat scraping and automated traffic. Reddit recently started forcing users to log in to be able to use Old Reddit, but in the “next few months,” the company says that you’ll have to be logged in and have used Old Reddit within the last six months from when the change rolls out to be able to continue browsing the platform with the classic experience.
作为打击数据抓取和自动化流量努力的一部分，Reddit 正在进一步限制“旧版 Reddit”（Old Reddit）的使用权限。Reddit 最近开始强制要求用户登录才能使用旧版界面，但该公司表示，在“未来几个月”内，用户不仅需要登录，还必须在变更生效前的六个月内使用过旧版 Reddit，才能继续以经典界面浏览该平台。

Reddit says the six-month window covers “the vast majority of all Old Reddit users.” The announcement didn’t go into detail, but it’s clearly aimed at blocking not just new account creation for bots, but also any bots that might access unused or abandoned accounts. As part of the changes, Reddit will stop supporting RSS feeds on November 13th because RSS is “now a common surface for large-scale scraping and automated abuse,” and suggested replacements like Discord Relay for moderation help.
Reddit 表示，这六个月的窗口期覆盖了“绝大多数旧版 Reddit 用户”。虽然公告没有提供详细说明，但这显然旨在阻止机器人创建新账号，同时也为了拦截那些可能访问闲置或废弃账号的机器人。作为调整的一部分，Reddit 将于 11 月 13 日停止支持 RSS 订阅，理由是 RSS “目前已成为大规模抓取和自动化滥用的常见渠道”，并建议使用 Discord Relay 等工具作为版主管理的替代方案。

Reddit: If you use RSS for feeds outside of a community you moderate, there is no replacement. We know RSS has been a beloved part of the open web for a long time, and we’re grateful to everyone who used it to stay connected to Reddit.
Reddit：如果您在所管理的社区之外使用 RSS 订阅，目前没有替代方案。我们深知 RSS 长期以来一直是开放网络中备受喜爱的一部分，我们也感谢每一位通过它与 Reddit 保持联系的用户。

The company has been waging war against unsanctioned access to its data for some time, including blocking the Internet Archive’s Wayback Machine to prevent AI scraping, suing Anthropic over alleged unauthorized bot access, and striking deals with Google and OpenAI to use Reddit data for training. Reddit knows that Old Reddit is beloved by many users, and in May 2025, CEO Steve Huffman said the company would “keep it online as long as people are using it.” But this past August, Huffman said that Reddit had gotten to a point where “we need to make some changes” because the experience was being used by “everyone who spams, scrapes, or does anything bad on Reddit.”
长期以来，该公司一直在打击未经授权的数据访问行为，包括封锁互联网档案库（Internet Archive）的 Wayback Machine 以防止 AI 抓取，起诉 Anthropic 涉嫌未经授权的机器人访问，并与 Google 和 OpenAI 达成协议，允许其使用 Reddit 数据进行训练。Reddit 深知旧版界面深受许多用户喜爱，2025 年 5 月，首席执行官 Steve Huffman 曾表示，只要还有人在使用，公司就会“让它保持在线”。但今年 8 月，Huffman 表示 Reddit 已经到了“必须做出一些改变”的地步，因为旧版界面正被“所有在 Reddit 上发送垃圾信息、抓取数据或进行恶意行为的人”所利用。

In its announcement today, Reddit said that the recent login requirement for Old Reddit “helped reduce scraping and automated abuse” but “still allowed any logged-in account to access Old Reddit, including accounts with no prior Old Reddit use.” Logged-in moderators, however, will still be able to use Old Reddit without a recent usage requirement.
在今天的公告中，Reddit 表示，近期对旧版 Reddit 实施的登录要求“有助于减少抓取和自动化滥用”，但“仍然允许任何已登录的账号访问旧版界面，包括那些此前从未用过旧版界面的账号”。不过，已登录的版主仍可使用旧版 Reddit，且不受近期使用记录的限制。

Reddit also shared updates for the previously announced transition moving apps and bots that use Reddit’s public data API to the company’s developer platform. Reddit will begin removing API access for users that haven’t registered their apps by January 12th, 2027, and all remaining public API access “will end in March 2027.”
Reddit 还分享了关于此前宣布的过渡计划的最新进展，即要求使用 Reddit 公共数据 API 的应用程序和机器人迁移至公司的开发者平台。Reddit 将于 2027 年 1 月 12 日起，取消未注册应用的用户的 API 访问权限，所有剩余的公共 API 访问权限“将于 2027 年 3 月终止”。

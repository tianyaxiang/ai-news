# openclaw / openclaw

**OpenClaw 🦞 — Your assistant, on your devices, in your chats**
OpenClaw 🦞 — 你的个人助理，运行在你的设备上，存在于你的聊天中。

OpenClaw is an open-source AI assistant that runs on your own computer and meets you in the channels you already use: Discord, iMessage, Slack, Teams, Telegram, WhatsApp, and 20+ more, plus native apps for macOS, iOS, Android, Windows, and Linux.
OpenClaw 是一款开源 AI 助理，它运行在你自己的电脑上，并集成在你已经在使用的聊天平台中：包括 Discord、iMessage、Slack、Teams、Telegram、WhatsApp 等 20 多种平台，此外还提供适用于 macOS、iOS、Android、Windows 和 Linux 的原生应用。

One Gateway runs it as a personal assistant on a laptop or as a shared team deployment; configuration is the only difference. Yours, with no catch. State, memory, and credentials live on your hardware.
通过一个网关（Gateway），它既可以作为笔记本电脑上的个人助理，也可以作为团队共享部署；两者唯一的区别在于配置。它是完全属于你的，没有任何隐形条件。状态、记忆和凭据都存储在你自己的硬件上。

Models and agent harnesses (Claude, Codex, local models) are plugins you can swap without changing anything else. Your prompts go to the model provider and chat platforms you configure, plus any diagnostics export you enable yourself; by default OpenClaw itself phones home for nothing but a daily version check, anonymous feature statistics are opt-in, and update.checkOnStart: false disables both (what OpenClaw sends).
模型和代理框架（如 Claude、Codex、本地模型）都是插件，你可以随意更换而无需改动其他任何部分。你的提示词（Prompts）只会发送给你配置的模型提供商和聊天平台，以及你自己启用的诊断导出数据；默认情况下，OpenClaw 除了每日版本检查外不会向外发送任何数据，匿名功能统计是可选的，设置 `update.checkOnStart: false` 即可禁用这两项（OpenClaw 发送的所有内容）。

OpenClaw is stewarded by the OpenClaw Foundation, an independent 501(c)(3), and has no paid tier, hosted service, or token. The architecture case — trusted gateway, untrusted execution, deterministic policy — is in Why OpenClaw.
OpenClaw 由独立的 501(c)(3) 非营利组织 OpenClaw Foundation 管理，没有付费层级、托管服务或代币。关于其架构案例（受信任的网关、不受信任的执行、确定性策略）的详细说明，请参阅“Why OpenClaw”。

### Install
### 安装

The installer supports macOS, Linux, and Windows. It provisions a supported Node.js runtime when needed.
安装程序支持 macOS、Linux 和 Windows。它会在需要时自动配置受支持的 Node.js 运行时。

**# macOS / Linux / WSL2**
```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

**# Windows PowerShell**
```powershell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

Already manage Node.js? Install the published package instead (Node 24.16+ or 26.1+; Node 26 recommended):
如果你已经管理了 Node.js，可以直接安装已发布的包（要求 Node 24.16+ 或 26.1+；推荐使用 Node 26）：

```bash
npm install -g openclaw@latest --allow-scripts=openclaw
```

That command is for npm 12 or npm 11.16+. On npm 11.15 and earlier, omit `--allow-scripts=openclaw`. See the installation guide for the lifecycle script contract, Docker, Nix, and other deployment paths.
该命令适用于 npm 12 或 npm 11.16+。对于 npm 11.15 及更早版本，请省略 `--allow-scripts=openclaw`。有关生命周期脚本契约、Docker、Nix 及其他部署路径的详细信息，请参阅安装指南。

### Quick start
### 快速开始

On a fresh install, the installer scripts start onboarding automatically. Complete the wizard they open. If you installed the package directly with npm, pnpm, or Bun, run:
全新安装后，安装脚本会自动启动引导程序。请完成弹出的向导。如果你是直接通过 npm、pnpm 或 Bun 安装的包，请运行：

```bash
openclaw onboard --install-daemon
```

After onboarding:
引导完成后：

```bash
openclaw gateway status
openclaw dashboard
```

Onboarding verifies model access, creates the workspace, and configures the Gateway. The last command opens the Control UI; send a message there to confirm the assistant is working. See the getting started guide for channel setup and troubleshooting.
引导程序会验证模型访问权限、创建工作区并配置网关。最后一条命令会打开控制界面（Control UI）；在界面中发送一条消息以确认助理是否正常工作。有关频道设置和故障排除，请参阅入门指南。

### How it fits together
### 架构组成

The Gateway is the local control plane for sessions, tools, events, and channel connections. The Control UI, CLI, and TUI connect to the Gateway. Channels bring the assistant to WhatsApp, Telegram, Slack, Discord, Google Chat, Signal, iMessage, and other messaging services. Companion apps and nodes add voice, Canvas, camera, screen, and device-local actions on supported platforms. OpenClaw works with hosted and local model providers. Its tools, skills, and plugins extend what an assistant can do.
网关是用于会话、工具、事件和频道连接的本地控制平面。控制界面（Control UI）、CLI 和 TUI 都连接到网关。频道将助理带入 WhatsApp、Telegram、Slack、Discord、Google Chat、Signal、iMessage 等消息服务中。配套应用和节点在受支持的平台上增加了语音、Canvas、摄像头、屏幕和设备本地操作功能。OpenClaw 支持托管和本地模型提供商。其工具、技能和插件扩展了助理的能力。

### Security
### 安全性

Treat inbound messages as untrusted input. DM-capable channels pair unknown senders by default; approve a pairing request with `openclaw pairing approve <channel> <code>`. Tools run on the host for the main session unless you configure sandboxing. Read the security guide, exposure runbook, and sandboxing guide before connecting other users or exposing the Gateway remotely.
请将入站消息视为不受信任的输入。支持私信（DM）的频道默认会配对未知发送者；使用 `openclaw pairing approve <channel> <code>` 来批准配对请求。除非你配置了沙盒，否则工具将在主会话的主机上运行。在连接其他用户或远程暴露网关之前，请务必阅读安全指南、暴露运行手册和沙盒指南。

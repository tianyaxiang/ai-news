# DesignAgent3D: Interactive 3D Scene Editing via Designer-like Multimodal Reasoning

**DesignAgent3D：通过类设计师多模态推理实现交互式 3D 场景编辑**

Text guided 3D scene editing provides an intuitive interface for modifying reconstructed environments, but remains difficult because natural language design requests are often semantically underspecified and must be grounded in cluttered 3D scenes.

文本引导的 3D 场景编辑为修改重建环境提供了一种直观的界面，但由于自然语言设计需求往往在语义上不够明确，且必须在复杂的 3D 场景中进行定位，因此该任务仍然具有挑战性。

Existing methods typically formulate the task as one-shot conditional generation from a single prompt, failing to resolve ambiguous user intents or achieve precise spatial grounding. Consequently, they suffer from severe object localization drift, tracking failure under occlusions, and the notorious multi-view "sticker effect."

现有方法通常将该任务表述为基于单个提示词的一次性条件生成，无法解决模糊的用户意图或实现精确的空间定位。因此，这些方法往往会遭受严重的对象定位漂移、遮挡下的跟踪失败以及臭名昭著的多视图“贴纸效应”困扰。

To overcome these limitations, we present DesignAgent3D, an interactive multimodal agentic framework that reformulates 3D scene editing as a designer-like Plan-Perceive-Act paradigm. The agent first plans by interacting with the user to clarify underspecified design goals, then perceives by grounding the intended edit to specific objects or regions in the 3D scene, and finally acts by applying controlled visual modifications while preserving scene consistency.

为了克服这些局限性，我们提出了 DesignAgent3D，这是一个交互式多模态智能体框架，它将 3D 场景编辑重新定义为一种类设计师的“规划-感知-行动”（Plan-Perceive-Act）范式。该智能体首先通过与用户交互来规划并澄清不明确的设计目标，然后通过将预期的编辑定位到 3D 场景中的特定对象或区域来进行感知，最后通过应用受控的视觉修改来执行操作，同时保持场景的一致性。

The edits are further integrated into the underlying 3D representation, supporting persistent and multi-view consistent novel-view rendering. Extensive experiments across both NeRF and 3D Gaussian Splatting backbones demonstrate that DesignAgent3D significantly outperforms state-of-the-art baselines, delivering superior semantic intent alignment, impeccable spatial localization accuracy, and high-fidelity multi-view consistency.

这些编辑被进一步集成到底层的 3D 表示中，支持持久且具有多视图一致性的新视角渲染。在 NeRF 和 3D 高斯泼溅（3D Gaussian Splatting）骨干网络上的大量实验表明，DesignAgent3D 显著优于现有的最先进基准方法，提供了卓越的语义意图对齐、无可挑剔的空间定位精度以及高保真的多视图一致性。

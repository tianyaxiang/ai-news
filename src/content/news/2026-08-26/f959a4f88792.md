# GeForce Now is getting support for the Steam Controller
# GeForce Now 即将支持 Steam 控制器

Nvidia’s GeForce Now cloud gaming service will officially support Valve’s Steam Controller and Steam Machine starting later this year. With Steam Controller support, you’ll be able to play games with Valve’s great new gamepad when using the GeForce Now app on your Steam Deck or Steam Machine. If you’re using GeForce Now on Windows or macOS, support for the Steam Controller is coming “later,” Nvidia says.

Nvidia 的 GeForce Now 云游戏服务将于今年晚些时候正式支持 Valve 的 Steam 控制器（Steam Controller）和 Steam Machine。通过对 Steam 控制器的支持，当你在 Steam Deck 或 Steam Machine 上使用 GeForce Now 应用时，将能够使用 Valve 这款出色的新游戏手柄进行游戏。Nvidia 表示，如果你是在 Windows 或 macOS 上使用 GeForce Now，对 Steam 控制器的支持将在“稍后”推出。

GeForce Now is getting a few other upgrades, too. Nvidia will soon add new DLSS 4.5 controls for DLSS Super Resolution, Dynamic Frame Generation, and Ray Reconstruction. (Ray Reconstruction is also officially launching for RTX GPUs in early access.) The previously-announced GOG single sign on is now available. The service will come to more of Amazon’s Fire TV Sticks “later this year,” and you’ll be able to buy a subscription through Amazon. And as of last week, you can officially use GeForce Now on Firefox.

GeForce Now 还将迎来其他几项升级。Nvidia 即将为 DLSS 超分辨率（Super Resolution）、动态帧生成（Dynamic Frame Generation）和光线重建（Ray Reconstruction）添加新的 DLSS 4.5 控制选项。（光线重建功能也已正式以抢先体验形式在 RTX GPU 上推出。）此前宣布的 GOG 单点登录功能现已可用。该服务将于“今年晚些时候”登陆更多亚马逊 Fire TV Stick 设备，届时你将可以通过亚马逊购买订阅。此外，从上周开始，你已经可以正式在 Firefox 浏览器上使用 GeForce Now 了。

Nvidia’s Gamescom announcements also include news for its upcoming RTX Spark chip family: EA, Embark, and Ubisoft are planning to support the chip, which is set to launch this fall, with games like EA Sports F1 25, Apex Legends, Arc Raiders, and Anno 117: Pax Romana. EA is also working on native support for its Javelin Anticheat technology for the company’s “biggest multiplayer games.”

Nvidia 在科隆游戏展（Gamescom）上的公告还包括其即将推出的 RTX Spark 芯片系列的消息：EA、Embark 和 Ubisoft 计划支持该芯片，该芯片定于今年秋季发布，支持的游戏包括《EA Sports F1 25》、《Apex 英雄》、《Arc Raiders》和《纪元 117：罗马和平》。EA 也在为其“最大的多人游戏”开发 Javelin 反作弊技术的原生支持。

Nvidia also shared details about 007 First Light’s path tracing update launching in September, upgrades to RTX Remix, and more, and you can read about everything that’s new in the company’s blog post.

Nvidia 还分享了关于《007：第一道曙光》（007 First Light）将于 9 月推出的路径追踪更新、RTX Remix 的升级等详细信息，你可以在该公司的官方博客文章中阅读所有最新内容。

# The Witcher 4 developers target a 2028 release
# 《巫师 4》开发商目标于 2028 年发布

CD Projekt Red’s big Witcher sequel is still a couple years away.
CD Projekt Red 的这部《巫师》系列重磅续作距离发布还有几年时间。

CD Projekt Red is aiming to launch The Witcher 4 sometime in 2028, joint CEO Michał Nowakowski says in a new video. CD Projekt Red has been working on its next mainline Witcher title for years and has shown videos of it, but now the studio is providing a target release window for when the game might actually come out.
CD Projekt Red 联席首席执行官 Michał Nowakowski 在一段新视频中表示，公司计划在 2028 年的某个时间点推出《巫师 4》。CD Projekt Red 多年来一直致力于开发这款《巫师》系列的正统续作，并曾展示过相关视频，但直到现在，工作室才给出了该游戏可能正式发售的目标时间窗口。

There’s more new Witcher to come before The Witcher 4, though. At this week’s Gamescom event, CD Projekt Red will be showing off its upcoming Witcher 3 expansion, Songs of the Past, which is scheduled to release sometime in 2027. Songs of the Past is also set to be part of Gamescom’s Opening Night Live event hosted by Geoff Keighley, which kicks off at 2PM ET on Tuesday.
不过，在《巫师 4》发布之前，还会有更多《巫师》系列的新内容。在本周的科隆游戏展（Gamescom）上，CD Projekt Red 将展示其即将推出的《巫师 3》扩展包《往昔之歌》（Songs of the Past），该扩展包计划于 2027 年发布。《往昔之歌》也将出现在由 Geoff Keighley 主持的科隆游戏展“开幕之夜直播”（Opening Night Live）活动中，该活动将于美东时间周二下午 2 点开始。

CD Projekt Red is also working on a multiplayer spinoff set in the universe of The Witcher that’s codenamed Project Siris. Earlier in August, the company confirmed that it laid off staff working on the game.
CD Projekt Red 还在开发一款以《巫师》世界观为背景的多人衍生游戏，代号为“Project Siris”。今年 8 月早些时候，该公司证实已裁减了负责该项目的部分员工。

# anthropics / claude-plugins-community

**Claude Plugins — Community**
**Claude Plugins — 社区版**

Community-contributed plugins for Claude Cowork and Claude Code.
这是为 Claude Cowork 和 Claude Code 提供的社区贡献插件库。

**What this repo is**
**关于此仓库**

A read-only mirror of the community plugin marketplace. The `.claude-plugin/marketplace.json` file here is the list of community plugins available to install. It is synced nightly from Anthropic's internal review pipeline. Every plugin listed here has been submitted via claude.ai, passed automated security scanning, and been approved for distribution.
这是一个社区插件市场的只读镜像。此处的 `.claude-plugin/marketplace.json` 文件包含了可供安装的社区插件列表。该列表每晚会从 Anthropic 的内部审核流程中同步更新。此处列出的每个插件均已通过 claude.ai 提交，经过了自动化安全扫描，并已获准发布。

**Using this marketplace**
**如何使用此市场**

**Claude Cowork**
Install plugins from `claude.com/plugins`.
请通过 `claude.com/plugins` 安装插件。

**Claude Code**
`claude plugin marketplace add anthropics/claude-plugins-community`
`claude plugin install <plugin-name>@claude-community`

**Submitting a plugin**
**提交插件**

Submit via `clau.de/plugin-directory-submission`. Pull requests opened directly against this repo are closed automatically — all changes flow from the internal review pipeline.
请通过 `clau.de/plugin-directory-submission` 进行提交。直接针对此仓库发起的 Pull Request 将会被自动关闭——所有变更均需通过内部审核流程进行同步。

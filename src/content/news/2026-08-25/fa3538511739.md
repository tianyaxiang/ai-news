### Can a blog post be handwritten?
### 博客文章可以用手写吗？

Can a blog post be handwritten? 2026-08-20
博客文章可以用手写吗？2026年8月20日

Can a blog post be handwritten? Suppose I handwrite a post on my supernote, then export it as a webp, which supports XMP metadata.
博客文章可以用手写吗？假设我在我的 Supernote 上手写了一篇文章，然后将其导出为支持 XMP 元数据的 WebP 格式。

Pretty sure I should be able to read that with javascript. Then, I could embed the webp on a blog post, and write a script that will toggle between hand-writing and the OCR'd (and edited) text metadata.
我很确定我可以用 JavaScript 读取它。然后，我可以将这张 WebP 图片嵌入到博客文章中，并编写一个脚本，在手写原稿和经过 OCR（及编辑）的文本元数据之间进行切换。

Worth an experiment, I reckon. Wonder if you can read my handwriting, though. ⌨︎
我觉得这值得一试。不过，不知道你能不能看懂我的字迹。⌨︎

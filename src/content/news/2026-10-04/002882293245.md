# Fast Polynomial Transcendentals for LLMs
# 大语言模型的高效多项式超越函数计算

**Abstract:** Graphics processing unit (GPU) generations scale matrix, special-function, and memory pipelines at different rates, so kernel bottlenecks move as hardware evolves. FlashAttention-4 exposed this imbalance inside attention on NVIDIA Blackwell. We test whether short polynomial programs can accelerate other special-function-unit (SFU) operations in large language models (LLMs).

**摘要：** 图形处理器（GPU）的每一代更新在矩阵运算、特殊函数运算和内存流水线上的扩展速度各不相同，因此内核瓶颈会随着硬件的演进而发生转移。FlashAttention-4 揭示了 NVIDIA Blackwell 架构中注意力机制内部存在的这种不平衡。我们测试了短多项式程序是否能够加速大语言模型（LLM）中其他特殊函数单元（SFU）的操作。

We first compare native PyTorch evaluation with packed fused multiply--add (FMA) programs in an isolated IEEE binary16 (FP16) sweep spanning L2-resident and high-bandwidth-memory (HBM)-resident working sets. We then replace native sigmoid, tanh, and sigmoid linear unit (SiLU) with degree-3 or degree-4 bfloat16 (BF16) programs in four GB200 integration tasks: dense SiLU, tanh-softcapped attention, sigmoid attention, and routed-expert Swish-gated linear unit (SwiGLU). The programs combine analytical symmetry, target-format rounding, and packed arithmetic inside consuming kernels.

我们首先将原生 PyTorch 计算与打包的融合乘加（FMA）程序进行了对比，在 IEEE binary16 (FP16) 的隔离环境下，涵盖了驻留于 L2 缓存和高带宽内存（HBM）的工作集。随后，我们在四个 GB200 集成任务中，将原生的 sigmoid、tanh 和 SiLU 函数替换为 3 次或 4 次多项式 bfloat16 (BF16) 程序，这些任务包括：稠密 SiLU、tanh 软上限注意力机制、sigmoid 注意力机制以及路由专家 Swish 门控线性单元（SwiGLU）。这些程序在消耗内核内部结合了分析对称性、目标格式舍入以及打包算术运算。

The isolated paths improve by 1.19--2.19x in L2 and 1.00--1.70x in HBM. The dense-SiLU, tanh-softcapped-attention, and routed-expert substitutions improve complete training-step throughput by 2.7\%, 2.9\%, and 8.0\%, respectively. The sigmoid-attention substitution improves complete-attention forward by 7.4\% and the complete GPU step by 0.3\%.

在隔离路径测试中，L2 缓存性能提升了 1.19 至 2.19 倍，HBM 性能提升了 1.00 至 1.70 倍。稠密 SiLU、tanh 软上限注意力机制和路由专家替换方案分别使完整的训练步骤吞吐量提升了 2.7%、2.9% 和 8.0%。sigmoid 注意力机制的替换使完整注意力前向计算提升了 7.4%，并使完整的 GPU 计算步骤提升了 0.3%。

Same-checkpoint open-weight ablations and one paired pre-training comparison per task extend the evaluation to model behavior. At common horizons near 100 billion tokens, the final smoothed training-loss differences (polynomial minus native) range from $-0.107$ to $+0.079$ across the four tasks.

通过相同检查点的开源权重消融实验以及每个任务的一次配对预训练对比，我们将评估范围扩展到了模型行为层面。在接近 1000 亿 token 的常见训练周期下，四个任务的最终平滑训练损失差值（多项式减去原生）范围在 $-0.107$ 到 $+0.079$ 之间。

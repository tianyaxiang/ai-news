# Effect-TS / effect

Effect is a library for building robust, maintainable, type-safe, and production-grade applications in TypeScript. It helps you handle the hard problems at scale: typed errors, dependency injection, structured concurrency, scheduling, tracing, and unified schema validation. Effect 4.x is a long-term support (LTS) release. If you are upgrading from Effect 3.x, follow the migration guide.

Effect 是一个用于在 TypeScript 中构建健壮、可维护、类型安全且生产级应用程序的库。它能帮助你处理大规模应用中的难题：类型化错误、依赖注入、结构化并发、调度、追踪以及统一的模式验证。Effect 4.x 是一个长期支持（LTS）版本。如果你是从 Effect 3.x 升级，请参考迁移指南。

### Installation
`npm install effect`

### 安装
`npm install effect`

### Requirements
TypeScript 5.9 or newer. TypeScript 7 is recommended for the best performance and compatibility with Effect's TypeScript tooling. Node.js 18 or newer is the general minimum for running Effect on Node.js. Some integration packages require newer runtimes; for example, `@effect/sql-sqlite-node` requires Node.js 22.16 or newer. Strict type-checking: the `strict` flag must be enabled in your `tsconfig.json`.

### 要求
TypeScript 5.9 或更高版本。建议使用 TypeScript 7 以获得最佳性能以及与 Effect TypeScript 工具链的兼容性。在 Node.js 上运行 Effect，通常最低要求为 Node.js 18。部分集成包需要更新的运行时；例如，`@effect/sql-sqlite-node` 需要 Node.js 22.16 或更高版本。严格类型检查：必须在 `tsconfig.json` 中启用 `strict` 标志。

### Long-term support
Teams depend on Effect for systems they expect to run for years. Effect 4.x is a long-term support (LTS) release with the following guarantees:
* At least three years of support, including bug and security fixes.
* Bug fixes for one year after the next major version is released.
* Security fixes for two years after the next major version is released.
* Stable APIs reserve breaking changes for major releases. APIs marked unstable may change in minor releases, and experimental APIs may change in patch releases.

### 长期支持
许多团队依赖 Effect 来构建预期运行多年的系统。Effect 4.x 是一个长期支持（LTS）版本，并提供以下保证：
* 至少三年的支持，包括错误修复和安全补丁。
* 下一个主要版本发布后，继续提供一年的错误修复。
* 下一个主要版本发布后，继续提供两年的安全修复。
* 稳定版 API 的破坏性变更仅限于主要版本。标记为不稳定的 API 可能会在次要版本中更改，而实验性 API 可能会在补丁版本中更改。

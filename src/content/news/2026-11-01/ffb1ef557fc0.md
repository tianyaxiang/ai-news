Enlightenment 0.28.0 Release 2026-10-31 - by Carsten Haitzler This is the latest release of Enlightenment. Added initial NetBSD support, including power commands and signal handling. Added a NetworkManager module supporting Wi-Fi, Ethernet, Bluetooth networking, and VPNs. Added automatic detection of NetworkManager and ConnMan network services. Added network signal strength, security indicators, connection details, and tooltips. Added saved connection management and forget buttons to NetworkManager and ConnMan. Added NetworkManager traffic indicators, threaded polling, and configurable polling intervals. Added VPN import, username prompts, authentication messages, and remembered form fields. Added connectivity callbacks and captive portal login URL refresh handling. Modernized NetworkManager dialogs, connection lists, Wi-Fi controls, and theme integration. Fixed NetworkManager startup detection, suspend/resume dialog spam, and stale VPN indicators. Fixed NetworkManager memory safety, D-Bus lifecycle, shutdown races, and popup refresh loops.

Enlightenment 0.28.0 版本发布于 2026 年 10 月 31 日，由 Carsten Haitzler 撰写。这是 Enlightenment 的最新版本。增加了对 NetBSD 的初步支持，包括电源命令和信号处理。添加了一个支持 Wi-Fi、以太网、蓝牙网络和 VPN 的 NetworkManager 模块。增加了对 NetworkManager 和 ConnMan 网络服务的自动检测。添加了网络信号强度、安全指示器、连接详情和工具提示。为 NetworkManager 和 ConnMan 添加了已保存连接管理和“忘记”按钮。添加了 NetworkManager 流量指示器、线程轮询和可配置的轮询间隔。添加了 VPN 导入、用户名提示、身份验证消息和记住表单字段功能。添加了连接回调和强制门户登录 URL 刷新处理。现代化了 NetworkManager 对话框、连接列表、Wi-Fi 控件和主题集成。修复了 NetworkManager 启动检测、挂起/恢复对话框垃圾信息以及过期的 VPN 指示器。修复了 NetworkManager 内存安全、D-Bus 生命周期、关机竞争条件和弹出窗口刷新循环。

Added native PipeWire mixer support alongside PulseAudio. Added mixer actions to select audio outputs and cycle between sinks. Improved mixer event handling, popup keyboard controls, and missing-output error handling. Added an integrated clipboard history module with configurable persistent history. Modernized clipboard popups with themed controls and individually removable history entries. Improved clipboard content tracking, selection timing, startup, shutdown, and configuration handling. Restored the Pants module with skirts, kilts, lederhosen, malloc variants, and translations. Added battery charge limits and remembered maximum charge settings per battery. Moved battery and AC polling into a worker thread. Removed the obsolete battery helper, fixed BSD builds, and capped displayed battery health at 100%. Added ACPI CPU power profile support and handling for all kernel-provided options. Matched AMD GPU power settings to CPU power levels. Extended CPU polling intervals and reduced polling while displays are off. Fixed CPU frequency gadget startup, sizing, and gradient rendering. Fixed deferred suspend handling and unnecessary powersave wakeups.

在 PulseAudio 之外增加了对原生 PipeWire 混音器的支持。添加了用于选择音频输出和在接收器之间循环的混音器操作。改进了混音器事件处理、弹出式键盘控件和缺失输出的错误处理。添加了一个带有可配置持久历史记录的集成剪贴板历史模块。现代化了带有主题控件和可单独删除历史条目的剪贴板弹出窗口。改进了剪贴板内容跟踪、选择时机、启动、关闭和配置处理。恢复了带有裙子、苏格兰短裙、皮裤、malloc 变体和翻译的 Pants 模块。添加了电池充电限制和每个电池记住最大充电设置的功能。将电池和交流电轮询移至工作线程。移除了过时的电池助手，修复了 BSD 构建，并将显示的电池健康状况上限设为 100%。添加了 ACPI CPU 电源配置文件支持以及对所有内核提供选项的处理。将 AMD GPU 电源设置与 CPU 电源级别相匹配。延长了 CPU 轮询间隔，并在显示器关闭时减少了轮询。修复了 CPU 频率小部件的启动、大小调整和渐变渲染。修复了延迟挂起处理和不必要的节能唤醒。

Enabled process priority adjustments through the system helper without requiring `CAP_SYS_NICE` on Enlightenment. Improved process statistics CPU accounting, formatting, layering, and window-change handling. Fixed process statistics shutdown waits and invalid polling wakeups. Added configurable X11 keyboard repeat rate and delay. Added a smooth “Roll Up” window shading transition. Added window actions for always-on-top, always-below, and normal stacking. Fixed gadget dragging, positioning, ordering, sizing, and mouse event handling. Prevented unintended shelf gadget detachment and improved autoscroll behavior.

# Windows 11 tries new shortcuts for Xbox gaming mode and search

Windows 11 正在尝试为 Xbox 游戏模式和搜索功能添加新的快捷方式。

The latest Windows 11 Insider build adds some powerful new search features and quick settings while in Xbox mode. The Xbox shortcuts let you control things like Bluetooth, WiFi, and power settings without having to exit gaming mode.

最新的 Windows 11 预览版在 Xbox 模式下增加了一些强大的新搜索功能和快速设置。这些 Xbox 快捷方式允许你在不退出游戏模式的情况下控制蓝牙、WiFi 和电源设置等选项。

The search improvements are quite comprehensive. You can now filter results for files, actions, or web results. You can also use the search box to perform actions like changing the screen brightness or volume, and even perform actions on a connected phone, including making calls.

搜索功能的改进非常全面。你现在可以筛选文件、操作或网页搜索结果。你还可以使用搜索框执行诸如更改屏幕亮度或音量等操作，甚至可以对已连接的手机执行操作，包括拨打电话。

Results can also offer much more detail, like when a file was last modified and its author, or pull in charts for stock prices and weather forecasts. And you can train Windows 11 search by clicking inline thumbs-up or thumbs-down icons to help it improve over time.

搜索结果现在可以提供更多细节，例如文件的最后修改时间和作者，或者调取股票价格和天气预报的图表。此外，你可以通过点击内嵌的“点赞”或“点踩”图标来训练 Windows 11 的搜索功能，帮助其不断改进。

For the full list of changes, check out Microsoft’s blog post. Beta Build 26220.9836 and Experimental Build 26340.9843 are both available now to Windows Insiders.

如需查看完整的更改列表，请查阅微软的官方博客文章。Beta 版本 26220.9836 和实验版本 26340.9843 现已向 Windows Insider 用户开放。

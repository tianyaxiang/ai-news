# caddyserver / caddy

Caddy is an extensible server platform that uses TLS by default.
Caddy 是一个可扩展的服务器平台，默认启用 TLS。

### Features
### 功能特性

*   **Easy configuration with the Caddyfile:** Powerful configuration with its native JSON config.
    **通过 Caddyfile 轻松配置：** 使用原生 JSON 配置进行强大的配置管理。
*   **Dynamic configuration with the JSON API:** Config adapters if you don't like JSON.
    **通过 JSON API 进行动态配置：** 如果你不喜欢 JSON，可以使用配置适配器。
*   **Automatic HTTPS by default:** ZeroSSL and Let's Encrypt for public names; fully-managed local CA for internal names & IPs.
    **默认自动 HTTPS：** 为公共域名提供 ZeroSSL 和 Let's Encrypt 支持；为内部域名和 IP 提供全托管的本地 CA。
*   **Production-ready:** Stays up when other servers go down due to TLS/OCSP/certificate-related issues; scales to hundreds of thousands of sites.
    **生产环境就绪：** 在其他服务器因 TLS/OCSP/证书相关问题宕机时仍能保持运行；可扩展至数十万个站点。
*   **Highly extensible:** Modular architecture lets Caddy do anything without bloat.
    **高度可扩展：** 模块化架构让 Caddy 在不臃肿的前提下实现任何功能。
*   **Written in Go:** A language with higher memory safety guarantees than other servers.
    **使用 Go 编写：** 相比其他服务器，该语言具有更高的内存安全保障。

### Overview
### 概览

Caddy is most often used as an HTTPS server, but it is suitable for any long-running Go program. First and foremost, it is a platform to run Go applications. Caddy "apps" are just Go programs that are implemented as Caddy modules.
Caddy 最常被用作 HTTPS 服务器，但它适用于任何长期运行的 Go 程序。首先，它是一个运行 Go 应用程序的平台。Caddy 的“应用”本质上就是作为 Caddy 模块实现的 Go 程序。

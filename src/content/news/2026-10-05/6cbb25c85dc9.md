# ncdu: NCurses Disk Usage (an updated fork)
# ncdu：NCurses 磁盘使用情况分析工具（更新分支）

ncdu-zig Description
Ncdu is a disk usage analyzer with an ncurses interface. It is designed to find space hogs on a remote server where you don't have an entire graphical setup available, but it is a useful tool even on regular desktop systems.
**ncdu-zig 描述**
Ncdu 是一款带有 ncurses 界面的磁盘使用情况分析工具。它旨在帮助用户在无法使用完整图形界面的远程服务器上查找占用空间的“大户”，但它在常规桌面系统上同样是一个实用的工具。

Ncdu aims to be fast, simple and easy to use, and should be able to run in any minimal POSIX-like environment with ncurses installed. See the ncdu 2 release announcement for information about the differences between this Zig implementation (2.x) and the C version (1.x).
Ncdu 的目标是快速、简洁且易于使用，并且能够在任何安装了 ncurses 的最小化类 POSIX 环境中运行。有关此 Zig 实现版本（2.x）与 C 语言版本（1.x）之间差异的信息，请参阅 ncdu 2 的发布公告。

Install
You can use the Zig build system if you're familiar with that. There's also a handy Makefile that supports the typical targets, e.g.:
make
sudo make install PREFIX=/usr
**安装**
如果你熟悉 Zig 构建系统，可以使用它进行构建。此外，项目中还提供了一个方便的 Makefile，支持常见的构建目标，例如：
make
sudo make install PREFIX=/usr

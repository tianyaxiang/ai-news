Exowatt, a software company, used SageMaker Tuning to build cheaper custom tools that AWS said were up to 49x less costly and more accurate than bigger rivals.

软件公司 Exowatt 利用 SageMaker Tuning 构建了更廉价的定制化工具。据亚马逊云科技（AWS）称，这些工具的成本最高降低了 49 倍，且准确性优于规模更大的竞争对手。

Key Takeaways: Exowatt used SageMaker Tuning to build two task-specific AI models that beat frontier models on accuracy while cutting costs by up to 49x. AWS said Exowatt used Amazon SageMaker AI serverless model customization to create a repeatable pipeline for edge and cloud deployments. An AWS post explained evaluation bias can cause teams to overestimate large general models without clean ground-truth tests. SageMaker Tuning was serverless so Exowatt did not have to reserve dedicated tuning infrastructure before each job.

核心要点：Exowatt 使用 SageMaker Tuning 构建了两个特定任务的 AI 模型，在准确性上超越了前沿模型，同时将成本降低了多达 49 倍。AWS 表示，Exowatt 利用 Amazon SageMaker AI 无服务器模型定制功能，为边缘和云端部署创建了可重复的流水线。AWS 的一篇文章解释称，评估偏差可能导致团队在缺乏清晰的基准测试（ground-truth tests）的情况下，高估大型通用模型。由于 SageMaker Tuning 是无服务器的，Exowatt 无需在每次任务前预留专门的微调基础设施。

AWS said Exowatt used Amazon SageMaker AI serverless model customization to create a repeatable pipeline for both edge and cloud deployments, and a second AWS post the same day on evaluation bias explains why companies can overestimate large general models without clean ground-truth tests. Exowatt is building AI for operational use cases where cost and latency matter as much as model breadth.

AWS 表示，Exowatt 利用 Amazon SageMaker AI 无服务器模型定制功能，为边缘和云端部署创建了可重复的流水线。同日，AWS 发布了另一篇关于评估偏差的文章，解释了为何企业在缺乏清晰基准测试的情况下会高估大型通用模型。Exowatt 正在为那些既看重成本和延迟，也看重模型广度的运营场景构建 AI。

SageMaker is Amazon's managed platform for training, tuning and deploying models without forcing customers to build the infrastructure stack from scratch. The claim is not that frontier models stopped mattering, but that many enterprise tasks need smaller models tuned on the right data, tested on the right benchmark and cheap enough to run at production scale.

SageMaker 是亚马逊的托管平台，用于训练、微调和部署模型，无需客户从零开始构建基础设施堆栈。这并不是说前沿模型不再重要，而是许多企业任务需要更小的模型——这些模型需在正确的数据上进行微调，在正确的基准上进行测试，且成本足够低，以支持生产规模的运行。

SageMaker Tuning Beats Bigger Models On Narrow Tasks: This distinction has become a major shift in business AI, with frontier models performing broadly but extra generality adding cost, latency and operational complexity for firms that need a narrow function.

SageMaker Tuning 在细分任务上击败大型模型：这种区别已成为商业 AI 的重大转变。前沿模型虽然表现广泛，但对于需要特定功能的机构而言，额外的通用性增加了成本、延迟和运营复杂性。

AWS said Exowatt built a pipeline that produced specialized models for two deployment targets, important because edge systems often require smaller footprints and more predictable response times than cloud-only applications. The 49x figure is the part buyers will remember, because cost gaps of that size can decide whether a feature stays in pilot or becomes a shipped product.

AWS 表示，Exowatt 构建的流水线为两个部署目标生成了专用模型，这一点很重要，因为与纯云端应用相比，边缘系统通常需要更小的占用空间和更可预测的响应时间。49 倍的成本差距是买家会记住的部分，因为这种规模的成本差异往往决定了一个功能是停留在试点阶段，还是成为正式发布的产品。

If a custom model also beats the larger baseline on accuracy, the argument for defaulting to the biggest available model weakens. Why Clean Evaluation Suddenly Matters More: The companion AWS discussion of evaluation bias addresses a common AI buying mistake, where teams often compare a new model against labels produced by an incumbent model and treat the result as objective.

如果定制模型在准确性上也击败了大型基准模型，那么默认选择最大可用模型的理由就会减弱。为何清晰的评估突然变得更加重要：AWS 关于评估偏差的配套讨论指出了一个常见的 AI 采购错误，即团队经常将新模型与现有模型生成的标签进行比较，并将结果视为客观的。

That can hide gains from a specialized alternative. If the benchmark inherits the older system's mistakes, a newer model that improves real outcomes may still look worse on paper.

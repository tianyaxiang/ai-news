# A practical checklist for building image and video generation workflows

构建媒体生成工作流不仅仅是添加一个提示框。界面需要传达正在请求的内容、工作何时完成，以及如果出现故障用户可以采取什么措施。以下是小型团队设计此类流程的实用清单。

1. Make inputs explicit
Collect the source, intended output and format separately. If a user supplies a reference image, show a preview and make it clear whether the image is used as an inspiration, a first frame or an editing target. Validate file types and size before starting work, and explain the error in terms the person can act on.

1. 明确输入内容
分别收集源文件、预期输出和格式。如果用户提供了参考图像，请显示预览，并明确该图像是用作灵感、第一帧还是编辑目标。在开始工作前验证文件类型和大小，并以用户可操作的方式解释错误。

2. Show the cost and request before starting
A summary should state the chosen model, output size, relevant credits or price, and any input that will be sent to an external processor. If a setting is unavailable, ask the user to choose another option rather than silently changing the request.

2. 在开始前显示成本和请求
摘要应说明所选模型、输出大小、相关积分或价格，以及将发送给外部处理器的任何输入。如果某项设置不可用，请要求用户选择其他选项，而不是静默更改请求。

3. Treat generation as a job
Media generation can outlast a browser request. A durable job record with a stable ID makes it possible to show pending, running, completed and failed states after a refresh. Retries need particular care: a timeout is not proof that the provider did nothing, so reconcile the existing job before sending a second potentially billable request.

3. 将生成视为一项任务
媒体生成过程可能会超过浏览器请求的持续时间。带有稳定 ID 的持久任务记录使得在刷新后能够显示待处理、运行中、已完成和失败的状态。重试需要特别小心：超时并不证明提供商没有执行任何操作，因此在发送第二个可能产生费用的请求之前，请先核对现有任务。

4. Review outputs, not only status codes
A successful response is not the same as a usable result. Check that the returned asset can be saved and displayed, that its dimensions and format match the request, and that private files remain accessible only to authorized users. For video, also check the first frame, duration, playback and download behavior.

4. 审查输出结果，而不仅仅是状态码
成功的响应并不等同于可用的结果。检查返回的资产是否可以保存和显示，其尺寸和格式是否符合请求，以及私有文件是否仅对授权用户可见。对于视频，还要检查第一帧、时长、播放和下载行为。

5. Give people a path forward
A useful history view lets users return to a result, download it or start a new variation. If an operation fails, show what happened and whether a retry would create a new job or incur another charge. Avoid promising an exact generation time when the upstream system does not guarantee one.

5. 为用户提供后续路径
实用的历史记录视图允许用户返回查看结果、下载或开始新的变体。如果操作失败，请显示发生了什么，以及重试是否会创建新任务或产生额外费用。当上游系统无法保证生成时间时，请避免承诺确切的生成时间。

Disclosure: I work on Jynno, an AI creative studio for images and video. This checklist describes design questions to evaluate; it is not a claim that every product implements them in the same way.

披露：我供职于 Jynno，这是一家专注于图像和视频的 AI 创意工作室。本清单描述了需要评估的设计问题；这并非声称每个产品都以相同的方式实现这些功能。

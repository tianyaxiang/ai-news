# Performance, Efficiency and Collapse -- Advantages and Challenges in Offline Post-training of Code LLMs
# 性能、效率与崩溃——代码大模型离线后训练的优势与挑战

**Abstract:** Post-training with reinforcement learning (RL) is a critical phase in the development of code-generating large language models (LLMs), as it ensures adherence to instructions and the production of functionally correct code. 

**摘要：** 基于强化学习（RL）的后训练是代码生成大模型（LLM）开发中的关键阶段，因为它能确保模型遵循指令并生成功能正确的代码。

This process typically requires computationally intensive code sample generation from Transformer-based LLMs and substantial GPU-CPU communication for sequence verification. 

该过程通常需要基于 Transformer 的大模型进行计算密集型的代码样本生成，并涉及大量的 GPU-CPU 通信以进行序列验证。

To address these computational challenges, this work examines whether RL-based post-training can be performed entirely offline by leveraging existing datasets rather than generating new samples. 

为了解决这些计算挑战，本研究探讨了是否可以通过利用现有数据集而非生成新样本，来完全离线地执行基于强化学习的后训练。

The findings indicate that, with only a few hours of training, zero-shot code generation performance of LLMs can be substantially improved without online sampling. 

研究结果表明，仅需几个小时的训练，大模型在无需在线采样的情况下，其零样本（zero-shot）代码生成性能即可得到显著提升。

Additionally, offline RL produces performance gains across models ranging from 0.5B to 7B parameters, although the extent of improvement varies among model families.

此外，离线强化学习在参数规模从 0.5B 到 7B 的模型上均带来了性能提升，尽管不同模型系列的改进幅度有所差异。

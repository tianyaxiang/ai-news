### Does Video Memory Use What It Retrieves? A Causal Audit of Memory Specificity
### 视频记忆是否真的使用了它所检索的内容？关于记忆特异性的因果审计

**Abstract:** Video models increasingly use memory to preserve information over long sequences, with the assumption that gains come from retrieving and using the correct past content. Standard memory ablations test whether memory helps, but not whether the retrieved content is responsible. We test this directly with read-time memory substitution, which replaces the consumed memory value while leaving the rest of the computation unchanged. This separates memory benefit from memory specificity, the extent to which the gain depends on retrieved content.

**摘要：** 视频模型越来越多地利用记忆来在长序列中保存信息，其前提假设是性能的提升源于对正确历史内容的检索和使用。标准的记忆消融实验仅能测试记忆是否有帮助，但无法验证所检索的内容是否是性能提升的真正原因。我们通过“读取时记忆替换”（read-time memory substitution）直接对此进行了测试，即在保持其余计算不变的情况下，替换掉被消耗的记忆值。这种方法将“记忆收益”与“记忆特异性”（即收益在多大程度上依赖于所检索内容）区分了开来。

Across frozen video world models, identity-free controls containing no evaluation-specific content recover essentially the full benefit on Ego-Exo4D and 7-Scenes and about 70% on TUM. In the Ego-Exo4D dose response, recovery falls from 102% to 1% as these values move away from observed training-memory representations, supporting representation repair as the best-supported explanation in this setting. WorldMem shows graded dependence. A wrong memory from the same trajectory recovers 94.1% of the PSNR benefit relative to zero content, while a donor from a disjoint trajectory and biome recovers 43.7%.

在冻结的视频世界模型中，不包含任何评估特定内容的“无身份控制”（identity-free controls）在 Ego-Exo4D 和 7-Scenes 数据集上几乎恢复了全部收益，在 TUM 数据集上恢复了约 70%。在 Ego-Exo4D 的剂量反应测试中，随着这些值偏离观察到的训练记忆表征，恢复率从 102% 降至 1%，这支持了“表征修复”（representation repair）是该设置下最合理的解释。WorldMem 模型表现出分级的依赖性：来自同一轨迹的错误记忆可恢复相对于零内容 94.1% 的 PSNR 收益，而来自不相交轨迹和生物群落的捐赠记忆仅能恢复 43.7%。

SAM 2 shows strong content dependence. On DAVIS, replacing the correct spatial memory with a valid wrong memory reduces mean region and boundary score from 0.926 to 0.182. At MOSEv2 reappearance, it falls from 0.459 to 0.000. These results show that memory gains can depend on generic representation support, broader context, or exact episodic content. Read-time substitution provides a direct way to distinguish them.

SAM 2 模型则表现出强烈的“内容依赖性”。在 DAVIS 数据集上，将正确的空间记忆替换为有效的错误记忆，会导致平均区域和边界得分从 0.926 降至 0.182。在 MOSEv2 的重现任务中，该得分从 0.459 降至 0.000。这些结果表明，记忆带来的收益可能取决于通用的表征支持、更广泛的上下文，或是精确的情景内容。而“读取时记忆替换”为区分这些因素提供了一种直接的方法。

### Title: I built Craftfolio — I'd like some honest feedback
### 标题：我开发了 Craftfolio —— 期待大家的真实反馈

Hey everyone, I’ve been building Craftfolio, a tool for creating developer portfolios and resumes. I started it mainly as a way to push myself beyond smaller coding projects and build something that could actually be useful to other developers.
大家好，我最近开发了 Craftfolio，这是一个用于创建开发者作品集和简历的工具。我启动这个项目的初衷，主要是为了挑战自己，跳出小型编程项目的局限，去构建一个真正能为其他开发者提供价值的产品。

Some of the things I’ve built into it include live previews, importing content, different portfolio styles, HTML export, and PDF printing. I’m still working on it, and I’m particularly interested in feedback on the UI, overall experience, and what you think I should improve or remove. What would you change if you were building this? Thanks!
目前我已经实现的功能包括：实时预览、内容导入、多种作品集样式、HTML 导出以及 PDF 打印。我仍在持续开发中，特别希望能听到大家关于 UI 设计、整体使用体验的反馈，以及你们认为我应该改进或删减的地方。如果是你来开发这个工具，你会做出哪些改变？谢谢！

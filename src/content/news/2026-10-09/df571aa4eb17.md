Posted on October 8, 2026 by Bevy Contributors

Bevy 0.20
发布于 2026 年 10 月 8 日，由 Bevy 贡献者撰写

The Zorah scene rendered in Bevy Solari. Thanks to 227 contributors, 817 pull requests, community reviewers, and our generous donors, we're happy to announce the Bevy 0.20 release on crates.io!

在 Bevy Solari 中渲染的 Zorah 场景。感谢 227 位贡献者、817 个拉取请求、社区审阅者以及我们慷慨的捐赠者，我们很高兴地宣布 Bevy 0.20 在 crates.io 上发布了！

For those who don't know, Bevy is a refreshingly simple data-driven game engine built in Rust. You can check out our Quick Start Guide to try it today. It's free and open source forever! You can grab the full source code on GitHub. Check out Bevy Assets for a collection of community-developed plugins, games, and learning resources.

对于那些还不了解的人，Bevy 是一款用 Rust 构建的、令人耳目一新的简单数据驱动游戏引擎。您可以查看我们的快速入门指南来立即尝试。它永远免费且开源！您可以在 GitHub 上获取完整的源代码。查看 Bevy Assets 以获取社区开发的插件、游戏和学习资源集合。

To update an existing Bevy App or Plugin to Bevy 0.20, check out our 0.19 to 0.20 Migration Guide. Since our last release a few months ago we've added a ton of new features, bug fixes, and quality of life tweaks, but here are some of the highlights:

要将现有的 Bevy 应用程序或插件更新到 Bevy 0.20，请查看我们的 0.19 到 0.20 迁移指南。自几个月前我们上次发布以来，我们添加了大量新功能、错误修复和易用性调整，以下是一些亮点：

Solari and DLSS: Solari, Bevy's realtime pathtraced renderer, is now faster, more accurate, supports more Bevy rendering features, and runs on macOS via Metal! BSN Syntax Improvements: BSN, Bevy's new scene system, had some syntax changes that made it much easier to read and compose.

Solari 和 DLSS：Bevy 的实时路径追踪渲染器 Solari 现在更快、更准确，支持更多 Bevy 渲染功能，并可通过 Metal 在 macOS 上运行！BSN 语法改进：Bevy 的新场景系统 BSN 进行了一些语法更改，使其更易于阅读和组合。

Ready Event: BSN scene entities now trigger an observable Ready event when all of their children have been spawned. More UI Widgets: Bevy Feathers, Bevy's opinionated editor-centric UI toolkit, now has Color Input, Scrollable List View, Dropdown Selection, and Lazy Menu widgets. The Number Input widget is now scrubbable / draggable, and we've added Headless Tab Widgets.

Ready 事件：当 BSN 场景实体的所有子项都已生成时，它们现在会触发一个可观察的 Ready 事件。更多 UI 组件：Bevy Feathers（Bevy 以编辑器为中心的 UI 工具包）现在拥有颜色输入、可滚动列表视图、下拉选择和懒加载菜单组件。数字输入组件现在支持拖动/滑动，我们还添加了无头标签页组件。

WESL Shaders: Bevy has officially adopted the WESL shader language (a standardized extension of WGSL). WESL is already an improvement over Bevy's old custom WGSL dialect, and we've been working with the WESL team to plan out the future of shader development in Bevy.

WESL 着色器：Bevy 已正式采用 WESL 着色器语言（WGSL 的标准化扩展）。WESL 已经是对 Bevy 旧版自定义 WGSL 方言的改进，我们一直在与 WESL 团队合作，规划 Bevy 中着色器开发的未来。

Sprite Materials and Extended 2D Materials: It is now possible to create custom shader materials for Sprites, and 2D mesh materials can now be extended like they can in 3D. Pan Orbit Camera: Bevy now has a "pan orbit camera", making it possible to navigate scenes in a CAD-like way.

精灵材质和扩展 2D 材质：现在可以为精灵创建自定义着色器材质，并且 2D 网格材质现在可以像 3D 中那样进行扩展。平移轨道相机：Bevy 现在拥有“平移轨道相机”，使得以类似 CAD 的方式导航场景成为可能。

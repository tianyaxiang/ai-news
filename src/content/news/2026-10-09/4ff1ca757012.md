Title: Microsoft’s new Windows Search is exactly what Windows 11 needs

标题：微软全新的 Windows 搜索正是 Windows 11 所需要的

Windows Search is being overhauled with a focus on speed and capability. Windows Search has been one of the most frustrating parts of Windows 11, and now Microsoft is addressing this with a significant overhaul. A new redesigned Windows Search is now in testing that is much faster, more capable, and a lot more modern.

Windows 搜索正在进行全面改革，重点在于提升速度和功能。Windows 搜索一直是 Windows 11 最令人沮丧的部分之一，现在微软正通过一次重大升级来解决这个问题。目前正在测试的全新重构版 Windows 搜索速度更快、功能更强，且更加现代化。

“This new Windows Search experience is built for speed,” says Anshul Rawat, corporate vice president of the Windows product team at Microsoft. “It’s built on WinUI 3 and is part of our broader investment in modernizing our core Windows experiences.”

“这种全新的 Windows 搜索体验专为速度而生，”微软 Windows 产品团队企业副总裁 Anshul Rawat 表示，“它基于 WinUI 3 构建，是我们对 Windows 核心体验进行现代化改造这一更广泛投资的一部分。”

Microsoft says early testing of this new search has shown “substantial improvements in performance and memory usage,” meaning the company isn’t adding extra bloat to Windows to improve search, either. The UI has also been greatly improved, with speedy animations and a large preview pane.

微软表示，这项新搜索的早期测试显示“在性能和内存占用方面有显著改善”，这意味着该公司并没有通过增加额外的臃肿程序来提升搜索性能。用户界面也得到了极大改进，拥有流畅的动画效果和一个大型预览窗格。

While search is being overhauled visually, behind the scenes Microsoft is also improving the basics. “We’re also improving how Windows Search understands what you’re looking for, including better matching for typos and synonyms,” says Rawat.

在视觉上对搜索进行重构的同时，微软也在幕后改进其基础功能。Rawat 说：“我们还在改进 Windows 搜索对用户意图的理解方式，包括对拼写错误和同义词的匹配能力。”

I got to try out this new Windows Search interface at Microsoft’s Windows and Surface event yesterday, and I was impressed with just how quick it is and how decluttered it feels. Right now if you search for something like the height of an actor it will take a few seconds to figure it out and show you essentially a miniature Bing result.

昨天在微软的 Windows 和 Surface 活动上，我有幸试用了这个全新的 Windows 搜索界面，其响应速度之快和界面之简洁给我留下了深刻印象。目前，如果你搜索诸如某位演员的身高之类的信息，系统需要几秒钟才能处理并显示出一个类似迷你版必应（Bing）的搜索结果。

The new Windows Search just surfaces the result inline, much like the modern search interfaces you see in iOS and Android. These inline results also extend to previews of PowerPoint presentations, photos, and other files.

全新的 Windows 搜索直接在行内显示结果，非常类似于你在 iOS 和 Android 上看到的现代搜索界面。这些行内结果还扩展到了 PowerPoint 演示文稿、照片和其他文件的预览。

The most impressive part of this new Windows Search is being able to use it like a launcher, just like many third-party tools, and have it take actions for tasks like turning Bluetooth or dark mode on and off. You can even ask search to minimize windows, or open apps side-by-side. If you use Phone Link, these actions will also extend to your phone so you could simply type “text mom, I’m running late” and it will send a text message from your phone.

这个新版 Windows 搜索最令人印象深刻的部分在于，你可以像使用许多第三方工具一样将其作为启动器使用，并让它执行诸如开关蓝牙或深色模式等任务。你甚至可以让搜索功能最小化窗口或并排打开应用程序。如果你使用“手机连接”（Phone Link），这些操作还可以扩展到你的手机上，这样你只需输入“给妈妈发短信说我晚点到”，它就会通过你的手机发送短信。

Microsoft is testing this new Windows Search interface with its Windows Insiders right now, so that should mean we’ll see it appear in Windows 11 in the coming months. “Looking to next year, work is already underway to bring the new Windows Search experience to the Start menu and have it adapt naturally to different taskbar positions and Windows configurations,” says Rawat.

微软目前正在与 Windows Insider 测试人员一起测试这个新的 Windows 搜索界面，这意味着我们应该会在未来几个月内看到它出现在 Windows 11 中。Rawat 表示：“展望明年，我们已经在着手将全新的 Windows 搜索体验引入‘开始’菜单，并使其能够自然地适应不同的任务栏位置和 Windows 配置。”

How I Built It The central idea behind HirePilot is that your career data shouldn't need to leave your computer just to help you prepare for a job. I built the application around Google's Gemma 3 4B model, running locally through Ollama. Instead of relying on a proprietary cloud LLM API, HirePilot performs its core AI tasks using local inference.

我是如何构建它的：HirePilot 背后的核心理念是，你的职业数据不应该为了准备工作而离开你的电脑。我围绕 Google 的 Gemma 3 4B 模型构建了该应用程序，并通过 Ollama 在本地运行。HirePilot 不依赖专有的云端 LLM API，而是通过本地推理执行其核心 AI 任务。

The stack: AI: Gemma 3 4B through Ollama. Frontend: React 19, TypeScript, Vite, Tailwind CSS, and Lucide React. Backend: Python, FastAPI, Pydantic, and HTTPX. Resume processing: pypdf and python-docx. Company research: ddgs for DuckDuckGo search, with optional Tavily integration. Persistence: Browser localStorage for application sessions, edits, and preparation progress.

技术栈：AI：通过 Ollama 运行的 Gemma 3 4B。前端：React 19、TypeScript、Vite、Tailwind CSS 和 Lucide React。后端：Python、FastAPI、Pydantic 和 HTTPX。简历处理：pypdf 和 python-docx。公司研究：用于 DuckDuckGo 搜索的 ddgs，以及可选的 Tavily 集成。持久化：用于应用程序会话、编辑和准备进度的浏览器 localStorage。

I separated the workflow into focused stages: resume and JD analysis, contextual clarification, resume generation, company research, interview preparation, and checklist generation. The resume matching score is calculated from matching skills, requirement gaps, and keyword coverage. It is an estimate of alignment with the JD, not a guarantee of passing an ATS. The application also distinguishes candidate-confirmed information from missing skills, so the AI doesn't need to fabricate experience to make a resume appear stronger.

我将工作流程分为几个重点阶段：简历与职位描述分析、情境澄清、简历生成、公司研究、面试准备和清单生成。简历匹配分数是根据匹配的技能、需求差距和关键词覆盖率计算得出的。这只是对职位匹配度的估计，并不能保证通过 ATS 系统。该应用程序还将候选人确认的信息与缺失的技能区分开来，因此 AI 不需要捏造经验来使简历看起来更出色。

Why Does Open Innovation Matter? For HirePilot, open innovation is what makes a privacy-focused, affordable career tool practical. 🔒 Privacy by design Resumes contain personal information and employment history. Running inference locally means candidates can use AI without sending their resume to a commercial LLM provider. Company research is handled separately. Search queries contain relevant company and role information, not the candidate's resume or personal contact details.

为什么开放创新很重要？对于 HirePilot 而言，开放创新是使这款注重隐私且经济实惠的职业工具变得切实可行的关键。🔒 隐私设计：简历包含个人信息和就业历史。在本地运行推理意味着候选人可以在不将简历发送给商业 LLM 提供商的情况下使用 AI。公司研究是单独处理的。搜索查询仅包含相关的公司和职位信息，而不包含候选人的简历或个人联系方式。

💸 No mandatory per-request LLM fees Once Ollama and the model are installed, the core AI workflow can run on the user's hardware without paying a commercial LLM API for each request. There is still a hardware requirement, and web research needs an internet connection. 🔄 Freedom to experiment Ollama makes it straightforward to experiment with different locally installed models. Developers can adjust prompts, generation settings, and model choices without tying the application to one proprietary API.

💸 无需按请求支付 LLM 费用：一旦安装了 Ollama 和模型，核心 AI 工作流就可以在用户的硬件上运行，而无需为每次请求支付商业 LLM API 费用。当然，这仍然有硬件要求，且网络研究需要互联网连接。🔄 实验自由：Ollama 使得尝试不同的本地安装模型变得非常简单。开发人员可以调整提示词、生成设置和模型选择，而无需将应用程序绑定到某个专有的 API 上。

🌱 Accessible career preparation A paid AI subscription shouldn't be a prerequisite for building a better resume or preparing for an interview. Local inference makes the core workflow more accessible while giving users greater control over their data.

🌱 可及的职业准备：付费的 AI 订阅不应成为制作更好简历或准备面试的先决条件。本地推理使核心工作流更易于获取，同时让用户对自己的数据拥有更大的控制权。

# Prompt-Space Meta-Learning Does Not Transfer Across Users: A Frozen-LLM Negative Result
# 提示空间元学习无法跨用户迁移：冻结大语言模型的负面结果

**Abstract:** Personalizing a frozen large language model (LLM) to individual users is often framed as a meta-learning problem in prompt space: each user is a task, and one seeks a shared natural-language adaptation policy that, given a handful of the user's labeled interactions, configures the frozen model for that user.

**摘要：** 将冻结的大语言模型（LLM）针对个人用户进行个性化定制，通常被构建为提示空间中的元学习问题：每个用户即为一个任务，研究目标是寻找一种共享的自然语言适配策略，该策略在给定少量用户标注交互数据的情况下，为该用户配置冻结模型。

The framing is attractive because it is backbone-agnostic and reuses the machinery of prompt optimization, yet the field rarely tests whether the optimized meta-objective encodes transferable cross-user adaptation rather than generic instruction quality.

这种框架之所以具有吸引力，是因为它与底层模型无关，且能够复用提示优化机制。然而，学术界很少验证优化后的元目标函数究竟是编码了可迁移的跨用户适配能力，还是仅仅提升了通用的指令质量。

We study this question with Muse (Meta-learned User-adaptation via Shared Evolution), which evolves a single shared adaptation prompt over a meta-train user population by reflective prompt evolution, freezes it, and applies it zero-shot to held-out users; matched controls isolate learning from confounds of phrasing and selection.

我们通过 Muse（基于共享演化的元学习用户适配）研究了这一问题。Muse 通过反射式提示演化，在元训练用户群体中演化出一个单一的共享适配提示，将其冻结后，零样本（zero-shot）应用于留出的测试用户；通过匹配的对照组，我们将学习效果与措辞及选择偏差等混杂因素隔离开来。

On two standard personalization benchmarks (LaMP-2 categorization and LaMP-3 rating) over 200 held-out users each, Muse does not significantly improve on its own un-evolved seed prompt or on a structure-broken control that meta-trains on mismatched user-support pairs, and is dominated by plain few-shot retrieval on the rating task (Delta MAE +0.175, p < 0.001).

在两个标准的个性化基准测试（LaMP-2 分类和 LaMP-3 评分）中，针对每个基准测试的 200 多名留出用户，Muse 的表现并未显著优于其未经演化的种子提示，也未优于在不匹配的用户-支持对上进行元训练的结构破坏对照组；在评分任务中，其表现甚至不及简单的少样本检索（Delta MAE +0.175, p < 0.001）。

We attribute these outcomes to a single mechanism, meta-objective collapse: the meta-validation objective is statistically invariant to whether the user-support correspondence is genuine (p=0.555 on LaMP-2, p=0.622 on LaMP-3), so it cannot be optimized into transferable adaptation and instead rewards instruction polish and validation overfitting.

我们将这些结果归因于单一机制——元目标崩溃（meta-objective collapse）：元验证目标在统计学上对于用户与支持数据之间的对应关系是否真实并不敏感（LaMP-2 上 p=0.555，LaMP-3 上 p=0.622），因此它无法被优化为可迁移的适配能力，反而倾向于奖励指令润色和验证集过拟合。

The seed-prompt, wrong-support, and invariance-oracle controls form a reusable protocol that separates learned adaptation from these confounds.

种子提示、错误支持和不变性预言机（invariance-oracle）对照组构成了一套可复用的协议，能够将习得的适配能力与上述混杂因素区分开来。

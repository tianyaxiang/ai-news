# ZipTok3D: High-Fidelity 3D Tokenization with Compact Token Prefixes
# ZipTok3D：基于紧凑 Token 前缀的高保真 3D Token 化技术

**Abstract:** Compact token sequences are essential for efficient 3D generation. However, existing 3D tokenizers typically organize latent representations either over spatial regions or as fixed-size sets of global tokens, both suffering sharp reconstruction degradation when compressed to extremely low token budgets.
**摘要：** 紧凑的 Token 序列对于高效的 3D 生成至关重要。然而，现有的 3D Token 化器通常将潜在表示组织在空间区域上，或作为固定大小的全局 Token 集合；当压缩到极低的 Token 预算时，这两种方法都会导致重建质量的急剧下降。

In this paper, we present ZipTok3D, a 3D tokenizer designed for high-fidelity reconstruction from extremely short token sequences. Its key idea is to organize object geometry into progressively informative global-token prefixes and unfold these compact representations through iterative decoding.
在本文中，我们提出了 ZipTok3D，这是一种专为从极短 Token 序列进行高保真重建而设计的 3D Token 化器。其核心思想是将物体几何结构组织成具有渐进信息量的全局 Token 前缀，并通过迭代解码来展开这些紧凑的表示。

Specifically, nested dropout randomly truncates the latent sequence after encoding during training and requires each retained prefix to reconstruct the complete object, thereby prioritizing essential geometric information in the leading tokens.
具体而言，嵌套 Dropout（nested dropout）在训练期间编码后随机截断潜在序列，并要求每个保留的前缀都能重建完整的物体，从而确保关键的几何信息被优先放置在靠前的 Token 中。

The decoder then repeatedly applies a parameter-shared Transformer block to recover fine-grained geometry from each prefix without a separate generative sampling stage.
随后，解码器重复应用参数共享的 Transformer 模块，从每个前缀中恢复细粒度的几何结构，而无需额外的生成式采样阶段。

With the same token dimension, ZipTok3D achieves reconstruction quality comparable to the 32-token COD-VAE baseline using only one token on ShapeNet and four on TRELLIS, yielding $32\times$ and $8\times$ shorter token sequences, respectively.
在相同的 Token 维度下，ZipTok3D 在 ShapeNet 上仅使用 1 个 Token，在 TRELLIS 上仅使用 4 个 Token，即可达到与 32-token 的 COD-VAE 基准相当的重建质量，分别实现了 32 倍和 8 倍的 Token 序列压缩。

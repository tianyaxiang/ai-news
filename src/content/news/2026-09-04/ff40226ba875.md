# Audacity 4.0

**Audacity 4.0**
Audacity 4 rebuilds the application interface on Qt and introduces many new quality-of-life improvements, including a new clip-editing model. Most Audacity 3 workflows remain available, but some controls have moved or changed.
Audacity 4 在 Qt 框架上重构了应用程序界面，并引入了许多新的易用性改进，包括全新的剪辑编辑模型。大多数 Audacity 3 的工作流程依然可用，但部分控件的位置或操作方式已发生变化。

### Editing clips
### 剪辑编辑
Clips can be selected directly. Click a clip header to select it, or Shift-click to select multiple clips. Several clips can be edited together. Moving, trimming and time stretching apply to all selected clips.
剪辑可以直接选中。点击剪辑标题即可选中，按住 Shift 键点击可选中多个剪辑。多个剪辑可以同时进行编辑，移动、修剪和时间拉伸操作将应用于所有选中的剪辑。

Clips can be grouped. Groups remain together when moved, copied, pasted or duplicated. Clips can be placed more freely. They can move between mono and stereo tracks. Moving a clip over another replaces the overlapped part instead of blocking the move.
剪辑可以进行分组。分组后的剪辑在移动、复制、粘贴或重复时会保持在一起。剪辑的放置更加自由，可以在单声道和立体声轨道之间移动。将一个剪辑移动到另一个剪辑上方时，会替换重叠部分，而不是阻止移动。

Splitting has a dedicated tool. Press or hold S, then click the waveform or clip header. Split, split-cut, split-delete, split at silences and split to a new track are also available as commands.
分割功能拥有专用工具。按下或按住 S 键，然后点击波形或剪辑标题即可。分割、分割剪切、分割删除、静音处分割以及分割到新轨道等功能也可作为命令使用。

Paste handles more cases automatically. Audacity can create a track when needed, adapt compatible channel layouts and paste audio files from the operating-system clipboard. Alignment guides, sample-boundary snapping and per-project snap settings have been added or expanded.
粘贴功能可自动处理更多情况。Audacity 可以在需要时创建轨道、适配兼容的声道布局，并从操作系统剪贴板粘贴音频文件。对齐参考线、采样边界吸附以及针对每个项目的吸附设置也已添加或扩展。

### Interface and tools
### 界面与工具
The interface has been rebuilt on Qt, with native high-DPI rendering. Toolbars and panels can be moved, docked, floated, shown or hidden. UI layouts can be saved as Workspaces. Audacity includes Modern, Classic and Music workspaces. Light, dark and high-contrast themes are available, along with accent colors, track colors and several clip styles.
界面基于 Qt 重构，支持原生高 DPI 渲染。工具栏和面板可以移动、停靠、悬浮、显示或隐藏。UI 布局可以保存为“工作区”（Workspaces）。Audacity 内置了现代、经典和音乐工作区。提供浅色、深色和高对比度主题，以及强调色、轨道颜色和多种剪辑样式。

The new Home screen shows recent projects with preview thumbnails. The separate Select, Envelope, Draw and Multi-tool modes have been removed. Their functions are now context-sensitive: Volume envelopes are displayed in the Clip gain mode. Sample drawing becomes available when the waveform is zoomed to individual samples. Splitting is available by holding S.
新的主屏幕显示带有预览缩略图的最近项目。原有的选择、包络、绘制和多功能工具模式已被移除，其功能现在根据上下文自动切换：音量包络显示在“剪辑增益”模式中；当波形缩放到单个采样级别时，采样绘制功能可用；按住 S 键即可进行分割。

Track and effect parameters use consistent rotary controls with fine adjustment and double-click reset. Sync-Lock has been removed. Delete, cut and paste now have explicit variants for either leaving a gap or moving later material to preserve timing.
轨道和效果参数使用统一的旋钮控件，支持微调和双击重置。Sync-Lock（同步锁定）已被移除。删除、剪切和粘贴现在有明确的变体，可以选择保留间隙或移动后续素材以保持时间轴同步。

### Playback and recording
### 播放与录音
The playhead remains visible during navigation and can be dragged to a new position. Playback can seek to another position without stopping. Recording can start anywhere on the timeline and creates a clip at that position. Loop boundaries and the interaction between playback, selections and loops have been revised.
播放头在导航过程中保持可见，并可拖动到新位置。播放过程中无需停止即可跳转到其他位置。录音可以在时间轴的任何位置开始，并在该位置创建一个剪辑。循环边界以及播放、选择和循环之间的交互逻辑已进行修订。

Punch and Roll, lead-in recording, latency compensation, software playthrough and per-track input monitoring have been rebuilt for the new interface. Audio Setup now includes system-default devices, refreshable device lists and custom channel mapping. Audacity can follow operating-system device changes automatically. Official Windows builds include ASIO playback and recording support.
“打入打出”（Punch and Roll）、预录音、延迟补偿、软件直通和单轨道输入监听功能已针对新界面重构。音频设置现在包括系统默认设备、可刷新设备列表和自定义声道映射。Audacity 可以自动跟随操作系统的设备变更。官方 Windows 版本包含 ASIO 播放和录音支持。

### Tracks, meters and effects
### 轨道、电平表与效果
Track headers now contain live playback and recording meters. Preset handling is consistent across built-in, destructive and realtime effects. Built-in effects, generators and analyzers have been rebuilt for the Qt interface. Supported plugin formats are VST3, Nyquist, LV2 on Linux and Audio Units on macOS. Audacity can display generated controls when a plugin's own interface is unavailable. Spectrogram has been redesigned with clearer guides and rulers, and faster rendering.
轨道标题现在包含实时播放和录音电平表。预设处理在内置、破坏性（destructive）和实时效果中保持一致。内置效果、生成器和分析器已为 Qt 界面重构。支持的插件格式包括 VST3、Nyquist、Linux 上的 LV2 以及 macOS 上的 Audio Units。当插件自身界面不可用时，Audacity 可以显示生成的控件。频谱图经过重新设计，具有更清晰的参考线和标尺，渲染速度更快。

### Projects, import and export
### 项目、导入与导出
Audacity 4 uses the new .aup4 project format. .aup3 projects open and convert to .aup4 without changing the original file. Converted projects cannot be saved back to .aup3. Older .aup projects can be imported. Project files store preview thumbnails and Audacity 4's additional clip and appearance data. And last but not least, we had the audacity to change the Audacity logo.
Audacity 4 使用全新的 .aup4 项目格式。.aup3 项目打开后会转换为 .aup4，且不会更改原始文件。转换后的项目无法保存回 .aup3 格式。旧版的 .aup 项目可以导入。项目文件现在存储预览缩略图以及 Audacity 4 新增的剪辑和外观数据。最后但同样重要的是，我们“大胆地”（audacity）更换了 Audacity 的图标。

### Compatibility notes
### 兼容性说明
The following Audacity 3 features are not available in Audacity 4.0, but we're working on adding them in future releases: Time Tracks, Note/MIDI tracks, Mixer, Macro Manager and the scripting pipe, VAMP and LADSPA plugin hosting. Play-at-speed, Sync-Lock and the old tool modes were replaced by the workflows described above. Additionally, Audacity 4 ships with some missing exporting and rendering features, analyzers, and effects.
以下 Audacity 3 的功能在 Audacity 4.0 中暂不可用，但我们正致力于在未来版本中添加它们：时间轨道（Time Tracks）、音符/MIDI 轨道、混音器、宏管理器及脚本管道、VAMP 和 LADSPA 插件托管。播放速度控制、Sync-Lock 和旧版工具模式已被上述工作流程取代。此外，Audacity 4 目前缺少部分导出和渲染功能、分析器及效果器。

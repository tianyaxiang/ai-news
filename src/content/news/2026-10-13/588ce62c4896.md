# SRT vs VTT: Which Caption File to Use, and How to Convert

SRT and VTT both hold timed captions as plain text. Here is how they differ, which one YouTube, Vimeo and a video tag want, and how to convert between them.
SRT 和 VTT 都是以纯文本形式存储定时字幕的文件格式。本文将介绍它们的区别、YouTube、Vimeo 及 video 标签各自的要求，以及如何在两者之间进行转换。

Summary: VTT is the safer pick when you can choose: Vimeo recommends it and the HTML track element expects a .vtt file. YouTube accepts both. To convert SRT to VTT, add a WEBVTT first line and change the comma before the milliseconds to a period, then save as UTF-8. Zoom saves cloud-recording transcripts as VTT and Teams offers .docx or .vtt, so the same conversion steps apply to both.
摘要：在可以选择的情况下，VTT 是更稳妥的选择：Vimeo 推荐使用它，而 HTML track 元素也需要 .vtt 文件。YouTube 则两者皆可。若要将 SRT 转换为 VTT，需在第一行添加 WEBVTT，并将毫秒前的逗号改为句点，然后以 UTF-8 编码保存。Zoom 将云录制转录保存为 VTT，Teams 则提供 .docx 或 .vtt 格式，因此两者均适用相同的转换步骤。

Which format for which place: VTT is the safer default when you get to choose. Vimeo recommends WebVTT, and the HTML <track> element expects a .vtt file. YouTube lists both formats, so SRT is fine there.
适用场景：在可以选择时，VTT 是更安全的默认格式。Vimeo 推荐使用 WebVTT，而 HTML <track> 元素也需要 .vtt 文件。YouTube 支持这两种格式，因此在那里使用 SRT 也是可以的。

How the two files look: Both are plain text: a timing line, the caption, a blank line. Here is the same caption in each.
文件外观：两者均为纯文本，包含时间轴行、字幕内容和空行。以下是同一字幕在两种格式中的表现。

SRT:
1
00:00:01,000 --> 00:00:03,500
Welcome back to the channel.

2
00:00:03,800 --> 00:00:06,200
Today we're fixing a leaky tap.

WebVTT:
WEBVTT
00:00:01.000 --> 00:00:03.500
Welcome back to the channel.

00:00:03.800 --> 00:00:06.200
<v Sam>Today we're fixing a leaky tap.

The differences you will actually run into: A WebVTT file must begin with the word WEBVTT. SRT has no header, just a counter before each caption. SRT writes the timestamp as HH:MM:SS,mmm with a comma, according to YouTube's format list. The WebVTT spec uses a period, and it lets you drop the hours. The numbers above each caption are optional in WebVTT, so converted files can keep them. WebVTT can mark who is speaking with a <v> voice tag, move a caption with cue settings such as position, align and line, and hold NOTE comments and STYLE blocks with CSS. YouTube says an SRT file carries no style information and no positioning.
实际遇到的差异：WebVTT 文件必须以 WEBVTT 开头。SRT 没有文件头，每段字幕前只有一个序号。根据 YouTube 的格式列表，SRT 的时间戳格式为 HH:MM:SS,mmm，使用逗号分隔。WebVTT 规范使用句点，并允许省略小时部分。WebVTT 中字幕上方的数字是可选的，因此转换后的文件可以保留它们。WebVTT 可以使用 <v> 语音标签标记说话人，通过位置、对齐和行等提示设置移动字幕，并包含 NOTE 注释和 CSS 样式块。YouTube 表示 SRT 文件不包含任何样式信息或定位信息。

YouTube: Either format uploads. YouTube points beginners to SRT (or SBV) because it needs only timing and text, and SRT must be plain UTF-8. Pick VTT when a caption has to sit somewhere other than the default spot, or you want bold, italic or underline. YouTube's page limits WebVTT styling to those three tags and describes its WebVTT support as an initial implementation, so don't count on fancy CSS surviving.
YouTube：两种格式均可上传。YouTube 建议初学者使用 SRT（或 SBV），因为它仅需时间和文本，且 SRT 必须是纯 UTF-8 编码。当字幕需要放置在非默认位置，或者需要加粗、斜体或下划线时，请选择 VTT。YouTube 的页面将 WebVTT 样式限制为这三种标签，并将其 WebVTT 支持描述为初步实现，因此不要指望复杂的 CSS 能生效。

Vimeo: Vimeo takes SRT and WebVTT, both in UTF-8. To add a file, open your Library, open the video, click the Languages button in the toolbar to the left of the player, then click the plus button and upload the file from your computer. Two dropdowns ask for the language and whether the file is a subtitle or a caption track. The three-dot menu next to an uploaded file lets you download, replace, delete or edit it.
Vimeo：Vimeo 接受 UTF-8 编码的 SRT 和 WebVTT 文件。要添加文件，请打开您的库，打开视频，点击播放器左侧工具栏中的“语言”按钮，然后点击加号按钮并从电脑上传文件。两个下拉菜单会询问语言以及该文件是字幕还是隐藏式字幕轨道。已上传文件旁边的三点菜单允许您下载、替换、删除或编辑它。

A video tag on your own page: Browsers load the track from a .vtt file, so an SRT has to be converted first. A minimal version:
自建网页的 video 标签：浏览器从 .vtt 文件加载轨道，因此 SRT 必须先进行转换。最小化版本如下：

<video controls src="talk.mp4">
  <track default kind="captions" srclang="en" label="English" src="talk.en.vtt">
</video>

MDN's attribute notes cover the rest. kind="captions" includes sound effects and musical cues, while kind="subtitles" covers dialogue or its translation and requires srclang. Only one track per video can carry default. The track URL must have the same origin as the page unless the <video> element has a crossorigin attribute, which matters if your captions sit on a CDN.
MDN 的属性说明涵盖了其余内容。kind="captions" 包含音效和音乐提示，而 kind="subtitles" 涵盖对话或其翻译，并需要 srclang。每个视频只能有一个轨道设置为 default。除非 <video> 元素具有 crossorigin 属性，否则轨道 URL 必须与页面同源，如果您的字幕存放在 CDN 上，这一点很重要。

A media player or TV app: Open the player's subtitle or caption menu, or its help page, and see which formats it names. If it lists both, either works. If it lists one, convert to that. If the clip has to play anywhere, you can also build the subtitles into the picture.
媒体播放器或电视应用：打开播放器的字幕菜单或帮助页面，查看它列出的格式。如果两者都列出，则均可使用。如果只列出一种，请转换为该格式。如果视频片段需要在任何地方播放，您也可以将字幕直接压制进视频画面中。

Converting SRT to VTT and back: A short file takes a few minutes in a plain-text editor. Work on a copy and save as UTF-8, which YouTube, Vimeo and the WebVTT spec all call for. If CapCut's auto captions fail and you need an SRT instead, see the SRT import fallback for CapCut.
SRT 与 VTT 的互转：在纯文本编辑器中处理短文件只需几分钟。请在副本上操作并保存为 UTF-8 编码，这是 YouTube、Vimeo 和 WebVTT 规范的要求。如果剪映（CapCut）的自动字幕失败且您需要 SRT，请参阅剪映的 SRT 导入备选方案。

SRT to VTT: Add WEBVTT as the first line, then a blank line. Change the comma before the milliseconds in every timing line to a period. In an editor with regular-expression search, find (\d\d:\d\d:\d\d),(\d\d\d) and replace it with \1.\2 (some editors want $1.$2). A plain replace-all on commas would also change commas inside the dialogue. Save the file with a .vtt extension.
SRT 转 VTT：在第一行添加 WEBVTT，然后空一行。将每一行时间轴中毫秒前的逗号改为句点。在支持正则表达式搜索的编辑器中，查找 (\d\d:\d\d:\d\d),(\d\d\d) 并将其替换为 \1.\2（某些编辑器需要 $1.$2）。直接全部替换逗号会改变对话内容中的逗号。保存文件时使用 .vtt 扩展名。

VTT to SRT: Delete the WEBVTT line and any NOTE or STYLE blocks. Change the period before the milliseconds in each timing line to a comma. If a timestamp has no hours, add them, so 05:12.300 becomes 00:05:12,300. Remove anything after the timing on that line (align:, position:) and strip <v Name> tags. SRT has no place for them. Number the captions 1, 2, 3 from the top and save with a .srt extension.
VTT 转 SRT：删除 WEBVTT 行以及任何 NOTE 或 STYLE 块。将每一行时间轴中毫秒前的句点改为逗号。如果时间戳没有小时，请补上，例如将 05:12.300 变为 00:05:12,300。删除该行时间轴之后的所有内容（align:、position: 等）并去除 <v Name> 标签，SRT 不支持这些。从顶部开始为字幕编号 1, 2, 3，并以 .srt 扩展名保存。

Why Zoom and Teams give you a VTT: Zoom saves the audio transcript of a cloud recording as a separate VTT file. That needs a Pro, Business, Education or Enterprise account with both cloud recording and audio transcription turned on. Teams lets the organizer and co-organizers download a meeting transcript as .docx or .vtt from Chat → Recap → Transcript → Download dropdown. A meeting transcript needs a time for each passage and a name for each speaker, and WebVTT has both built in through cue timings and the <v> tag. Teams also offers the .docx if you just want to read the text. For an SRT from either app, follow the VTT to SRT steps above. The full steps for getting the file are in our guides to saving a Zoom transcript and downloading a Teams transcript. If you only have plain text with no times, see our guide on adding timing to a plain transcript.
为什么 Zoom 和 Teams 提供 VTT：Zoom 将云录制的音频转录保存为单独的 VTT 文件。这需要开启了云录制和音频转录功能的专业版、商业版、教育版或企业版账户。Teams 允许组织者和共同组织者通过“聊天”→“回顾”→“转录”→“下载”下拉菜单下载 .docx 或 .vtt 格式的会议转录。会议转录需要每段话的时间和说话人姓名，WebVTT 通过提示时间轴和 <v> 标签内置了这两项功能。如果您只想阅读文本，Teams 也提供 .docx 格式。若要从这两个应用获取 SRT，请按照上述 VTT 转 SRT 的步骤操作。获取文件的完整步骤请参阅我们关于保存 Zoom 转录和下载 Teams 转录的指南。如果您只有没有时间的纯文本，请参阅我们关于为纯文本添加时间轴的指南。

If the captions don't show up: Accented or non-Latin characters look broken. The file isn't UTF-8. Vimeo warns.
如果字幕无法显示：带重音或非拉丁字符显示乱码。文件不是 UTF-8 编码。Vimeo 曾发出过此类警告。

Most of the writing a developer does all day isn't code. It's Slack replies, Notion specs and Linear tickets, typed fast between other things. Each of those apps hides shortcuts that cut that writing time down, and macOS adds a few more on top. Here are the 10 built-in tricks and 3 apps I'd learn first, grouped by where you'll use them.

开发者全天大部分的写作工作并非编写代码，而是在处理其他事务的间隙，快速输入 Slack 回复、Notion 规范和 Linear 工单。这些应用程序中都隐藏着能缩短写作时间的快捷键，macOS 系统也额外提供了一些功能。以下是我建议优先学习的 10 个内置技巧和 3 款应用程序，并按使用场景进行了分类。

Slack 1. Press Up arrow to fix the message you just sent. Typo in the message you sent five seconds ago? From an empty message field, the Up arrow opens your last message for editing by default. You can change that preference if you'd rather Up move focus to the last visible message.

Slack 1. 按向上箭头键修改刚发送的消息。五秒前发送的消息有错别字？在空白的消息输入框中，默认情况下，按向上箭头键即可打开上一条消息进行编辑。如果你希望向上箭头键将焦点移至最后一条可见消息，可以在偏好设置中进行更改。

Slack keyboard shortcuts 2. Format without leaving the keyboard. Select text and press Cmd+Shift+C for inline code, Cmd+Option+Shift+C for a code block, or Cmd+Shift+8 for a bulleted list. Shift+Enter starts a new line instead of sending, and Cmd+Shift+F applies markdown formatting.

Slack 键盘快捷键 2. 无需离开键盘即可进行格式化。选中文字并按 Cmd+Shift+C 可插入行内代码，按 Cmd+Option+Shift+C 可插入代码块，按 Cmd+Shift+8 可创建项目符号列表。Shift+Enter 可换行而不发送消息，Cmd+Shift+F 可应用 Markdown 格式。

Slack keyboard shortcuts 3. Paste a link over selected text. With a URL on your clipboard, select a word and press Cmd+V to turn it into a hyperlink. It reads much cleaner than a raw URL in the middle of a sentence. Notion does the same thing, so it's one habit that works in both.

Slack 键盘快捷键 3. 在选定文本上粘贴链接。当剪贴板中有 URL 时，选中一个词并按 Cmd+V，即可将其转换为超链接。这比在句子中间直接放一个原始 URL 看起来整洁得多。Notion 也有同样的功能，因此这是一个在两个应用中都适用的习惯。

Notion 4. Type Markdown and let it convert. At the start of a line, ## plus space makes a heading, [] plus space makes a to-do, and > plus space makes a toggle. Three dashes make a divider. You can write a whole spec without touching the block menu.

Notion 4. 输入 Markdown 并自动转换。在行首输入 ## 加空格可创建标题，[] 加空格可创建待办事项，> 加空格可创建折叠列表。输入三个连字符可创建分割线。你无需触碰块菜单即可写完一份完整的规范。

Notion keyboard shortcuts 5. Cmd+/ to change blocks you already wrote. Select one or more blocks and press Cmd+/ to turn them into a different type, change color, or move them. Typing /turn at the start or end of a block does the same thing for one block. Handy when a pasted list should have been a set of to-dos.

Notion 键盘快捷键 5. 使用 Cmd+/ 修改已编写的块。选中一个或多个块并按 Cmd+/，即可将其转换为其他类型、更改颜色或移动它们。在块的开头或结尾输入 /turn 对单个块也有同样的效果。当粘贴的列表本应是待办事项时，这个功能非常方便。

Notion keyboard shortcuts 6. @remind inside the doc. Type @remind and a date like "tomorrow" or "next Wednesday" to set a reminder right in the text. Plain @ plus a date inserts a date, and @ plus a name mentions a teammate and notifies them.

Notion 键盘快捷键 6. 在文档内使用 @remind。输入 @remind 和日期（如“明天”或“下周三”）即可直接在文本中设置提醒。直接输入 @ 加日期可插入日期，输入 @ 加姓名可提及团队成员并通知他们。

Linear 7. Option+C for issue templates. Templates prefill properties and can include placeholder text that prompts whoever files the issue for the details you always end up asking for. Press Option+C to create an issue from one, or pick Template in the new-issue modal.

Linear 7. 使用 Option+C 调用工单模板。模板可以预填属性，并包含占位符文本，提示提交工单的人提供你总是需要追问的详细信息。按 Option+C 可从模板创建工单，或者在新建工单的弹窗中选择“模板”。

Linear issue templates 8. Copy an issue as Markdown. Open the command menu with Cmd+K while viewing an issue and choose "copy issue in markdown." Useful for pasting a ticket into a PR description, a doc, or an AI chat without losing the formatting. The editor also converts Markdown you paste in.

Linear 工单模板 8. 以 Markdown 格式复制工单。在查看工单时，按 Cmd+K 打开命令菜单，选择“以 Markdown 格式复制工单”。这对于将工单粘贴到 PR 描述、文档或 AI 对话中且不丢失格式非常有用。编辑器还会自动转换你粘贴的 Markdown 内容。

macOS built-ins that work in all three 9. Option+Shift+Cmd+V to paste and match style. Pasting from a web page or email often drags in fonts and colors that don't belong. Paste and Match Style applies the style of the surrounding text instead, in apps that support it.

macOS 内置功能（适用于以上三者） 9. 使用 Option+Shift+Cmd+V 进行粘贴并匹配样式。从网页或电子邮件粘贴内容时，往往会带入不必要的字体和颜色。“粘贴并匹配样式”功能会在支持的应用中，将内容应用为周围文本的样式。

Mac keyboard shortcuts 10. Option+Delete and Control+K. Option+Delete removes the whole word to the left of the cursor, which beats holding Delete. Control+K cuts from the cursor to the end of the paragraph into a separate clipboard, and Control+Y pastes it back, without touching your main clipboard.

Mac 键盘快捷键 10. Option+Delete 和 Control+K。Option+Delete 可删除光标左侧的整个单词，这比按住 Delete 键更高效。Control+K 可将从光标处到段落末尾的内容剪切到一个独立的剪贴板中，Control+Y 可将其粘贴回来，且不会影响你的主剪贴板。

Apps I'd add on top 11. PopClip. Select text in any app and a small bar pops up with actions like copy, search, and a big library of extensions. It's a one-time license (also in Setapp), with a fully functional free trial for your first 250 actions.

我额外推荐的应用程序 11. PopClip。在任何应用中选中文字，都会弹出一个小工具栏，提供复制、搜索以及庞大的扩展库等操作。它是一次性买断制（也包含在 Setapp 中），并提供前 250 次操作的全功能免费试用。

12. Superwhisper. Hold a shortcut, talk, and the edited transcript is pasted into the app you're using, Slack and Notion included. Modes adjust tone and formatting, so a rambling voice note can come out as a tidy update. Free tier, with Pro features free for your first 3,000 words.

12. Superwhisper。按住快捷键说话，编辑后的转录文本就会粘贴到你正在使用的应用中，包括 Slack 和 Notion。多种模式可调整语气和格式，让一段杂乱的语音笔记变成整洁的更新内容。提供免费层级，前 3000 字可免费使用 Pro 功能。

13. DraftKey. For the typing you still do, DraftKey shows a suggested ending for your sentence in gray and Tab adds it. Tapping Command+Option opens rewrites like Shorter, Clearer, or Professional, and you preview the result before choosing Insert. It works in compatible text fields, you choose which apps it runs in, and some custom editors are excluded, so test it in your Slack, Notion and Linear setup.

13. DraftKey。对于你仍需手动输入的内容，DraftKey 会以灰色显示建议的句子结尾，按 Tab 键即可补全。点击 Command+Option 可打开重写选项，如“更简短”、“更清晰”或“更专业”，你可以在选择插入前预览结果。它适用于兼容的文本框，你可以选择它在哪些应用中运行，部分自定义编辑器可能不支持，因此请在你的 Slack、Notion 和 Linear 环境中进行测试。

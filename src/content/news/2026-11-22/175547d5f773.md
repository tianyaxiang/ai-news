# Did your document survive the move to Markdown? Three checks after MarkItDown

A successful conversion can still lose information MarkItDown turns documents into Markdown for downstream tools. A readable result is useful, but it is worth checking whether the text still carries the facts your agent needs.

即使转换成功，信息仍可能丢失。MarkItDown 将文档转换为 Markdown 以供下游工具使用。可读的结果固然有用，但值得检查文本是否仍然包含您的代理所需的事实。

Start with a small fixture. Put a unique sentence in the final section, then check that it appears in the output. Include a small table with an empty cell. Compare the rendered Markdown with the source and make sure each value still belongs to the correct column.

从一个小测试开始。在最后一部分放入一个独特的句子，然后检查它是否出现在输出中。包含一个带有空单元格的小表格。将渲染后的 Markdown 与源文件进行比较，确保每个值仍然属于正确的列。

Include a link whose label differs from its destination. Confirm that both survive and that the output still points to the intended page. Keep the original file alongside the converted version.

包含一个标签与其目标不同的链接。确认两者都得以保留，并且输出仍然指向预期的页面。将原始文件与转换后的版本放在一起。

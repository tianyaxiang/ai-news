Normalising UK numbers A call log export, a contact card and a number read aloud rarely agree on format. The same mobile can appear as 07700 900123, +44 7700 900123, 0044 7700 900123 or the hybrid +44 (0)7700 900123. A naive digit strip turns the last one into 4407700900123, which matches nothing. A small normaliser to E.164 handles the common cases and refuses to guess on the rest:

标准化英国号码：通话记录导出文件、联系人名片和口述号码的格式很少一致。同一个手机号码可能显示为 07700 900123、+44 7700 900123、0044 7700 900123 或混合格式 +44 (0)7700 900123。简单的数字提取会将最后一个号码变成 4407700900123，这无法匹配任何内容。一个小型 E.164 标准化程序可以处理常见情况，并拒绝猜测其余部分：

```python
import csv, io, re
from datetime import datetime, timedelta

def to_e164_uk(raw: str):
    """Normalise a UK-style number for comparison. Returns None if unsure."""
    s = raw.replace("(0)", "") # "+44 (0)7700 ..." trunk-prefix habit
    digits = re.sub(r"\D", "", s)
    if s.strip().startswith("+"): return "+" + digits
    if digits.startswith("00"): return "+" + digits[2:]
    if digits.startswith("0") and len(digits) in (10, 11): return "+44" + digits[1:]
    return None # don't guess
```

Returning None for 7700900123 (no trunk prefix, no country code) is deliberate. A false match is worse than an honest "can't tell".

对于 7700900123（无主干前缀，无国家代码）返回 None 是刻意为之的。错误的匹配比诚实的“无法判断”更糟糕。

Checking the claim against the log Assume a CSV export with a timestamp, a direction, a number and a duration. Many phones and carriers let you export something similar, though column names vary. The check looks for outgoing calls to the claimed number inside a lookback window, and separately notes inbound or missed calls from it:

根据日志核实主张：假设有一个包含时间戳、方向、号码和时长的 CSV 导出文件。许多手机和运营商都允许您导出类似内容，尽管列名各不相同。该检查会在回溯窗口内查找拨往所称号码的呼出电话，并单独记录来自该号码的呼入或未接来电：

```python
def load_log(text: str):
    rows = []
    for r in csv.DictReader(io.StringIO(text)):
        rows.append({
            "at": datetime.fromisoformat(r["timestamp"]),
            "direction": r["direction"],
            "number": to_e164_uk(r["number"]),
            "seconds": int(r["duration_s"]),
        })
    return rows

def check_callback_claim(rows, claimed_number, claimed_at, lookback_days=7):
    target = to_e164_uk(claimed_number)
    if target is None: return {"verdict": "cannot normalise claimed number"}
    start = claimed_at - timedelta(days=lookback_days)
    window = [r for r in rows if start <= r["at"] <= claimed_at]
    out = [r for r in window if r["direction"] == "outgoing" and r["number"] == target]
    inc = [r for r in window if r["direction"] in ("incoming", "missed") and r["number"] == target]
    if out:
        verdict = "this device did dial the number in the window"
    else:
        verdict = "no outgoing call to this number from this device in the window"
    return {"target": target, "window_rows": len(window), "outgoing_matches": [r["at"].isoformat() for r in out], "earlier_inbound_from_it": [r["at"].isoformat() for r in inc], "verdict": verdict}
```

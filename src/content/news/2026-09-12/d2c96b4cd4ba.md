### Agentic Development Needs a Famous 5-Minute Install
### 智能体开发需要一个著名的“5分钟安装”体验

WordPress became 40% of the Internet because it allowed anyone who could follow along a guide on a Linux terminal to install the Web Server and have the blog up and running in 5 minutes. That famous 5-minute install is what made WordPress the dominant web technology on the web.
WordPress 占据了互联网 40% 的份额，因为它让任何能够跟随 Linux 终端指南操作的人，都能在 5 分钟内安装好 Web 服务器并让博客运行起来。正是那个著名的“5 分钟安装”成就了 WordPress 在 Web 技术领域的统治地位。

Agents like Claude and Codex have taken over not just app and web development in the last 6-12 months - they have also taken over site creation. Anyone can jump into Claude, give it some direction and in 5 minutes get back a pretty damn good set of 2-3 static pages they can throw up on the web with any web server. That is the agent's 5-minute install.
在过去的 6 到 12 个月里，像 Claude 和 Codex 这样的智能体不仅接管了应用和 Web 开发，还接管了网站创建工作。任何人都可以进入 Claude，给出一些指令，并在 5 分钟内得到一套相当不错的 2-3 个静态页面，然后将其部署到任何 Web 服务器上。这就是智能体时代的“5 分钟安装”。

But what happens when you want to add a signup form, a calendar, or a small booking system? The agent can build you any bespoke system you want - but will it be secure? Will it be extendable? Will it even be maintainable by the agent in 6 months or will it be a re-write next year?
但当你想要添加注册表单、日历或小型预订系统时，情况会怎样呢？智能体可以为你构建任何你想要的定制系统，但它安全吗？它具有可扩展性吗？6 个月后，智能体还能维护它吗？还是说明年就得重写？

What agentic development needs is the famous 5-minute install with an agent-first CMS that has sandboxed plugins and a standard prescription for how to do the 90% of common tasks so that it will be maintainable and consistent over the next years.
智能体开发所需要的是一个著名的“5 分钟安装”体验，配套一个“智能体优先”的 CMS（内容管理系统）。它需要具备沙盒插件机制，并为 90% 的常见任务提供标准化的解决方案，从而确保系统在未来几年内是可维护且一致的。

Right now everyone has their own bespoke system. Framer is out there and that's awesome - but it doesn't help me if I want to create an online booking system or start selling a widget. We need an agent-first 5-minute install for the new web development environment.
目前，每个人都在使用自己的定制系统。Framer 很棒，但如果我想创建一个在线预订系统或开始销售小部件，它就帮不上忙了。我们需要为新的 Web 开发环境提供一种“智能体优先”的 5 分钟安装方案。

# Conformal Calibration Transfer

**Abstract:** Conformal prediction converts point predictions into set-valued predictions with coverage guarantees under exchangeability between calibration and deployment data. We study conformal calibration transfer, where this requirement fails because labeled calibration is available only in a source space, while prediction sets are needed in a target space linked to the source through unlabeled paired observations (e.g., paired modalities or sensor changes).

**摘要：** 一致性预测（Conformal prediction）能够在校准数据与部署数据满足可交换性（exchangeability）的前提下，将点预测转换为具有覆盖保证的集合值预测。我们研究了“一致性校准迁移”（conformal calibration transfer），在这种场景下，上述前提无法满足，因为带标签的校准数据仅存在于源空间，而我们需要在目标空间进行预测，且目标空间与源空间通过无标签的配对观测（例如配对模态或传感器变化）相关联。

We propose Transported Conformal Calibration (TCC): we transport labeled source calibration into the target space using the paired data, and then correct residual post-transport mismatch using only unlabeled target inputs. We instantiate this correction with two complementary methods: TCC-KS, which uses a label-free uncertainty surrogate to detect mismatch and adjust calibration conservatively, and weighted-TCC, which reweights transported calibration toward the target domain for improved efficiency when weights are stable.

我们提出了“迁移一致性校准”（Transported Conformal Calibration, TCC）：利用配对数据将带标签的源校准信息迁移到目标空间，随后仅使用无标签的目标输入来修正迁移后的残余偏差。我们通过两种互补的方法实现了这种修正：TCC-KS，它使用一种无需标签的不确定性代理来检测偏差并进行保守的校准调整；以及加权TCC（weighted-TCC），它在权重稳定时通过将迁移后的校准信息向目标域重加权，从而提高效率。

We provide finite-sample target-domain coverage guarantees that adapt to an observable measure of mismatch. Across CIFAR-100-C, Tiny-ImageNet-C, and SEN12MS, we show reliable target-domain coverage transfer without labeled target calibration data, with label-free diagnostics that predict when correction is needed.

我们提供了适应可观测偏差度量的有限样本目标域覆盖保证。通过在 CIFAR-100-C、Tiny-ImageNet-C 和 SEN12MS 数据集上的实验，我们证明了在没有带标签目标校准数据的情况下，该方法能够实现可靠的目标域覆盖迁移，并具备预测何时需要修正的无标签诊断能力。

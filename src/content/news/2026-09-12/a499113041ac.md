# Rethinking Handwritten Character Recognition
# 重新思考手写字符识别

Non-Latin handwritten character recognition (HCR) remains understudied. Dominant methods consider it as generic image classification, which uses model scale to implicitly learn stroke structure. Structural-prior efficiency---the principle that explicitly encoding script-geometric regularities as architectural inductive biases can be both more accurate and require fewer parameters.

非拉丁语系的手写字符识别（HCR）目前仍未得到充分研究。主流方法将其视为通用的图像分类问题，依赖模型规模来隐式学习笔画结构。本文提出了“结构先验效率”（Structural-prior efficiency）原则，即通过将书写系统的几何规律显式编码为架构归纳偏置，不仅能提高准确性，还能减少参数需求。

We introduce GraphemeNet, a unified multi-script architecture, governed by two orthogonal binary axes. Axis 1 operationalises stroke-level geometric regularity via Persistent Scaffold Injection (PSI): a script-specific asymmetric convolution injects a stroke scaffold as a weighted residual at every encoder stage, continuously anchoring learned features to script geometry---distinct from skip connections, auxiliary losses, or attention reweighting.

我们引入了 GraphemeNet，这是一种由两个正交二元轴控制的统一多脚本架构。轴 1 通过“持久支架注入”（Persistent Scaffold Injection, PSI）实现笔画级几何规律的操作：一种特定于脚本的非对称卷积在每个编码器阶段将笔画支架作为加权残差注入，持续将学习到的特征锚定在脚本几何结构上——这与跳跃连接、辅助损失或注意力重加权有着本质区别。

Axis 2 selects between global average pooling with gated fusion and cross-scale attention with a Stroke Topology Module (STM), depending on whether glyph discrimination requires spatial relational reasoning. A Linear Capsule Routing (LCR) with $O(n)$ routing is shared universally.

轴 2 根据字形辨识是否需要空间关系推理，在“带门控融合的全局平均池化”与“带笔画拓扑模块（STM）的跨尺度注意力机制”之间进行选择。此外，该架构全局共享一种 $O(n)$ 复杂度的线性胶囊路由（LCR）。

On fourteen benchmarks across eight writing systems, the architecture generalises with only scaffold and decoder topology varying per script, consistently challenging, outperforming published baselines, and establishing structural-prior efficiency as a broadly applicable principle for multi-script HCR.

在涵盖八种书写系统的十四个基准测试中，该架构表现出极强的泛化能力，仅需针对不同脚本调整支架和解码器拓扑。它持续挑战并超越了已发表的基准模型，确立了“结构先验效率”作为多脚本 HCR 广泛适用原则的地位。

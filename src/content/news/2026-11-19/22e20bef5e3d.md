Computer Science > Machine Learning arXiv:2611.21688 (cs) [Submitted on 16 Nov 2026] Title: DeltaHarness: Self-Evolving Harnesses for Resource-Adaptive Tool Execution Authors: Lecheng Yan, Jianze Lin, Xicheng Han, Xiantao Xu, Wenxi Li, Chenyang Lyu.

计算机科学 > 机器学习 arXiv:2611.21688 (cs) [提交于 2026 年 11 月 16 日] 标题：DeltaHarness：用于资源自适应工具执行的自进化工具链。作者：Lecheng Yan, Jianze Lin, Xicheng Han, Xiantao Xu, Wenxi Li, Chenyang Lyu。

Abstract: Tool-using agents rely on execution harnesses to organize and schedule tool operations. The same task and resource description can conceal runtime conditions that reverse the latency ordering of valid execution plans. Resolving this uncertainty requires firsthand execution in the target setting.

摘要：使用工具的智能体依赖执行工具链来组织和调度工具操作。相同的任务和资源描述可能隐藏了运行时条件，这些条件会逆转有效执行计划的延迟顺序。解决这种不确定性需要在目标环境中进行实地执行。

We introduce DeltaHarness, an execution-guided policy-search method that adapts agent harnesses from cold-start measurements. Its QHI loop uses the observed response to update runtime dispatch, revise physical plans, and select experiments for later proposals. An independent confirmation panel controls policy replacement.

我们引入了 DeltaHarness，这是一种执行引导的策略搜索方法，能够根据冷启动测量结果调整智能体工具链。其 QHI 循环利用观测到的响应来更新运行时调度、修订物理计划，并为后续建议选择实验。一个独立的确认小组负责控制策略的替换。

With fixed dispatch, a revised materialization policy reduces complete-delivery latency by 30.0% on one video-editing task across three fresh pairs. On held-out tasks, the evolved policies reduce latency by 8.2% relative to the best fixed plan in one seed and by 4.6% relative to the initial proposal in another.

在固定调度的情况下，修订后的具体化策略在三个新对的一个视频编辑任务中，将完整交付延迟降低了 30.0%。在留出的任务上，进化后的策略在一个种子实验中比最佳固定计划降低了 8.2% 的延迟，在另一个实验中比初始建议降低了 4.6% 的延迟。

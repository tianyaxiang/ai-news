### General Resolution: LLM usage in Debian
### 通用决议：Debian 中的大语言模型（LLM）使用规范

**Proposal A Choice 1: No LLM contributions to Debian via Social Contract Preamble**
**提案 A 选项 1：通过《社会契约》序言禁止向 Debian 提交 LLM 生成的内容**

This proposal aims to expressly forbid any contributions to Debian written with the use or assistance of large language models (LLMs) or other generative AI tools. The scope of this GR is (non-exhaustive):
本提案旨在明确禁止任何使用大语言模型（LLM）或其他生成式 AI 工具辅助编写并提交给 Debian 的内容。本通用决议（GR）的适用范围包括（但不限于）：

*   Debian source packages
*   Official Debian project software, such as lintian
*   Debian web resources
*   Documentation and translations added by Debian contributors
*   Official communication from Debian
*   Debian 源码包
*   Debian 官方项目软件（如 lintian）
*   Debian 网络资源
*   由 Debian 贡献者添加的文档和翻译
*   Debian 的官方通讯

It does not include:
该规定不包含：

*   Upstream projects using LLMs for development
*   AI-related software
*   Upstream patches/security fixes etc.
*   使用 LLM 进行开发的上游项目
*   AI 相关软件
*   上游补丁/安全修复等

**Rationale**
**理由**

Debian has a well-earned reputation for stability. This stability is crucial to Debian's position in the free software ecosystem. It is our belief that widespread LLM usage comes from the "move fast, and break things" attitude that, while common in many parts of this industry, is contrary to what makes Debian Debian, and is inappropriate for Debian contributors.
Debian 以其稳定性赢得了良好的声誉。这种稳定性对于 Debian 在自由软件生态系统中的地位至关重要。我们认为，大范围使用 LLM 源于一种“快速行动，打破常规”的态度；尽管这种态度在行业许多领域很常见，但它与 Debian 的立身之本相悖，且不适合 Debian 的贡献者。

# 4 Claude Skills Every Data Scientist Needs in 2026
# 2026 年数据科学家必备的 4 项 Claude 技能

A couple months ago I wrote about 3 Claude skills every data scientist needs to learn in 2026: Claude Dashboards, Claude Cowork for prioritizing Jira tickets, and Debugging with Claude Code. But these use cases only scratch the surface. There are many more ways Claude can cut down repetitive work and free up time for the parts of the job that actually need a person. So here are 4 more.

几个月前，我写过一篇关于 2026 年数据科学家需要学习的 3 项 Claude 技能的文章：Claude 仪表板（Dashboards）、用于优先处理 Jira 工单的 Claude Cowork，以及使用 Claude Code 进行调试。但这些用例仅仅是冰山一角。Claude 还有许多其他方法可以减少重复性工作，并腾出时间处理那些真正需要人工介入的工作环节。因此，这里再介绍 4 项技能。

### 1. Deep Research for Comparing Modeling Approaches
### 1. 用于比较建模方法的深度研究（Deep Research）

When you ask Claude a question, it will pull from one of three sources: Its own training data and knowledge, Web search, or Research. Web search and Research both need to be enabled. Web search will query the web for a singular answer to your question. But Research runs a sequence of connected web searches on its own, each one building on what the last one found. It then hands back a comprehensive report with citations.

当你向 Claude 提问时，它会从以下三个来源之一获取信息：其自身的训练数据和知识、网页搜索，或深度研究。网页搜索和深度研究都需要手动开启。网页搜索会针对你的问题在网上查询单一答案；而深度研究则会自动运行一系列相互关联的网页搜索，每一次搜索都建立在前一次发现的基础上。最后，它会提交一份带有引用的综合报告。

**How to use research mode in Claude:**
* Click the + button at the bottom left of the chat window.
* Select Research (a blue indicator confirms it's active).
* If Claude doesn't trigger it automatically on a question that calls for it, say so directly: "Claude, please use the research tool to..."

**如何在 Claude 中使用研究模式：**
* 点击聊天窗口左下角的“+”按钮。
* 选择“Research”（蓝色指示灯表示已激活）。
* 如果 Claude 没有针对需要研究的问题自动触发该功能，请直接指令：“Claude，请使用研究工具来……”

### 2. HTML Project Brief for Stakeholders
### 2. 为利益相关者制作 HTML 项目简报

Let's say you work for a Social Media Marketing company where you’ve been working on a content engagement forecasting model for a specific short-form reel campaign. However, the model isn’t working as expected. So you and other data scientists make a 2-month plan for model improvements. But non-technical stakeholders are often impatient and don’t understand why the posts are not performing as well as initially expected. They want improvements this week (which as data scientists know is often an unrealistic deadline). Creating a project brief can help. It shouldn’t be overly technical, but it should explain the main concepts in plain language and give a good sense of the plan, the timeline, and the current state of the project.

假设你在一家社交媒体营销公司工作，正在为一个特定的短视频（Reel）活动开发内容互动预测模型。然而，模型的效果未达预期。于是，你和其他数据科学家制定了一个为期 2 个月的模型改进计划。但非技术背景的利益相关者往往缺乏耐心，不理解为什么帖子的表现不如预期。他们希望本周就能看到改进（作为数据科学家，我们都知道这通常是不切实际的截止日期）。创建一个项目简报会有所帮助。它不应过于技术化，而应以通俗易懂的语言解释核心概念，并清晰地传达计划、时间表和项目现状。

Claude is great at generating HTML summary pages. Here’s a prompt you can use:
"Create a single HTML project brief for stakeholders on our Content Engagement Forecasting Model v2 rebuild..."

Claude 非常擅长生成 HTML 摘要页面。你可以使用以下提示词：
“为我们的内容互动预测模型 v2 重构项目，为利益相关者创建一个单页 HTML 项目简报……”

### 3. Claude Design for Stakeholder Slide Decks
### 3. 用于制作利益相关者演示文稿的 Claude Design

Claude Design is a separate tool from Claude chat and Cowork, built for visual design work. Examples include: Slide decks, Mobile app design, HTML emails, Invoices, Resumes. It specializes in producing structured kinds of documents where text alignment and formatting matters more. If you've tried to create slide decks or invoices with pure Claude Chat or Cowork you may have noticed that it sometimes produces images with text overlapping or misaligned. Design is better at not making these mistakes.

Claude Design 是独立于 Claude 聊天和 Cowork 的工具，专为视觉设计工作而构建。应用场景包括：演示文稿（Slide decks）、移动应用设计、HTML 邮件、发票、简历等。它擅长制作对文本对齐和格式要求较高的结构化文档。如果你曾尝试用纯 Claude Chat 或 Cowork 制作演示文稿或发票，可能会发现它有时生成的图像会出现文字重叠或对齐错误。而 Design 工具在避免这些错误方面表现更好。

**How to use Claude Design:**
Click "Design" with the paint palette icon in the bottom left corner of Claude. Select "Slides" under Choose a template.

**如何使用 Claude Design：**
点击 Claude 左下角带有调色板图标的“Design”按钮，在“选择模板”下选择“Slides”（幻灯片）。

# SLIDEFORGE: An LLM Agent for Controllable Editing of Slides as Structured Artifacts
# SLIDEFORGE：用于幻灯片结构化可控编辑的 LLM 智能体

**Abstract:** Current AI agents compellingly describe slides. However, AI-assisted slide editing requires more than understanding: the output must retain layout, style, component structure, and native editability. Towards, AI-assisted slide editing, existing agents operate on screenshots or weak document representations and often fragment coherent visual units, rasterize editable content, or break layout.

**摘要：** 目前的 AI 智能体在描述幻灯片方面表现出色。然而，AI 辅助的幻灯片编辑不仅仅需要理解能力：输出结果必须保留原始的布局、风格、组件结构以及原生可编辑性。在 AI 辅助幻灯片编辑方面，现有的智能体通常基于截图或薄弱的文档表示进行操作，这往往会导致连贯的视觉单元碎片化、可编辑内容被栅格化，或破坏原有的布局。

In contrast, for controllable slide editing, we introduce an agentic framework, SLIDEFORGE, which builds a Deck State Graph, an executable slide state that links visual decomposition, native pptx object structure, and perceptual organization. By recovering human-referable components while retaining fine-grained editable structure, SLIDEFORGE supports theme-preserving reconstruction through slide-native operations and rendered-state verification.

相比之下，为了实现可控的幻灯片编辑，我们引入了一个智能体框架 SLIDEFORGE。它构建了一个“幻灯片状态图”（Deck State Graph），这是一种可执行的幻灯片状态，将视觉分解、原生 pptx 对象结构和感知组织联系起来。通过在保留细粒度可编辑结构的同时恢复人类可引用的组件，SLIDEFORGE 支持通过幻灯片原生操作和渲染状态验证来实现主题保持的重构。

We further introduce an evaluation paradigm for controllable slide transformation that jointly measures component recovery, preservation, restyling consistency, visual quality, and native editability. Experiments show that SLIDEFORGE outperforms direct prompting, screenshot-based agents, and generic code-agent baselines across these dimensions. Code is available at this https URL.

我们进一步引入了一种用于可控幻灯片转换的评估范式，该范式综合衡量了组件恢复、保留、重设风格的一致性、视觉质量以及原生可编辑性。实验表明，SLIDEFORGE 在这些维度上均优于直接提示（direct prompting）、基于截图的智能体以及通用的代码智能体基准。代码已在链接中提供。

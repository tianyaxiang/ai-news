# No-Regret Bayesian Optimization with Finite-Library Input-Warped Kernels
# 基于有限库输入扭曲核的无悔贝叶斯优化

**Abstract:** Gaussian-process Bayesian optimization (GP-BO) excels at black-box optimization of costly functions, e.g., hyperparameter optimization (HPO) and multi-agent system (MAS) design. Convergence-rate guarantees exist for select methods, notably GP upper confidence bound (GP-UCB), but require a fixed kernel. Critically, the kernel encodes how input proximity affects objective value similarity. When raw coordinates poorly match this geometry - as with log-scaled hyperparameters or localized peaks - input warping can greatly improve sample efficiency, yet known GP-UCB proofs require a fixed kernel.

**摘要：** 高斯过程贝叶斯优化（GP-BO）在代价高昂函数的黑盒优化方面表现出色，例如超参数优化（HPO）和多智能体系统（MAS）设计。目前针对部分方法（特别是 GP 置信上限算法 GP-UCB）已存在收敛速率保证，但这些方法要求核函数固定。关键在于，核函数编码了输入邻近度如何影响目标值的相似性。当原始坐标与这种几何结构不匹配时（例如对数缩放的超参数或局部峰值），输入扭曲（Input Warping）可以显著提高采样效率，然而已知的 GP-UCB 证明均要求核函数保持不变。

We propose Finite-Library Input-Warped Bayesian Optimization (FLIWBO), which selects warps from a finite library of smooth input maps by any history-dependent rule. It adapts the input geometry to accelerate learning while retaining high-probability convergence guarantees under mild hypotheses, with an explicit $\sqrt(N_\varepsilon)$ library-size cost. Controlled diagnostics show that finite-library warping repairs planted geometry mismatches and identify FLIWBO failure cases.

我们提出了有限库输入扭曲贝叶斯优化（FLIWBO），它通过任何依赖于历史的规则，从平滑输入映射的有限库中选择扭曲方式。它通过调整输入几何结构来加速学习，同时在温和的假设下保留了高概率收敛保证，并具有明确的 $\sqrt(N_\varepsilon)$ 库规模成本。受控诊断表明，有限库扭曲修复了预设的几何不匹配问题，并识别出了 FLIWBO 的失效案例。

Across four repeated benchmarks - warped synthetic objectives, a confidence-fence trap, and Fashion-MNIST HPO - FLIWBO-UCB beats raw-coordinate GP-UCB under misspecified geometry, escapes traps that defeat even oracle-warp expected improvement, and recovers much of the gain from manual log scaling, while leading the tested methods that admit a matching regret guarantee. A 20-dimensional MAS design study further shows feasibility under costly noisy evaluations. Code for experiments is available: this https URL.

在四个重复的基准测试中——包括扭曲合成目标、置信围栏陷阱和 Fashion-MNIST HPO——FLIWBO-UCB 在几何结构错误指定的情况下击败了原始坐标 GP-UCB，逃脱了连“预言机扭曲期望改进”（oracle-warp expected improvement）都无法克服的陷阱，并恢复了大部分手动对数缩放带来的增益，同时在所有具备匹配遗憾保证的测试方法中处于领先地位。一项 20 维 MAS 设计研究进一步证明了其在代价高昂的噪声评估下的可行性。实验代码已公开：[链接]。

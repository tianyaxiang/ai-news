# VeriPhy: Agentic Physical Reasoning for World Model Evaluation and Refinement
# VeriPhy：用于世界模型评估与优化的代理物理推理

**Abstract:** Visual fluency in generated video does not imply physical reliability, and a scalar quality score alone is incapable of indicating the obligation a clip violates or the moment it fails. 
**摘要：** 生成视频的视觉流畅度并不意味着物理上的可靠性，仅凭标量质量分数无法指出视频片段违反了何种物理约束，也无法定位其失效的具体时刻。

We present VeriPhy, an auditable physical-verification system in which a text-only planner compiles the prompt into typed physical obligations and a statically validated execution plan before any frame is observed. 
我们提出了 VeriPhy，这是一个可审计的物理验证系统。在该系统中，纯文本规划器会在观察任何帧之前，将提示词（prompt）编译为类型化的物理约束以及经过静态验证的执行计划。

During execution, observations gate and scope only declared calls to frozen low-level experts (e.g., segmentation and tracking, counting, eleven typed physical measurements over the resulting tracks, depth, OCR, and audio-event detection). 
在执行过程中，观测结果仅对预先声明的、针对冻结底层专家模型（例如分割与追踪、计数、基于追踪结果的十一种类型化物理测量、深度估计、OCR 以及音频事件检测）的调用进行门控和范围限定。

Each action returns a provenance-carrying evidence record whose payload, when usable, is either a typed measurement or an explicitly tagged learned state. 
每个动作都会返回一个带有溯源信息的证据记录，其有效载荷（若可用）要么是类型化的测量数据，要么是经过明确标记的学习状态。

Typed resolvers and fixed composition map usable records to a three-valued state (supported, contradicted, or unknown, surfaced as plausible, implausible, or abstain) with full provenance, so that every verdict is traceable to the evidence that produced it. 
类型化解析器和固定组合机制将可用的记录映射为三值状态（支持、反驳或未知，分别对应合理、不合理或弃权），并保留完整溯源，从而确保每一个结论都能追溯到产生该结论的原始证据。

We anchor evaluation in a 1,500-clip corpus of human-annotated flaw records that localize real generation failures in prompt reference, space, and time. 
我们将评估锚定在一个包含 1,500 个视频片段的语料库上，这些片段带有由人工标注的缺陷记录，能够定位生成内容在提示词参考、空间和时间维度上的真实失效点。

On a 149-clip core carrying 304 such records, VeriPhy accounts for 228, against 164 for a published question-decomposition evaluator given the same clips and the same claims. 
在一个包含 304 条此类记录的 149 个核心片段测试集上，VeriPhy 成功识别了 228 条，而使用相同片段和相同声明的已发表问题分解评估器仅识别出 164 条。

Recall alone does not separate it from prompting the same backbone monolithically, which reaches 222; what separates them is that each decision retains its evidence record and provenance, making the traces auditable one verdict at a time and usable as the interface through which a critic verdict could be written back into generation. 
仅凭召回率并不能将其与直接对同一主干模型进行整体提示（monolithic prompting，召回率为 222）的方法区分开来；它们真正的区别在于，VeriPhy 的每一个决策都保留了证据记录和溯源信息，使得追踪过程可以逐个结论进行审计，并可作为接口将评估结论反馈回生成过程中。

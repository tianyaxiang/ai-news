# Generative Query Suggestion via Intent Coverage and Query-Level Credit Assignment
# 通过意图覆盖与查询级信用分配实现生成式查询建议

**Abstract:** Generative query suggestion aims to enhance user engagement by anticipating user intents and recommending relevant follow-up queries. A central challenge is to generate slates whose individual queries are useful while the slate covers distinct intents.

**摘要：** 生成式查询建议旨在通过预测用户意图并推荐相关的后续查询来增强用户参与度。其核心挑战在于：既要生成单个有用的查询，又要确保整个查询列表（slate）能够覆盖不同的意图。

We propose an Intent-Driven Query Suggestion Framework with dual-stage optimization. First, intent-aware diversity modeling constructs intent-aligned supervised fine-tuning (SFT) data and uses an Intent-Aware Diversity Reward to optimize intent coverage.

我们提出了一种具有双阶段优化功能的意图驱动查询建议框架。首先，意图感知多样性建模构建了与意图对齐的监督微调（SFT）数据，并利用“意图感知多样性奖励”来优化意图覆盖率。

Second, query-level credit assignment routes individual quality signals to the corresponding query tokens while sharing a slate-level diversity signal across the slate. Experiments on a large-scale production dataset, including online A/B testing and offline evaluation, show improvements in click-through rate, query quality, and intent coverage.

其次，查询级信用分配将单个质量信号路由至相应的查询标记，同时在整个查询列表中共享列表级的多样性信号。在大规模生产数据集上进行的实验（包括在线 A/B 测试和离线评估）表明，该方法在点击率、查询质量和意图覆盖率方面均有显著提升。

# Personalized Federated Hierarchical Gaussian Processes for Privacy-Preserving Modeling of Heterogeneous Distributed Systems
# 个性化联邦分层高斯过程：用于异构分布式系统的隐私保护建模

**Abstract:** We present Personalized Federated Hierarchical Gaussian Processes (pFedHGP) for probabilistic regression and classification when data are distributed across heterogeneous clients.
**摘要：** 我们提出了一种个性化联邦分层高斯过程（pFedHGP），用于处理数据分布在异构客户端时的概率回归和分类任务。

Each client's latent function decomposes into (i) a shared global component, (ii) a client-specific deviation that shares the global kernel structure, and (iii) a flexible local residual.
每个客户端的潜在函数被分解为：(i) 一个共享的全局组件；(ii) 一个共享全局核结构的客户端特定偏差；以及 (iii) 一个灵活的局部残差。

Sparse inducing-variable approximations and federated variational inference keep raw data local while the server synchronizes only low-dimensional statistics for the shared component.
稀疏诱导变量近似和联邦变分推理技术确保了原始数据保留在本地，而服务器仅需同步共享组件的低维统计信息。

Full predictive distributions support uncertainty-aware decisions.
完整的预测分布支持基于不确定性的决策。

In application studies, pFedHGP attains perfect fault classification in press tonnage monitoring using 13.77% of labeled cycles and recovers geographic zones in federated air-quality modeling without centralizing station-level time series.
在应用研究中，pFedHGP 在压力吨位监测中仅使用 13.77% 的标记周期就实现了完美的故障分类，并在联邦空气质量建模中无需集中处理站点级时间序列即可恢复地理区域。

An Instantaneous Linear Mixing Model viewpoint links the hierarchy to multi-output Gaussian processes for correlated sensors.
瞬时线性混合模型（Instantaneous Linear Mixing Model）的视角将该分层结构与相关传感器的多输出高斯过程联系起来。

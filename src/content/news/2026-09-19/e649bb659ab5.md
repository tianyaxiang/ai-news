# This cartridge-playing Game Boy clone is smaller and cheaper than Analogue’s Pocket
# 这款支持卡带的 Game Boy 复刻机比 Analogue Pocket 更小、更便宜

The FPGB Mini is only slightly wider than the original Nintendo cartridges it plays.
FPGB Mini 的机身宽度仅比它所支持的任天堂原版卡带稍宽一点。

FunnyPlaying, a Chinese company known for its Game Boy and GBA upgrade kits, has announced a new handheld that plays original Nintendo cartridges and ROMs. The FPGB Mini’s cartridge support is limited to the Game Boy and Game Boy Color so it isn’t as capable as the Analogue Pocket that’s also compatible with the GBA and Sega Game Gear. What still makes the FPGB Mini a tempting alternative is its extremely pocketable design resulting in a handheld only slightly wider than a Game Boy cartridge, and its cheaper price.
以生产 Game Boy 和 GBA 改装套件而闻名的中国公司 FunnyPlaying，近日发布了一款可以运行任天堂原版卡带和 ROM 的新掌机。FPGB Mini 对卡带的支持仅限于 Game Boy 和 Game Boy Color，因此其功能不如同时兼容 GBA 和世嘉 Game Gear 的 Analogue Pocket。但 FPGB Mini 依然是一个极具吸引力的替代品，原因在于它极其便携的设计——其机身宽度仅比 Game Boy 卡带稍宽，且价格更为亲民。

Following recent price hikes the Analogue Pocket is now $239.99 while the FPGB Mini is currently discounted from $89.99 to $69.99 for the first batch of just 20 units that quickly sold out. However, the company is potentially planning to release more following some hardware improvements, according to Retro Dodo who’s been testing the handheld for a few days and so far seems impressed with its design and capabilities.
在近期涨价后，Analogue Pocket 的售价已达 239.99 美元，而 FPGB Mini 的首批 20 台机器目前正以 69.99 美元的优惠价（原价 89.99 美元）发售，并已迅速售罄。据 Retro Dodo 报道，该媒体在测试了几天后对这款掌机的设计和性能印象深刻，并表示该公司计划在进行一些硬件改进后推出更多产品。

Like the Pocket the FPGB Mini uses field-programmable gate array (FPGA) technology to play Game Boy and GBC games as accurately as Nintendo’s original hardware does. But the FPGB Mini brings improvements like a 2.98-inch, 800x720-pixel LCD display, an 1,800mAh rechargeable battery, and a microSD slot for storing game saves, screenshots, or ROMs that can be played through emulation. The handheld’s compact size does prevent cartridges with rumble motors or other hardware additions from being used, but otherwise the FPGB Mini looks to be about as small as the Game Boy is ever going to get.
与 Pocket 一样，FPGB Mini 采用了现场可编程门阵列（FPGA）技术，能够像任天堂原版硬件一样精准地运行 Game Boy 和 GBC 游戏。此外，FPGB Mini 还带来了多项改进，包括一块 2.98 英寸、800x720 分辨率的 LCD 显示屏、一块 1800mAh 的可充电电池，以及一个用于存储游戏存档、截图或通过模拟器运行 ROM 的 microSD 卡槽。虽然受限于紧凑的机身尺寸，该掌机无法使用带有震动马达或其他附加硬件的卡带，但除此之外，FPGB Mini 看起来已经将 Game Boy 的体积压缩到了极致。

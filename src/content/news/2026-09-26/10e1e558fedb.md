# La verdadera alternativa para Rufus en Linux... ¡¿No es Balena-Etcher?!
# Linux 上 Rufus 的真正替代品……竟然不是 Balena-Etcher？！

Sí, lo acabas de leer bien, lo he dicho y escrito aquí y ahora, Balena-etcher no es la verdadera alternativa a Rufus en sistemas Linux... En lo que a ISOs de Windows se trata. Dejame explicarte.
没错，你没看错，我在这里郑重声明：在处理 Windows ISO 镜像时，Balena-Etcher 并不是 Linux 系统下 Rufus 的真正替代品。让我来解释一下。

Hace un par de horas un colega que se dedica ocasionalmente a reparar computadores de mesa y laptops me dijo "Necesito una version del win10 que sea ligera, a la de ya, mándame un pendrive" y yo que soy todo un caballero procedí a hacer lo que cualquiera que sepa del tema haría; Flashear una ISO de win10 LTSC (que pesa sus 4Gbs, a veces hasta 6GBs) en una USB de 8Gb.
几小时前，一位偶尔负责维修台式机和笔记本电脑的同事对我说：“我急需一个轻量版的 Win10，赶紧给我弄个启动 U 盘。”作为一名绅士，我便开始做任何懂行的人都会做的事：将一个 Win10 LTSC ISO 镜像（大小约 4GB 到 6GB）烧录到 8GB 的 U 盘中。

El meollo? que estoy en linux y no tengo acceso al ya conocido y confiable Rufus. Busco alternativa rapida y recuerdo que Balena es una buena alternativa para flashear ISOs. Conecto el pendrive, abro el balena, cargo el ISO y ¡BUM!... No funciona... ¿Qué?
问题在于，我使用的是 Linux 系统，无法使用那个众所周知且可靠的 Rufus。我寻找快速替代方案，想起了 Balena 是烧录 ISO 的好工具。我插上 U 盘，打开 Balena，加载 ISO，然后……砰！失败了……什么情况？

El error que me tira dice h.requestmetadata is not a function, si pudiera cargara la screenshot, pero no la tomé, en fin, que googlee el problema y resulta que Balena no es muy confiable en lo que a ISOs de Windows se trata, asi que, que hacemos? Dejame presentarte a WoeUSB. WoeUSB: La verdadera alternativa.
报错信息显示 `h.requestmetadata is not a function`。如果能上传截图就好了，但我当时没截。总之，我谷歌了一下这个问题，发现 Balena 在处理 Windows ISO 时确实不太靠谱。那么，我们该怎么办？让我为你介绍 WoeUSB。WoeUSB：这才是真正的替代品。

Dependiendo de en que sabor de Linux te encuentres la instalación cambiara, pero en general la encuentras en cualquier tienda de Apps, o en tu helper de AUR favorito, en mi caso hago uso del buen Paru: `paru -S woeusb-ng` Si a todo, y una vez ya instalado tendrás acceso a una GUI simple, rápida e intuitiva, y también la posibilidad de realizar el proceso mediante la terminal.
根据你所使用的 Linux 发行版，安装方式会有所不同，但通常你可以在任何应用商店或你最喜欢的 AUR 助手里找到它。以我为例，我使用的是好用的 Paru：`paru -S woeusb-ng`。一路确认安装后，你将获得一个简单、快速且直观的图形界面，同时也支持通过终端完成整个过程。

Esta vez hagamos el proceso por la terminal. `woeusb -h` nos da todos los datos que necesitamos: Según la ayuda, "WoeUSB can create a bootable Microsoft Windows(R) USB storage device from an existing Windows optical disk or an ISO disk image" tenemos la posibilidad de crear una usb bootable desde un disco óptico de Windows existente o desde una imagen ISO.
这次我们通过终端来操作。`woeusb -h` 提供了我们需要的所有信息：根据帮助文档，“WoeUSB 可以从现有的 Windows 光盘或 ISO 镜像创建可启动的 Microsoft Windows USB 存储设备”。我们既可以从现有的 Windows 光盘创建，也可以从 ISO 镜像创建。

Hagamos la segunda, en mi caso especificare las siguientes flags: `--device , -d` : Que borra todo el contenido de la usb, y crea el USB booteable desde cero. `--verbose , -v` : Nos dice todo lo que esta haciendo la utilidad. El comando quedaría algo tal que así: `woeusb -d -v ruta/a/tu/iso /dev/tuUSB`
我们选择后者。我将使用以下参数：`--device (-d)`：清除 U 盘所有内容，从零开始创建启动盘。`--verbose (-v)`：显示工具执行的所有详细步骤。命令格式如下：`woeusb -d -v 你的ISO路径 /dev/你的U盘`

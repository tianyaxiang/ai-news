# Tcl/Tk 9.1

**Tcl/Tk 9.1 Latest Release: Tcl/Tk 9.1.0 (Sep 29, 2026)**
**Tcl/Tk 9.1 最新版本：Tcl/Tk 9.1.0（2026 年 9 月 29 日）**

Tcl/Tk 9.1.0 is the current development work on Tcl and Tk, aiming toward stable releases in September 2026. They add new features and interfaces to the foundation of Tcl/Tk 9.0.
Tcl/Tk 9.1.0 是 Tcl 和 Tk 目前的开发版本，旨在 2026 年 9 月发布稳定版。它们在 Tcl/Tk 9.0 的基础上增加了新的功能和接口。

**Highlights of Tcl 9.1**
**Tcl 9.1 亮点**

* New command `unicode`: Unicode normalization
* 新命令 `unicode`：支持 Unicode 标准化
* New C routines `Tcl_UtfToNormalized*`: Unicode normalization
* 新的 C 例程 `Tcl_UtfToNormalized*`：支持 Unicode 标准化
* New command `timer`: monotonic clock; microsecond resolution
* 新命令 `timer`：单调时钟；微秒级分辨率
* New command `lfilter`: select items from list
* 新命令 `lfilter`：从列表中筛选项目
* New command `interp set`: variable access in child interpreter
* 新命令 `interp set`：在子解释器中访问变量
* New `subst` options: `-backslashes`, `-commands`, `-variables`.
* 新的 `subst` 选项：`-backslashes`、`-commands`、`-variables`
* New `switch` options: `-integer`.
* 新的 `switch` 选项：`-integer`
* Many C99 math routines now available as `expr` functions.
* 许多 C99 数学例程现已可用作 `expr` 函数。
* Applications now required to call an initialization routine, either `Tcl_FindExecutable` or `TclZipfs_AppHook`.
* 应用程序现在必须调用初始化例程，即 `Tcl_FindExecutable` 或 `TclZipfs_AppHook`。
* New C routine `Tcl_IsEmpty`.
* 新的 C 例程 `Tcl_IsEmpty`。
* New C routine `Tcl_GetEncodingNameForUser`.
* 新的 C 例程 `Tcl_GetEncodingNameForUser`。
* New C routine `Tcl_AttemptCreateHashEntry`.
* 新的 C 例程 `Tcl_AttemptCreateHashEntry`。
* New C routines `Tcl_ListObjRange`, `Tcl_ListObjRepeat`, `Tcl_ListObjReverse`.
* 新的 C 例程 `Tcl_ListObjRange`、`Tcl_ListObjRepeat`、`Tcl_ListObjReverse`。
* New C time API using `long long` in place of `Tcl_Time`.
* 新的 C 时间 API，使用 `long long` 代替 `Tcl_Time`。
* Case-insensitive filesystem paths on macOS.
* macOS 上支持不区分大小写的文件系统路径。
* `auto_execok` and `exec` search reform on Windows.
* Windows 上对 `auto_execok` 和 `exec` 的搜索机制进行了改革。
* Revised searches for script library and encodings.
* 修订了脚本库和编码的搜索方式。
* Improved list internals for memory efficiency of large lists.
* 改进了列表内部结构，提高了大型列表的内存效率。
* Extended support for 64-bit sizes.
* 扩展了对 64 位大小的支持。

**Highlights of Tk 9.1**
**Tk 9.1 亮点**

* Accessibility screen reader support.
* 支持辅助功能屏幕阅读器。
* Initial support for bidirectional text / RTL languages.
* 初步支持双向文本 / 从右向左（RTL）语言。
* New widget `ttk::toggleswitch`.
* 新的小部件 `ttk::toggleswitch`。
* New command `tk attribtable`.
* 新命令 `tk attribtable`。
* `send` command revised and improved on Aqua.
* 在 Aqua 系统上修订并改进了 `send` 命令。
* Handling of negative screen distances.
* 处理负屏幕距离。
* Extended states in `ttk::treeview` and `ttk::notebook`.
* 在 `ttk::treeview` 和 `ttk::notebook` 中扩展了状态。
* Improvements to `Tk_CanvasTextInfo`.
* 改进了 `Tk_CanvasTextInfo`。
* Rotated text on labels.
* 标签上的旋转文本支持。
* Limit message box and dialogs to physical screen width.
* 将消息框和对话框限制在物理屏幕宽度内。
* Improved listbox selection colors.
* 改进了列表框的选择颜色。
* Removed obsolete support for Windows XP appearances.
* 移除了对 Windows XP 外观的过时支持。

### Why DBX?

**🪶 25 MB, zero runtime bloat**
No Java JRE. No Python venv. No bundled Chromium. DBX ships as a single small binary — download, install, connect. DBeaver needs Java; TablePlus is Freemium. DBX runs everywhere with nothing extra.
**25 MB，零运行时臃肿**
无需 Java JRE，无需 Python 虚拟环境，无需捆绑 Chromium。DBX 以单个小型二进制文件形式发布——下载、安装、连接即可。DBeaver 需要 Java，TablePlus 是付费增值模式。DBX 无需任何额外依赖，随处运行。

**🤖 AI that lives in your editor**
Highlight a table, describe what you want, get SQL back — no copy-paste between tools. Works with Claude, OpenAI, or local models via Ollama. Built-in safety checks review AI-generated SQL before it runs.
**内置于编辑器的 AI**
选中表，描述需求，即可获得 SQL——无需在不同工具间复制粘贴。支持 Claude、OpenAI 或通过 Ollama 运行的本地模型。内置安全检查，在执行前审查 AI 生成的 SQL。

**🔌 MCP: your databases, AI-ready**
DBX speaks the Model Context Protocol. Claude Code, Cursor, Windsurf, and other AI coding agents can query your databases through connections you already set up. One config, everywhere.
**MCP：让你的数据库为 AI 就绪**
DBX 支持 Model Context Protocol (MCP)。Claude Code、Cursor、Windsurf 及其他 AI 编程智能体可以通过你已配置的连接直接查询数据库。一次配置，处处可用。

**🌐 Desktop + Docker + Web**
Native app on macOS, Windows, and Linux. Self-host via Docker for team access. Web version for browser-only environments. Same feature set. Same connections.
**桌面端 + Docker + Web**
支持 macOS、Windows 和 Linux 原生应用。通过 Docker 自托管以供团队访问。Web 版本适用于仅限浏览器的环境。功能一致，连接共享。

**📨 Not just databases**
Message queues and middleware get first-class consoles: Kafka, RocketMQ, RabbitMQ, Pulsar, and MQTT, plus Nacos, Consul, ZooKeeper, and etcd. Inspect topics and messages next to your databases — no extra tool.
**不仅是数据库**
消息队列和中间件拥有顶级控制台支持：Kafka、RocketMQ、RabbitMQ、Pulsar 和 MQTT，以及 Nacos、Consul、ZooKeeper 和 etcd。在数据库旁边即可检查主题和消息——无需额外工具。

**🧩 Plugin ecosystem**
Extend DBX with signed, sandboxed plugins from the built-in store — S3, Kubernetes, LDAP, and more. Build your own with the Go / TypeScript SDK.
**插件生态系统**
通过内置商店获取签名、沙箱化的插件来扩展 DBX 功能——支持 S3、Kubernetes、LDAP 等。使用 Go / TypeScript SDK 构建你自己的插件。

### Features

**100+ Databases, One Tool**
MySQL, PostgreSQL, SQLite, Cloudflare D1, Redis, MongoDB, DuckDB, ClickHouse, SQL Server, Oracle, Elasticsearch, Easysearch, Meilisearch, Qdrant, Milvus, Weaviate, MariaDB, TiDB, OceanBase, openGauss, GaussDB, KWDB, KingbaseES, Vastbase, GoldenDB, Doris, SelectDB, StarRocks, Manticore Search, Redshift, DM, TDengine, XuguDB, CockroachDB, Access, HighGo, UXDB, Dolt, and more.
**100+ 种数据库，一个工具搞定**
支持 MySQL、PostgreSQL、SQLite、Cloudflare D1、Redis、MongoDB、DuckDB、ClickHouse、SQL Server、Oracle、Elasticsearch、Easysearch、Meilisearch、Qdrant、Milvus、Weaviate、MariaDB、TiDB、OceanBase、openGauss、GaussDB、KWDB、KingbaseES、Vastbase、GoldenDB、Doris、SelectDB、StarRocks、Manticore Search、Redshift、DM、TDengine、XuguDB、CockroachDB、Access、HighGo、UXDB、Dolt 等。

New native and agent-driven drivers also cover Databricks, SAP HANA, Teradata, Vertica, Firebird, Exasol, YashanDB, GBase 8a/8s, Databend, RQLite, Turso, InfluxDB, QuestDB, IoTDB, etcd, ZooKeeper, Nacos, Consul KV, IRIS, and more. All in a single ~25 MB app. No bundled Chromium.
基于 Agent 的配置将 DBX 扩展至 H2、Snowflake、Trino、PrestoSQL、Hive、DB2、Informix、Neo4j、Cassandra、BigQuery、Cloud Spanner、Kylin、SunDB、JDBCX 及自定义 JDBC 连接。新增的原生和 Agent 驱动还涵盖了 Databricks、SAP HANA、Teradata、Vertica、Firebird、Exasol、YashanDB、GBase 8a/8s、Databend、RQLite、Turso、InfluxDB、QuestDB、IoTDB、etcd、ZooKeeper、Nacos、Consul KV、IRIS 等。所有功能集成在约 25 MB 的单个应用中，无捆绑 Chromium。

**Query Editor**
CodeMirror 6 with SQL syntax highlighting, metadata-aware autocomplete, Cmd+Enter execution, selected SQL execution, SQL formatting, diagnostics, and 9 editor themes. Persistent query history, saved SQL snippets, tab restore, and SQL file execution keep repeat work close at hand.
**查询编辑器**
采用 CodeMirror 6，支持 SQL 语法高亮、元数据感知自动补全、Cmd+Enter 执行、选中 SQL 执行、SQL 格式化、诊断及 9 种编辑器主题。持久化查询历史、已保存的 SQL 片段、标签页恢复和 SQL 文件执行功能，让重复工作触手可及。

**AI SQL Assistant**
Describe what you want in plain language — get SQL back. DBX can explain queries, optimize SQL, fix errors, and run AI-generated SQL through built-in safety checks. Works with Claude, OpenAI, local models, or any OpenAI-compatible endpoint.
**AI SQL 助手**
用自然语言描述需求，即可获得 SQL。DBX 可以解释查询、优化 SQL、修复错误，并通过内置安全检查运行 AI 生成的 SQL。支持 Claude、OpenAI、本地模型或任何兼容 OpenAI 的端点。

**Data Grid**
Virtual-scrolled table that handles large result sets. Inline editing, SQL preview before save, WHERE / ORDER BY controls, DataGrip-style filters, LIKE / NOT LIKE context filters, sorting, full-text search, pagination, column resize, auto-fit, row numbers, zebra stripes, and full cell details. Export or copy as CSV, JSON, Markdown, XLSX, or INSERT statements.
**数据网格**
支持虚拟滚动的表格，可处理大规模结果集。支持行内编辑、保存前 SQL 预览、WHERE / ORDER BY 控制、DataGrip 风格过滤器、LIKE / NOT LIKE 上下文过滤器、排序、全文搜索、分页、列宽调整、自动适应、行号、斑马纹及完整的单元格详情。支持导出或复制为 CSV、JSON、Markdown、XLSX 或 INSERT 语句。

**Schema Tools**
Schema browser — databases, schemas, tables, columns, indexes, foreign keys, triggers, with sidebar search & pin. Object browser — grouped procedures, functions, views, and source editing where supported. Table structure editor — reviewable column and index changes for supported engines. ER diagram — visualize table relationships. Schema diff — compare structures across connections. Explain plan — visual query execution plan. Field lineage — column-level lineage analysis. Database search — find objects across large schemas.
**架构工具**
架构浏览器——包含数据库、Schema、表、列、索引、外键、触发器，支持侧边栏搜索与固定。对象浏览器——分组显示存储过程、函数、视图，并在支持的情况下进行源码编辑。表结构编辑器——支持引擎的可审查列与索引变更。ER 图——可视化表关系。架构差异对比——跨连接对比结构。执行计划——可视化查询执行计划。字段血缘——列级血缘分析。数据库搜索——在大型 Schema 中查找对象。

**Data Operations**
Table import — CSV, Excel. Data transfer — migrate between databases. Database export — full database dump. Data compare — compare tables.
**数据操作**
表导入——支持 CSV、Excel。数据传输——数据库间迁移。数据库导出——完整数据库转储。数据对比——对比表数据。

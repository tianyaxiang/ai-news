# Alexa can’t control the aux input on Amazon Echo speakers anymore
# Alexa 无法再控制 Amazon Echo 音箱的辅助输入（AUX）功能

If you’ve been using an older Amazon Echo device as a speaker through its 3.5mm aux input, Alexa voice commands to play or pause from line in may stop working. Ars Technica points to this Reddit poster claiming they received a message from Amazon about the change, which the company has confirmed.
如果你一直通过 3.5mm 辅助输入接口将旧款 Amazon Echo 设备当作音箱使用，那么通过 Alexa 语音指令控制线路输入（line-in）播放或暂停的功能可能会失效。Ars Technica 指出，有 Reddit 用户发帖称收到了亚马逊关于此项变更的通知，亚马逊公司也已证实了这一消息。

According to Amazon spokesperson Claudia Chavira Velez, “We recently notified the very small number of customers using voice requests to play or pause audio from the aux audio input on select Echo devices that this functionality will no longer be supported.”
亚马逊发言人 Claudia Chavira Velez 表示：“我们最近通知了极少数使用语音请求来控制特定 Echo 设备辅助音频输入播放或暂停的客户，该功能将不再受支持。”

The message does not include any explanation for why the feature was removed. It also doesn’t mention any changes to audio output functionality like connecting an external speaker to an Echo Dot. Amazon’s statement notes that the physical connection still works on the devices that have the port: Echo Plus (2nd gen), Echo (3rd gen), Echo (4th gen), and Echo Studio (1st gen). Owners can control it from within the Alexa app, as well as pair Bluetooth speakers.
该通知并未解释移除此功能的原因。它也没有提及音频输出功能（例如将 Echo Dot 连接到外部音箱）有任何变化。亚马逊的声明指出，拥有该接口的设备（Echo Plus 第二代、Echo 第三代、Echo 第四代以及 Echo Studio 第一代）其物理连接功能仍然有效。用户仍可通过 Alexa App 进行控制，或配对蓝牙音箱。

As Ars Technica points out, it’s been years since Amazon released an Echo speaker with a 3.5mm aux port, and last year, Amazon also removed an Echo feature that allowed users to opt out of sending voice recordings to the cloud.
正如 Ars Technica 所指出的，亚马逊已经多年没有发布带有 3.5mm 辅助接口的 Echo 音箱了。此外，去年亚马逊还移除了 Echo 的一项功能，该功能曾允许用户选择不将语音录音发送到云端。

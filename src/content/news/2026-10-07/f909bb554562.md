### Bidirectional Type Slicing
### 双向类型切片 (Bidirectional Type Slicing)

**English:**
Bidirectional type slicing is a novel technique in programming language theory that combines bidirectional type checking with program slicing. This approach allows developers to extract minimal, executable subsets of code that are relevant to a specific type-directed task. By leveraging the bidirectional nature of the type system, the method ensures that the resulting "slice" remains well-typed and semantically consistent with the original program.

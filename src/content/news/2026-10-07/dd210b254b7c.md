# Pared - 在不禁用 SIP 的情况下移除不需要的 Apple Intelligence 模型

Unzip the download and drag Pared to Applications. Prefer the terminal? Run this to open the setup wizard: `curl -fsSL --proto '=https' --proto-redir '=https' https://github.com/4evy/pared/releases/latest/download/install.sh | sh` Requires Apple silicon and macOS 15 or newer. No Xcode or Homebrew needed. Website · Documentation · More install options.

解压下载的文件并将 Pared 拖入“应用程序”文件夹。更喜欢使用终端？运行以下命令以打开设置向导：`curl -fsSL --proto '=https' --proto-redir '=https' https://github.com/4evy/pared/releases/latest/download/install.sh | sh`。需要 Apple 芯片和 macOS 15 或更高版本。无需 Xcode 或 Homebrew。网站 · 文档 · 更多安装选项。

Apple Intelligence, on your terms. Choose which Apple Intelligence features stay on your Mac, then remove models you no longer need. Pared includes a native app, terminal wizard, and Nix modules. System Integrity Protection stays enabled.

按你的意愿使用 Apple Intelligence。选择哪些 Apple Intelligence 功能保留在你的 Mac 上，然后移除你不再需要的模型。Pared 包含原生应用程序、终端向导和 Nix 模块。系统完整性保护 (SIP) 保持开启状态。

Keep what you use. Keep Writing Tools, turn off Genmoji, or switch everything off. Pared keeps shared models needed by features in its catalog that you leave on or unmanaged.

保留你所使用的功能。你可以保留“写作工具”，关闭 Genmoji，或者关闭所有功能。对于你保留或未管理的目录中的功能，Pared 会保留它们所需的共享模型。

A few choices, then a review. Choose your features. Set each one to On, Off, or App Default. A new policy starts with everything off; review your choices before saving. Finish setup. Install Pared’s configuration profile in System Settings. It applies supported controls and blocks unwanted model downloads.

简单的选择，然后进行审核。选择你的功能。将每一项设置为“开启”、“关闭”或“应用默认”。新策略默认关闭所有功能；在保存前请检查你的选择。完成设置。在“系统设置”中安装 Pared 的配置文件。它会应用受支持的控制项并阻止不需要的模型下载。

Review model removal. Pared shows which models can go before you confirm. Saving feature settings and removing models are separate actions. Want a feature back? Turn it on, install the updated profile, then request its models in Pared. For features Pared can’t download directly, use their Apple app.

审核模型移除。Pared 会在确认前显示哪些模型可以被移除。保存功能设置和移除模型是两个独立的操作。想要恢复某个功能？将其开启，安装更新后的配置文件，然后在 Pared 中请求其模型。对于 Pared 无法直接下载的功能，请使用其对应的 Apple 应用程序。

Use Open Pared or run pared wizard. Opening either changes nothing; feature choices stay in a draft until you save. See the app manual or command-line guide for setup and commands.

使用 Open Pared 或运行 pared 向导。打开它们不会改变任何设置；功能选择会保留在草稿中，直到你点击保存。有关设置和命令，请参阅应用程序手册或命令行指南。

Configure it with Nix. Use the nix-darwin or Home Manager module to manage your choices. Both remove eligible models during activation by default; set `programs.pared.cleanupOnActivation = false;` to opt out. Install the generated profile in System Settings to block future downloads. See the Nix setup guide and option reference.

使用 Nix 进行配置。使用 nix-darwin 或 Home Manager 模块来管理你的选择。两者默认都会在激活期间移除符合条件模型；设置 `programs.pared.cleanupOnActivation = false;` 即可退出此行为。在“系统设置”中安装生成的配置文件以阻止未来的下载。请参阅 Nix 设置指南和选项参考。

Build from source. With Xcode 16 or newer, run from this checkout: `tools/build-app.sh` then `open .build/Pared.app`. For CLI and offline installation, see the command-line guide.

从源码构建。使用 Xcode 16 或更高版本，在检出目录中运行：`tools/build-app.sh`，然后运行 `open .build/Pared.app`。有关 CLI 和离线安装，请参阅命令行指南。

How it works. Pared uses Apple’s asset service to remove models. Read how profiles and model removal work for the implementation and compatibility limits.

工作原理。Pared 使用 Apple 的资产服务来移除模型。阅读关于配置文件和模型移除的工作原理，以了解实现细节和兼容性限制。

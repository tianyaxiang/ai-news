# HEIC to JPG on Mac: 3 Free Methods Compared
# Mac 系统将 HEIC 转为 JPG：三种免费方法对比

Mac users live in a HEIC world. Your iPhone saves photos as HEIC by default, AirDrop hands them to your Mac as HEIC, and everything is great — until you need to email one to a Windows user, upload it to a site that only accepts JPG, or attach it to an old-school form. Here are the three free ways I use to convert HEIC to JPG on macOS, compared honestly.

Mac 用户生活在 HEIC 的世界里。你的 iPhone 默认将照片保存为 HEIC 格式，通过 AirDrop 传到 Mac 上也是 HEIC，一切都很美好——直到你需要通过电子邮件发给 Windows 用户、上传到仅支持 JPG 的网站，或者将其附加到老式表单中。以下是我在 macOS 上将 HEIC 转换为 JPG 的三种免费方法，并进行了客观对比。

### Method 1: Preview (built-in, best for one-offs)
### 方法一：预览 (Preview)（内置工具，最适合单次转换）

Open the HEIC file in Preview, go to File → Export, and choose JPEG as the format. You can drag the quality slider if you want to balance size and fidelity. Pros: no install, no upload, works offline. Cons: one file at a time, and macOS versions before Big Sur can be finicky with some HEIC variants.

在“预览”中打开 HEIC 文件，前往“文件”→“导出”，然后选择 JPEG 作为格式。如果你想平衡文件大小和画质，可以拖动质量滑块。优点：无需安装、无需上传、可离线使用。缺点：一次只能处理一个文件，且 Big Sur 之前的 macOS 版本在处理某些 HEIC 变体时可能会出现问题。

### Method 2: The Shortcuts app (best for batches)
### 方法二：“快捷指令”应用 (Shortcuts)（最适合批量处理）

If you regularly convert a folder of photos, build a one-time Shortcut: "Convert Images" action, input = HEIC files, output = JPEG. Right-click any HEIC file in Finder → Quick Actions → run it. Pros: batch conversion, no third party. Cons: takes 10 minutes to set up the first time, and Shortcut quality defaults can surprise you (check the output format settings).

如果你经常需要转换整个文件夹的照片，可以创建一个一次性的“快捷指令”：使用“转换图像”操作，输入设为 HEIC 文件，输出设为 JPEG。在访达 (Finder) 中右键点击任何 HEIC 文件 →“快速操作”→ 运行它。优点：支持批量转换，无需第三方软件。缺点：首次设置需要 10 分钟，且快捷指令的默认质量设置可能会让你感到意外（记得检查输出格式设置）。

### 方法三：基于浏览器的转换器（最适合赶时间或使用共享电脑时）

### Which should you pick?
### 你该选哪种？

One photo, privacy doesn't matter: Preview. Recurring batches on your own Mac: Shortcuts. Any Mac, fast, nothing installed, photos stay on your device: the browser route.

处理单张照片且不介意隐私：使用“预览”。在自己的 Mac 上定期批量处理：使用“快捷指令”。在任何 Mac 上、追求速度、不想安装软件且希望照片留在本地：选择浏览器方案。

One thing to watch regardless of method: HEIC stores more color detail than JPG (10-bit vs 8-bit), so a conversion to JPG always loses a little dynamic range. If the photo will be edited later, keep the HEIC original. If it just needs to be viewed by someone on Windows or an old website, JPG is the safe universal choice.

无论使用哪种方法，有一点需要注意：HEIC 存储的色彩细节比 JPG 多（10-bit 对比 8-bit），因此转换为 JPG 总会损失一点动态范围。如果照片后续还需要编辑，请保留 HEIC 原件。如果只是为了让 Windows 用户查看或上传到旧网站，JPG 是安全且通用的选择。

### Bonus: the Terminal method (for nerds)
### 进阶：终端方法（极客专用）

macOS ships with sips, a command-line image processor that handles HEIC input on modern versions: `sips -s format jpeg input.HEIC --out output.jpg`. Wrap it in a loop and you can convert a whole folder without touching the GUI: `for f in *.HEIC; do sips -s format jpeg "$f" --out "${f%.HEIC}.jpg"; done`. It's fast and scriptable — handy if conversions are part of a build pipeline or a photo-processing script. Just know that sips uses default quality settings, so for photos where quality matters, check the output size and adjust with -s formatOptions.

macOS 自带 sips，这是一个命令行图像处理器，在现代版本中支持 HEIC 输入：`sips -s format jpeg input.HEIC --out output.jpg`。将其放入循环中，无需图形界面即可转换整个文件夹：`for f in *.HEIC; do sips -s format jpeg "$f" --out "${f%.HEIC}.jpg"; done`。它速度快且可脚本化，如果转换是构建流程或照片处理脚本的一部分，这非常方便。只需注意 sips 使用的是默认质量设置，因此对于画质要求较高的照片，请检查输出大小并使用 -s formatOptions 进行调整。

### File size reality check
### 关于文件大小的真相

Expect the JPG to be roughly 2x the size of the HEIC it came from. That's not the converter being wasteful — it's the price of JPEG's older compression. If you're converting a big batch for email, consider resizing down at the same time (Preview's Export and most browser tools offer this); a 12MP photo doesn't need to stay 12MP to look fine in a slide deck.

预期转换后的 JPG 大小约为原 HEIC 文件的两倍。这不是转换器效率低，而是 JPEG 这种老旧压缩格式的代价。如果你要为邮件转换大批量照片，考虑同时调整尺寸（“预览”的导出功能和大多数浏览器工具都提供此选项）；一张 1200 万像素的照片没必要保持原尺寸也能在幻灯片中显示良好。

# A sustainable web career, for when all this blows over
# 为风暴过后的未来，构建可持续的 Web 职业生涯

Wednesday 7 Oct 2026
2026年10月7日，星期三

For better or worse the web industry is going through a bit of a phase. The reasons are largely irrational. People still need the web, nothing has changed there. Regardless, the financials of this business are a struggle. Longterm career prospects are looking dicey.
无论好坏，Web 行业正在经历一段特殊的时期。其背后的原因大多是不理性的。人们依然需要 Web，这一点从未改变。然而，该行业的财务状况却举步维艰，长期的职业前景也显得扑朔迷离。

Because I openly reject the driving force intent on destroying my profession, and ruffle a few feathers doing so, I often get asked privately for advice from like-minded peers. I can only offer an uninspired but sensible reply: don’t quit a paying job without a fallback. Go to the Winchester, have a nice cold pint, and wait for all of this to blow over.
由于我公开抵制那些试图摧毁我职业生涯的驱动力，并因此得罪了一些人，志同道合的同行经常私下向我寻求建议。我只能给出一个平淡但务实的回答：在没有后路的情况下，不要辞掉有收入的工作。去温彻斯特酒吧（Winchester），喝上一杯冰镇啤酒，静候这一切风暴过去。

I’m confident the situation will improve. Before it does, what can we focus on to accelerate past the intellectual slump, and better position ourselves once things calm down?
我相信情况会好转。在此之前，我们应该专注于什么，以加速走出思维的低谷，并在局势平稳后占据更有利的地位呢？

### What’s in
### 值得投入的方向

For a sustainable web career, where better to look than critical skills in desperately short supply? My focus is on front-end development, but these areas of knowledge are relevant to anyone in the business of making websites.
为了实现可持续的 Web 职业生涯，还有什么比掌握那些极度稀缺的关键技能更好的选择呢？我的重点是前端开发，但这些知识领域对于任何从事网站制作的人来说都至关重要。

#### Accessibility
#### 无障碍访问 (Accessibility)

Accessibility has always been a foundation of web development but it’s never been more critical for everyone to champion it. Understand why accessibility is for everyone. Learn how to talk about accessibility in respect to real needs and practical implementation.
无障碍访问一直是 Web 开发的基石，但现在每个人都比以往任何时候更需要去捍卫它。要理解为什么无障碍访问关乎每一个人。学习如何从实际需求和具体实施的角度去探讨无障碍访问。

Accessibility has unfortunately become a virtue signal for certain tech groups. (I’m told LinkedIn is rife with misinformation.) Accessibility is not a feature that can be tacked on to a website like garnish. Accessibility issues can’t be fixed with an automated process at the end. Web professionals must be able to counter this mindset by respecting accessibility in all decisions from day one.
遗憾的是，无障碍访问在某些科技群体中已沦为一种“美德信号”（听说 LinkedIn 上充斥着此类误导信息）。无障碍访问不是像装饰品一样可以随意添加到网站上的功能。无障碍问题无法通过后期的自动化流程来解决。Web 专业人士必须从第一天起就在所有决策中尊重无障碍原则，以对抗这种错误心态。

Learn and adopt the guidelines as your baseline. Speak to and test with real people. Defer to specialists who are eager for you to understand the realities.
学习并采用相关指南作为你的基准。与真实用户交流并进行测试。虚心向那些渴望让你了解现实情况的专家请教。

#### CSS (in stylesheets)
#### CSS（样式表）

CSS is the most vibrant and evolving of the front-end standards. To architecture a good stylesheet takes deep understanding of the language features. Newer features like cascade layers and selectors that reduce specificity make this much easier.
CSS 是前端标准中最具活力且不断演进的部分。构建优秀的样式表需要对语言特性有深刻的理解。诸如级联层（cascade layers）和降低特异性的选择器等新特性，让这一切变得简单得多。

CSS has always been equipped to handle well-organised styles, but developers who refuse to learn and respect the language have sought to push complexity elsewhere, using simplified abstractions or “CSS-in-JS” solutions. These are inherently limiting, lead to poor performance, and don’t actually solve the problems they claim.
CSS 一直具备处理组织良好的样式的能力，但那些拒绝学习和尊重这门语言的开发者，试图通过使用简化的抽象或“CSS-in-JS”方案将复杂性转移到别处。这些方案本质上是受限的，会导致性能下降，且并不能真正解决它们所声称的问题。

CSS should be hard and learning it will give you the ability to express creativity beyond cookie cutter web design. CSS skills will be highly desirable as more websites wish to stand out against the convergence of a generated aesthetic.
CSS 本该是有难度的，学习它将使你拥有超越“千篇一律”网页设计的创造力。随着越来越多的网站希望在同质化的生成式审美中脱颖而出，CSS 技能将变得极具价值。

#### Communication skills
#### 沟通技巧

Communication is a “soft skill” in short supply (for obvious reasons). It’s a great skill if you wish to stand out as an expert, or simply be heard amongst the noise. Learn brevity and focus on important points. Don’t be afraid to ask questions.
沟通是一种稀缺的“软技能”（原因显而易见）。如果你想作为专家脱颖而出，或者仅仅是想在嘈杂的环境中被听到，这都是一项伟大的技能。学习简洁明了，专注于重点。不要害怕提问。

Address concerns tactfully and early before they escalate. Don’t point fingers, but “cover your ass” — everyone on a project should be working towards the same goal, but some may be misguided in their approach. Remain positive and don’t meet negativity head-on. If you can communicate well you’ll be highly respected in your role.
在问题升级之前，委婉且及时地处理疑虑。不要指责他人，但要学会“保护自己”——项目中的每个人都应朝着同一个目标努力，但有些人可能在方法上存在偏差。保持积极，不要正面硬刚负面情绪。如果你能善于沟通，你将在岗位上备受尊重。

#### Rejecting fascism
#### 抵制法西斯主义

You probably weren’t expecting this one, but here we are. The luxury of not “getting political” has abated. Far-right political ideology is on the rise and dormant hatred is waking up in tech. The epicentre of fash-tech is Musk’s “X” with people like David Heinemeier Hansson spewing racism and abusing authority in communities to push an agenda, and Guillermo Rauch taking a selfie with a war criminal. Large tech giants like Digital Ocean are funding this power grab. Be wary of those denying this threat. If you want to avoid being pushed away from this industry, recognise and reject fascism before it comes for you. Don’t stay silent.
你可能没料到这一点，但事实就是如此。那种“不谈政治”的奢侈已经不复存在了。极右翼政治意识形态正在抬头，科技界沉睡的仇恨正在苏醒。“法西斯科技”的中心是马斯克的“X”，像 David Heinemeier Hansson 这样的人在社区中散布种族主义并滥用职权来推行议程，而 Guillermo Rauch 则与战犯自拍。像 Digital Ocean 这样的大型科技巨头正在资助这种权力攫取。要警惕那些否认这一威胁的人。如果你不想被挤出这个行业，请在法西斯主义找上你之前识别并抵制它。不要保持沉默。

### What’s out
### 应当摒弃的方向

I’ve covered topics that’ll see us well for the future, but what should we forget?
我已经涵盖了对未来有益的话题，那么我们应该忘记什么呢？

#### React
#### React

Facebook’s experiment turned cargo cult is a legacy framework that still lingers, but there’s no reason to learn it today. React has entrenched itself as a lingua franca of code extruders. React code is generated faster than any human can possibly read it. Suffice it to say that despite stale job vacancies still demanding experience, React is not worth investing time. The days of high-paying React development are numbered.
Facebook 的这项实验演变成了“货物崇拜”（cargo cult），它是一个依然存在的遗留框架，但今天已经没有理由去学习它了。React 已成为代码生成器们的通用语言。React 代码生成的速度远超人类阅读的速度。无需多言，尽管陈旧的招聘信息仍要求相关经验，但 React 不值得投入时间。高薪 React 开发的日子已经屈指可数了。

#### GitHub
#### GitHub

GitHub is now a liability. For private repositories use self-hosted git forges. I’d recommend Forgejo. One of the many Tailscale-like services is an easy way to gate remote access. Don’t make stuff public for the dead internet to attack! For CI/CD go local too, or use independent services not tied to tech giants. Take the time to learn basic git commands. A little technical and infrastructure knowledge goes a long way.
GitHub 现在已成为一种负担。对于私有仓库，请使用自托管的 Git 平台。我推荐 Forgejo。使用类似 Tailscale 的服务可以轻松控制远程访问。不要把东西公开给“死气沉沉的互联网”去攻击！对于 CI/CD，也请转向本地，或使用不与科技巨头绑定的独立服务。花点时间学习基础的 Git 命令。一点点技术和基础设施知识就能让你受益匪浅。

#### Influencers
#### 影响者 (Influencers)

These people are handsome, charismatic, highly personable. I’m talking about: developer relations, youtubers, start-up founders, etc. When the tech industry met us halfway, influencers were entertaining and a good chinwag at after parties. Now the game has changed and we should not allow false narratives to dominate and dictate a closed-web future. Normal people still use the web. Incredibly few can afford to pay for the novelties that influencers peddle. Their attention economy is no longer our concern.
这些人长相帅气、魅力十足、平易近人。我说的是：开发者关系（DevRel）、YouTuber、初创公司创始人等等。当科技行业还处于繁荣期时，这些影响者在派对后确实能提供娱乐和谈资。但现在游戏规则变了，我们不应允许虚假的叙事主导并决定一个封闭的 Web 未来。普通人依然在使用 Web。极少数人能负担得起影响者兜售的那些新奇玩意。他们的注意力经济不再是我们需要关心的事。

So that’s my focus for a sustainable web career, when all this blows over.
这就是我为风暴过后，构建可持续 Web 职业生涯所关注的重点。

Remember that above all else: the web is a human creation for human needs. Those needs are not going anywhere. Drop the dead weight accumulated in times of prosperity. Go back to basics and position yourself well for when professional demand returns.
请记住最重要的一点：Web 是人类为了满足自身需求而创造的。这些需求不会消失。抛弃在繁荣时期积累的沉重负担。回归基础，为专业需求回归的那一天做好准备。

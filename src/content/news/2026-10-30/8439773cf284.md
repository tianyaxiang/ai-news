# You can generate and edit Google Docs files directly in Gemini chats now

现在，您可以直接在 Gemini 聊天中生成和编辑 Google Docs 文件。

Now you can generate, preview, and edit PDFs, Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code directly within Google Gemini. The new file editing capabilities are available starting today for all Gemini users, and while PDF previews/editing works on both the web and mobile, all other file formats are only in the web version for now.

现在，您可以直接在 Google Gemini 中生成、预览和编辑 PDF、Google Docs、Google Sheets、幻灯片、Markdown 文件、TXT 文件和代码。这项新的文件编辑功能从今天起向所有 Gemini 用户开放。虽然 PDF 的预览和编辑功能同时支持网页版和移动版，但目前其他所有文件格式仅支持网页版。

Google added support for generating and downloading files in Gemini earlier this year, but now you can tweak those files without leaving the Gemini app. Google says you can expand documents to edit them in full-screen mode and highlight text in files to ask Gemini questions or prompt it to make changes to the file, like highlighting a table and asking Gemini to turn it into a graph.

Google 今年早些时候在 Gemini 中增加了对生成和下载文件的支持，但现在您无需离开 Gemini 应用程序即可对这些文件进行调整。Google 表示，您可以展开文档以全屏模式进行编辑，并突出显示文件中的文本，以向 Gemini 提问或提示其对文件进行更改，例如选中一个表格并要求 Gemini 将其转换为图表。

You could already use Gemini to edit files with its integrations in Google’s Workspace apps, like the Gemini bar in Google Docs. Anthropic also launched a feature earlier this year that allows users to generate and edit documents and presentations in Claude chats.

您此前已经可以通过 Google Workspace 应用程序中的集成功能（例如 Google Docs 中的 Gemini 侧边栏）使用 Gemini 编辑文件。Anthropic 今年早些时候也推出了一项功能，允许用户在 Claude 聊天中生成和编辑文档及演示文稿。

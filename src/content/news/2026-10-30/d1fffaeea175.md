Microsoft is beginning the rollout of a Windows 11 preview update that finally addresses a persistent power user complaint with the operating system: the right-click menu that obliterated years of muscle memory on command locations and hid others behind an additional click. The timing is notable, as the announcement comes alongside Microsoft’s quarterly financial report, which showed a continued decline in the business of selling Windows licenses for new PCs.

微软正开始推送一项 Windows 11 预览版更新，旨在解决高级用户对该操作系统长期存在的一个不满：右键菜单。该菜单不仅破坏了用户多年来对命令位置的肌肉记忆，还将部分功能隐藏在额外的点击操作之后。此次更新的时机值得注意，因为它与微软的季度财务报告一同发布，报告显示 Windows 授权许可的销售业务持续下滑。

The preview update, KB5127936, is cumulative for Windows 11 versions 26H2 and 25H2. The update will be a gradual rollout before eventually moving on to a normal rollout for all Windows 11 devices once it reaches general availability. The highlight of the new update should calm annoyed users who have spent years with custom scripts and services in an attempt to shape Windows the way they would prefer it.

此次预览版更新 KB5127936 是针对 Windows 11 26H2 和 25H2 版本的累积更新。该更新将分阶段推送，待达到正式发布标准后，最终会向所有 Windows 11 设备全面推广。此次更新的亮点有望安抚那些多年来一直通过自定义脚本和服务来试图将 Windows 改造成自己偏好样式的用户。

Users will get a “customize menu” button that controls what commands appear when they right-click their mouse. Users can toggle built-in commands such as Send To or Create Shortcut on or off, rearrange what appears on the main menu, and control which third-party extensions show up in either the main or submenus. The gripe with the right-click menu had been that Microsoft hid familiar command locations behind a top row of icons while moving other familiar commands under the “Show more options” submenu. Now, Windows users can customize the whole thing around their habits.

用户将获得一个“自定义菜单”按钮，用于控制鼠标右键点击时显示的命令。用户可以开启或关闭“发送到”或“创建快捷方式”等内置命令，重新排列主菜单上的显示内容，并控制哪些第三方扩展程序出现在主菜单或子菜单中。此前，用户对右键菜单的不满在于，微软将熟悉的命令位置隐藏在顶部的一排图标之后，并将其他常用命令移至“显示更多选项”子菜单中。现在，Windows 用户可以根据自己的习惯完全自定义整个菜单。

The new preview also highlights a new Windows feature called Cloud Rebuild, a recovery option that can reinstall Windows 11 directly from the cloud, even when an existing Windows 11 fails to boot. Cloud Rebuild will pull the Windows 11 image and needed system drivers directly from Windows Update. Users will not need a custom recovery image or external media to reinstall Windows. There is an important distinction to note, however. Microsoft classifies Cloud Rebuild as a recovery option, but it behaves more like a fresh Windows install than a repair, as existing applications and files will not be included. Those worried about data security can sanitize entire system drives prior to reinstalling.

此次预览版还重点介绍了一项名为“云重构”（Cloud Rebuild）的新 Windows 功能。这是一种恢复选项，即使在现有 Windows 11 无法启动的情况下，也能直接从云端重新安装系统。“云重构”将直接从 Windows Update 获取 Windows 11 镜像和所需的系统驱动程序。用户无需自定义恢复镜像或外部介质即可重装系统。但需要注意一个重要区别：微软将“云重构”归类为恢复选项，但它的表现更像是全新的系统安装而非修复，因为现有的应用程序和文件将不会被保留。担心数据安全的用户可以在重装前清理整个系统驱动器。

Microsoft’s latest quarterly report, released this week, paints a less encouraging picture of its Windows OEM business. “Windows OEM revenue was below expectations and decreased 27% and 28% in constant currency, driven by the Windows 10 end of support demand in the prior year, inventory drawdowns by OEM and channel partners and weaker PC market demand,” said CFO Amy Hood, according to a transcript of the call. The broader Windows OEM and devices category, which includes Microsoft’s own Surface lineup, fell 22 percent, per the earnings release.

微软本周发布的最新季度报告显示，其 Windows OEM 业务的前景并不乐观。根据财报电话会议记录，首席财务官 Amy Hood 表示：“受去年 Windows 10 停止支持带来的需求影响、OEM 和渠道合作伙伴的库存削减以及 PC 市场需求疲软，Windows OEM 营收低于预期，按固定汇率计算分别下降了 27% 和 28%。”财报显示，包括微软自有 Surface 系列在内的更广泛的 Windows OEM 及设备类别营收下降了 22%。

The news for Microsoft isn’t negative all around, though, as its Azure platform saw a 48 percent jump, and Microsoft Cloud revenue was also up 30 percent, year over year—now roughly 70 percent of the company’s $92.3 billion total quarterly revenue.

不过，对微软而言并非全是坏消息，其 Azure 平台实现了 48% 的增长，微软云业务营收也同比增长了 30%，目前约占该公司 923 亿美元季度总营收的 70%。

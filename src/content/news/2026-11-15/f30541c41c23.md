Save this story. Cloud storage certainly has a lot going for it. For a start, if you drop your laptop into the sink, it's likely that a lot of your important work will be backed up somewhere in the cloud, as long as you’re using services such as Google Drive, OneDrive, and iCloud.

保存这篇文章。云存储确实有很多优点。首先，如果你不小心把笔记本电脑掉进水槽里，只要你使用了 Google Drive、OneDrive 和 iCloud 等服务，你大部分重要的工作内容很可能已经在云端备份好了。

Then there's file sharing: Not too many years ago, swapping large amounts of data with other people meant dragging and dropping and running around with USB drives (and perhaps even mailing them). Now, via a couple of clicks and a link, you can share just about anything with just about anyone, anywhere in the world.

接下来是文件共享：在不久前，与他人交换大量数据意味着拖拽文件、随身携带 USB 闪存盘到处跑（甚至可能需要邮寄它们）。现在，只需点击几下并生成一个链接，你就可以与世界各地的任何人分享几乎任何内容。

However, this comes with security risks attached. You don't want those links making their way to anyone they weren't intended for; otherwise, they’ve got access to your files and folders. They could potentially see what’s in them and maybe even make changes or delete files, depending on the permissions you’ve set.

然而，这伴随着安全风险。你不希望这些链接落入非预期的接收者手中；否则，他们就能访问你的文件和文件夹。根据你设置的权限，他们可能会查看其中的内容，甚至进行修改或删除文件。

It’s worth emphasizing that sharing files through these cloud storage services isn't inherently insecure—these shared links are actually very well protected by default. However, the longer they stick around, the bigger the risk gets. Your links could get mistakenly forwarded in an email, or one of your contacts could have their email account hacked.

值得强调的是，通过这些云存储服务共享文件本身并不不安全——这些共享链接在默认情况下实际上受到了很好的保护。然而，它们存在的时间越长，风险就越大。你的链接可能会被错误地转发到电子邮件中，或者你的某个联系人的电子邮件账户可能会被黑客入侵。

With that in mind, it’s prudent to run a regular audit on the cloud-sharing links you’ve got active. It shouldn’t take long: The apps involved usually make this pretty straightforward. Once you’ve closed a link down, no one else can get to it.

考虑到这一点，定期对你处于活动状态的云共享链接进行审计是明智之举。这不会花费太长时间：相关的应用程序通常使这一过程变得非常简单。一旦你关闭了一个链接，其他人就无法再访问它了。

Microsoft OneDrive: If you head to the Microsoft OneDrive portal on the web, you’ll see a Shared link in the navigation pane on the left: Click this, then select By you up at the top of the file list to see everything you’ve shared with other people. Use the Modified header if you want to sort the files and folders by the oldest or most recent.

Microsoft OneDrive：如果你前往网页版的 Microsoft OneDrive 门户，你会在左侧导航栏中看到一个“共享”（Shared）链接：点击它，然后在文件列表顶部选择“由你共享”（By you），即可查看你与他人共享的所有内容。如果你想按时间先后对文件和文件夹进行排序，可以使用“修改时间”（Modified）标题。

Click the three dots next to any file or folder, then Manage access to control who can get to it. If you've shared the file with specific people, you can remove some or all of them; if the file or folder is shared more widely with just a link, clicking the trash can gets rid of it. You can also open up Office files to manage access there.

点击任何文件或文件夹旁边的三个点，然后选择“管理访问权限”（Manage access）来控制谁可以访问它。如果你已将文件共享给特定人员，你可以移除其中部分或全部人员；如果文件或文件夹是通过链接更广泛地共享的，点击垃圾桶图标即可将其删除。你也可以打开 Office 文件并在其中管理访问权限。

It’s worth knowing that when you opt to share a file in OneDrive on the web (via the three dots and Share), if you click the cog icon on the Share panel, you can set an expiration date for the sharing—which saves you the trouble of having to tidy it up afterward.

值得注意的是，当你选择在网页版 OneDrive 中共享文件时（通过三个点和“共享”按钮），如果你点击共享面板上的齿轮图标，可以为共享设置过期日期——这省去了你事后清理的麻烦。

Apple iCloud: If iCloud Drive is your cloud storage service of choice, once you’ve got the main interface up on the web, you can click Shared on the navigation pane on the left to go straight to the files and folders you’re sharing with other people. There’s no easy way to sort them, but you can use the search box up in the top right corner.

Apple iCloud：如果 iCloud Drive 是你首选的云存储服务，一旦你在网页上打开主界面，就可以点击左侧导航栏上的“共享”（Shared），直接进入你与他人共享的文件和文件夹。目前没有简单的排序方法，但你可以使用右上角的搜索框。

Click the three dots next to a file or folder, then Managed Shared File to make changes. The next screen lets you block access for specific contacts and change permissions (from editing to just viewing, for example). If you want to cancel the sharing altogether, click Stop sharing.

点击文件或文件夹旁边的三个点，然后选择“管理共享文件”（Managed Shared File）进行更改。下一个屏幕允许你阻止特定联系人的访问并更改权限（例如，从编辑更改为仅查看）。如果你想完全取消共享，请点击“停止共享”（Stop sharing）。

Unlike OneDrive, iCloud doesn’t give you any way of putting expiration periods on shared links, so you have to clear them up manually.

与 OneDrive 不同，iCloud 没有提供为共享链接设置过期时间的方法，因此你必须手动清理它们。

Dropbox: Dropbox is one of the more aggressive services when it comes to tidying up shared links, and if you use the Dropbox app you might see reminders to review the files and folders you’ve shared with others. From Dropbox on the web, click Shared in the left-hand navigation pane to see files and folders you’re currently sharing.

Dropbox：在清理共享链接方面，Dropbox 是比较积极的服务之一。如果你使用 Dropbox 应用程序，可能会看到提醒你查看与他人共享的文件和文件夹的通知。在网页版 Dropbox 中，点击左侧导航栏中的“共享”（Shared）即可查看你当前正在共享的文件和文件夹。

You can get quite a detailed breakdown here, including by Files or by Folders. Click the three dots next to any entry, then Share, to see the current sharing options: You can remove access for contacts one by one, or click the cog icon (top left) to find the Unshare button that ends all sharing completely.

你可以在这里获得非常详细的分类，包括按文件或文件夹分类。点击任何条目旁边的三个点，然后选择“共享”（Share），即可查看当前的共享选项：你可以逐个移除联系人的访问权限，或者点击齿轮图标（左上角）找到“取消共享”（Unshare）按钮，彻底结束所有共享。

Dropbox does have link expiration features built in: If you open the share settings whenever you’re sharing a file or folder, you’ll see Link expiry as one of the options. It’s an easy way to keep things tidy, provided the people you’re sharing the file or folder with get around to viewing it in time.

Dropbox 确实内置了链接过期功能：每当你共享文件或文件夹并打开共享设置时，你都会看到“链接过期”（Link expiry）选项。这是一种保持整洁的简便方法，前提是你共享文件或文件夹的对象能及时查看。

Google Drive: Google Drive isn't quite as on top of shared links as other cloud storage services. If you open up the web portal, there’s no easy-to-access list of everything you've shared. The closest thing to it is clicking the People filter and then choosing contacts to see files and folders you've shared with them specifically. If you pick Anyone with the link from the drop-down list, you’ll see everything shared with a simple link.

Google Drive：Google Drive 在管理共享链接方面不如其他云存储服务那么到位。如果你打开网页门户，并没有一个易于访问的列表来显示你共享的所有内容。最接近的方法是点击“人员”（People）过滤器，然后选择联系人，查看你专门与他们共享的文件和文件夹。如果你从下拉列表中选择“任何拥有链接的人”（Anyone with the link），你将看到所有通过简单链接共享的内容。

To change the sharing settings for a file or folder, click on the three dots, then Share. Click the cog icon on the panel that pops up, then you can remove contacts as needed and turn the visible link off.

要更改文件或文件夹的共享设置，请点击三个点，然后选择“共享”（Share）。点击弹出面板上的齿轮图标，你就可以根据需要移除联系人并关闭可见链接。

As with iCloud, there’s no link expiration feature you can rely on here, so shared files and folders can’t be set to become unshared after a certain time has elapsed. It’s a shame Google doesn’t make it as easy as it could be.

与 iCloud 一样，这里没有可供依赖的链接过期功能，因此无法设置共享文件和文件夹在一段时间后自动取消共享。遗憾的是，Google 没有让这项操作变得像它本可以做到的那样简单。

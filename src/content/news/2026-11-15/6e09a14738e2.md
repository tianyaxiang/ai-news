# How to Run SteamOS on Your Mac

Save this story. Most of my Steam collection won't run on my Mac. It's not (entirely) my fault. I will be the first to admit that my collection is mostly old indie games, all of which work fine on Windows. Less so on the Mac. Apple stopped supporting 32-bit games back in 2019 when it released macOS Catalina. A good chunk of my Steam library has a "No" symbol next to it because of that restriction. And next year it will get even worse: macOS will drop support for running Intel Mac applications, which could leave even more games unplayable (though Apple claims that certain older games will keep working).

保存这篇文章。我的 Steam 游戏库中大部分游戏都无法在 Mac 上运行，这（并不完全）是我的错。我得承认，我的收藏大多是老派独立游戏，它们在 Windows 上运行得很好，但在 Mac 上却不尽如人意。苹果在 2019 年发布 macOS Catalina 时停止了对 32 位游戏的支持。由于这一限制，我的 Steam 库中很大一部分游戏旁边都出现了“禁止”符号。明年情况会更糟：macOS 将停止支持运行 Intel Mac 应用程序，这可能会导致更多游戏无法游玩（尽管苹果声称某些旧游戏仍能继续运行）。

But there's another way. A free, open source app called FX Steam Launcher boots the ARM version of SteamOS—the operating system that powers Valve's Steam Deck gaming handheld—right on your Mac, using a combination of a virtual machine and compatibility layers. You will need a Mac with an Apple Silicon processor, as Intel Macs aren't supported, running macOS 15 or later. I set this up recently, connected a controller, and I've been playing all kinds of games that are otherwise unplayable on my MacBook Air.

但还有另一种方法。一款名为 FX Steam Launcher 的免费开源应用程序可以在你的 Mac 上直接启动 ARM 版本的 SteamOS（即驱动 Valve Steam Deck 掌机的操作系统），它结合了虚拟机和兼容层技术。你需要一台搭载 Apple Silicon 芯片的 Mac（不支持 Intel Mac）并运行 macOS 15 或更高版本。我最近设置了这个程序，连接了手柄，现在可以玩各种在 MacBook Air 上原本无法运行的游戏了。

It wasn't even hard to set up. To get started, download the application, mount the DMG file, and drag the app to your Applications folder. The first time you launch the application, a pop-up will offer to download and install SteamOS for you in a virtual machine. Click Create New Disk, and you'll be asked a few questions. The most important step is the hard drive size—the default is 64 GB, which is plenty, but consider allocating more space if you plan on installing multiple large games. You can also choose the drive location, if you like, and set a password for opening SteamOS.

设置过程并不复杂。首先，下载该应用程序，挂载 DMG 文件，然后将应用拖到“应用程序”文件夹中。首次启动该程序时，会弹出一个窗口，提示你下载并在虚拟机中安装 SteamOS。点击“创建新磁盘”，系统会询问你几个问题。最重要的一步是设置硬盘大小——默认值为 64 GB，这已经足够了，但如果你打算安装多个大型游戏，可以考虑分配更多空间。你还可以根据需要选择磁盘位置，并为打开 SteamOS 设置密码。

Click Create, and the application will download SteamOS and install it in a virtual machine. I recommend using this time to pair a game controller with your Mac in System Settings under Bluetooth. FX Steam Launcher works with most current gamepads, including Xbox, DualSense, DualShock, and Made for iPhone. I used a Nintendo Pro Controller. Eventually, you will see the login screen, where you can enter your Steam credentials. Once you're in, you'll see your Steam library. The virtual machine operates like an actual Steam Deck, which takes some getting used to if you've never used one. It divides your library into games known to work in SteamOS and those that might work, which is helpful. A lot of my games started running immediately, with full gamepad support.

点击“创建”，应用程序就会下载 SteamOS 并将其安装在虚拟机中。我建议利用这段时间在系统设置的蓝牙选项中将游戏手柄与 Mac 配对。FX Steam Launcher 支持大多数主流游戏手柄，包括 Xbox、DualSense、DualShock 和“Made for iPhone”认证手柄。我使用的是任天堂 Pro 手柄。最终，你会看到登录界面，输入你的 Steam 凭据即可。进入后，你就能看到自己的 Steam 游戏库。该虚拟机的操作方式与真正的 Steam Deck 一样，如果你从未使用过，可能需要一点时间适应。它会将你的游戏库分为“已知可在 SteamOS 上运行”和“可能运行”的游戏，这非常有帮助。我的许多游戏都能立即运行，并完美支持手柄操作。

This isn't a drop-in solution for every game. SteamOS itself is quite fiddly, and you're now running it in a virtual machine. In some cases, I needed to tweak the graphics settings for games to run correctly. For Psychonauts, specifically, I had to download a user-made patch to get the controller working properly—but I'd have needed that fix for an actual Steam Deck too. When a game ran poorly, I frequently found the solution by Googling and finding actual Steam Deck owners who ran into similar problems.

这并不是所有游戏的万能解决方案。SteamOS 本身就比较复杂，而且你现在是在虚拟机中运行它。在某些情况下，我需要调整图形设置才能让游戏正常运行。以《脑航员》（Psychonauts）为例，我必须下载一个用户制作的补丁才能让手柄正常工作——但这在真正的 Steam Deck 上也是必需的。当游戏运行不佳时，我通常会通过谷歌搜索，找到遇到类似问题的 Steam Deck 用户，从而找到解决方案。

There is a limit to the processing power you get out of a Mac, especially if you (like me) are using a MacBook Air. And a virtual machine, by definition, doesn't have access to all of your machine's capabilities. But the list of compatible games, compiled from other users, shows which devices have successfully played various titles. Check that page for your favorite games before you dive in.

Mac 的处理能力是有极限的，尤其是如果你像我一样使用 MacBook Air 的话。而且，虚拟机从定义上来说无法调用你电脑的所有性能。不过，其他用户整理的兼容游戏列表显示了哪些设备成功运行了各种游戏。在开始之前，请先查看该页面，确认你喜欢的游戏是否在列。

If nothing else, this is a lot easier than my previous method for running Windows games on a Mac, which involved setting up a version of Wine that's no longer supported. I even got a few non-Steam games installed. Sideloading on SteamOS means booting into Desktop Mode, which you can find in the SteamOS sidebar under Power. You'll end up in a Linux-based desktop, complete with a web browser. You can download games, put them in the folder of your choice, and point Steam to them. I couldn't add custom art, but I got multiple games up and running this way.

至少，这比我之前在 Mac 上运行 Windows 游戏的方法简单多了，以前我需要配置一个早已不再维护的 Wine 版本。我甚至还安装了一些非 Steam 游戏。在 SteamOS 上侧载游戏意味着要进入“桌面模式”，你可以在 SteamOS 侧边栏的“电源”选项下找到它。你将进入一个基于 Linux 的桌面环境，里面配有网页浏览器。你可以下载游戏，将它们放入你选择的文件夹，然后在 Steam 中指向它们。虽然我无法添加自定义封面，但通过这种方式确实成功运行了多款游戏。

Honestly, Valve should update the official Steam Mac client with similar compatibility tech so it can run Windows games natively. It would be a huge hit with Mac users. If you're a power user, I recommend checking out the settings for FX Steam Launcher, which you can open from the menu bar or with the keyboard shortcut Command-comma. You can change the resolution for your virtual Steam Deck, configure the sound to your liking, and submit game statistics.

老实说，Valve 应该为官方 Steam Mac 客户端更新类似的兼容技术，使其能够原生运行 Windows 游戏。这一定会受到 Mac 用户的热烈欢迎。如果你是高级用户，我建议查看 FX Steam Launcher 的设置，你可以通过菜单栏或快捷键 Command+逗号打开它。你可以更改虚拟 Steam Deck 的分辨率，根据喜好配置声音，并提交游戏统计数据。

It's remarkable software. And, with an HDMI cable and a gamepad, you can plug your MacBook into your TV and game from your couch. That's what I plan on doing when I'm done writing this article (which I guess is right now).

这是一款出色的软件。只要有一根 HDMI 线和一个游戏手柄，你就可以把 MacBook 接到电视上，坐在沙发上玩游戏。写完这篇文章后（我想现在就是时候了），我打算就这样做。

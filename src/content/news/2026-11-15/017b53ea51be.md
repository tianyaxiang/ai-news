Running the scan. The Nuclei template compares two HTTP requests. First, it verifies that the normal route works. Then, it sends the url parameter as an array. The match requires both responses to meet the condition status_code_1 == 200 && status_code_2 == 500. Request on the local server Result: GET /contacto HTTP 200. The contact page loaded. GET /?url%5B%5D=contacto HTTP 500. The url parameter arrived as an array. Nuclei registered a match. A TypeError appeared in the PHP log on line 9 of app/core/Router.php. The router passes the url value directly to trim(), which expects a string: $rawUrl = isset($_GET['url']) ? trim($_GET['url'], '/') : '';

Ejecutar el escaneo. La plantilla de Nuclei compara dos peticiones HTTP. Primero verifica que la ruta normal funcione. Después envía el parámetro url como arreglo. La coincidencia exige que ambas respuestas cumplan la condición status_code_1 == 200 && status_code_2 == 500. Petición en el servidor local Resultado: GET /contacto HTTP 200. Se cargó la página de contacto. GET /?url%5B%5D=contacto HTTP 500. El parámetro url llegó como arreglo. Nuclei registró una coincidencia. En el log de PHP apareció un TypeError en la línea 9 de app/core/Router.php. El enrutador pasa el valor de url directamente a trim(), que espera una cadena: $rawUrl = isset($_GET['url']) ? trim($_GET['url'], '/') : '';

View the revised router line. We classified the finding as low in the template because the test demonstrated a server error in that request, with scope limited to the reproduced case. The proposed fix is to check the type of url before normalizing it and return HTTP 400 when receiving an array. The regression test must maintain the 200 of the valid route and check that the 500 disappears on the invalid input.

Ver la línea del enrutador revisada. Clasificamos el hallazgo como bajo en la plantilla porque la prueba demostró un error de servidor en esa petición, con alcance limitado al caso reproducido. La corrección propuesta es comprobar el tipo de url antes de normalizarlo y devolver HTTP 400 al recibir un arreglo. La prueba de regresión debe mantener el 200 de la ruta válida y comprobar que desaparece el 500 en la entrada inválida.

Integrating Nuclei into the publishing flow. The workflow packages the commit, excludes local configuration, and verifies PHP syntax. Then it launches the package copy, executes Nuclei, and saves resultados-nuclei.jsonl as an execution artifact. Conclusion. The most useful part of the test was being able to relate an application response to a line of code. The template allows repeating that check when the team changes the router.

Conclusión. Lo más útil de la prueba fue poder relacionar una respuesta de la aplicación con una línea de código. La plantilla permite repetir esa comprobación cuando el equipo cambie el enrutador.

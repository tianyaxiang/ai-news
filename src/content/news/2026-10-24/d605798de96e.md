Title: The open source references I keep in my own account (standalone editions, honestly labelled)

标题：我保存在自己账户中的开源参考资料（独立版本，已诚实标注）

Quick honesty note before anything else: none of the projects below are mine. They are well known open source references that I keep as standalone editions in my GitHub account, each one credited to its upstream project in the repo description and README, because I actually use them in my daily work as a full-stack developer.

在开始之前先做一个诚实的说明：以下项目都不是我的。它们是众所周知的开源参考资料，我将它们作为独立版本保存在我的 GitHub 账户中，每一个都在仓库描述和 README 中注明了其上游项目，因为我作为一名全栈开发人员，确实在日常工作中会用到它们。

Why keep your own editions at all? Three reasons. My tooling keeps working even if an upstream repo moves. I can pin the exact version my workflow depends on. And I add a small enhancement layer on top: standardised docs, dependabot, CI and lint, so every edition behaves the same way in my setup.

为什么要保留自己的版本呢？有三个原因。即使上游仓库迁移，我的工具也能继续工作。我可以锁定工作流所依赖的确切版本。此外，我还添加了一个小的增强层：标准化的文档、dependabot、CI 和 lint，这样每个版本在我的设置中表现都是一致的。

The ones that earn their keep: public-apis, standalone edition (https://github.com/mujtbabbas/public-apis) The collective list of free APIs. Original: public-apis/public-apis. I reach for it at the start of almost every integration.

物有所值的项目：public-apis，独立版本 (https://github.com/mujtbabbas/public-apis)。免费 API 的集合列表。原版：public-apis/public-apis。我在几乎每次集成开始时都会用到它。

free-for-dev, standalone edition (https://github.com/mujtbabbas/free-for-dev) Free tiers of SaaS, PaaS and IaaS offerings. Original: ripienaar/free-for-dev. It pairs well with my own FreeDomain list if you are bootstrapping a side project at zero cost.

free-for-dev，独立版本 (https://github.com/mujtbabbas/free-for-dev)。SaaS、PaaS 和 IaaS 产品的免费层级。原版：ripienaar/free-for-dev。如果你正在以零成本启动一个副业项目，它与我自己的 FreeDomain 列表搭配使用效果很好。

markitdown, standalone edition (https://github.com/mujtbabbas/markitdown) Microsoft's tool for converting files and office documents to Markdown. Original: microsoft/markitdown. It sits in the middle of my document pipelines.

markitdown，独立版本 (https://github.com/mujtbabbas/markitdown)。微软用于将文件和办公文档转换为 Markdown 的工具。原版：microsoft/markitdown。它位于我的文档流水线的中间环节。

ui-ux-pro-max-skill, standalone edition (https://github.com/mujtbabbas/ui-ux-pro-max-skill) A design intelligence skill for AI assisted UI work. It shapes how I brief design tasks before writing code.

ui-ux-pro-max-skill，独立版本 (https://github.com/mujtbabbas/ui-ux-pro-max-skill)。一种用于 AI 辅助 UI 工作的设计智能技能。它塑造了我在编写代码之前如何简述设计任务的方式。

If you use these tools too, star the ORIGINALS first, they earned it. If my editions are useful to you, a star there helps me justify the maintenance time. And if you maintain similar reference editions, I would like to hear how you handle upstream updates in the comments.

如果你也使用这些工具，请先为原版加星，它们理应获得这些赞誉。如果我的版本对你有用，加星可以帮助我证明维护时间的合理性。如果你也维护类似的参考版本，我很想在评论区听听你是如何处理上游更新的。

# Donating Agent Skills to the Agentic AI Foundation

Today, we’re donating Agent Skills, the open standard that gives AI agents specialized knowledge and workflows, to the Agentic AI Foundation (AAIF). More than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, have integrated Agent Skills since we published the standard in December 2025.

今天，我们将 Agent Skills（一种为 AI 智能体提供专业知识和工作流的开放标准）捐赠给智能体 AI 基金会（AAIF）。自 2025 年 12 月我们发布该标准以来，包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code 在内的 70 多个智能体平台已经集成了 Agent Skills。

Agent interoperability through simplicity: A skill is a folder containing a SKILL.md file that teaches an agent a specific task or domain, along with any scripts or reference material it needs. We developed skills while working on Claude Code. It handled general knowledge work well, but often lacked the procedural knowledge that real business tasks need. Within weeks of our October 2025 launch, developers published thousands of skills on GitHub and wrote loaders for Codex, Cursor, and OpenCode. We then published Agent Skills as an open standard, under its own GitHub organization and domain, so any agent could use it. So far, 1 million skills have been published and nearly 280 million installed.

通过简洁性实现智能体互操作性：一个“技能”（Skill）是一个包含 SKILL.md 文件的文件夹，它向智能体传授特定任务或领域的知识，并附带其所需的任何脚本或参考资料。我们在开发 Claude Code 时创建了这些技能。它能很好地处理通用知识工作，但往往缺乏实际业务任务所需的程序性知识。在 2025 年 10 月发布后的几周内，开发者们在 GitHub 上发布了数千个技能，并为 Codex、Cursor 和 OpenCode 编写了加载器。随后，我们将 Agent Skills 作为开放标准发布，并拥有独立的 GitHub 组织和域名，以便任何智能体都能使用它。到目前为止，已有 100 万个技能被发布，安装量接近 2.8 亿次。

Donating Agent Skills to AAIF: We’re committed to keeping Agent Skills open, community-driven, and vendor-neutral. Today, we are donating the standard to the Agentic AI Foundation (AAIF) under the Linux Foundation, which we co-founded with Block and OpenAI last year, and to which we donated the Model Context Protocol (MCP). The AAIF will provide a neutral home to the standard going forward, ensuring the community has a say in where Agent Skills go next.

向 AAIF 捐赠 Agent Skills：我们致力于保持 Agent Skills 的开放性、社区驱动性和供应商中立性。今天，我们将该标准捐赠给 Linux 基金会旗下的智能体 AI 基金会（AAIF）。该基金会是我们去年与 Block 和 OpenAI 共同创立的，我们也曾向其捐赠了模型上下文协议（MCP）。AAIF 将为该标准提供一个中立的未来发展平台，确保社区对 Agent Skills 的后续发展拥有话语权。

We are donating the Agent Skills name and logo, the GitHub organization, and the agentskills.io domain. You can continue to use the standard or contribute to it without joining the AAIF. Engineers from Anthropic, Google, OpenAI, and other companies will maintain the standard as individuals, with David Soria Parra and Mahesh Murag as Lead Maintainers.

我们正在捐赠 Agent Skills 的名称和徽标、GitHub 组织以及 agentskills.io 域名。即使不加入 AAIF，您也可以继续使用该标准或为其做出贡献。来自 Anthropic、Google、OpenAI 和其他公司的工程师将以个人身份维护该标准，David Soria Parra 和 Mahesh Murag 将担任首席维护者。

What comes next: We’ve proposed starting with a roadmap covering versioned releases, a formal proposal process, and security guidance for people who write and install skills. As with MCP, the project will continue to prioritize community input and transparent decision-making. You can join the project’s Discord to give feedback on proposed specification changes.

接下来要做什么：我们建议从一份路线图开始，涵盖版本化发布、正式提案流程，以及为编写和安装技能的人员提供安全指南。与 MCP 一样，该项目将继续优先考虑社区意见和透明的决策过程。您可以加入项目的 Discord，对拟议的规范变更提供反馈。

Thank you to the developers who built with Agent Skills from the start, and to the teams who brought skills into their products. Read the specification at agentskills.io and join the discussion on GitHub.

感谢从一开始就使用 Agent Skills 进行构建的开发者，以及将这些技能引入其产品的团队。请访问 agentskills.io 阅读规范，并加入 GitHub 上的讨论。

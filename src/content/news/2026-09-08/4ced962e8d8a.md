# BER-PEF: Unified Human Mobility Predictability Evaluation via Bayes Error Rate Estimation
# BER-PEF：基于贝叶斯错误率估计的统一人类移动性可预测性评估

**Abstract:** Human mobility predictability concerns the best prediction performance attainable from a given target and input information, but its ground truth is not directly observable on real mobility data. We present BER-PEF, a Bayes-error-rate-based framework that converts BER estimation into mobility predictability estimation and provides a unified protocol for comparing estimators without observable ground truth.

**摘要：** 人类移动性的可预测性关注的是在给定目标和输入信息下所能达到的最佳预测性能，但在真实的移动性数据中，其真实值（Ground Truth）无法直接观测。我们提出了 BER-PEF，这是一个基于贝叶斯错误率（BER）的框架，它将 BER 估计转化为移动性可预测性估计，并为在没有可观测真实值的情况下比较各种估计器提供了一套统一的协议。

The framework maps symbolic sequences, numeric trajectories, contextual features, and learned representations into a common feature--label space, then evaluates estimator outputs along controlled perturbation curves against a shared predictability reference interval by measuring deviations below the interval, above the interval, and across the full interval.

该框架将符号序列、数值轨迹、上下文特征和学习到的表征映射到一个通用的特征-标签空间中，然后通过测量低于、高于以及跨越整个参考区间的偏差，沿着受控扰动曲线对估计器的输出进行评估，并将其与共享的可预测性参考区间进行对比。

Experiments on Foursquare NYC and TKY, GeoLife, and T-Drive show that several BER-based estimators achieve lower reference discrepancy than existing predictability methods on symbolic sequences and numeric trajectories, while their estimates track changes in empirical prediction performance under perturbation.

在 Foursquare NYC 和 TKY、GeoLife 以及 T-Drive 数据集上的实验表明，几种基于 BER 的估计器在符号序列和数值轨迹上的参考差异均低于现有的可预测性方法，同时它们的估计值能够追踪扰动下经验预测性能的变化。

Additional analyses show that contextual inputs and multiple structured representations can be evaluated under the same protocol, and that aggregating evidence across multiple perturbation levels provides a more reliable basis for estimator selection than relying on a single unperturbed observation. BER-PEF therefore offers a unified and verifiable path for evaluating predictability estimators on heterogeneous mobility data when ground-truth predictability is unavailable.

进一步分析表明，上下文输入和多种结构化表征可以在同一协议下进行评估，并且跨多个扰动水平聚合证据，比仅依赖单一的未扰动观测值能为估计器选择提供更可靠的依据。因此，当无法获得真实的可预测性时，BER-PEF 为评估异构移动数据上的可预测性估计器提供了一条统一且可验证的途径。

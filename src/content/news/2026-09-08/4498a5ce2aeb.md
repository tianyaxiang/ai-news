# Modular Deep Recurrent Neural Network: Application to Quadrotors
# 模块化深度循环神经网络：在四旋翼飞行器上的应用

**Abstract:** A modular deep Recurrent Neural Network (RNN) is introduced to facilitate the process of deploying various architectures of RNNs, and to automatically compute derivatives for gradient-based learning methods.
**摘要：** 本文介绍了一种模块化深度循环神经网络（RNN），旨在简化各种 RNN 架构的部署过程，并为基于梯度的学习方法自动计算导数。

The modularity leads to a set of new architectures, one of which includes feedforward inter-layer connections. By adding feedforward inter-layer connections in a multi-layer RNN, it is observed that the capability of the RNN to learn and model high-order dynamics and nonlinearities is significantly improved.
这种模块化特性衍生出了一系列新架构，其中一种架构包含了层间前馈连接。通过在多层 RNN 中加入层间前馈连接，研究发现该网络学习和建模高阶动力学及非线性特征的能力得到了显著提升。

The problem of vanishing/exploding gradient in space for a multilayer RNN is also alleviated using feedforward connections. These results are demonstrated using a quadrotor case study, for which a model of the altitude dynamics is learned with our particular network structure, while existing methods are unable to generalize as quickly or at all.
利用前馈连接，多层 RNN 在空间维度上的梯度消失/爆炸问题也得到了缓解。这些结果通过四旋翼飞行器的案例研究得到了验证：利用我们特定的网络结构，成功学习到了高度动力学模型，而现有方法则无法如此快速地进行泛化，甚至完全无法实现。

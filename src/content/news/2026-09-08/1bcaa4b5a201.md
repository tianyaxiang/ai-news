# Data-Driven Learning of Unknown Nonlinear Differential Equations Using Functional Analysis
# 基于泛函分析的未知非线性微分方程数据驱动学习

**Abstract:** In this paper, the problem of data-driven discovery of nonlinear ordinary differential equations (ODEs) is recast, and a new interpretable machine learning (ML) method is proposed. The proposed method aims to learn the unknown vector field of nonlinear dynamics without prior knowledge of the system's physics from only one single state trajectory's data.

**摘要：** 在本文中，我们重新构建了非线性常微分方程（ODEs）的数据驱动发现问题，并提出了一种新的可解释机器学习（ML）方法。该方法旨在仅利用单条状态轨迹的数据，在无需预先了解系统物理知识的情况下，学习非线性动力学的未知向量场。

The proposed method has two fundamental differences with existing methods: 1) the formulation presented in this method is derived based on Functional Analysis and Operator Theory, and 2) the cost function is constructed in the function space as a distance between two functions as an integral, instead of the discrete-sum of errors used in existing ML approaches.

该方法与现有方法有两个根本区别：1）本文提出的公式推导基于泛函分析和算子理论；2）代价函数是在函数空间中构建的，表现为两个函数之间的积分距离，而非现有机器学习方法中常用的误差离散和。

An incremental learning algorithm is proposed to learn the unknown vector field to handle new training samples in an online manner. The proposed method can discover the unknown vector field from both forced and unforced autonomous and non-autonomous (or time-varying) dynamical systems.

本文提出了一种增量学习算法，用于学习未知向量场，以在线方式处理新的训练样本。该方法能够从受迫与非受迫、自治与非自治（或时变）动力系统中发现未知向量场。

The proposed method is able to simultaneously discover unknown external forces as a function of time and unknown underlying dynamics. Finally, numerical examples are given to demonstrate the advantages of the proposed method.

该方法能够同时发现作为时间函数的未知外力以及未知的底层动力学规律。最后，通过数值算例证明了该方法的优势。

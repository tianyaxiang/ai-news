# Bill Gates tries to install MovieMaker (2003)
# 比尔·盖茨尝试安装 MovieMaker (2003)

**From:** Bill Gates  
**Sent:** Wednesday, January 15, 2003 10:05 AM  
**To:** Jim Allchin  
**Cc:** Chris Jones; Bharat Shah; Joe Peterson; Will Poole; Brian Valentine; Anoop Gupta  
**Subject:** Windows Usability Systematic degradation flame  
**发件人：** 比尔·盖茨  
**发送时间：** 2003年1月15日，星期三，上午10:05  
**收件人：** Jim Allchin  
**抄送：** Chris Jones; Bharat Shah; Joe Peterson; Will Poole; Brian Valentine; Anoop Gupta  
**主题：** 关于 Windows 可用性系统性退化的愤怒反馈

I am quite disappointed at how Windows Usability has been going backwards and the program management groups don't drive usability issues.  
我对 Windows 的可用性不断倒退，以及项目管理团队未能推动解决可用性问题感到非常失望。

Let me give you my experience from yesterday. I decided to download Moviemaker and buy the Digital Plus pack so I went to Microsoft.com. They have a download place so I went there.  
让我给你们讲讲我昨天的经历。我决定下载 Moviemaker 并购买 Digital Plus 套件，于是我访问了 Microsoft.com。他们有一个下载专区，我就去了那里。

The first 5 times I used the site it timed out while trying to bring up the download page. Then after an 8 second delay I got it to come up. This site is so slow it is unusable.  
我前 5 次访问该网站时，在尝试打开下载页面时都超时了。之后在 8 秒的延迟后，页面才显示出来。这个网站慢得根本无法使用。

It wasn't in the top 5 so I expanded the other 45. These 45 names are totally confusing. These names make stuff like: C:\Documents and Settings\billg\My Documents\My Pictures seem clear. They are not filtered by the system I can in on and so many of the things are strange.  
它不在前 5 名里，所以我展开了另外 45 个选项。这 45 个名称完全令人困惑。相比之下，像 `C:\Documents and Settings\billg\My Documents\My Pictures` 这样的路径看起来都显得清晰明了。系统没有进行筛选，很多东西看起来都很奇怪。

I tried scoping to Media stuff. Still no moviemaker. I typed in moviemaker. Nothing. I typed in movie maker. Nothing. So I gave up and sent mail to Amir saying - where is this Moviemaker download? Does it exist?  
我尝试缩小范围到媒体类，还是没有 Moviemaker。我输入了“moviemaker”，没结果。我输入了“movie maker”，还是没结果。所以我放弃了，给 Amir 发了封邮件问：Moviemaker 的下载在哪里？它真的存在吗？

So they told me that using the download page to download something was not something they anticipated. They told me to go to the main page search button and type movie maker (not moviemaker!).  
他们告诉我，使用下载页面来下载东西并不是他们预期的操作方式。他们让我去主页的搜索按钮，输入“movie maker”（而不是“moviemaker！”）。

I tried that. The site was pathetically slow but after 6 seconds of waiting up it came. I thought for sure now I would see a button to just go do the download. In fact it is more like a puzzle that you get to solve. It told me to go to Windows Update and do a bunch of incantations.  
我试了一下。网站慢得可怜，但在等待 6 秒后页面出现了。我本以为现在肯定能看到一个直接下载的按钮。事实上，这更像是一个需要你去解开的谜题。它让我去 Windows Update 执行一堆“咒语”。

This struck me as completely odd. Why should I have to go somewhere else and do a scan to download moviemaker? So I went to Windows update. Windows Update decides I need to download a bunch of controls. Not just once but multiple times where I get to see weird dialog boxes. Doesn't Windows update know some key to talk to Windows?  
这让我觉得非常奇怪。为什么我必须去别的地方进行扫描才能下载 Moviemaker？于是我去了 Windows Update。Windows Update 判定我需要下载一堆控件。不是一次，而是多次，期间我看到了各种奇怪的对话框。Windows Update 难道不知道如何与 Windows 进行交互吗？

Then I did the scan. This took quite some time and I was told it was critical for me to download 17megs of stuff. This is after I was told we were doing delta patches to things but instead just to get 6 things that are labeled in the SCARIEST possible way I had to download 17meg.  
然后我进行了扫描。这花了不少时间，系统告诉我必须下载 17MB 的内容。在此之前我被告知我们正在做增量补丁，但为了获取 6 个标记得极其“吓人”的项目，我竟然不得不下载 17MB 的数据。

So I did the download. That part was fast. Then it wanted to do an install. This took 6 minutes and the machine was so slow I couldn't use it for anything else during this time. What the heck is going on during those 6 minutes? That is crazy. This is after the download was finished.  
我进行了下载，那部分很快。然后它要求安装。这花了 6 分钟，期间机器慢得我无法做任何其他事情。这 6 分钟里到底在干什么？太疯狂了。这还是在下载完成之后发生的事。

Then it told me to reboot my machine. Why should I do that? I reboot every night - why should I reboot at that time? So I did the reboot because it INSISTED on it. Of course that meant completely getting rid of all my Outlook state.  
然后它让我重启机器。我为什么要这么做？我每天晚上都会重启——为什么非要在那个时候重启？我重启了，因为它“坚持”要这么做。当然，这意味着我所有的 Outlook 状态都被彻底清除了。

So I got back up and running and went to Windows Update again. I forgot why I was in Windows Update at all since all I wanted was to get Moviemaker. So I went back to Microsoft.com and looked at the instructions. I have to click on a folder called WindowsXP. Why should I do that? Windows Update knows I am on Windows XP.  
重新启动并运行后，我又回到了 Windows Update。我甚至忘了我为什么要进 Windows Update，因为我想要的只是 Moviemaker。所以我回到 Microsoft.com 查看说明。我必须点击一个叫 WindowsXP 的文件夹。为什么要这么做？Windows Update 应该知道我用的是 Windows XP。

What does it mean to have to click on that folder? So I get a bunch of confusing stuff but sure enough one of them is Moviemaker. So I do the download. The download is fast but the Install takes many minutes. Amazing how slow this thing is.  
点击那个文件夹到底是什么意思？我看到了一堆令人困惑的东西，但其中确实有一个是 Moviemaker。我进行了下载。下载很快，但安装花了好多分钟。这东西慢得惊人。

At some point I get told I need to go get Windows Media Series 9 to download. So I decide I will go do that. This time I get dialogs saying things like "Open" or "Save". No guidance in the instructions which to do. I have no clue which to do.  
在某个环节，我被告知需要去下载 Windows Media Series 9。于是我决定去下载。这次我看到了显示“打开”或“保存”的对话框。说明书里没有任何指导该选哪一个。我完全不知道该选哪个。

The download is fast and the install takes 7 minutes for this thing. So now I think I am going to have Moviemaker. I go to my add/remove programs place to make sure it is there. It is not there.  
下载很快，但安装这个东西花了 7 分钟。现在我想我应该有 Moviemaker 了。我去“添加/删除程序”里确认它是否在里面。结果它不在。

What is there? The following garbage is there. Microsoft Autoupdate Exclusive test package, Microsoft Autoupdate Reboot test package, Microsoft Autoupdate testpackage1, Microsoft AUtoupdate testpackage2, Microsoft Autoupdate Test package3.  
那里面有什么？全是垃圾：Microsoft Autoupdate Exclusive test package, Microsoft Autoupdate Reboot test package, Microsoft Autoupdate testpackage1, Microsoft AUtoupdate testpackage2, Microsoft Autoupdate Test package3。

Someone decided to trash the one part of Windows that was usable? The file system is no longer usable. The registry is not usable. This program listing was one sane place but now it is all crapped up.  
有人决定毁掉 Windows 中唯一可用的部分吗？文件系统已经不可用了，注册表也不可用。这个程序列表原本是唯一正常的地方，但现在也被搞得一团糟。

But that is just the start of the crap. Later I have listed things like Windows XP Hotfix see Q329048 for more information. What is Q329048? Why are these series of patches listed here? Some of the patches just things like Q810655 instead of saying see Q329048 for more information. What an absolute mess.  
但这仅仅是垃圾的开始。后面我还列出了诸如“Windows XP Hotfix see Q329048 for more information”之类的东西。Q329048 是什么？为什么这些补丁系列会列在这里？有些补丁只写了像 Q810655 这样的东西，而不是写“查看 Q329048 获取更多信息”。简直是一团糟。

Moviemaker is just not there at all. So I give up on Moviemaker and decide to download the Digital Plus Package. I get told I need to go enter a bunch of information about myself. I enter it all in and because it decides I have mistyped something I have to try again. Of course it has cleared out most of what I typed.  
Moviemaker 根本就不在里面。所以我放弃了 Moviemaker，决定下载 Digital Plus 套件。我被告知需要输入一堆关于我个人的信息。我全部输入了，但因为它判定我输错了什么，我必须重试。当然，它已经清空了我输入的大部分内容。

I try typing the right stuff in 5 times and it just keeps clearing things out for me to type them in again. So after more than an hour of craziness and making my programs list garbage and being scared and seeing that Microsoft.com is a terrible website I haven't run Moviemaker and I haven't got the plus package.  
我尝试输入正确的信息 5 次，但它一直清空内容让我重新输入。经过一个多小时的疯狂折腾，我的程序列表变成了垃圾，我感到很后怕，并且意识到 Microsoft.com 是一个糟糕的网站，而我既没能运行 Moviemaker，也没拿到 Plus 套件。

The lack of attention to usability represented by these experiences blows my mind. I thought we had reached a low with Windows Network places or the messages I get when I try to use 802.11. (don't you just love that root certificate message?) When I really get to use the stuff I am sure I will have more feedback.  
这些经历所体现出的对可用性的漠视让我震惊。我本以为 Windows 网络邻居或者我尝试使用 802.11 时收到的消息已经够糟糕了。（难道你不喜欢那个根证书消息吗？）等我真正开始使用这些东西时，我肯定会有更多的反馈。

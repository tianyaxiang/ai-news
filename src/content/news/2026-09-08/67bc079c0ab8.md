# AdaptVPR: Route-Aware Hard Positive Generation for Robust Visual Place Recognition
# AdaptVPR：面向鲁棒视觉地点识别的路径感知难正样本生成方法

**Abstract:** Visual Place Recognition (VPR) localizes a query image by retrieving database images of the same or nearby place, yet its robustness is often degraded by domain shifts arising from illumination, weather, seasonal changes, and dynamic occlusions. One contributing factor is the limited appearance diversity of the same place in existing training data. 

**摘要：** 视觉地点识别（VPR）通过检索数据库中相同或邻近地点的图像来定位查询图像，但其鲁棒性常因光照、天气、季节变化及动态遮挡带来的域偏移而降低。导致这一问题的原因之一是现有训练数据中同一地点的外观多样性有限。

To address this issue, we propose AdaptVPR, a route-aware generative augmentation framework that constructs same-place hard positives for robust VPR training. AdaptVPR first uses a vision language model to parse scene attributes and estimate editing feasibility, while a rule-based scheduler determines the generation route according to editability scores and risk constraints. 

为了解决这一问题，我们提出了 AdaptVPR，这是一个路径感知的生成式增强框架，旨在构建用于鲁棒 VPR 训练的同地点难正样本。AdaptVPR 首先利用视觉语言模型解析场景属性并评估编辑可行性，同时通过基于规则的调度器根据可编辑性评分和风险约束来确定生成路径。

The generation process is decomposed into three complementary routes: the Global Appearance Route introduces global scene changes in weather, illumination, and time of day; the Local Occlusion Route inserts plausible dynamic occluders; and the Dual Route combines both types of perturbations to produce more challenging appearance shifts. 

生成过程被分解为三条互补的路径：全局外观路径引入天气、光照和时间段的全局场景变化；局部遮挡路径插入合理的动态遮挡物；双重路径则结合了上述两种扰动，以产生更具挑战性的外观偏移。

Each generated candidate is evaluated using a VPR-oriented verification scheme based on geometric consistency and appearance diversity, reducing the risk of structural drift while ensuring sufficient appearance variation. Global candidates are generated once and rejected if verification fails, while Local Occlusion and Dual candidates use verification feedback for limited prompt refinement and regeneration. 

每个生成的候选样本都会通过一种面向 VPR 的验证方案进行评估，该方案基于几何一致性和外观多样性，在确保足够外观变化的同时降低了结构漂移的风险。全局候选样本生成一次，若验证失败则直接剔除；而局部遮挡和双重候选样本则利用验证反馈进行有限的提示词优化和重新生成。

Using this framework, we construct AdaptCities, containing 160K verified synthetic same-place hard positives. Experiments across multiple VPR baselines and vision foundation backbones show consistent gains on standard benchmarks and substantial improvements under challenging domain shifts, with R@1 gains of up to 9.2%. The source code and data resources are publicly available at this https URL.

利用该框架，我们构建了 AdaptCities 数据集，其中包含 16 万个经过验证的合成同地点难正样本。在多个 VPR 基线模型和视觉基础骨干网络上的实验表明，该方法在标准基准测试中表现出持续的性能提升，并在具有挑战性的域偏移下取得了显著改进，R@1 指标最高提升了 9.2%。源代码和数据资源已在指定链接公开。

# Qwen3.8-Max vs Alibaba international

Alibaba's Singapore (international) list for Qwen3.8-Max is about $2.00 input / $0.25 cached input / $6.00 output per 1M tokens. That is a solid flagship price. On a month that sends every token to Max, switching hosts for a few cents per million barely moves the bill. What does move it is putting the easy steps on Flash and keeping Max for the hard ones, on one OpenAI-compatible key.

How to route without a fancy router
```python
from openai import OpenAI
client = OpenAI(base_url="https://api.iteracompute.com/v1", api_key="YOUR_KEY")

EASY = {"classify", "summarize_tool_output", "extract", "commit_message", "format_check"}

def run(step: str, messages: list[dict]) -> str:
    model = "qwen/qwen3.8-flash" if step in EASY else "qwen/qwen3.8-max"
    r = client.chat.completions.create(model=model, messages=messages)
    return r.choices[0].message.content
```

Caveats
Thinking / reasoning tokens usually bill as output. Default high effort on Max inflates the output column faster than the input price suggests. Put the stable prefix (system prompt, tools, repo context) first so cache hits stay high. A request ID at the top of the system prompt resets the hit rate. This is not a claim that any host is the cheapest in the world. fp8 / promo / multi-provider pin setups can undercut a single-host mix. Measure on your own traffic.

注意事项
思考/推理 token 通常按输出计费。Max 默认的高努力程度会导致输出列的增长速度快于输入价格所暗示的水平。将稳定的前缀（系统提示词、工具、仓库上下文）放在最前面，以保持较高的缓存命中率。系统提示词顶部的请求 ID 会重置命中率。这并非声称任何主机商是全球最便宜的。fp8 / 促销 / 多供应商固定设置可能会比单一主机组合更便宜。请根据您自己的流量进行衡量。

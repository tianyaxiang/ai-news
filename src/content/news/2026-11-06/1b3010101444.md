# scenario-labs / skills

Scenario Agent Skills are designed to teach AI coding agents (such as Claude Code, Cursor, Codex, Copilot, and over 70 others) how to create production-ready content using Scenario via the Scenario MCP server. This includes images, video, audio, textures, skyboxes, 3D assets, and custom-trained models for games, entertainment, and any creative vertical.

Scenario Agent Skills 旨在教导 AI 编码代理（如 Claude Code、Cursor、Codex、Copilot 及其他 70 多种工具）如何通过 Scenario MCP 服务器利用 Scenario 创建生产级内容，包括游戏、娱乐及任何创意领域所需的图像、视频、音频、纹理、天空盒、3D 资产和定制训练模型。

The expert tools listed at the bottom function differently: they are collections of skills that drive DCC (digital content creation) software and game engines installed on your machine (ZBrush, Blender, Maya, Unreal Engine, Unity, Godot, Roblox Studio). These are distilled from expert tutorials, conference talks, and official documentation. They require the application itself rather than the Scenario MCP server, and each family folder's README documents how it was built and the extent of its verification.

列表底部的专家工具运作方式有所不同：它们是一系列驱动您本地安装的 DCC（数字内容创作）软件和游戏引擎（如 ZBrush、Blender、Maya、Unreal Engine、Unity、Godot、Roblox Studio）的技能集合。这些工具提炼自专家教程、会议演讲和官方文档。它们需要相应的应用程序而非 Scenario MCP 服务器，且每个系列文件夹的 README 文件都记录了其构建方式及验证程度。

Skills follow the Agent Skills format. Install Everything for Scenario. Every Scenario skill, without the expert tools: the default for working through the Scenario MCP.

技能遵循 Agent Skills 格式。安装 Scenario 的所有内容。除专家工具外的所有 Scenario 技能：这是通过 Scenario MCP 进行工作的默认设置。

By role or goal. INSTALL.md groups the skills by job, from 2D artist to producer, and by outcome, from game art to ChatGPT pets, with one command each.

按角色或目标分类。INSTALL.md 将技能按工作岗位（从 2D 艺术家到制作人）和成果（从游戏美术到 ChatGPT 宠物）进行分组，每组均可通过单条命令安装。

Expert tools. A family installs as one set, since its specialists import the lead skill's scripts: select its "Expert tools" group in the installer menu, or run the command in its family README (ZBrush, Blender, Maya, Unreal Engine, Unity, Godot, Roblox Studio).

专家工具。一个系列作为一个整体安装，因为其专家组件会导入主技能的脚本：请在安装程序菜单中选择其“Expert tools”组，或运行其系列 README 中的命令（适用于 ZBrush、Blender、Maya、Unreal Engine、Unity、Godot、Roblox Studio）。

选择或安装单个技能。

npx skills add scenario-labs/skills --skill scenario

Pin a reviewed release. The commands above fetch the latest copy of each skill from main. To install a reviewed state instead, pin both the installer and the commit, taken from a release's tag. Run it again with a newer commit to move.

锁定已审核的版本。上述命令会从 main 分支获取每个技能的最新副本。若要安装已审核的状态，请锁定安装程序和提交记录（取自发布标签）。再次运行并使用更新的提交记录即可进行更新。

npx skills@1.7.4 add scenario-labs/skills#<commit> --skill <name>

npx skills@1.7.4 add scenario-labs/skills#<commit> --skill <name>

The menu's topic groups cannot be selected from the command line: the CLI matches --skill against exact skill names only, and a group flag is an open request upstream (vercel-labs/skills#992). From a script or CI, run the default command above or a role command from INSTALL.md with -y, which skips every prompt.

菜单的主题组无法通过命令行选择：CLI 仅将 --skill 与精确的技能名称进行匹配，而组标志是上游的一个待处理请求 (vercel-labs/skills#992)。在脚本或 CI 中，请运行上述默认命令或 INSTALL.md 中的角色命令并加上 -y 参数，这将跳过所有提示。

The Scenario skills need the Scenario MCP server connected:
claude mcp add --transport http scenario https://mcp.scenario.com/mcp
Or add https://mcp.scenario.com/mcp to any MCP client and sign in with a Scenario account (OAuth), or use an API key. Full setup lives in the scenario skill.

Scenario 技能需要连接 Scenario MCP 服务器：
claude mcp add --transport http scenario https://mcp.scenario.com/mcp
或者将 https://mcp.scenario.com/mcp 添加到任何 MCP 客户端，并使用 Scenario 账户 (OAuth) 登录，或使用 API 密钥。完整设置位于 scenario 技能中。

Staying up to date. Releases are how changes become visible: every feature, fix, and documentation change merged to main lands in the next release, staged by release-please as an open release PR. Merging that PR tags a version, updates CHANGELOG.md in this repository, publishes a GitHub release, and posts the notes to the Scenario changelog.

保持更新。发布是变更可见的方式：合并到 main 分支的每一项功能、修复和文档更改都会进入下一次发布，并由 release-please 暂存为开放的发布 PR。合并该 PR 会标记版本、更新本仓库的 CHANGELOG.md、发布 GitHub Release，并将说明发布到 Scenario 更新日志中。

To learn that a skill changed, watch this repository's releases (Watch, then Custom, then Releases on GitHub) or check any of the changelog pages above. An entry scoped to a single skill carries that skill's name; changes spanning several skills appear under broader scopes such as skills. To pull the changes, run npx skills update where you installed, or re-run your original npx skills add command. To stay on a reviewed state, pin the install (see Install).

要了解技能是否发生变更，请关注本仓库的发布（在 GitHub 上点击 Watch，选择 Custom，然后选择 Releases）或查看上述任何更新日志页面。针对单个技能的条目会带有该技能的名称；跨越多个技能的变更会出现在更广泛的范围下，例如 skills。要拉取更改，请在安装位置运行 npx skills update，或重新运行原始的 npx skills add 命令。若要保持在已审核的状态，请锁定安装版本（参见“安装”部分）。

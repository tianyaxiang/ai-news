# Beyond Language Priors: Diagnosing and Fixing Visual-Origin Hallucinations in Multimodal LLM
# 超越语言先验：诊断并修复多模态大语言模型中的视觉源幻觉

**Abstract:** Existing research on object hallucination in multimodal large language models (MLLMs) predominantly attributes the problem to language priors such as over-reliance on textual co-occurrence statistics. We challenge this view by presenting quantitative evidence for a complementary, under-explored cause: visual-origin hallucination, where hallucinations arise from incorrect visual feature extraction and misalignment between image and text embeddings.

**摘要：** 现有关于多模态大语言模型（MLLM）中对象幻觉的研究，主要将该问题归因于语言先验，例如对文本共现统计数据的过度依赖。我们通过提供定量证据，对这一观点提出了挑战，并揭示了一个互补且尚未被充分探索的原因：视觉源幻觉。在这种情况下，幻觉源于错误的视觉特征提取以及图像与文本嵌入之间的未对齐。

Through cosine similarity analysis and Smooth Grad-CAM entropy measurements, we show that hallucinated samples exhibit systematically lower image-text similarity (average 0.158 vs. -0.122) and inverted attention patterns, where attention is dispersed when the target object is present but wrongly concentrated when it is absent.

通过余弦相似度分析和 Smooth Grad-CAM 熵测量，我们发现幻觉样本表现出系统性更低的图文相似度（平均 0.158 对比 -0.122）以及反转的注意力模式：当目标对象存在时，注意力反而分散；而当目标对象缺失时，注意力却错误地集中。

Guided by this diagnosis, we propose Adversarial Contrastive Fine-Tuning (ACFT). ACFT uses an Adversarial Hallucination Attribute Flipping (AHAF) procedure, involving minimal, targeted adversarial perturbations that flip an image's hallucination attribute, to construct perfectly aligned positive-negative pairs, which are then used for contrastive fine-tuning.

基于这一诊断，我们提出了对抗性对比微调（ACFT）。ACFT 使用对抗性幻觉属性翻转（AHAF）程序，通过最小的、有针对性的对抗性扰动来翻转图像的幻觉属性，从而构建完美对齐的正负样本对，并将其用于对比微调。

AHAF simultaneously serves as a diagnostic probe, revealing that MLLM visual representations lie dangerously close to hallucination decision boundaries. Requiring only 0.9% of the COCO dataset and adding zero inference overhead, ACFT achieves state-of-the-art performance on POPE, MME, and four description-level hallucination benchmarks across LLaVA, MiniGPT-4, and Qwen2.5-VL. AHAF 同时作为一种诊断探针，揭示了 MLLM 的视觉表示处于极其接近幻觉决策边界的危险位置。ACFT 仅需使用 0.9% 的 COCO 数据集，且不增加任何推理开销，在 LLaVA、MiniGPT-4 和 Qwen2.5-VL 等模型上，于 POPE、MME 及四个描述级幻觉基准测试中均达到了最先进（SOTA）的性能。代码可在该链接获取。

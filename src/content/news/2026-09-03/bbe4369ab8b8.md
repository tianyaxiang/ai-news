# REAL-Q: E2E LLM Quantization via Dynamic Gradient Descent

**Abstract:** Post-training quantization (PTQ) is essential for deploying large language models (LLMs) under strict resource constraints. State-of-the-art PTQ methods quantize each layer with a single closed-form second-order solver: to remain analytically tractable, they heavily approximate the global loss (dropping cross-channel coupling, pooling output rows into groups), and they then freeze the resulting Hessian across the entire layer, with no way to refresh it as the loss landscape shifts column by column--a phenomenon we call information misalignment.

**摘要：** 训练后量化（PTQ）对于在严格的资源限制下部署大语言模型（LLM）至关重要。目前最先进的 PTQ 方法通常使用单一的闭式二阶求解器来量化每一层：为了保持分析上的可处理性，它们对全局损失进行了大量的近似（舍弃了跨通道耦合，并将输出行合并为组），随后将得到的 Hessian 矩阵在整个层中冻结，无法随着损失函数空间逐列变化而进行更新——我们将这种现象称为“信息失准”（information misalignment）。

We propose REAL-Q (Real-time E2E-loss Aligned LLM Quantization), a novel PTQ paradigm that breaks this compromise: instead of diluting the objective for the sake of analytic tractability, REAL-Q targets an end-to-end-aligned surrogate of the global loss and refines it via fine-grained, dynamic Block-wise Gradient Descent applied after every column block (128 columns). By coupling this fine-grained correction with a sliding window mechanism for smooth cross-layer transitions, REAL-Q effectively mitigates error propagation across the network.

我们提出了 REAL-Q（实时端到端损失对齐的 LLM 量化），这是一种打破上述妥协的新型 PTQ 范式：REAL-Q 不再为了分析上的可处理性而削弱目标函数，而是瞄准全局损失的端到端对齐代理，并通过在每个列块（128 列）之后应用细粒度的动态块梯度下降（Block-wise Gradient Descent）对其进行优化。通过将这种细粒度校正与用于平滑跨层过渡的滑动窗口机制相结合，REAL-Q 有效地缓解了网络中的误差传播。

On LLaMA-3.1 (8B and 70B) and Qwen3 (0.6B-32B) at W4A16, REAL-Q reduces end-to-end KL divergence by up to ~49% relative to state-of-the-art globally-guided methods.

在 W4A16 配置下的 LLaMA-3.1（8B 和 70B）及 Qwen3（0.6B-32B）模型上，与目前最先进的全局引导方法相比，REAL-Q 将端到端 KL 散度降低了高达约 49%。

# A Practical Introduction to PySpark Window Functions
# PySpark 窗口函数实用入门

When you are looking to aggregate your data, the standard PySpark `groupBy()` function can do all that for you. It’s what it was built for, but it has a fundamental restriction. It only ever returns one row per collection of data records. You SUM a thousand rows, or a million rows, you get one row back.
当你需要聚合数据时，标准的 PySpark `groupBy()` 函数完全可以胜任。这就是它被设计出来的初衷，但它有一个根本性的限制：对于每一组数据记录，它只会返回一行结果。无论你对一千行还是上百万行数据进行求和，最终都只会得到一行数据。

Often, that’s exactly what you want, but sometimes it would be handy to also get back some additional data from some or all of the rows that went into the aggregation. That’s where the PySpark Window functions come into play. They let you calculate values across related records without collapsing those records into a single result. This means you keep the transaction details while gaining aggregation information about the wider group.
通常这正是你想要的，但有时如果能同时获取参与聚合的部分或全部行的额外数据会非常方便。这时 PySpark 窗口函数（Window functions）就派上用场了。它们允许你在相关记录之间进行计算，而无需将这些记录折叠成单一结果。这意味着你既保留了交易明细，又能获得关于更大范围群组的聚合信息。

They are useful when you need rankings, running totals, comparisons with previous records, or calculations within groups. In this article, I’ll explain how PySpark window functions work and show how to use them for several common tasks:
当你需要进行排名、计算累计总额、与前序记录进行比较或在组内进行计算时，它们非常有用。在本文中，我将解释 PySpark 窗口函数的工作原理，并展示如何使用它们完成几个常见任务：

* Ranking rows within groups (组内行排名)
* Calculating running totals (计算累计总额)
* Comparing current and previous values (比较当前值与前序值)
* Finding each row’s share of a group total (查找每行在组总计中的占比)
* Selecting the top records from each group (从每组中选择排名靠前的记录)

My examples use a small sales dataset, but the same techniques apply equally well to larger data sets like event logs, financial records, customer activity, sensor readings, and many other types of ordered or grouped data.
我的示例使用了一个小型销售数据集，但同样的技术也完全适用于更大型的数据集，例如事件日志、财务记录、客户活动、传感器读数以及许多其他类型的有序或分组数据。

### Setting up PySpark
### 设置 PySpark

If PySpark is not already installed on your system, create a project folder and add it with `uv`:
如果你的系统尚未安装 PySpark，请创建一个项目文件夹并使用 `uv` 添加它：

```powershell
mkdir pyspark-windows
cd pyspark-windows
uv init
uv venv
.venv\Scripts\activate
uv pip install pyspark
```

Next, we can test whether the installation worked OK by creating a Spark session:
接下来，我们可以通过创建一个 Spark 会话来测试安装是否成功：

```python
import os
import sys
os.environ["PYSPARK_PYTHON"] = sys.executable
os.environ["PYSPARK_DRIVER_PYTHON"] = sys.executable
from pyspark.sql import SparkSession

spark = (
    SparkSession.builder
    .master("local[*]")
    .appName("sales-analysis")
    .config("spark.pyspark.python", sys.executable)
    .config("spark.pyspark.driver.python", sys.executable)
    .getOrCreate()
)
```

The `local[*]` setting runs Spark locally and allows it to use the available processor cores. You don’t need a cluster to follow my examples. Just make sure the code above runs without errors by saving it to a suitable file and running this command:
`local[*]` 设置会在本地运行 Spark，并允许它使用所有可用的处理器核心。你不需要集群即可跟随我的示例。只需将上述代码保存到合适的文件中并运行以下命令，确保代码无误即可：

```bash
python spark_submit spark_example.py
```

### Creating our example dataset
### 创建示例数据集

The dataset contains sales made by three stores over several days:
该数据集包含了三家商店在几天内的销售情况：

```python
from datetime import date
from pyspark.sql import functions as F
from pyspark.sql import types as T
from pyspark.sql.window import Window

sales_data = [
    (1, "London_Store", date(2026, 1, 2), "Laptop", 1200.00),
    (2, "London_Store", date(2026, 1, 3), "Monitor", 350.00),
    (3, "London_Store", date(2026, 1, 5), "Keyboard", 90.00),
    (4, "London_Store", date(2026, 1, 8), "Laptop", 1350.00),
    (5, "Manchester_Store", date(2026, 1, 2), "Monitor", 320.00),
    (6, "Manchester_Store", date(2026, 1, 4), "Laptop", 1100.00),
    (7, "Manchester_Store", date(2026, 1, 6), "Mouse", 45.00),
    (8, "Manchester_Store", date(2026, 1, 9), "Laptop", 1250.00),
    (9, "Bristol_Store", date(2026, 1, 3), "Keyboard", 85.00),
    (10, "Bristol_Store", date(2026, 1, 4), "Monitor", 300.00),
    (11, "Bristol_Store", date(2026, 1, 7), "Laptop", 1050.00),
    (12, "Bristol_Store", date(2026, 1, 10), "Monitor", 330.00),
]

sales_schema = T.StructType([
    T.StructField("transaction_id", T.IntegerType(), False),
    T.StructField("store", T.StringType(), False),
    T.StructField("sale_date", T.DateType(), False),
    T.StructField("product", T.StringType(), False),
    T.StructField("amount", T.DoubleType(), False),
])

sales = spark.createDataFrame(sales_data, schema=sales_schema)
sales.orderBy("store", "sale_date").show()
```

Each row represents one transaction. We’ll use window functions to analyse the transactions while keeping every row in the result.
每一行代表一笔交易。我们将使用窗口函数来分析这些交易，同时在结果中保留每一行。

### What is a window?
### 什么是窗口？

A window defines the set of rows that PySpark should consider when calculating a value for the current row.
窗口定义了 PySpark 在为当前行计算值时应考虑的行集。

Most window specifications contain one or more of these parts:
大多数窗口规范包含以下部分中的一个或多个：

* `partitionBy()`: divides the data into groups. (将数据划分为组)
* `orderBy()`: defines the order of rows inside each group. (定义组内行的顺序)
* `rowsBetween()` or `rangeBetween()`: defines the window frame relative to the current row. (定义相对于当前行的窗口框架)

Here is a basic window specification:
这是一个基本的窗口规范：

```python
store_window = Window.partitionBy("store")
```

This divides the data by store. Every London transaction belongs to one window partition, every Manchester transaction belongs to another, and every Bristol transaction belongs to a third.
这会按商店对数据进行划分。每一笔伦敦的交易属于一个窗口分区，每一笔曼彻斯特的交易属于另一个，而每一笔布里斯托尔的交易则属于第三个。

You can use that window with an aggregate function:
你可以将该窗口与聚合函数一起使用：

```python
sales_with_store_total = sales.withColumn(
    "store_total", F.sum("amount").over(store_window),
)
sales_with_store_total.orderBy("store", "sale_date").show()
```

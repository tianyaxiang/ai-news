# Stochastic complexity of vectors containing cluster structure
# 包含聚类结构的向量的随机复杂性

**Abstract:** This paper studies the problem of computing the stochastic probability (shortest code length) of the encoded vectors containing cluster structure using Normalized Maximum Likelihood (NML) model. This is of great theoretical and practical importance in data clustering based on Minimum Description Length (MDL) principle, such as for estimating the best number of clusters and best cluster structure for the data.

**摘要：** 本文研究了使用归一化最大似然（NML）模型计算包含聚类结构的编码向量的随机概率（最短码长）的问题。这在基于最小描述长度（MDL）原则的数据聚类中具有重要的理论和实践意义，例如用于估计数据的最佳聚类数量和最佳聚类结构。

Straightforward computation of the shortest code length of the vector containing cluster structure based on the NML model requires polynomial time with respect to the size of the vector and number of clusters. We show that this is a tractable problem by introducing a recursion formula for the efficient computation of normalizing constant from the NML model. The time complexity of the new formula is linear opposed to previous polynomial time with respect to the size of the vector and number of clusters.

基于 NML 模型直接计算包含聚类结构的向量的最短码长，其时间复杂度相对于向量大小和聚类数量而言是多项式的。我们通过引入一个递归公式来高效计算 NML 模型中的归一化常数，从而证明了这是一个可处理的问题。与之前相对于向量大小和聚类数量的多项式时间复杂度相比，新公式的时间复杂度是线性的。

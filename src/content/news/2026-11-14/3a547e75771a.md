If you want to build client dashboard in notion that holds every client, every status, and every payment in one place, a single Clients database with three linked views does the whole job — no code, no paid template, no spreadsheet to maintain. This is a simple dashboard built in minutes on the free plan, with dummy data only.

如果你想在 Notion 中构建一个能将所有客户、状态和付款集中在一处的客户仪表板，只需一个包含三个关联视图的“客户”数据库即可完成所有工作——无需代码、无需付费模板，也无需维护电子表格。这是一个在免费版 Notion 上几分钟内即可构建的简单仪表板，仅包含演示数据。

What you need: A free Notion account, one new page for the dashboard, and three dummy clients to practise with — a design studio, a bakery, and a consultancy. The problem: client details live in five places at once. A name in a chat, a rate in an email, a deadline in a spreadsheet, and a payment you are not sure arrived. When a client asks for an update, you hunt through chats instead of answering, and the client you forgot to follow up quietly goes elsewhere.

你需要准备：一个免费的 Notion 账户、一个用于仪表板的新页面，以及三个用于练习的演示客户——一家设计工作室、一家面包店和一家咨询公司。问题在于：客户详情往往分散在五个地方。聊天记录里的名字、邮件里的费率、电子表格里的截止日期，以及不确定是否到账的付款。当客户询问进度时，你不得不翻找聊天记录而不是直接回复，而那些你忘记跟进的客户则会悄悄流失。

The fix: one Notion client dashboard. One dashboard holds the whole client list: a Clients database with a status per client, a linked view that shows only the ones who need a follow-up, and a simple income view that totals what each client is worth. Open Notion and every client is in one place.

解决方案：一个 Notion 客户仪表板。一个仪表板即可容纳整个客户列表：一个包含每个客户状态的“客户”数据库、一个仅显示需要跟进客户的关联视图，以及一个汇总每个客户价值的简单收入视图。打开 Notion，所有客户尽在掌握。

Step 1: Make the Clients database. On your dashboard page, add a database and give it these properties — this is the whole schema, copy it as-is: { "database": "Clients", "properties": { "Name": "title", "Company": "text", "Status": "select — Lead, Active, Paused, Done", "Contact": "text", "Monthly value": "number", "Paid this month": "checkbox" } }. Every client becomes one row holding everything about that client.

第一步：创建“客户”数据库。在仪表板页面上，添加一个数据库并设置以下属性——这是完整的架构，请按原样复制：{ "database": "Clients", "properties": { "Name": "title", "Company": "text", "Status": "select — Lead, Active, Paused, Done", "Contact": "text", "Monthly value": "number", "Paid this month": "checkbox" } }。每个客户都将成为一行，包含关于该客户的所有信息。

Step 2: Give every client a status. Use a select property with four options: Lead — you are talking to them; Active — work is running; Paused — waiting for now; Done — project finished. Status is the one field that runs the dashboard.

第二步：为每个客户设置状态。使用包含四个选项的选择属性：Lead（潜在客户）——正在沟通中；Active（活跃）——工作进行中；Paused（暂停）——暂时等待；Done（完成）——项目已结束。状态是驱动仪表板的核心字段。

Step 3: Track the money. Add a number property for monthly value and a checkbox for paid this month. Dummy data to practise with: Client (Demo Studio), Monthly value ($1,200/mo), Status (Active), Paid (Yes); Client (Demo Bakery), Monthly value ($450), Status (Lead), Paid (No); Client (Demo Consultancy), Monthly value ($800/mo), Status (Paused), Paid (No).

第三步：追踪资金。添加一个用于月价值的数字属性和一个用于本月是否付款的复选框。练习用的演示数据：客户（演示工作室），月价值（$1,200/月），状态（活跃），已付款（是）；客户（演示面包店），月价值（$450），状态（潜在客户），已付款（否）；客户（演示咨询公司），月价值（$800/月），状态（暂停），已付款（否）。

Step 4: Build three views from one database. Link the same database three times on one page — views are filters, the data stays in one place: Active clients — only the work running now; Follow-ups — Leads who need a message; Grouped by status — the whole pipeline at a glance.

第四步：基于同一个数据库构建三个视图。在页面上关联同一个数据库三次——视图即过滤器，数据保持在同一处：活跃客户——仅显示当前进行中的工作；跟进——需要发送消息的潜在客户；按状态分组——一目了然的整个业务流程。

Step 5: Test it with dummy clients. Add the three dummy clients, flip a Lead to Active, and mark a payment as paid. The views update themselves — the Active list grows, the follow-up list shrinks, and the income view adds up the month.

第五步：用演示客户进行测试。添加三个演示客户，将一个“潜在客户”更改为“活跃”，并将一笔付款标记为“已付”。视图会自动更新——活跃列表增加，跟进列表减少，收入视图会自动汇总本月金额。

The finished result: One dashboard in Notion where every client, every status, and every payment lives together. Open it each morning and you know exactly who needs attention today. Status tells you where each client stands, the follow-up view tells you who to message next, and the income view tells you what the month is worth before you invoice. This dashboard is built for clients, status, and income — not for making Notion look pretty.

最终结果：Notion 中的一个仪表板，让每个客户、每种状态和每笔付款都汇集在一起。每天早上打开它，你就能确切知道今天谁需要关注。状态告诉你每个客户的进展，跟进视图告诉你接下来该联系谁，收入视图则在开票前告诉你本月的价值。这个仪表板是为了管理客户、状态和收入而构建的，而不是为了让 Notion 看起来漂亮。

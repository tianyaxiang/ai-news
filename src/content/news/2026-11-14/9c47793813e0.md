# Build a Robot Pick-and-Place Simulation with SimReady Assets

本指南展示了一个饮料罐拾取与放置任务，该任务使用 UR17G 机械臂、Robotiq 2F-140 夹爪和饮料罐在 Isaac Sim 中构建场景，检查其行为，并运行一个带有智能体生成控制的拾取与放置示例。

For robotics workflows, SimReady means an OpenUSD asset has been prepared with the properties needed for a defined simulation use case, such as collisions, mass, joints, and joint drives. SimReady Central, an open asset library on Hugging Face, lets you reuse robot and object assets with authored simulation properties and profile-validation evidence.

对于机器人工作流而言，“SimReady”意味着 OpenUSD 资产已针对特定的模拟用例准备好了所需的属性，例如碰撞、质量、关节和关节驱动。SimReady Central 是 Hugging Face 上的一个开放资产库，允许您重复使用具有预设模拟属性和配置文件验证证据的机器人及物体资产。

What makes a robot asset SimReady? SimReady Foundation defines what features the OpenUSD asset needs for a simulation use case. Its specifications connect three levels: Profile: a group of features for a use case, such as a robot body. Features: capabilities needed for the use case, such as joints that can be controlled. Requirements: checks on the settings needed for each feature, such as a joint’s drive settings.

是什么让机器人资产成为 SimReady？SimReady 基础规范定义了 OpenUSD 资产在模拟用例中所需的功能。其规范连接了三个层面：配置文件（Profile）：针对特定用例的一组功能，例如机器人本体；功能（Features）：用例所需的能力，例如可控关节；要求（Requirements）：对每个功能所需设置的检查，例如关节的驱动设置。

For this task, those properties include the arm and gripper’s joints and a beverage can asset collisions and mass. Validation checks these settings against the profile’s requirements. The simulation then tests whether the assembled robot can use them to pick up and move the can.

对于此任务，这些属性包括机械臂和夹爪的关节，以及饮料罐资产的碰撞和质量。验证过程会根据配置文件的要求检查这些设置。随后，模拟将测试组装好的机器人是否能利用这些属性来拾取并移动罐子。

What comes with the asset, and what do you add? The UR17G, Robotiq 2F-140, and beverage can packages include the models and their simulation settings. You assemble the scene and add task code to define the arm–gripper assembly, work surface, starting positions, and controls for moving the arm and opening and closing the gripper.

资产自带什么，您又需要添加什么？UR17G、Robotiq 2F-140 和饮料罐软件包包含了模型及其模拟设置。您需要组装场景并添加任务代码，以定义机械臂与夹爪的组合、工作台面、起始位置，以及用于移动机械臂和开关夹爪的控制程序。

What should you check before running a pick-and-place task? A robot can look visually correct while stationary in Isaac Sim but move or interact with objects incorrectly when the simulation runs. Before running pick-and-place, test its joints, movement, and contact behavior. You can ask the agent to perform these tests or do them manually in Isaac Sim.

在运行拾取与放置任务前应该检查什么？机器人在 Isaac Sim 中静止时看起来可能完全正常，但在模拟运行时，其移动或与物体的交互可能会出错。在运行拾取与放置任务前，请测试其关节、运动和接触行为。您可以要求智能体执行这些测试，也可以在 Isaac Sim 中手动完成。

Joint settings: Review the arm and gripper’s joint limits and drive settings. Movement: Test a small arm movement and open and close the gripper. Contact: Confirm that the can rests on the work surface without falling through it. During pick-and-place, watch whether a beverage can stay in the gripper as the arm moves.

关节设置：检查机械臂和夹爪的关节限位及驱动设置。运动：测试小范围的机械臂移动，并开关夹爪。接触：确认罐子稳固地放置在工作面上，不会穿透表面。在拾取与放置过程中，观察机械臂移动时饮料罐是否能保持在夹爪中。

Build a pick-and-place simulation in Isaac Sim. This example combines the UR17G arm, Robotiq 2F-140 gripper, and beverage can in Isaac Sim. The task is to grasp the can, lift it, move it to a target, and release it. You can also leverage SimReady Central Space search service endpoint to look for OEM curated content.

在 Isaac Sim 中构建拾取与放置模拟。本示例在 Isaac Sim 中结合了 UR17G 机械臂、Robotiq 2F-140 夹爪和饮料罐。任务目标是抓取罐子、将其提起、移动到目标位置并释放。您还可以利用 SimReady Central Space 搜索服务终端来查找由原始设备制造商（OEM）策划的内容。

Step 1: Download the robot arm, gripper, and beverage can assets. Open SimReady Central and find the UR17G arm, Robotiq 2F-140 gripper, and beverage can used here. Select Download on each asset, then use Save to folder or the supplied Hugging Face command. Keep all three complete asset folders intact so Isaac Sim can find their supporting files.

第一步：下载机械臂、夹爪和饮料罐资产。打开 SimReady Central，找到此处使用的 UR17G 机械臂、Robotiq 2F-140 夹爪和饮料罐。选择每个资产的“下载”，然后使用“保存到文件夹”或提供的 Hugging Face 命令。请保持这三个完整的资产文件夹结构完整，以便 Isaac Sim 能够找到其支持文件。

What does asset validation tell you? The arm validation report uses the Robot-Body 4.0.0 profile and the gripper validation report uses Robot-Gripper 3.0.0. Both record passing PhysX driven-joint checks, which inspect joint-drive settings. SimReady profile validation provides a shared baseline for reusing these assets.

资产验证告诉了您什么？机械臂验证报告使用 Robot-Body 4.0.0 配置文件，夹爪验证报告使用 Robot-Gripper 3.0.0。两者均记录了通过 PhysX 驱动关节检查的结果，该检查用于审查关节驱动设置。SimReady 配置文件验证为重复使用这些资产提供了一个共享的基准。

Step 2: Assemble the robot and compose the scene for pick and place. With the assets downloaded, use your agent with Isaac Sim skills to help assemble the robot, run validation tools, and create the pick-and-place controls. You can also perform these steps manually using the linked documentation.

第二步：组装机器人并构建拾取与放置场景。资产下载完成后，使用您的智能体配合 Isaac Sim 技能来协助组装机器人、运行验证工具并创建拾取与放置控制程序。您也可以参考链接文档手动执行这些步骤。

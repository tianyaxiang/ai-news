Privacy and network behavior Plannotator does not collect usage telemetry or analytics. Plans, diffs, annotations, drafts, history, and configuration stay local by default. Each plan review, annotate, archive, share-portal, and code-review app surface checks GitHub for the latest Plannotator release when it loads.

隐私和网络行为：Plannotator 不收集使用遥测或分析数据。计划、差异、标注、草稿、历史记录和配置默认保留在本地。每个计划审查、标注、存档、共享门户和代码审查应用程序界面在加载时都会检查 GitHub 以获取最新的 Plannotator 版本。

This sends no plan or review content and gives the Plannotator project owner no usage analytics, although GitHub receives an ordinary request. There is currently no opt-out setting for the release check. Local Git code review can also query the configured origin with git ls-remote to detect the default branch and a stale baseline; it does not send the local diff.

这不会发送任何计划或审查内容，也不会向 Plannotator 项目所有者提供使用分析，尽管 GitHub 会收到一个普通请求。目前没有针对版本检查的退出设置。本地 Git 代码审查还可以使用 `git ls-remote` 查询配置的源，以检测默认分支和过时的基准；它不会发送本地差异。

That remote query runs when the review opens, when the page loads its diff, when you switch the diff type or base (including the "Diff out of date · Refresh" button), and when you press Fetch — never on a timer, so an idle review page makes no network calls.

该远程查询在审查打开时、页面加载差异时、切换差异类型或基准时（包括“差异已过期 · 刷新”按钮）以及按下“获取”时运行——从不按计时器运行，因此空闲的审查页面不会进行任何网络调用。

Turn it off entirely with plannotator review --no-git-remote-check, PLANNOTATOR_GIT_REMOTE_CHECK=0, or { "gitRemoteCheck": false } in ~/.plannotator/config.json; the compare target then comes from local refs only and the "behind GitHub" banner never appears.

可以通过 `plannotator review --no-git-remote-check`、`PLANNOTATOR_GIT_REMOTE_CHECK=0` 或在 `~/.plannotator/config.json` 中设置 `{ "gitRemoteCheck": false }` 来完全关闭它；此时比较目标仅来自本地引用，“落后于 GitHub”的横幅将永远不会出现。

Content leaves the local workflow only when a network feature needs it: URL annotation fetches the requested site, through Jina Reader by default for public pages or directly when Jina is disabled or unavailable. GitHub and GitLab review uses your authenticated CLI and Git remote to retrieve PR or MR data.

内容仅在网络功能需要时才会离开本地工作流：URL 标注会获取请求的站点，对于公共页面默认通过 Jina Reader 获取，或者在 Jina 被禁用或不可用时直接获取。GitHub 和 GitLab 审查使用你经过身份验证的 CLI 和 Git 远程仓库来检索 PR 或 MR 数据。

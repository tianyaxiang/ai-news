# Android can now securely migrate your logins between password managers
# Android 现在可以安全地在密码管理器之间迁移您的登录信息

As longer, more complex passwords have become a necessity, remembering all those strings of numbers, letters, and special characters has become nearly impossible. Password managers can solve that problem, but what happens when you want to move to a different login organizer? Sure, you could manually type all your logins into a new app, but now Android can do that for you without the tedium.

随着密码变得越来越长、越来越复杂，记住所有这些数字、字母和特殊字符的组合几乎变得不可能。密码管理器可以解决这个问题，但如果您想更换到另一个登录管理工具该怎么办？当然，您可以手动将所有登录信息输入到新应用中，但现在 Android 可以为您代劳，省去繁琐的过程。

Google designed the new login transfer process to happen entirely on your phone, so you need the corresponding apps installed with your credentials synced. To start the move, you’ll have to find the import option in the app you want to use. The location of that feature will vary, but in Google Password Manager (built into Android), it’s near the top under the settings tab.

Google 设计的这项新登录信息迁移流程完全在您的手机上完成，因此您需要安装相应的应用程序并同步您的凭据。要开始迁移，您需要在想要使用的应用程序中找到导入选项。该功能的位置因应用而异，但在 Google 密码管理器（内置于 Android 中）里，它位于设置选项卡下的顶部附近。

The import option in Google Password Manager will plug in to the new migration system, while export still just creates an unencrypted CSV with your passwords that can be dumped into any app. It will be similar in other apps, so make sure to start the process in the app you want to use. Currently, this works in Google’s app, 1Password, Bitwarden, and Dashlane.

Google 密码管理器中的导入选项将接入新的迁移系统，而导出功能仍然只是创建一个包含您密码的未加密 CSV 文件，可以导入到任何应用程序中。其他应用程序的操作流程也类似，因此请务必在您想要使用的应用程序中启动该过程。目前，此功能适用于 Google 自家应用、1Password、Bitwarden 和 Dashlane。

Once you trigger the migration, the Android system will verify your identity and ask you to confirm the move in your new password manager. Android can move both passwords and passkeys without creating any risky text files. Even if you’ve got a lot of passwords, the process should wrap up quickly.

一旦您触发迁移，Android 系统将验证您的身份，并要求您在新的密码管理器中确认迁移。Android 可以在不创建任何高风险文本文件的情况下迁移密码和通行密钥（passkeys）。即使您有很多密码，整个过程也能很快完成。

The migration happens in the Android system even if started from a third-party app.

即使是从第三方应用程序启动，迁移过程也会在 Android 系统内部完成。

This feature doesn’t require an OS update or new app downloads beyond grabbing the password manager you want to use. It’s integrated with Google Play Services and works on all devices running Android 8.0 Oreo or higher. Play Services support currently only goes back to 7.0 Nougat, so password migration should work on virtually every operational Google-certified Android device in the world.

此功能不需要操作系统更新或下载新应用，只需获取您想要使用的密码管理器即可。它与 Google Play 服务集成，适用于所有运行 Android 8.0 Oreo 或更高版本的设备。Play 服务目前支持回溯至 Android 7.0 Nougat，因此密码迁移功能几乎可以在全球所有运行中的 Google 认证 Android 设备上使用。

If you want to use a password manager that isn’t on the list, you’re currently stuck doing a manual import or an unencrypted CSV. This feature relies on the Credential Transfer API, which the previously mentioned apps have all implemented. Google says more password managers will add support for transfers via this API eventually but does not offer a timeline.

如果您想使用的密码管理器不在列表中，目前只能进行手动导入或使用未加密的 CSV 文件。此功能依赖于“凭据传输 API”（Credential Transfer API），上述应用程序均已实现该接口。Google 表示，未来会有更多密码管理器通过此 API 添加对传输的支持，但并未提供具体时间表。

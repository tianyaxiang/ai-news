Backstory The Maybe Finance (archived/abandoned repo) team spent most of 2021–2022 building a full-featured personal finance and wealth management app. It even included an “Ask an Advisor” feature that connected users with a real CFP/CFA — all included with your subscription. The business end of things didn't work out, and so they stopped developing the app in mid-2023. After spending nearly $1 million on development (employees, contractors, data providers, infra, etc.), the team open-sourced the app. Their goal was to let users self-host it for free — and eventually launch a hosted version for a small fee. They actually did launch that hosted version … briefly. That also didn’t work out — at least not as a sustainable B2C business — so now here we are: hosting a community-maintained fork to keep the codebase alive and see where this can go next. Join us!

背景：Maybe Finance（已归档/废弃的仓库）团队在 2021 年至 2022 年的大部分时间里，致力于构建一款功能齐全的个人理财和财富管理应用。它甚至包含了一项“咨询顾问”功能，将用户与真正的 CFP/CFA（注册理财规划师/特许金融分析师）联系起来，且全部包含在订阅费用中。由于商业运作未能成功，他们在 2023 年年中停止了该应用的开发。在投入近 100 万美元用于开发（员工、承包商、数据提供商、基础设施等）后，该团队将应用开源。他们的目标是让用户免费自托管，并最终以少量费用推出托管版本。他们确实短暂地推出了该托管版本，但同样未能成功——至少作为可持续的 B2C 业务未能成功——所以现在我们在这里：托管一个由社区维护的分支，以保持代码库的活力，并探索未来的发展方向。加入我们！

Hosting Sure Sure is a fully working personal finance app that can be self hosted with Docker. Sure can be accessed from a browser, the macOS desktop app, the mobile app, API clients, and LLM agents. See Sure Clients for an overview.

托管 Sure：Sure 是一款功能完备的个人理财应用，可以通过 Docker 进行自托管。用户可以通过浏览器、macOS 桌面应用、移动应用、API 客户端和 LLM 代理访问 Sure。请参阅“Sure 客户端”以获取概览。

One-click Install Render expects each button target branch to have a render.yaml at the repository root. The branch-ready Blueprint files live in branches/<branch-name>/render.yaml in a separate repo and can be copied to each corresponding branch root. Option What it deploys latest stable Sure - No AI Sure web, Sidekiq worker, Render Postgres, and Render Key Value. AI tokens are intentionally blank. Sure - Simple AI Sure with OpenAI-backed AI settings, pgvector-ready Postgres, Sidekiq, and Render Key Value. Render prompts for the OpenAI token. Sure - External AI Sure with external assistant settings plus AlphaClaw, which manages the OpenClaw gateway on Render.

一键安装：Render 要求每个按钮目标分支在仓库根目录下都有一个 render.yaml 文件。准备好分支的蓝图文件位于单独仓库的 branches/<branch-name>/render.yaml 中，可以复制到每个对应的分支根目录。选项：部署内容。latest stable：Sure - 无 AI，Sure web、Sidekiq worker、Render Postgres 和 Render Key Value。AI 令牌故意留空。Sure - 简单 AI：Sure 带有 OpenAI 支持的 AI 设置、支持 pgvector 的 Postgres、Sidekiq 和 Render Key Value。Render 会提示输入 OpenAI 令牌。Sure - 外部 AI：Sure 带有外部助手设置以及 AlphaClaw，后者在 Render 上管理 OpenClaw 网关。

# Claude Fable 5.2 scores 65 on Artificial Analysis, highest so far

Released November 2026

2026年11月发布

Claude Fable 5.2 (Max, Default Fallback) is amongst the leading models in intelligence, but particularly expensive when comparing to other models of similar price. It's also notably slow per task and very verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

Claude Fable 5.2 (Max, Default Fallback) 在智能方面处于领先模型之列，但与同等价格的其他模型相比，其价格尤为昂贵。此外，该模型在处理任务时速度明显较慢，且输出非常冗长。该模型支持文本和图像输入，输出文本，并拥有 100 万个 token 的上下文窗口。

Claude Fable 5.2 (Max, Default Fallback) scores 65 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 40). When evaluating the Intelligence Index, it generated 275M tokens, which is very verbose in comparison to the median of 72.8M.

Claude Fable 5.2 (Max, Default Fallback) 在 Artificial Analysis 智能指数上得分为 65 分，远高于同类模型的平均水平（中位数为 40）。在评估智能指数时，它生成了 2.75 亿个 token，与 7280 万的中位数相比，显得非常冗长。

Pricing for Claude Fable 5.2 (Max, Default Fallback) is $8.00 per 1M input tokens (expensive, median: $2.00) and $40.00 per 1M output tokens (expensive, median: $10.00). On average, it costs $26.54 per task to evaluate Claude Fable 5.2 (Max, Default Fallback) on the Intelligence Index.

Claude Fable 5.2 (Max, Default Fallback) 的定价为每 100 万输入 token 8.00 美元（昂贵，中位数为 2.00 美元），每 100 万输出 token 40.00 美元（昂贵，中位数为 10.00 美元）。平均而言，在智能指数上评估 Claude Fable 5.2 (Max, Default Fallback) 每个任务的成本为 26.54 美元。

At 44.4 minutes per Intelligence Index task, Claude Fable 5.2 (Max, Default Fallback) is notably slow compared with the median of 12.7 minutes for comparable models (lower is better).

在智能指数任务中，Claude Fable 5.2 (Max, Default Fallback) 平均每个任务耗时 44.4 分钟，与同类模型 12.7 分钟的中位数相比明显较慢（数值越低越好）。

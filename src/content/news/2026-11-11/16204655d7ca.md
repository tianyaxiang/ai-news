# Introducing Cortex - A web framework in C and oriented toward AI-native workflows

Cortex is a web application framework designed to feel familiar if you’ve used Ruby on Rails, but implemented in C and oriented toward AI-native workflows. It embraces the “Rails Way”: convention over configuration, a clear project structure, and an emphasis on developer happiness. If you already know how a Rails app is organized, you’ll feel at home.

Cortex 是一个 Web 应用程序框架，旨在让使用过 Ruby on Rails 的用户感到亲切，但它是用 C 语言实现的，并面向 AI 原生工作流。它秉承了“Rails 之道”：约定优于配置、清晰的项目结构以及对开发者幸福感的重视。如果你已经了解 Rails 应用的组织方式，那么你会感到非常熟悉。

The difference is under the hood: Cortex is written in C, giving you low-level control, a small footprint, and excellent performance. Contributing Cortex is open source and just getting started. Whether you’re a C veteran, a Rails developer curious about systems programming, or someone passionate about AI tooling, there’s a place for you here. Report bugs, suggest features, improve the docs, or open a pull request at github.com/sergiomaia/cortex.

其不同之处在于底层：Cortex 使用 C 语言编写，为你提供了底层控制能力、较小的内存占用以及卓越的性能。Cortex 是开源的，目前正处于起步阶段。无论你是 C 语言老手、对系统编程感到好奇的 Rails 开发者，还是对 AI 工具充满热情的爱好者，这里都有你的一席之地。你可以通过 github.com/sergiomaia/cortex 报告错误、建议功能、改进文档或提交拉取请求。

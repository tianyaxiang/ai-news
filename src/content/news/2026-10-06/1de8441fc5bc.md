# boykopovar / AnyPS5

About
关于

Tool for automatic executables porting to Linux and Windows. Includes a relinker that converts executable to the target system's native format and implementations of system prx libraries suitable for dynamic linking. No emulation or separate runtime process.
这是一个用于将可执行文件自动移植到 Linux 和 Windows 的工具。它包含一个重链接器（relinker），可将可执行文件转换为目标系统的原生格式，并实现了适用于动态链接的系统 prx 库。该工具不涉及模拟或独立的运行时进程。

Status
状态

* System libraries: percentage of the functions known to the project so far (declared in core/libs/prx), not of every PS5 system function. The total grows as more functions are declared.
* 系统库：目前项目已知的函数百分比（在 core/libs/prx 中声明），并非所有 PS5 系统函数。随着更多函数的声明，该比例会不断增加。

List of verified games
已验证游戏列表

Dreaming Sarah (2D platformer) runs at a stable 60 fps on a GTX 1050 Ti / i5-7500 3.4GHz.
《Dreaming Sarah》（2D 平台游戏）在 GTX 1050 Ti / i5-7500 3.4GHz 配置下可稳定运行在 60 帧。

Unsupported or unexpected states strictly throw std::runtime_error. what() is printed to stderr and the process terminates.
对于不支持或意外的状态，程序会严格抛出 `std::runtime_error`。错误信息（what()）会被打印到 stderr，随后进程终止。

The shader recompiler successfully produces SPIR-V (validated via Spirv-Tools when built with ANYPS5_ENABLE_SPIRV_TOOLS).
着色器重编译器可成功生成 SPIR-V（当使用 `ANYPS5_ENABLE_SPIRV_TOOLS` 构建时，可通过 Spirv-Tools 进行验证）。

输入映射

SDL-mapped game controllers are supported, including analog sticks and triggers. Keyboard and mouse controls can be configured with an anyps5-input.ini file. See input mapping for the supported devices and configuration format.
支持 SDL 映射的游戏控制器，包括模拟摇杆和扳机键。键盘和鼠标控制可以通过 `anyps5-input.ini` 文件进行配置。请参阅输入映射以了解支持的设备和配置格式。

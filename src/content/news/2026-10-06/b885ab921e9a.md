# Command-line tool quickly removes Apple Intelligence from macOS 27
# 命令行工具可快速从 macOS 27 中移除 Apple Intelligence

A new tool is allowing Mac users the ability again to easily turn off Apple Intelligence with one click and free up to 12GB of storage. Unlike with previous versions of macOS, macOS 27 Golden Gate doesn’t have a toggle for turning off Apple Intelligence. That makes disabling AI features that you may not want more difficult. It also means that the AI models necessary for running Apple Intelligence will take up space on your disk, even if you don’t use them or if you go through your settings to individually find and disable AI capabilities.

一款新工具让 Mac 用户能够再次通过一键操作轻松关闭 Apple Intelligence，并释放高达 12GB 的存储空间。与以往的 macOS 版本不同，macOS 27 Golden Gate 没有提供关闭 Apple Intelligence 的开关。这使得禁用你不想要的 AI 功能变得更加困难。这也意味着，即使你不使用这些功能，或者即便你通过设置逐一查找并禁用了 AI 功能，运行 Apple Intelligence 所需的 AI 模型仍会占用你的磁盘空间。

In response, a developer known as Om Lahore on GitHub last week created RemoveMacAI, a command-line tool that allows macOS 27 users to “turn off Apple Intelligence on macOS 27″ in a way that is “fully reversible,” per the GitHub page. They said that Apple’s Intelligence models take up “about 12GB,” but the models can actually take up over 30GB, The Verge noted. RemoveMacAI “turns off Siri, Writing Tools, Genmoji, Image Playground, the ChatGPT extension, and all the summaries, then it deletes the models and stops macOS from downloading them again. Dictation still works because it’s a separate setting,” the developer said in a Reddit post first spotted by MacRumors.

对此，一位名为 Om Lahore 的开发者上周在 GitHub 上创建了 RemoveMacAI。根据 GitHub 页面显示，这是一个命令行工具，允许 macOS 27 用户以“完全可逆”的方式“关闭 macOS 27 上的 Apple Intelligence”。该开发者表示 Apple Intelligence 模型占用“约 12GB”空间，但据《The Verge》指出，这些模型实际上可能占用超过 30GB 的空间。该开发者在 Reddit 的一则帖子（由 MacRumors 最先发现）中表示，RemoveMacAI 可以“关闭 Siri、写作工具、Genmoji、图像游乐场 (Image Playground)、ChatGPT 扩展以及所有摘要功能，然后删除这些模型并阻止 macOS 再次下载它们。听写功能仍可正常使用，因为它是一个独立的设置。”

On Reddit, RemoveMacAI’s developer said the tool is open source and further explained how it works: It uses a configuration profile you approve in System Settings plus Apple’s own asset service, so [System Integrity Protection] stays on and nothing in /System gets touched directly. removemacai revert removes the profile, and macOS downloads the models again when you turn a feature back on. The dev also said you can remove only the Apple Intelligence features you don’t want and keep the others. Some users on Reddit have reported that the tool works, and it has 1,700 stars on GitHub as of this writing.

在 Reddit 上，RemoveMacAI 的开发者表示该工具是开源的，并进一步解释了其工作原理：它使用你在“系统设置”中批准的配置文件，加上苹果自身的资源服务，因此 [系统完整性保护 (SIP)] 保持开启状态，且 /System 目录下的任何内容都不会被直接触动。执行 `removemacai revert` 命令会移除该配置文件，当你重新开启某项功能时，macOS 会再次下载相应的模型。该开发者还表示，你可以选择仅移除你不想要的 Apple Intelligence 功能，而保留其他功能。一些 Reddit 用户反馈该工具确实有效，截至撰稿时，它在 GitHub 上已获得 1,700 个星标。

Interest in RemoveMacAI demonstrates the aversion that some users have to some or all of Apple Intelligence’s features, despite growing focus from Apple on AI-driven device and software upgrades in its computers and other devices. “Reminds me of all the de-crufting you’ve always needed to do when you install Windows. Looks like we’ve gotten to the point on macOS too, where you need to run third-party scripts on a new OS installation to gain back control of your system resources and remove unwanted crapware,” a Hacker News user wrote in response to RemoveMacAI.

尽管苹果日益关注其电脑及其他设备中由 AI 驱动的硬件和软件升级，但对 RemoveMacAI 的关注表明，部分用户对 Apple Intelligence 的部分或全部功能存在抵触情绪。一位 Hacker News 用户在评论 RemoveMacAI 时写道：“这让我想起安装 Windows 时总是需要进行的各种清理工作。看来 macOS 也到了这一步：在安装新系统后，你需要运行第三方脚本来重新获得系统资源的控制权，并移除不需要的垃圾软件。”

Although many users are happy to leverage Apple Intelligence in their gadgets, RemoveMacAI is a simple way for the rest to regain control over Apple Intelligence’s presence on their computers that Apple previously offered.

虽然许多用户乐于在设备上使用 Apple Intelligence，但对于其他用户来说，RemoveMacAI 提供了一种简单的方法，让他们能够重新获得对电脑上 Apple Intelligence 存在与否的控制权——而这种控制权原本是苹果应该提供的。

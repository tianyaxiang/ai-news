# Flirt is now Open-Source

**Flirt 现已开源**

2026-10-05 I'm happy to announce that Flirt is finally open-source: [codeberg.org/flirt/flirt](https://codeberg.org/flirt/flirt)

2026年10月5日，我很高兴地宣布 Flirt 终于开源了：[codeberg.org/flirt/flirt](https://codeberg.org/flirt/flirt)

Edit: In case you're reading about Flirt for the first time: Flirt is a review tool that optimizes for the "patch series" workflow, where the author continuously amends, rebases and force-pushes their changes. Flirt remembers what you previously reviewed and shows you the difference to the current state. It is a local-first tool and is compatible with multiple backends, e.g. GitHub and mailing lists.

编辑：如果你是第一次了解 Flirt：Flirt 是一款针对“补丁系列”（patch series）工作流进行优化的代码审查工具。在这种工作流中，作者会不断地修改、变基（rebase）并强制推送（force-push）他们的变更。Flirt 会记录你之前的审查内容，并向你展示与当前状态的差异。它是一款“本地优先”（local-first）的工具，并兼容多种后端，例如 GitHub 和邮件列表。

Warning: I don't yet consider it ready for general use. There are still plenty of bugs and missing features. If you're not considering to become a contributor, I recommend being a little more patient. I'll probably write another blog post when Flirt is ready for you.

警告：我认为它目前还不适合通用。它仍然存在许多 Bug 和缺失的功能。如果你不打算成为贡献者，我建议你再耐心等待一下。当 Flirt 准备好供大众使用时，我可能会再写一篇博客文章。

Potential contributor or not, consider joining the discussion on Zulip. Please note that using LLMs to write messages is not allowed.

无论你是否打算成为贡献者，都可以考虑加入 Zulip 上的讨论。请注意，不允许使用大语言模型（LLM）来撰写消息。

Since Flirt is hosted on Codeberg, a hypothetical Forgejo-backend would be used to dog-food Flirt. This doesn't exist yet! Creating it next-up on my todo list.

由于 Flirt 托管在 Codeberg 上，因此需要一个假设的 Forgejo 后端来对 Flirt 进行“吃自己的狗粮”（dog-food，即在开发中使用自己的产品）。目前这个后端还不存在！创建它是我待办事项列表中的下一项任务。

Thanks for reading!

感谢阅读！

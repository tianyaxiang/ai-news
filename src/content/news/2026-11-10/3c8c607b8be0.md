# A C++ Quicksort Faster Than std::sort

A C++ Quicksort Faster Than std::sort blqsort is a very fast quicksort algorithm. I am not aware of any other general-purpose comparison-based sorting algorithm that is faster on random data. Only specialized SIMD-based algorithms are generally faster when dealing with small primitive data types.

blqsort 是一个非常快速的快速排序算法。据我所知，在处理随机数据时，没有其他通用的基于比较的排序算法比它更快。只有在处理小型原始数据类型时，专门的基于 SIMD 的算法通常才会更快。

blqsort The main ideas are branchless partitioning, sorting networks for small partitions and robust pivot selection. The implementation is available on GitHub under the MIT license. There is also a C version of it, including multithreaded versions, each as a single header file.

blqsort 的主要思想是无分支分区、针对小分区的排序网络以及稳健的枢轴选择。该实现可在 GitHub 上以 MIT 许可证获取。它还有一个 C 语言版本，包括多线程版本，每个版本都是一个单独的头文件。

You can prevent this with tail call elimination. That is, the first recursive call remains, while the second is replaced by a loop iteration. You now need to ensure that the smaller partition is called recursively. So swap them if necessary.

你可以通过尾调用消除来防止这种情况。也就是说，保留第一个递归调用，而将第二个替换为循环迭代。现在你需要确保较小的分区被递归调用。因此，必要时交换它们。

void sortq(double* ar, int len) { while (len >= 2) { double piv = ar[0]; int mid = 0; for (int i = 1; i < len; i++) { if (ar[i] < piv) { mid += 1; std::swap(ar[mid], ar[i]); } } std::swap(ar[mid], ar[0]); double* ar2 = ar + mid + 1; int len2 = len - mid - 1; len = mid; if (len2 > len) { std::swap(len, len2); std::swap(ar, ar2); } sortq(ar2, len2); } }

Sorting networks For partitions with up to about 20 elements, insertion sort is faster than quicksort. But there is something even faster for small partitions: sorting networks. Each partition size is handled in its own program branch. For a partition size of two, the two elements are simply compared and swapped if necessary. However, as the number of elements increases, the logic becomes increasingly complex.

排序网络：对于最多约 20 个元素的分区，插入排序比快速排序更快。但对于小分区，还有更快的方案：排序网络。每个分区大小都在其自己的程序分支中处理。对于大小为 2 的分区，只需比较这两个元素并在必要时进行交换。然而，随着元素数量的增加，逻辑变得越来越复杂。

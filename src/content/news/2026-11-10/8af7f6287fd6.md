Install the HA-MCP integration (requires Home Assistant 2026.8.0 or newer; see compatibility details). On Home Assistant 2026.8–2026.10, open HACS, search for HA-MCP, then Download. On Home Assistant 2026.11 or newer, open Settings → Marketplace, accept its first-run warning, and search for HA-MCP, then Install. 快速入门：以下设置适用于 9.0.0 版本（2026 年 10 月 28 日）及更高版本；早期版本显示的设置表单较短，不包含管理员账户步骤。安装 HA-MCP 集成（需要 Home Assistant 2026.8.0 或更新版本；请参阅兼容性详情）。在 Home Assistant 2026.8–2026.10 版本上，打开 HACS，搜索 HA-MCP，然后下载。在 Home Assistant 2026.11 或更新版本上，打开“设置”→“市场”，接受首次运行警告，搜索 HA-MCP，然后安装。HA-MCP 位于默认目录中，因此安装和接收更新无需连接 GitHub 或添加自定义存储库。上方的徽章也会打开其目录页面。如果已经从早期的 homeassistant-ai/ha-mcp-integration 存储库安装过？它会继续接收相同的版本更新。在市场上，请保持 GitHub 连接，以便对该自定义存储库进行后台检查。旧的已安装版本可能仍显示为“HA-MCP Custom Component”；搜索 HA-MCP 可匹配这两个名称。重启 Home Assistant。

Decide which administrator account the server acts as. Either create a long-lived access token on your own account (your profile → Security → Long-lived access tokens → Create token; it works from anywhere if it leaks, and the server's changes show under your name), or, safer, create an account just for HA-MCP under Settings → People → Add person with Allow login, Local access only and Administrator on. Never use your own login for the second option. Go to Settings → Devices & Services → Add Integration, search for HA-MCP and choose HA-MCP Server. Paste your token, or enter the user name and password of the account you made for HA-MCP (HA-MCP creates its token), pick how clients may connect — Remote access through Home Assistant (start with Secret URL, the simplest; Home Assistant sign-in adds a login) and/or Network access: Local network — then click Submit. Both start disabled, so a client on another device needs one of them. Copy the connect URL from the entry's Configure screen (Settings → Devices & Services → “HA-MCP — Manage Home Assistant with AI” → HA-MCP Server → Configure). A notification confirms the server started and points you there. Paste that URL into your AI client — done.

确定服务器将以哪个管理员账户身份运行。您可以为自己的账户创建一个长期访问令牌（个人资料 → 安全 → 长期访问令牌 → 创建令牌；如果泄露，它可以在任何地方使用，且服务器的更改将显示在您的名下），或者更安全地，在“设置”→“人员”→“添加人员”下专门为 HA-MCP 创建一个账户，并开启“允许登录”、“仅限本地访问”和“管理员”权限。第二种选项切勿使用您自己的登录信息。前往“设置”→“设备与服务”→“添加集成”，搜索 HA-MCP 并选择“HA-MCP Server”。粘贴您的令牌，或输入您为 HA-MCP 创建的账户的用户名和密码（HA-MCP 会自动创建其令牌），选择客户端的连接方式——通过 Home Assistant 进行远程访问（从 Secret URL 开始，这是最简单的方式；Home Assistant 登录会增加一层验证）和/或网络访问：本地网络——然后点击提交。两者默认均为禁用状态，因此其他设备上的客户端需要启用其中之一。从条目的“配置”屏幕（设置 → 设备与服务 → “HA-MCP — Manage Home Assistant with AI” → HA-MCP Server → 配置）复制连接 URL。通知会确认服务器已启动并引导您前往该处。将该 URL 粘贴到您的 AI 客户端中——完成。

Connect URL. The Configure screen gives you a Home Assistant webhook URL for remote clients — https://<your-ha-domain>/api/webhook/<webhook-id> through Nabu Casa or any reverse proxy already pointed at Home Assistant (locally, http://<ha-host>:8123/api/webhook/<webhook-id>). For clients on the same network, the server is also reachable directly at http://<ha-ip>:9584/private_<random>. Replaces other install methods: the in-process server is a complete, standalone ha-mcp install — it takes the place of the app (add-on), Docker, and uvx/PyPI (stdio) methods. Run only one; do not run the in-process server alongside another install. Local only? Leave remote access disabled at setup (or turn off Remote access via webhook in the entry options) — no webhook is registered at all, while the direct port and sidebar panel keep working. Settings panel: while the server runs, an admin-only HA-MCP panel appears in the Home Assistant sidebar for managing tools, feature flags, backups, and themes. Optional authentication: set Authentication mode to ha_auth to require a Home Assistant account sign-in instead of using the secret URL as the credential.

连接 URL。“配置”屏幕为您提供了一个用于远程客户端的 Home Assistant Webhook URL — https://<your-ha-domain>/api/webhook/<webhook-id>（通过 Nabu Casa 或任何已指向 Home Assistant 的反向代理；本地为 http://<ha-host>:8123/api/webhook/<webhook-id>）。对于同一网络上的客户端，服务器也可以直接通过 http://<ha-ip>:9584/private_<random> 访问。取代其他安装方法：进程内服务器是一个完整、独立的 ha-mcp 安装——它取代了应用程序（插件）、Docker 和 uvx/PyPI (stdio) 方法。仅运行一种；请勿将进程内服务器与其他安装方式同时运行。仅限本地？在设置时保持远程访问禁用（或在条目选项中关闭“通过 Webhook 进行远程访问”）——这样就不会注册任何 Webhook，而直接端口和侧边栏面板仍可正常工作。设置面板：当服务器运行时，Home Assistant 侧边栏会出现一个仅限管理员的 HA-MCP 面板，用于管理工具、功能标志、备份和主题。可选身份验证：将身份验证模式设置为 ha_auth，以要求使用 Home Assistant 账户登录，而不是使用 Secret URL 作为凭据。

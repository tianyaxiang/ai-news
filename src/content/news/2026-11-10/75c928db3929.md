Pairing sequences lazily with Iterator.zip()
使用 Iterator.zip() 惰性配对序列

Suppose you are checking a weather forecast against the temperatures recorded over the same four days. The predictions come from your model, while the actual values come from observations. To calculate each day’s error, you need to pair the values at the same position. Both sequences must cover the same days in the same order. In Node.js 26 and earlier, if both sequences were arrays, you would typically use .map() with an index lookup: 01-iterators/iterator-zip-old.js// Node.js 26 and earlierconst predicted = [18, 21, 20, 23]const actual = [19, 20, 22, 21] const errors = predicted.map((prediction, i) => actual[i] - prediction)console.log(errors) // [1, -1, 2, -2]
假设你正在对照同一四天内记录的温度来检查天气预报。预测值来自你的模型，而实际值来自观测数据。为了计算每一天的误差，你需要将相同位置的值进行配对。两个序列必须涵盖相同的天数且顺序一致。在 Node.js 26 及更早版本中，如果两个序列都是数组，你通常会使用带有索引查找的 .map()：01-iterators/iterator-zip-old.js// Node.js 26 及更早版本const predicted = [18, 21, 20, 23]const actual = [19, 20, 22, 21] const errors = predicted.map((prediction, i) => actual[i] - prediction)console.log(errors) // [1, -1, 2, -2]

That works well for arrays. But what if observations come from a generator, or your model returns an iterator of predictions? Index lookups won’t work on those inputs, and converting them to arrays means loading both sequences into memory first. In Node.js 27, Iterator.zip() takes an iterable of iterables and returns a lazy iterator of pairs. We can calculate the errors with the same pipeline whether the inputs are arrays or iterators: 01-iterators/iterator-zip.jsconst predicted = [18, 21, 20, 23]const actual = [19, 20, 22, 21] const errors = Iterator.zip([predicted, actual]) .map(([prediction, observation]) => observation - prediction) .toArray() console.log(errors) // [1, -1, 2, -2] Each pair contains a prediction and its corresponding obs
这对于数组来说效果很好。但如果观测数据来自生成器，或者你的模型返回的是预测值的迭代器呢？索引查找在这些输入上将无法工作，而将它们转换为数组意味着必须先将两个序列加载到内存中。在 Node.js 27 中，Iterator.zip() 接收一个可迭代对象的集合，并返回一个惰性的配对迭代器。无论输入是数组还是迭代器，我们都可以使用相同的管道来计算误差：01-iterators/iterator-zip.jsconst predicted = [18, 21, 20, 23]const actual = [19, 20, 22, 21] const errors = Iterator.zip([predicted, actual]) .map(([prediction, observation]) => observation - prediction) .toArray() console.log(errors) // [1, -1, 2, -2] 每一对都包含一个预测值及其对应的观测值。

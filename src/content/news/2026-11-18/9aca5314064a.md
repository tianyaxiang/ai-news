# Redict is deprecated

Redict is deprecated
Drew DeVault
November 17, 2026

Redict 已被弃用
Drew DeVault
2026 年 11 月 17 日

I must unfortunately announce that Redict is officially deprecated, and Redict 7.3.6 is the final release. I had hoped to rally the Redis diaspora around a copyleft initiative, to protect ourselves from future rug-pulls, and made Redict to serve this purpose.

我很遗憾地宣布，Redict 已正式弃用，Redict 7.3.6 是其最终版本。我曾希望围绕一项 Copyleft（著佐权）倡议团结 Redis 的流散社区，以保护我们免受未来“撤资”的影响，并为此创建了 Redict。

However, with the valkey project’s success, and Redis’s return to a copyleft license, Redict was not able to build a sustainable community. We recommend that Redict users switch to valkey, which uses a permissive license but has better long-term prospects.

然而，随着 Valkey 项目的成功以及 Redis 回归 Copyleft 许可证，Redict 未能建立起一个可持续的社区。我们建议 Redict 用户切换到 Valkey，它虽然使用宽松许可证，但具有更好的长期前景。

We advise against switching back to Redis; though it is once again open source, and copyleft, it uses a contributor license agreement which will facilitate another rug-pull when Redis has a bad financial quarter.

我们建议不要切回 Redis；尽管它再次开源并采用了 Copyleft 协议，但它使用了贡献者许可协议（CLA），这将在 Redis 财务季度表现不佳时，再次促成“撤资”行为。

Switching to valkey is straightforward: if you install from your package manager, simply install valkey and move your config file:
# mv /etc/redict.conf /etc/valkey.conf

切换到 Valkey 非常简单：如果你是通过包管理器安装的，只需安装 valkey 并移动配置文件即可：
# mv /etc/redict.conf /etc/valkey.conf

If you use containers, simply pull the valkey container instead and ensure that it runs with the appropriate config file.

如果你使用容器，只需拉取 valkey 容器，并确保它使用相应的配置文件运行即可。

Thanks to everyone who has contributed to Redict, endorsed the fork as the future of Redis, and switched to it on their own machines. We had a good run :)

感谢所有为 Redict 做出贡献、支持该分支作为 Redis 未来，并在自己的机器上切换使用它的人。我们经历了一段美好的时光 :)

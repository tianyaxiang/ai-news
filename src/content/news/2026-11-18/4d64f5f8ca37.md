Hundreds of websites using the Optimizely website personalization platform served unsuspecting visitors a potent malware cocktail that targeted cryptocurrency wallets, stole payment card data, cookies, and screenshots, and delivered exploit kits for infecting iPhones and iPads, researchers said Tuesday.

研究人员周二表示，数百个使用 Optimizely 网站个性化平台的网站向毫无戒心的访问者提供了强效恶意软件组合，这些恶意软件针对加密货币钱包，窃取支付卡数据、Cookie 和屏幕截图，并分发用于感染 iPhone 和 iPad 的漏洞利用工具包。

ReportURI said it identified 178 websites—including CNN, Zoom, the BBC, and Salesforce—that were affected. JavaScript digitally signed by Optimizely and then loaded into customer pages had been modified to include malicious components that attempted to infect visitor devices with multiple payloads.

ReportURI 表示，他们确定了 178 个受影响的网站，其中包括 CNN、Zoom、BBC 和 Salesforce。由 Optimizely 进行数字签名并加载到客户页面中的 JavaScript 已被修改，其中包含了试图用多种有效载荷感染访问者设备的恶意组件。

When wares were installed successfully, they swapped user cryptocurrency wallet addresses for the attackers. Other components skimmed payment cards, stole cookies and screenshots, and, on iPhones and iPads, delivered iOS exploit kits known as Coruna and DarkSword.

当恶意软件成功安装后，它们会将用户的加密货币钱包地址替换为攻击者的地址。其他组件则会窃取支付卡信息、Cookie 和屏幕截图，并在 iPhone 和 iPad 上分发名为 Coruna 和 DarkSword 的 iOS 漏洞利用工具包。

Optimizely serves JavaScript “snippets” that include both company code and code that is provided by each customer. The JavaScript, which can be served directly from Optimizely or from a customer endpoint, runs on every page the customer serves. Somehow, the attackers wrote their own code into a portion of each affected customer’s JavaScript and then delivered it from cdn.optimizely.com. A valid certificate for that domain signed the JavaScript.

Optimizely 提供包含公司代码和每个客户提供的代码的 JavaScript“片段”。这些 JavaScript 可以直接从 Optimizely 或客户终端提供，并在客户提供的每个页面上运行。攻击者以某种方式将他们自己的代码写入了每个受影响客户的 JavaScript 部分，然后通过 cdn.optimizely.com 进行分发。该域名的有效证书对这些 JavaScript 进行了签名。

ReportURI researcher Scott Helme said the delivery mechanism wasn’t a CDN cache poisoning attack, which uses HTTP to cause a CDN to cache harmful responses. Instead, the attack relied on Optimizely’s legitimate infrastructure, including its domains, to serve the tainted code. Optimizely’s own customer JavaScript for the www.optimizely.com and login.optimizely.com URLs were also affected.

ReportURI 研究员 Scott Helme 表示，这种分发机制并非 CDN 缓存中毒攻击（即利用 HTTP 导致 CDN 缓存有害响应）。相反，此次攻击依赖于 Optimizely 的合法基础设施（包括其域名）来分发受污染的代码。Optimizely 用于 www.optimizely.com 和 login.optimizely.com 网址的客户 JavaScript 也受到了影响。

“We don’t know how the attacker got write access to so many unrelated customer projects: a compromised Optimizely system, a compromised credential with cross-customer access, or something else,” ReportURI Helme wrote. “That’s for Optimizely to explain.” Optimizely representatives didn’t respond to questions sent by email.

“我们不知道攻击者是如何获得这么多互不相关的客户项目的写入权限的：是 Optimizely 系统被入侵、具有跨客户访问权限的凭据被泄露，还是其他原因，” ReportURI 的 Helme 写道。“这需要 Optimizely 来解释。” Optimizely 的代表没有回复通过电子邮件发送的问题。

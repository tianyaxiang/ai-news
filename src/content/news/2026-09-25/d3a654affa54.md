### I'm building a credit score for code health — starting with vibe coders
### 我正在为代码健康度建立一套“信用评分”系统——从“感觉派”程序员开始

The fastest-growing codebase in the world right now is code nobody fully read. AI writes it, humans ship it, users depend on it. I think "did the AI write good code?" is about to become a real question teams ask.
目前世界上增长最快的代码库，是那些没人完全读过的代码。AI 编写它们，人类发布它们，用户依赖它们。我认为，“AI 写的代码质量好吗？”即将成为团队必须面对的一个现实问题。

Code Sonar is my answer: deterministic scoring (same repo, same score, every time — no vibes in the scoring), 8 checks, results in seconds, findings written for humans. Free scans coming while I build in public.
Code Sonar 是我的解决方案：确定性评分（同一个代码库，每次得分都相同——评分过程不靠“感觉”），包含 8 项检查，秒级出结果，且分析报告是为人阅读而编写的。在我公开构建的过程中，将提供免费扫描服务。

If you've shipped AI-written code, I'd genuinely like to know what score it gets — and whether you trust the number. (I built this.)
如果你发布过 AI 编写的代码，我真心想知道它能得多少分，以及你是否信任这个分数。（这是我开发的工具。）

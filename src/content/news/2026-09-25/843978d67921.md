# F-Droid gets its biggest update in a decade with new UI and smoother app installs
# F-Droid 迎来十年来最大更新：全新 UI 与更流畅的应用安装体验

Virtually every Android device comes with the Play Store preloaded, but there are other ways to get apps. F-Droid bills itself as a community-driven source for free and open source Android apps, but its official app store has gone 10 years without a major update. That’s finally changing: After a multiyear effort, the team has just announced F-Droid 2.0 is rolling out.

几乎每一台 Android 设备都预装了 Google Play 商店，但获取应用还有其他途径。F-Droid 自诩为一个由社区驱动的免费开源 Android 应用源，但其官方应用商店已经有 10 年没有进行过重大更新了。这种情况终于发生了改变：经过多年的努力，开发团队刚刚宣布 F-Droid 2.0 正在逐步推送。

The new F-Droid client was redesigned from scratch in Kotlin Compose, which is the standard for modern Android apps. This makes the store much more responsive, and there’s optional support for Android’s Material theming. The interface has also been cleaned up considerably, making the most important functions easier to access and hiding some others in overflow menus.

全新的 F-Droid 客户端使用现代 Android 应用的标准开发框架 Kotlin Compose 从零重构。这使得商店的响应速度大幅提升，并可选支持 Android 的 Material Design 主题。界面也经过了大幅精简，让核心功能更易于访问，同时将一些次要功能隐藏在溢出菜单中。

While the new F-Droid looks nicer, the update was largely about making it easier to find and install apps. When F-Droid first appeared, there wasn’t much to see, but now it has thousands of open source apps. Unlike the Play Store, F-Droid doesn’t track your taps and installs to push ads and suggestions—it helps you find things and gets out of the way.

虽然新版 F-Droid 看起来更美观，但此次更新的核心在于让查找和安装应用变得更加简单。F-Droid 刚问世时内容寥寥，而现在它已经拥有数千款开源应用。与 Play 商店不同，F-Droid 不会追踪你的点击和安装记录来推送广告或建议——它只专注于帮你找到所需内容，并保持简洁。

F-Droid now includes a huge number of categories, drilling down to specialized niches like firewalls, password managers, and VPNs. You can see all these groups in the search tab. There are also higher-level categories listed on the main Discover page. When searching for apps, F-Droid will now be able to return results based on app descriptions rather than just names.

F-Droid 现在包含了海量的分类，细化到了防火墙、密码管理器和 VPN 等专业领域。你可以在搜索标签页中查看所有这些分组。在主页的“发现”页面也列出了更高级别的分类。在搜索应用时，F-Droid 现在能够根据应用描述而非仅仅是名称来返回结果。

When you find an app, F-Droid 2.0 will make the installation process easier. Google has long put up roadblocks for sideloaded apps, citing the security implications. This is also the rationale behind its upcoming developer verification system. For now at least, apps will be easier to install from F-Droid thanks to the use of Google’s pre-approval API.

当你找到应用后，F-Droid 2.0 将简化安装流程。长期以来，Google 以安全为由为侧载应用设置了重重障碍，这也是其即将推出的开发者验证系统的背后逻辑。至少目前，得益于 Google 预批准 API 的使用，从 F-Droid 安装应用将变得更加容易。

Instead of downloading an APK, opening it, and confirming the scary sideloading pop-up, you’ll just be able to verify that you want to install an app before the download. So you tap “Install” in F-Droid, and then tap “Install” again in a system pop-up. That’s one more click than the Play Store, but it’s still an improvement.

你不再需要下载 APK 文件、打开它并确认那个令人不安的侧载弹窗，而是在下载前直接验证安装意图即可。你只需在 F-Droid 中点击“安装”，然后在系统弹窗中再次点击“安装”。虽然这比 Play 商店多了一次点击，但这依然是一个进步。

The team also says that F-Droid 2.0 will automatically check for and install app updates (unless you disable this). It can also download and install multiple apps simultaneously. Given the auto-updates, F-Droid no longer uses pull-to-refresh on the app screen, which the developers acknowledge may upset their particular user base. Manual updates are still available in the three-dot menu for peace of mind.

开发团队还表示，F-Droid 2.0 将自动检查并安装应用更新（除非你手动禁用此功能）。它还可以同时下载和安装多个应用。鉴于自动更新功能的加入，F-Droid 不再在应用界面使用“下拉刷新”，开发人员承认这可能会让部分用户感到不习惯。为了让用户放心，手动更新功能依然保留在三点菜单中。

The new F-Droid client is rolling out in stages over the next two weeks—the default installer on the F-Droid site hasn’t been replaced yet. If you want the 2.0 release right now, it’s available on the versions page. The official client is not the only way to access F-Droid apps, but now you’ll have less reason to seek out an alternative.

全新的 F-Droid 客户端将在未来两周内分阶段推送——F-Droid 官网上的默认安装包尚未替换。如果你现在就想体验 2.0 版本，可以在版本页面下载。官方客户端并非访问 F-Droid 应用的唯一方式，但现在你已经没有太多理由去寻找替代品了。

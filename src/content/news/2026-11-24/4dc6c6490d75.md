# OpenAI and Cisco introduce Shirudo

OpenAI 和 Cisco 共同推出了 Shirudo，这是一个开源运行时环境，旨在帮助团队在部署补丁的同时保护 Linux 系统。在一项受控测试中，由 Codex 生成的防护盾在无需重启的情况下，成功拦截了一次针对正在运行的 Elasticsearch 服务的 Java4Shell 漏洞利用尝试。

We’re inviting developers, security researchers, and infrastructure operators across the industry to help develop the project further. The project brings together OpenAI’s frontier AI, security and infrastructure research and Cisco’s infrastructure and security expertise to help protect the systems people rely on every day.

我们诚邀行业内的开发人员、安全研究人员和基础设施运维人员共同推动该项目的发展。该项目汇集了 OpenAI 在前沿人工智能、安全和基础设施领域的研究成果，以及 Cisco 在基础设施和安全方面的专业知识，旨在帮助保护人们日常依赖的系统。

Testing and deploying a patch can still take days or weeks. Protecting a service in the meantime can be challenging because an exploit and a legitimate request may rely on the same Linux operation. Blocking that operation entirely could take the service offline.

测试和部署补丁往往需要数天甚至数周的时间。在此期间保护服务极具挑战性，因为漏洞利用请求和合法请求可能依赖于相同的 Linux 操作。如果完全封锁该操作，可能会导致服务中断。

Shirudo (Japanese for “shield”) is designed to help security teams navigate this tradeoff. Teams can test whether a temporary safeguard, called a shield, blocks the behavior that exposes a vulnerability while allowing legitimate requests through. Once an operator approves the shield, it can be deployed while the service continues running.

Shirudo（日语意为“盾牌”）旨在帮助安全团队平衡这一矛盾。团队可以测试一种称为“防护盾”的临时保护措施，验证其在拦截暴露漏洞的行为的同时，是否允许合法请求通过。一旦运维人员批准该防护盾，它便可在服务持续运行的同时进行部署。

“We’re giving defenders better models and tools to find and fix vulnerabilities faster, but finding a bug today doesn’t mean you can patch every system tomorrow. We are partnering closely with Cisco on Shirudo to help teams protect the systems they need to keep running while they build and roll out a fix. So many teams rely on the same software that it makes sense to build these tools in the open. Now when one team finds a better way to protect a system, others don’t have to start from scratch.” — Greg Brockman, President and Co-founder of OpenAI

“我们正在为防御者提供更好的模型和工具，以更快地发现和修复漏洞，但今天发现漏洞并不意味着明天就能修补所有系统。我们正与 Cisco 在 Shirudo 项目上紧密合作，帮助团队在构建和发布修复程序的同时，保护那些必须保持运行的系统。由于许多团队依赖相同的软件，以开源方式构建这些工具非常有意义。现在，当一个团队找到更好的系统保护方法时，其他团队就不必从零开始了。”—— Greg Brockman，OpenAI 总裁兼联合创始人

How Shirudo works: Shirudo uses eBPF, a Linux technology that allows small programs to run at specific points inside the operating system. This makes it possible to observe suspicious activity and apply targeted security protections to running systems.

Shirudo 的工作原理：Shirudo 使用了 eBPF 技术，这是一种允许小型程序在操作系统内部特定位置运行的 Linux 技术。这使得观察可疑活动并对正在运行的系统实施针对性的安全保护成为可能。

OpenAI and Cisco are designing Shirudo around four core capabilities: Live protection, Defense at machine speed, Trusted deployment, and Hardware-backed verification.

OpenAI 和 Cisco 围绕四项核心能力设计了 Shirudo：实时保护、机器速度防御、可信部署以及硬件支持的验证。

The Shirudo technical walkthrough from the Linux Plumbers Conference shows how to apply a shield and verify it on the target host. The Java4Shell vulnerability is another example illustrating how a targeted shield can protect a running application while a permanent patch is being prepared.

Linux Plumbers Conference 上的 Shirudo 技术演示展示了如何在目标主机上应用防护盾并进行验证。Java4Shell 漏洞是另一个示例，说明了在准备永久补丁的同时，针对性的防护盾如何保护正在运行的应用程序。

Rethinking infrastructure: Shirudo is a first step toward infrastructure that can adapt to emerging threats while remaining reliable. We want to strengthen the operating system foundations needed to deploy these protections at scale, including hardening the kernel and core services, limiting workload permissions, and making updates and recovery safer.

重新思考基础设施：Shirudo 是迈向能够适应新兴威胁且保持可靠性的基础设施的第一步。我们希望加强大规模部署这些保护措施所需的操作系统基础，包括加固内核和核心服务、限制工作负载权限，并使更新和恢复过程更加安全。

Building in the open: OpenAI and Cisco are open-sourcing Shirudo so developers, security researchers, and infrastructure operators can inspect the code, test protections, and contribute to its development. Shirudo is licensed under BSD 2-Clause, with its BPF programs dual-licensed under BSD and GPL.

以开源方式构建：OpenAI 和 Cisco 将 Shirudo 开源，以便开发人员、安全研究人员和基础设施运维人员能够检查代码、测试保护措施并为其开发做出贡献。Shirudo 采用 BSD 2-Clause 许可协议，其 BPF 程序采用 BSD 和 GPL 双重许可。

# What VP != VNP Means (In 3 Minutes)

I assume you know about the P vs. NP problem. But what is this wacky thing Anthropic just posted? You learned how to take a determinant in your linear algebra class: det(123456789)=1⋅(5⋅9-6⋅8)-2⋅(4⋅9-6⋅7)+3⋅(4⋅8-5⋅7)=0 The naive way is fine for 3×3 matrices, but notice that you need to perform Θ(n!) arithmetic operations here. Exercise for the reader is to find the exact number of operations (hint: start with a recurrence relation).

我想你应该了解 P 与 NP 问题。但 Anthropic 最近发布的这个古怪的东西是什么呢？你在线性代数课上学过如何计算行列式：det(123456789)=1⋅(5⋅9-6⋅8)-2⋅(4⋅9-6⋅7)+3⋅(4⋅8-5⋅7)=0。对于 3×3 的矩阵，朴素的方法是可以的，但请注意，这里需要执行 Θ(n!) 次算术运算。留给读者的练习是找出确切的运算次数（提示：从递推关系开始）。

Luckily, if you paid attention, you will remember there are faster ways to do this for big n×n matrices, like Gaussian elimination. If we stick only to adding and multiplying, we can still find a determinant in polynomial time (there are better ways, but this is an old, readable method). A related problem to the determinant is finding the permanent. It’s like a determinant without any subtraction: perm(123456789)=1⋅(5⋅9+6⋅8)+2⋅(4⋅9+6⋅7)+3⋅(4⋅8+5⋅7)=450

幸运的是，如果你当时有认真听讲，你会记得对于大型 n×n 矩阵，有更快的计算方法，比如高斯消元法。如果我们只使用加法和乘法，仍然可以在多项式时间内求出行列式（虽然有更好的方法，但这是一种古老且易读的方法）。与行列式相关的一个问题是计算积和式（permanent）。它就像是没有减法的行列式：perm(123456789)=1⋅(5⋅9+6⋅8)+2⋅(4⋅9+6⋅7)+3⋅(4⋅8+5⋅7)=450

Unlike determinants, there is no known way to compute permanents in polynomial time. Since finding the permanent of a matrix of 0s and 1s is NP-hard (and in fact #P-complete), it would be pretty important if there were a way. This means that for P to equal NP, there must be some trick to computing permanents using AND/OR/NOT on the bits of the input that is better than addition and multiplication. There are many problems where access to Boolean operators is helpful, but it isn’t clear how they would help with the permanent. If you think of a way, go claim your $1 million.

这意味着，如果 P 要等于 NP，就必须存在某种技巧，通过对输入位使用与/或/非（AND/OR/NOT）运算来计算积和式，且这种方法要优于加法和乘法。在许多问题中，使用布尔运算符是有帮助的，但目前尚不清楚它们如何能帮助计算积和式。如果你想到了办法，去领取你的 100 万美元奖金吧。

Title: What Helps Language-Model Agents Review Violent Video? A Controlled Comparison with a Human Evidence Reference

标题：什么有助于语言模型智能体审查暴力视频？与人类证据参考的对照比较

Systems that flag violent video for a human operator can now be built from language models without training, by combining perception models and letting a language model decide. We ask how the observations of the perception models should reach the decision, and which evidence matters.

现在，无需训练即可利用语言模型构建为人类操作员标记暴力视频的系统，方法是结合感知模型并让语言模型进行决策。我们探讨了感知模型的观察结果应如何得出决策，以及哪些证据至关重要。

On the XD-Violence test set (799 clips) we fix one set of perception agents (video description, object detection, sound tagging, speech recognition and speech tagging) and one reasoning model, and compare three interfaces: messages between agents, a typed evidence graph explored with tools, and flat text read in one pass; and a single audio-visual model given the raw clip.

在 XD-Violence 测试集（799 个片段）上，我们固定了一组感知智能体（视频描述、目标检测、声音标记、语音识别和语音标记）以及一个推理模型，并比较了三种接口：智能体之间的消息传递、通过工具探索的类型化证据图、一次性读取的平面文本；以及给定原始片段的单一视听模型。

Two annotators provide a human reference that records the decision, the incident segments and whether they relied on sight, sound or speech. Flat text matches the single model (F1 0.967 against 0.968), while the graph agent and message passing are less accurate; a variant of the graph agent developed on a separate set did not close the gap, and both graph summaries and multi-turn tool use lowered accuracy.

两名标注员提供了人类参考数据，记录了决策、事件片段以及他们是依赖视觉、听觉还是语音。平面文本的表现与单一模型相当（F1 分数分别为 0.967 和 0.968），而图智能体和消息传递的准确性较低；在独立数据集上开发的图智能体变体并未缩小这一差距，且图摘要和多轮工具使用都降低了准确性。

These results hold with reworded prompts and with a larger reasoning model, except that the larger model weakens message passing enough for the graph agent to beat it. Sound events improve F1 by +0.012 [+0.004, +0.021], in line with the annotators, who used sound or speech on most violent clips.

这些结果在重写提示词和使用更大的推理模型时依然成立，唯一的例外是更大的模型削弱了消息传递的效果，使得图智能体能够胜出。声音事件将 F1 分数提高了 +0.012 [+0.004, +0.021]，这与标注员的情况一致，他们在大多数暴力片段中都使用了声音或语音信息。

Citations of stored observations are faithful, changing about half of the decisions when removed, but no more so with the graph than with flat text, and the agent pipeline costs about 3 times the GPU time of the single model. We also report two artefacts of vision-language describers that mislead pipelines built on them.

对存储观察结果的引用是忠实的，移除这些引用会改变约一半的决策，但图方法在这方面的表现并不比平面文本更好，且智能体流水线的 GPU 耗时约为单一模型的 3 倍。我们还报告了视觉-语言描述器的两个伪影，它们会误导基于其构建的流水线。

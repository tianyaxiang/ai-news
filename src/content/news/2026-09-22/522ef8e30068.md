# MemeTAG: Keyword-Driven Meme Classification through Tag Embedding Reconstruction
# MemeTAG：基于标签嵌入重构的关键词驱动模因分类

The proliferation of harmful internet memes poses a significant societal threat, yet their automated classification remains a formidable algorithmic challenge due to the nuanced, multimodal nature of their content.

有害互联网模因的激增对社会构成了重大威胁，然而由于其内容具有微妙的多模态特性，对其进行自动分类仍然是一项艰巨的算法挑战。

To address this, we introduce MemeTAG, a novel dual-objective framework that pioneers a keyword-aware approach to meme classification. Our core innovation is a two-part semantic guidance mechanism: first, we leverage a pretrained Vision-Language Model to generate a set of descriptive keywords, that capture the high-level semantics.

为了解决这一问题，我们引入了 MemeTAG，这是一个新颖的双目标框架，开创了模因分类的关键词感知方法。我们的核心创新在于一个两部分的语义引导机制：首先，我们利用预训练的视觉-语言模型生成一组描述性关键词，以捕捉高层语义。

Second, we introduce the Aggregated Tag Inference Network (ATIN), an attention-based module that distills these keywords into a single, rich semantic embedding. This embedding serves as a target for a novel auxiliary reconstruction loss, which compels the model to learn deeply aligned visual and textual features.

其次，我们引入了聚合标签推理网络（ATIN），这是一个基于注意力机制的模块，将这些关键词提炼为单一且丰富的语义嵌入。该嵌入作为一种新颖辅助重构损失的目标，迫使模型学习深度对齐的视觉和文本特征。

This approach, combined with an efficient three-stage training strategy, establishes a new state-of-the-art on the HarMeme, Hateful Memes Challenge (HMC), and PrideMM datasets, decisively outperforming existing state-of-the-art methods.

这种方法结合高效的三阶段训练策略，在 HarMeme、Hateful Memes Challenge (HMC) 和 PrideMM 数据集上确立了新的行业领先水平（SOTA），显著优于现有的顶尖方法。

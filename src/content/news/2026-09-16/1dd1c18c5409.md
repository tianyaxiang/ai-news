# BudgetBench: A Budget-Tiered Protocol and Pilot Harness for Memory Strategy Evaluation in Local Large Language Model Agents

**BudgetBench：用于本地大语言模型智能体内存策略评估的预算分级协议与试点工具**

---

**Abstract:** For local large language model agents, active context is a scarce resource: memory capacity, prefill latency, cache growth, and service objectives all constrain how many input tokens each call can afford. 

**摘要：** 对于本地大语言模型智能体而言，活跃上下文是一种稀缺资源：内存容量、预填充延迟、缓存增长以及服务目标，都限制了每次调用所能负担的输入 Token 数量。

We present BudgetBench, an active-budget protocol and reference harness that treats the per-call input-token budget as the independent variable when comparing memory strategies. Holding the model, task, sampler, and decoding fixed, it sweeps budgets over 2K, 4K, 8K, 16K, and 32K tokens and records quality, budget utilization, latency, and, as a first-class outcome, budget-violation rates. 

我们提出了 BudgetBench，这是一个主动预算协议及参考工具，在比较内存策略时，将单次调用的输入 Token 预算作为自变量。在保持模型、任务、采样器和解码方式不变的情况下，它对 2K、4K、8K、16K 和 32K Token 的预算范围进行扫描，并记录质量、预算利用率、延迟，以及作为核心指标的预算违规率。

The core contribution is this reusable measurement surface: a swappable MemoryStrategy contract, explicit budget enforcement, deterministic or versioned graders, prompt-audit metadata, and reproducibility artifacts, released at this https URL. 

其核心贡献在于这一可复用的测量平台：包含可替换的 MemoryStrategy（内存策略）契约、明确的预算执行机制、确定性或版本化的评分器、提示词审计元数据以及可复现性工件，均已在指定网址发布。

We substantiate the protocol with pilot studies rather than final rankings. Across a local qwen2.5:1.5b pilot (89 items each on SWE-bench Verified and LongBench v2), a hosted 50-item Qwen3 30B-A3B LongBench replication with exact tokenization, and a 500-item LongMemEval oracle study scored by the official GPT-4o evaluator, the harness exposes budget-compliance failures, non-monotonic quality curves, and operating points that single-budget evaluation hides. 

我们通过试点研究而非最终排名来验证该协议。通过本地 qwen2.5:1.5b 试点（在 SWE-bench Verified 和 LongBench v2 上各 89 项）、托管的 50 项 Qwen3 30B-A3B LongBench 精确分词复现，以及由官方 GPT-4o 评估器评分的 500 项 LongMemEval 预言机研究，该工具揭示了单一预算评估所掩盖的预算合规性失败、非单调质量曲线以及特定运行点。

The budgeted-versus-full-context direction remains unresolved: the local slice is near-null and the hosted replication favors full context in point estimate. We report results transparently, including that the early pilot's tokenizer approximation undercounts some served-model prompts, so its violation rows are tokenizer-approximation diagnostics, not claim-bearing results; all timings are operational diagnostics. 

关于“预算限制与全上下文”的对比方向仍未有定论：本地切片结果接近于零，而托管复现的点估计则倾向于全上下文。我们透明地报告了结果，包括早期试点中的分词器近似计算低估了部分服务模型提示词的情况，因此其违规行仅作为分词器近似的诊断参考，而非结论性结果；所有时间数据均为操作诊断指标。

The reusable contribution is the protocol, harness, and failure-reporting discipline needed to scale fixed-budget memory-strategy evaluation.

该研究的可复用贡献在于为扩展固定预算内存策略评估所需的协议、工具以及故障报告规范。

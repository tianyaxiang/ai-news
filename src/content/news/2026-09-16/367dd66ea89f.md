# Synthetic Leprosy Image Generation Using Mask-Conditioned Latent Diffusion and Transfer Learning from Large Chronic Wound Datasets
# 利用掩码条件潜在扩散模型与大型慢性伤口数据集迁移学习生成麻风病合成图像

**Abstract:** Machine learning for neglected tropical diseases is limited by data, not algorithms: public annotated image sets for leprosy (Hansen's disease) number in the hundreds, orders of magnitude below what generative models require. We ask whether a model trained on abundant chronic wound photography transfers to this low-data regime.

**摘要：** 被忽视的热带疾病的机器学习研究受限于数据而非算法：公开的麻风病（汉森病）标注图像集仅有数百张，比生成模型所需的数据量低了几个数量级。我们探讨了在海量慢性伤口摄影图像上训练的模型是否能迁移到这种低数据场景中。

We build a three-stage pipeline. First, a DeepLabV3-ResNet50 segmentation network (validation Dice 0.876, IoU 0.799) supplies lesion masks for two wound datasets that ship without them. Second, we assemble a mask-conditioned latent diffusion model from Stable Diffusion 1.5 components and train it on 3,280 region-of-interest wound crops, widening the UNet input convolution from 4 to 11 channels to admit three mask feature maps and a blurred low-frequency context latent.

我们构建了一个三阶段流水线。首先，利用 DeepLabV3-ResNet50 分割网络（验证集 Dice 系数为 0.876，IoU 为 0.799）为两个原本缺乏掩码的伤口数据集提供病灶掩码。其次，我们利用 Stable Diffusion 1.5 的组件组装了一个掩码条件潜在扩散模型，并在 3,280 个感兴趣区域（ROI）的伤口裁剪图上进行训练，将 UNet 输入卷积从 4 通道扩展至 11 通道，以容纳三个掩码特征图和一个模糊的低频上下文潜在变量。

Third, we fine-tune this model on 708 leprosy image-mask pairs drawn from 764 images of approximately 150 patients. We evaluate with LPIPS perceptual distance, anchored by a real-versus-real baseline computed on the same 242 anchor images as the cross-set comparisons; without that reference the cross-set distances cannot be interpreted.

第三，我们在来自约 150 名患者的 764 张图像中提取的 708 对麻风病图像-掩码对上对该模型进行了微调。我们使用 LPIPS 感知距离进行评估，并以与跨数据集比较相同的 242 张锚点图像计算出的“真实对真实”基准作为参照；若无此参照，跨数据集的距离将无法解读。

The generated set shows no mode collapse: its internal perceptual diversity (0.662) is statistically indistinguishable from that of the real leprosy set (0.672, 95% CI [0.664, 0.680]). Generated images sit 0.044 LPIPS outside the real distribution - measurably apart, but under half of one standard deviation. Fine-tuning shifted the output distribution only marginally, which we trace to lesion geometry reaching the network through input concatenation alone.

生成的图像集未出现模式崩溃：其内部感知多样性（0.662）在统计学上与真实的麻风病图像集（0.672，95% 置信区间 [0.664, 0.680]）无显著差异。生成的图像在 LPIPS 指标上偏离真实分布 0.044——虽然存在可测量的差距，但不到一个标准差的一半。微调仅轻微改变了输出分布，我们将其归因于病灶几何形状仅通过输入拼接的方式传递给网络。

Chronic wound photography is therefore a viable donor domain for leprosy lesion synthesis: low-level appearance transfers well, and the remaining barrier is semantic control rather than image quality.

因此，慢性伤口摄影是麻风病病灶合成的一个可行的供体领域：低级外观特征迁移效果良好，目前剩余的障碍在于语义控制而非图像质量。

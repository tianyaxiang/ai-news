# Evaluating LLM-Generated Rules for Heart Disease Prediction
## 评估用于心脏病预测的大语言模型生成规则

**Abstract:** This study compares traditional machine learning models and Large Language Model (LLM)-generated rule-based systems for heart disease prediction using the UCI Heart Disease dataset. Several classifiers, including Logistic Regression, K-Nearest Neighbors (KNN), Support Vector Machine (SVM), Naive Bayes, Decision Tree, and Random Forest, were evaluated alongside rule-based systems generated using GPT-4o and Claude Sonnet 4.6.

**摘要：** 本研究利用 UCI 心脏病数据集，对比了传统机器学习模型与大语言模型（LLM）生成的基于规则的系统在心脏病预测方面的表现。研究评估了多种分类器，包括逻辑回归、K-近邻（KNN）、支持向量机（SVM）、朴素贝叶斯、决策树和随机森林，并将其与使用 GPT-4o 和 Claude Sonnet 4.6 生成的规则系统进行了比较。

Model performance was assessed using accuracy, precision, recall, and F1-score metrics. Experimental results show that traditional machine learning models consistently outperform LLM-generated rule-based systems in predictive performance. Random Forest achieved the best overall performance with 90.2% accuracy, a precision of 0.829, perfect recall of 1.0, and an F1-score of 0.906. Naive Bayes followed closely with 88.5% accuracy and an F1-score of 0.881.

模型性能通过准确率、精确率、召回率和 F1 分数等指标进行评估。实验结果表明，在预测性能方面，传统机器学习模型始终优于 LLM 生成的规则系统。其中，随机森林模型表现最佳，准确率达到 90.2%，精确率为 0.829，召回率为完美的 1.0，F1 分数为 0.906。朴素贝叶斯紧随其后，准确率为 88.5%，F1 分数为 0.881。

In contrast, the LLM-generated rule models achieved lower performance, with Claude Sonnet 4.6 reaching 80.3% accuracy (F1-score: 0.833) and GPT-4o obtaining 70.5% accuracy (F1-score: 0.690). Despite the performance gap, the LLM-generated rules provide interpretable IF-THEN diagnostic logic that enhances explainability and transparency in clinical decision-making. These findings highlight the trade-off between predictive performance and interpretability in medical artificial intelligence systems.

相比之下，LLM 生成的规则模型表现较低，Claude Sonnet 4.6 的准确率为 80.3%（F1 分数：0.833），GPT-4o 的准确率为 70.5%（F1 分数：0.690）。尽管存在性能差距，但 LLM 生成的规则提供了可解释的“如果-那么”（IF-THEN）诊断逻辑，增强了临床决策过程中的可解释性和透明度。这些发现凸显了医疗人工智能系统中预测性能与可解释性之间的权衡。

Quickstart Option A — install as a Claude Code plugin (recommended). 快速入门选项 A——作为 Claude Code 插件安装（推荐）。在 Claude Code 内部运行：`/plugin marketplace add elementalsouls/Claude-BugHunter` 和 `/plugin install claude-bughunter@elementalsouls`。所有 83 项技能和 15 条命令将加载在 `claude-bughunter:` 命名空间下，并在插件版本更新时自动更新，无需将文件复制到 `~/.claude/` 目录中。

Option B — copy install (no plugin system / pin to a clone): git clone https://github.com/elementalsouls/Claude-BugHunter.git cd Claude-BugHunter # macOS / Linux bash scripts/install.sh # Windows (PowerShell) pwsh ./scripts/install.ps1 Both copy the skills + commands into ~/.claude/ (macOS/Linux) or %USERPROFILE%\.claude\ (Windows) and wire the hunt engagement scaffolder.

选项 B——复制安装（无需插件系统/固定克隆版本）：执行 `git clone https://github.com/elementalsouls/Claude-BugHunter.git`，进入目录后，macOS/Linux 运行 `bash scripts/install.sh`，Windows 运行 `pwsh ./scripts/install.ps1`。这两种方式都会将技能和命令复制到 `~/.claude/`（macOS/Linux）或 `%USERPROFILE%\.claude\`（Windows）目录中，并配置狩猎参与脚手架。

Scope — what this bundle is for, and what it isn't This bundle covers the external attack surface — anything reachable from the internet without first compromising an internal endpoint. In scope Bug bounty hunting — web apps, APIs, SaaS, GraphQL, OAuth, JWT, file upload, IDOR, SSRF, RCE chains Web application pentesting — full hunt-* coverage of OWASP-mapped bug classes + discipline rules External red-team engagements — initial-access against internet-facing enterprise estate: M365 / Entra ID, Okta-as-IdP, SharePoint on-prem (ToolShell + legacy SOAP), VMware vCenter / Workspace ONE, SSL VPN appliances (Cisco / Fortinet / Citrix / Palo Alto / Pulse / SonicWall / F5), Android APK red-team, supply-chain recon Cloud misconfig + post-credential escalation — public S3, IMDS chains, STS AssumeRole, cross-account confused-deputy Recon + OSINT — subdomain enum, identity-fabric mapping, certificate transparency, JS analysis, secret scanning Reporting — H1, Bugcrowd (VRT-aware)

范围——此工具包的用途及非用途。此工具包涵盖外部攻击面，即无需先攻破内部端点即可从互联网访问的任何内容。范围包括：漏洞赏金狩猎（Web 应用、API、SaaS、GraphQL、OAuth、JWT、文件上传、IDOR、SSRF、RCE 链）、Web 应用渗透测试（涵盖 OWASP 映射的漏洞类别及准则）、外部红队演练（针对面向互联网的企业资产进行初始访问：M365/Entra ID、Okta-as-IdP、本地 SharePoint、VMware vCenter/Workspace ONE、SSL VPN 设备、Android APK 红队、供应链侦察）、云配置错误及凭据获取后的提权（公共 S3、IMDS 链、STS AssumeRole、跨账户混淆代理）、侦察与 OSINT（子域名枚举、身份架构映射、证书透明度、JS 分析、密钥扫描）、报告（H1、Bugcrowd，支持 VRT）。

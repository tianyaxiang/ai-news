### Sector Heat Rolling Window Comparison: Unit-Testing AI Theme Heat from 1h to 3d

一个与人工智能相关的概念在“一小时热度榜”上排名第二，在“三天热度榜”上排名第十一。这究竟是突然爆发，还是主题正在降温？通常两者都不是。这只是两个衡量不同事物的滚动窗口，只有当有人在未核实比较有效性的情况下进行对比时，这种差距才会变成一个“故事”。本文将板块热度滚动窗口的比较视为待测试的代码。我们不再使用阅读清单，而是编写断言：一个用于提取单个主题所有窗口数据的捕获函数，一组在描述结果前必须通过的检查，以及一套用于描述结果形态的术语。示例使用了 Lava 的概念热度榜，所有数字仅供说明。

#### The Data: Concept Heat Board Windows
数据：概念热度榜窗口

入口点是 `GET /hot/concepts`，通过 MCP 工具 `get_market_hot_concepts` 暴露给代理。

| 参数/字段 | 含义 | 默认值 | 注释 |
| :--- | :--- | :--- | :--- |
| window | 1h, 4h, 18h, 24h, 3d | 24h | 概念无 7d 选项 |
| min_score | 仅统计机构/KOL 评分至少达到此值的提及次数 | unset | 分数约 450–1500；~1000 为中位数，1050 约为前 10% |
| limit | 1–200 | 50 | 无 |
| offset | 概念在窗口内被提及的次数 | - | 概念级计数 |
| agencies | 提及该概念的不同机构/KOL 数量 | - | 按匿名 agency_id 去重 |
| heat_chg_1d, heat_chg_3d, heat_z20 | 统计数据 | - | OpenAPI 中有精确公式 |

跨窗口工作时，有三个属性至关重要：窗口从 `meta.server_time` 开始回溯。1h 是过去一小时，3d 是过去 72 小时。短窗口对单条长贴或集中爆发更为敏感。最长的概念窗口为 3d。对于周度或更长周期的视图，请切换到类型为 `concept` 的日度面板 `/panel/daily`。过于通用的术语在排名之前会被移除。榜单上的名称是规范化的，可传递给下钻端点。被移除的通用术语不会出现在任何窗口中，因此跨窗口的差距绝不会由它们“解释”。榜单每 2 分钟刷新一次。概念成员排名 `/concepts/stocks` 每 10 分钟刷新一次。仅此时间差就解释了许多“数字对不上”的报告。

#### Step 1: Capture All Windows in One Round
第一步：单轮捕获所有窗口

```python
# ai_theme_windows.py - 仅供说明；基础 URL 和令牌为占位符
import os, requests
BASE = os.environ.get("LAVA_BASE", "<YOUR_LAVA_BASE>/subscribe/v1")
HEADERS = {"Authorization": "Bearer " + os.environ.get("LAVA_API_KEY", "<YOUR_TOKEN>")}
WINDOWS = ("1h", "4h", "18h", "24h", "3d")
TARGET = "<从榜单复制的规范概念名称>"

def capture(target, min_score=None, limit=200):
    snap = {}
    for w in WINDOWS:
        params = {"window": w, "limit": limit}
        if min_score is not None:
            params["min_score"] = min_score
        resp = requests.get(BASE + "/hot/concepts", params=params, headers=HEADERS, timeout=60).json()
        assert resp["ok"], resp.get("code")
        data = resp["data"]
        rows = data if isinstance(data, list) else data.get("list", [])
        # 假设概念名称列为 "concept"；请在 OpenAPI 中确认
        hit = next(((i + 1, r) for i, r in enumerate(rows) if r.get("concept") == target), None)
        snap[w] = {
            "params": params,
            "server_time": resp["meta"]["server_time"],
            "request_id": resp["meta"]["request_id"],
            "rank": hit[0] if hit else None,
            "mentions": hit[1].get("mentions") if hit else None,
            "agencies": hit[1].get("agencies") if hit else None,
            "heat_z20": hit[1].get("heat_z20") if hit else None,
        }
    return snap

snap = capture(TARGET)
```

排名为 `None` 意味着“该窗口前 200 名内未出现”。请按此方式记录，切勿记为零。

#### Step 2: Assertions That Must Pass Before Interpretation
第二步：解读前必须通过的断言

```python
import pandas as pd
def check(snap):
    times = [pd.Timestamp(s["server_time"]) for s in snap.values()]
    assert max(times) - min(times) < pd.Timedelta(minutes=5), "来自不同轮次的窗口"
    scores = {s["params"].get("min_score") for s in snap.values()}
    assert len(scores) == 1, "各窗口 min_score 不一致"
    assert all(s["params"]["limit"] == 200 for s in snap.values()), "limit 太小"
    present = [w for w, s in snap.items() if s["rank"] is not None]
    assert present, "在任何窗口中均未找到目标 - 请检查名称是否精确"
    return True

check(snap)
```

每个断言的保护作用如下：同一轮次。混合不同轮次的捕获数据会将经过的时间变成虚假的窗口差异。此处的五分钟容差是本地选择，而非 API 规则。相同的 `min_score`。一个带阈值的窗口与一个不带阈值的窗口比较的是两个不同的人群来源。`limit=200`。在长窗口中，AI 主题可能会跌出默认的前 50 名并悄然消失。精确名称。手动输入的别名（如“AI”与较长的规范名称）会导致精确匹配失败。请从榜单复制字符串并将其用于 `/concepts/stocks`（概念，最多 30 个字符）。

#### Step 3: Describe the Shape with Counts, Not Ranks
第三步：用计数而非排名来描述形态

排名取决于榜单上的所有其他概念。`mentions`（提及次数）和 `agencies`（机构数量）属于概念本身，因此应据此计算形态：

```python
def shape(snap):
    m24 = snap["24h"]["mentions"] or 0
    share_1h = (snap["1h"]["mentions"] or 0) / m24 if m24 else None
    r1, r3 = snap["1h"]["rank"], snap["3d"]["rank"]
    if share_1h is not None and share_1h >= 0.15 and (r3 is None or (r1 and r1 < r3)):
        label = "short-window concentrated"
    elif r1 and r3 and abs(r1 - r3) <= 3:
        label = "multi-window aligned"
    elif r3 and (r1 is None or r3 < r1):
        label = "long-window accumulated"
    else:
        label = "mixed"
    return share_1h, label
```

0.15 和 3 的阈值仅供说明；请设置您自己的阈值。术语仅限于这些标签。它们描述的是形态，并不预测未来。此外，请比较机构数量与提及次数。短窗口提及次数高但机构数量少，意味着少数来源在大量发帖。当两者同时上升时，参与度实际上正在扩大。`heat_z20` 是窗口特定的。请务必写成“24h heat_z20”，切勿对不同窗口的 Z 分数取平均值，因为它们来自不同的区间。

# ggml-org / ggml

ggml Tensor library for machine learning Quick start Build from source: git clone https://github.com/ggml-org/ggml cd ggml mkdir build && cd build cmake .. cmake --build . --config Release -j 8 For a minimal, fully commented example (matrix multiplication), see examples/simple.

ggml 是一个用于机器学习的张量库。快速入门：从源码构建：git clone https://github.com/ggml-org/ggml cd ggml mkdir build && cd build cmake .. cmake --build . --config Release -j 8。有关一个带有完整注释的最小示例（矩阵乘法），请参阅 examples/simple。

Description The main goal of ggml is to be a simple, portable, and efficient tensor library for machine learning with minimal setup. Plain C/C++ implementation without any dependencies Cross-platform - x86, ARM, RISC-V, LoongArch, PowerPC, s390x, and WebAssembly SIMD-optimized kernels for x86, ARM, and RISC-V Broad backend support - CPU, GPU, NPU, and browser 2- to 8-bit integer quantization, plus MXFP4 and NVFP4 microscaling formats Zero memory allocations during runtime

描述：ggml 的主要目标是成为一个简单、可移植且高效的机器学习张量库，且只需极少的设置。纯 C/C++ 实现，无任何依赖；跨平台支持 - x86、ARM、RISC-V、LoongArch、PowerPC、s390x 和 WebAssembly；针对 x86、ARM 和 RISC-V 的 SIMD 优化内核；广泛的后端支持 - CPU、GPU、NPU 和浏览器；支持 2 到 8 位整数量化，以及 MXFP4 和 NVFP4 微缩放格式；运行时零内存分配。

文档：GGUF 文件格式、ggml 简介、GGML 技巧与窍门。贡献：对于核心 ggml 库的更改（包括对 CMake 构建系统的更改），请在 llama.cpp 中提交 PR——这样做将使您的 PR 更具可见性、经过更好的测试，并更有可能被审核。

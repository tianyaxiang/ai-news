# Securing the agentic enterprise with data lineage

SponsoredIn partnership withCyberhaven A sales representative asks an AI agent for customer pricing, and the agent pulls data from multiple sources: restricted pricing systems, internal communications, and archived quotes. The output looks accurate to the agent, so a second agent uses the data to draft the proposal for the sales rep. No human checks either handoff. When it’s discovered that the proposal includes unapproved, confidential, and sensitive information, no one can trace where the problematic data entered the workflow or how it spread across systems, files, and agents. This scenario illustrates why AI governance needs to evolve, rapidly and dynamically. As more enterprises begin to use agentic AI in daily workflows, they’re realizing that they must manage more than static files; they must manage moving and fragmented data that is continuously ingested, copied, summarized, transformed, reused, and redistributed in new forms. In short, AI security isn’t a tool problem; it’s a data visibility problem.

这种情况说明了为什么 AI 治理需要快速且动态地演进。随着越来越多的企业开始在日常工作流中使用智能体 AI，他们意识到自己必须管理的不仅仅是静态文件；他们必须管理不断被摄取、复制、汇总、转换、重用并以新形式重新分发的移动且碎片化的数据。简而言之，AI 安全不是一个工具问题，而是一个数据可见性问题。

Consequently, traditional security approaches built solely around applications, systems, networks, or endpoints are no longer sufficient. Securing agentic AI at scale requires understanding how data moves. Teams, therefore, need to establish data lineage in order to effectively manage governance, accountability, and trust across human, agentic, and hybrid workflows. Download the report

因此，仅围绕应用程序、系统、网络或端点构建的传统安全方法已不再足够。大规模保护智能体 AI 需要了解数据的移动方式。因此，团队需要建立数据血缘关系，以便在人类、智能体和混合工作流中有效地管理治理、问责制和信任。下载报告。

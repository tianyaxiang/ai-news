The Original Open-Source PR Reviewer This repository contains the open-source PR Agent Project. It is not the Qodo offering for open-source projects. PR-Agent is an open-source, AI-powered code review agent and a community-maintained legacy project of Qodo. It is distinct from Qodo's primary AI code review offering, which provides a feature-rich, context-aware experience. Qodo offers a free version for open-source projects and integrates seamlessly with GitHub, GitLab, Bitbucket, and Azure DevOps for high-quality automated reviews.

最初的开源 PR 审查器。此存储库包含开源 PR Agent 项目。它并非 Qodo 为开源项目提供的产品。PR-Agent 是一个由 AI 驱动的开源代码审查代理，也是 Qodo 社区维护的遗留项目。它与 Qodo 的主要 AI 代码审查产品不同，后者提供功能丰富且具备上下文感知能力的体验。Qodo 为开源项目提供免费版本，并与 GitHub、GitLab、Bitbucket 和 Azure DevOps 无缝集成，以实现高质量的自动化审查。

# Create an AI Podcast Generator with ElevenLabs

### 使用 ElevenLabs 创建 AI 播客生成器

Why an AI‑Powered Podcast? Podcasts have exploded in popularity, but producing a full episode still means spending hours on research, script‑writing, recording, and editing. What if you could automate the whole pipeline? By combining a large‑language model (LLM) for content generation with a state‑of‑the‑天才 text‑to‑speech (TTS) service, you can spin up a fully voiced episode in minutes.

为什么选择 AI 驱动的播客？播客的受欢迎程度呈爆炸式增长，但制作一期完整的节目仍然意味着需要花费数小时进行研究、撰写脚本、录音和剪辑。如果能将整个流程自动化会怎样？通过将用于内容生成的大语言模型 (LLM) 与最先进的文本转语音 (TTS) 服务相结合，你可以在几分钟内生成一期配音完整的节目。

In this guide we’ll build a simple AI Podcast Generator that: Takes a topic prompt, asks an LLM (e.g., OpenAI’s gpt‑4o) to write a short script. Sends each paragraph to ElevenLabs – a high‑quality TTS platform that supports voice cloning. Concatenates the audio files into a single MP3 ready for publishing. Everything is done with plain Python and a few command‑line tools, so you can drop it into a CI job, a serverless function, or your local dev environment.

在本指南中，我们将构建一个简单的 AI 播客生成器，它可以：接收主题提示，要求 LLM（例如 OpenAI 的 gpt-4o）编写简短脚本。将每个段落发送给 ElevenLabs——一个支持语音克隆的高质量 TTS 平台。将音频文件合并为可供发布的单个 MP3。所有操作均使用纯 Python 和几个命令行工具完成，因此你可以将其放入 CI 作业、无服务器函数或本地开发环境中。

### 1. Get Your API Keys

### 1. 获取你的 API 密钥

Save your keys as environment variables (never hard‑code them!):
`export OPENAI_API_KEY="sk-..."`
`export ELEVENLABS_API_KEY="your-elevenlabs-key"`
Both services use bearer tokens in the Authorization header, so keeping them in the environment is the safest approach.

将你的密钥保存为环境变量（切勿硬编码！）：
`export OPENAI_API_KEY="sk-..."`
`export ELEVENLABS_API_KEY="your-elevenlabs-key"`
这两项服务都在 Authorization 请求头中使用 bearer 令牌，因此将它们保存在环境中是最安全的方法。

### 3. Turn Text into Speech with ElevenLabs

### 3. 使用 ElevenLabs 将文本转换为语音

ElevenLabs provides a clean REST API that accepts plain text and returns an MP3 buffer. You can experiment with different voice IDs or even upload a custom cloned voice through ElevenLabs’ dashboard. For a truly branded podcast, clone the voice of your host and reference it here – the same API call works with the cloned voice’s ID.

ElevenLabs 提供了一个简洁的 REST API，它接受纯文本并返回 MP3 缓冲区。你可以尝试不同的语音 ID，甚至可以通过 ElevenLabs 的仪表板上传自定义的克隆语音。为了打造真正的品牌播客，请克隆你主持人的声音并在此处引用——相同的 API 调用同样适用于克隆语音的 ID。

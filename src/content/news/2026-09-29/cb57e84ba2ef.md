# cs341-illinois / coursebook

**Coursebook**
**课程手册**

Welcome to the systems programming coursebook! This repository houses a high-quality, open-source introductory systems programming textbook used by the CS 341: System Programming course at the University of Illinois Urbana-Champaign.
欢迎来到系统编程课程手册！本仓库收录了一本高质量、开源的系统编程入门教材，该教材由伊利诺伊大学厄巴纳-香槟分校（UIUC）的 CS 341：系统编程课程所使用。

The book assumes that you have taken a programming language course and are familiar with assembly instructions. All of the code and instruction will be in C, as it is the de-facto language of the Linux Kernel.
本书假设读者已经修过编程语言课程，并熟悉汇编指令。所有的代码和教学内容都将使用 C 语言编写，因为它是 Linux 内核事实上的标准语言。

The Coursebook is an aim to standardize and build upon Angrave's original wikibook experiment. The most recent version of the coursebook as a single pdf is here: main.pdf.
本课程手册旨在规范并扩展 Angrave 最初的维基图书（wikibook）实验。该手册的最新版 PDF 文件可在此处获取：main.pdf。

**Overview Goals**
**概述与目标**

Improve the quality and rigour of the original wikibook while maintaining openness.
在保持开放性的同时，提高原维基图书的质量和严谨性。

Improve the factualness by including citations, footnotes, extended reading, and a glossary.
通过加入引用、脚注、扩展阅读和术语表，提高内容的准确性。

Have exports in the form of pdf, markdown, and html.
支持导出为 PDF、Markdown 和 HTML 格式。

Automagically build so writers can focus on writing.
实现自动化构建，让作者能够专注于写作。

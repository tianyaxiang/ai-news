# ProCAP: Probabilistic Cross-Attentive Prompt Learning for Vision-Language Models
# ProCAP：用于视觉-语言模型的概率交叉注意力提示学习

**Abstract:** Pre-trained vision-language models such as CLIP can recognize new categories via prompting, but they often struggle when labeled data are scarce or the test distribution shifts. Prompt learning adapts only a small set of parameters while keeping the backbone frozen, yet many existing multimodal prompt learners couple the visual and textual branches weakly and can be brittle in low-shot regimes.

**摘要：** 诸如 CLIP 之类的预训练视觉-语言模型可以通过提示（prompting）识别新类别，但在标注数据稀缺或测试分布发生偏移时，它们往往表现不佳。提示学习（Prompt learning）仅需调整少量参数，同时保持主干网络冻结，然而许多现有的多模态提示学习器在视觉和文本分支之间的耦合较弱，且在少样本（low-shot）场景下可能不够稳健。

We propose ProCAP, a probabilistic cross-attentive prompt learning framework that improves cross-modal interaction and training stability without updating any CLIP weights: it learns both visual and textual prompt tokens and links them through stacked bidirectional multi-head cross-attention so the two branches refine each other across prompt depth.

我们提出了 ProCAP，这是一个概率交叉注意力提示学习框架，它在不更新任何 CLIP 权重的情况下，改善了跨模态交互和训练稳定性：该框架同时学习视觉和文本提示标记，并通过堆叠的双向多头交叉注意力机制将它们连接起来，从而使两个分支在提示深度上相互优化。

To reduce overfitting under limited supervision, we parameterize prompt tokens with Gaussian means and variances and regularize them with lightweight KL and L2 penalties, and we further add a compact symmetric InfoNCE head that aligns cross-attended image features with class-level text representations in a shared low-dimensional space.

为了减少有限监督下的过拟合，我们使用高斯均值和方差对提示标记进行参数化，并利用轻量级的 KL 和 L2 惩罚对其进行正则化。此外，我们还增加了一个紧凑的对称 InfoNCE 头，在共享的低维空间中将交叉注意力处理后的图像特征与类级文本表示进行对齐。

Across few-shot base-to-novel generalization on 11 datasets, cross-dataset transfer, and domain generalization on ImageNet shift benchmarks, ProCAP achieves strong aggregate base-to-novel performance and competitive transfer performance while keeping the CLIP backbone unchanged.

在 11 个数据集的少样本基准到新颖（base-to-novel）泛化、跨数据集迁移以及 ImageNet 偏移基准的领域泛化测试中，ProCAP 在保持 CLIP 主干网络不变的情况下，实现了强大的综合基准到新颖性能以及具有竞争力的迁移性能。

# An actively maintained and updated Motif fork actually exists
# 一个真正处于活跃维护和更新状态的 Motif 分支确实存在

Motif is great, I love how it looks and feels, and I want it to be actively maintained. I want a healthy ecosystem of Motif applications and even window managers and desktop environments, so I can run a real Motif environment. Sadly, while Motif has been open source for a while, the project itself stalled years ago, with little to no activity from anyone involved. That may be changing, as a number of developers decided to take matters into their own hands last year.

Motif 很棒，我喜欢它的外观和操作感，我希望它能得到持续的维护。我希望看到一个健康的 Motif 应用生态系统，甚至包括窗口管理器和桌面环境，这样我就能运行一个真正的 Motif 环境。遗憾的是，虽然 Motif 开源已经有一段时间了，但该项目本身在多年前就已停滞，几乎没有任何相关人员参与活动。这种情况可能正在改变，因为去年一些开发者决定亲自接手此事。

This fork of Motif was born of a desire to keep Motif (and other X11 technologies) alive and well. The original upstream Sourceforge project hasn’t had any activity in over two years, none of the project admins have been active for at least that amount of time, the official bug tracker has disappeared into the void; and the user forum was closed way back in 2017. Sadly, it appears that the original upstream has abandoned the project.

这个 Motif 分支的诞生源于让 Motif（以及其他 X11 技术）保持活力和健康的愿望。最初的 Sourceforge 上游项目已经两年多没有任何活动了，项目管理员至少在同样长的时间内没有活跃过，官方的错误追踪器也已消失在虚无中；而用户论坛早在 2017 年就已关闭。遗憾的是，最初的上游项目似乎已经放弃了该项目。

I’ve incorporated some fixes from upstream that have laid dormant for years, a few others from Gentoo, and made a few improvements of my own. I intend to maintain this fork, and in doing so advocate for the continued use of the user interface toolkit that defined an era, and influenced many of the user interfaces that came after it. ↫ Tim Hentenaar at the Motif fork’s GitHub page

我整合了一些在上游沉睡多年的修复补丁，以及来自 Gentoo 的一些补丁，并自己做了一些改进。我打算维护这个分支，并以此倡导继续使用这个定义了一个时代、并影响了后来许多用户界面的工具包。—— Tim Hentenaar 在 Motif 分支 GitHub 页面上的留言

Some of the people involved are people I know online, so I have a bit of faith in this fork being able to stand the test of time, but of course, managing a complex project like this is hard, so who knows how long the enthusiasm remains. Still, this fork has seen five releases since its inception a little over a year ago, which seems promising. It may seem weird for some to have a love for Motif, but I’m the kind of person who installs weird, outdated corporate and industrial software I don’t understand on my HP c8000 dual PA-RISC workstation running HP-UX just to enjoy the Motif interfaces they sometimes ship. We all have our quirks.

参与其中的一些人是我在网上认识的，所以我对这个分支能够经受住时间的考验抱有一点信心。当然，管理这样一个复杂的项目很困难，所以谁也不知道这种热情能持续多久。不过，这个分支自一年多前创建以来已经发布了五个版本，这看起来很有希望。对某些人来说，热爱 Motif 可能显得很奇怪，但我就是那种会在运行 HP-UX 的 HP c8000 双 PA-RISC 工作站上安装我不理解的、古怪且过时的企业和工业软件，只为了欣赏它们有时附带的 Motif 界面的人。我们都有自己的怪癖。

From my experiences talking to people online, I know there’s actually a rather solid number of people like me, and I hope that at some point the developers in this group can gain enough critical mass to build something like a basic Linux distribution or desktop environment using the disparate, actively-maintained Motif projects out there that yes, still exist. It’s a long shot, but in today’s computing landscape, where more and more people feel uncomfortable with “modern” software, I really feel like there’s a niche for something like this to exist. A really small niche, surely, but a niche all the same.

根据我在网上与人交流的经验，我知道实际上有相当多像我这样的人。我希望在某个时候，这个群体中的开发者能够达到足够的规模，利用现有的、分散但处于活跃维护状态的 Motif 项目（是的，它们确实存在）构建出类似基础 Linux 发行版或桌面环境的东西。这虽然很难实现，但在当今的计算环境下，越来越多的人对“现代”软件感到不适，我真的觉得这种东西是有其生存空间的。当然，这是一个非常小的利基市场，但它毕竟是一个利基市场。

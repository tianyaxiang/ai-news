# If you love a website, back it up

这个故事始于一个小小的悲剧。你看，我有一些老网页，我喜欢时不时回去看看。有些网站多年甚至几十年都没有变过，时不时去看看它们，就像看望一位老朋友是否安好，这让人感到一种小小的慰藉。当然，悲剧有时也会发生。曾经有一个名为 teapuppies.com 的粉丝网站，是关于一部名为《Ochaken》（茶犬）的老动画系列和玩具系列的。这些可爱的卡通狗角色长着茶叶耳朵，每一个都以不同种类的茶命名。

The site had been online since 2004 and had basically not changed since 2005, but it was nice just having it around. Except when I went to visit it a few weeks ago, and discovered that not only was the site gone but the domain is now being used to serve online gambling ads. I work in web archiving, by the way. Which is to say that I should have known the site would go offline someday, and that I have the tools to have done something about it. I could have archived that site while it was still around, but I didn’t.

这个网站自 2004 年上线以来，基本从 2005 年起就没变过，但能留着它感觉真好。然而几周前当我再次访问时，却发现网站不仅消失了，域名现在还被用来投放网络赌博广告。顺便提一下，我从事的是网络归档工作。也就是说，我本该预见到这个网站终有一天会下线，而且我有工具可以为此做点什么。我本可以在它还在的时候将其归档，但我没有。

This post is here to beg you to do what I didn’t think to, and to teach you how. You see, when I talk to a lot of people about web archiving, they always seem to believe it’s something they couldn’t do. It’s something a big organization like the Internet Archive does, and if you want a webpage to be saved you just have to wait and hope it gets done. But that’s not true!

这篇文章旨在恳求你去做我没想到的事，并教你如何去做。你看，当我与许多人谈论网络归档时，他们似乎总认为这是他们做不到的事情。他们觉得这是像“互联网档案”（Internet Archive）这样的大型组织才会做的事，如果你想保存一个网页，只能等待并祈祷它能被保存下来。但事实并非如此！

What I really want everyone to know is that you have control over the world around you, you can take action to preserve things and make things better. And not just can, but should! Don’t just wait for someone else to act - get out there and and make it happen! Got a favourite site? Back it up! Got some information you don’t want to get lost? Back it up! Favourite post somewhere? All together now. Back! It! Up!

我真正想让大家知道的是，你对周围的世界拥有掌控权，你可以采取行动来保存事物并让事情变得更好。不仅可以，而且应该！不要只是等待别人采取行动——走出去，让它发生！有喜欢的网站吗？备份它！有不想丢失的信息吗？备份它！某处有喜欢的帖子吗？大家一起喊：备份！它！

All of the tools I’ll be showing off in this post use standard web archiving formats like WARC. You don’t have to worry about any of the technical details, but I’m telling you that because it means there are a lot of really great tools to do whatever you want with them. Here, just as an example, is an entire archived website embedded right in this blog post: You can even click through all the links, look at all of the images, the works. It’s an entire website right in a post!

我在本文中展示的所有工具都使用像 WARC 这样的标准网络归档格式。你不必担心任何技术细节，我之所以提到这一点，是因为这意味着有很多非常棒的工具可以让你随心所欲地使用它们。这里，作为一个例子，是一个直接嵌入在这篇博文中的完整归档网站：你甚至可以点击所有的链接，查看所有的图片，应有尽有。这是一个直接出现在帖子里的完整网站！

(And if you don’t trust me to keep this up, and you want the web archive to host somewhere else? You can download it for yourself right from there. Just click the kebab menu and choose “download archive”, and you can do whatever you like with it. In fact, please do!) I just happen to think these are the best tools there are for personal web archiving.

Option 1 - ArchiveWeb.page browser extension By far the easiest personal web archiving tool is the ArchiveWeb.page browser extension for Chrome. This doesn’t take much in the way of setup or technical skills, and it works for anything: a single page, an entire website, a social media post or profile. So long as you can see it in a web browser, you can save it. All you really need to do is: Install the browser extension. Visit the first page you want to archive. Click the ArchiveWeb.page icon in the toolbar, then click “Start Archiving”. If your page has any interactive elements, click on those to make sure all their data loads. Visit any other pages you want captured in the same collection and let the extension grab them. Click the ArchiveWeb.page icon in the toolbar, then click “Stop Archiving”. You’re done! You just archived a web page!

选项 1 - ArchiveWeb.page 浏览器扩展程序。目前最简单的个人网络归档工具是适用于 Chrome 的 ArchiveWeb.page 浏览器扩展程序。它不需要太多的设置或技术技能，适用于任何内容：单个页面、整个网站、社交媒体帖子或个人资料。只要你能在浏览器中看到它，你就可以保存它。你真正需要做的只是：安装浏览器扩展程序。访问你想归档的第一个页面。点击工具栏中的 ArchiveWeb.page 图标，然后点击“开始归档”。如果你的页面有任何交互元素，请点击它们以确保所有数据都已加载。访问你想在同一集合中捕获的任何其他页面，并让扩展程序抓取它们。点击工具栏中的 ArchiveWeb.page 图标，然后点击“停止归档”。大功告成！你刚刚归档了一个网页！

Now that it’s all saved, you can preview it and see how it went by clicking the extension’s icon and then the home icon to open the extension dashboard. From there, you can click on your archiving session to preview the pages you archived, load them in browser, and see if they work. (I’ll go into more details on how you can look at web archives and share them with others later in this post.)

现在一切都已保存，你可以通过点击扩展程序的图标，然后点击主页图标打开扩展程序仪表板，来预览并查看归档效果。从那里，你可以点击你的归档会话来预览你归档的页面，在浏览器中加载它们，并查看它们是否正常工作。（我将在本文后面详细介绍如何查看网络档案并与他人分享。）

Option 2 - archiveweb.page app If you don’t want to install a browser extension, or you don’t have Chrome installed, you can also grab the standalone archiveweb.page app. This is basically the same thing as the browser extension above, it just has its own web browser built in. It also opens straight to the menu that lets you browse your web archives, so it’s a handy way to look at your web archives locally. Pretty much everything else I described above applies.

选项 2 - archiveweb.page 应用程序。如果你不想安装浏览器扩展程序，或者没有安装 Chrome，你也可以获取独立的 archiveweb.page 应用程序。这基本上与上面的浏览器扩展程序相同，只是它内置了自己的网页浏览器。它还会直接打开让你浏览网络档案的菜单，因此这是一种在本地查看网络档案的便捷方式。我上面描述的其他所有内容基本都适用。

Option 3 - Browsertrix The above options are great for single pages or sites that are small enough for you to browse manually. But if you’ve got a webpage that’s big enough that it’s going to be annoying visiting all of the pages by hand, you probably want to look at a web crawler tool for web archiving. There are a bunch of options out there, but the easiest to use as an individual is probably Browsertrix. A web crawler is basically an automation tool built around a web browser; you provide instructions on what page to start from and what pages it should visit, and it will go ahead and click links to automatically find pages so that it can archive the page as completely as possible.

选项 3 - Browsertrix。上述选项非常适合单个页面或小到可以手动浏览的网站。但如果你有一个网页大到手动访问所有页面会很麻烦，你可能需要考虑使用网络爬虫工具进行网络归档。市面上有很多选择，但作为个人用户，最容易使用的可能是 Browsertrix。网络爬虫基本上是一个围绕网页浏览器构建的自动化工具；你提供从哪个页面开始以及应该访问哪些页面的指令，它就会自动点击链接以查找页面，从而尽可能完整地归档该页面。

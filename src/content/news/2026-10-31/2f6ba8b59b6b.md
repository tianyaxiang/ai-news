# expo / skills

Expo Skills Official AI agent skills from the Expo team for building, deploying, upgrading, and debugging Expo apps.
Expo Skills 是来自 Expo 团队的官方 AI 代理技能，用于构建、部署、升级和调试 Expo 应用。

How It Works Skills give AI agents focused Expo knowledge: when to use Expo APIs, how to structure common workflows, and which Expo, EAS, React Native, iOS, and Android constraints matter. Expo documentation, Expo CLI, and EAS CLI remain the source of truth; these skills help agents apply them correctly.
工作原理：这些技能为 AI 代理提供了专注的 Expo 知识：何时使用 Expo API、如何构建常见工作流程，以及哪些 Expo、EAS、React Native、iOS 和 Android 的约束条件至关重要。Expo 文档、Expo CLI 和 EAS CLI 仍然是事实来源；这些技能旨在帮助代理正确地应用它们。

Installation For Claude Code or Codex, install the plugin so updates are handled by the official plugin marketplace. For Cursor, OpenCode, and other AI coding agents, use the skills CLI.
安装：对于 Claude Code 或 Codex，请安装插件，以便通过官方插件市场处理更新。对于 Cursor、OpenCode 和其他 AI 编码代理，请使用 skills CLI。

Path Best for Plugin install Claude Code or Codex, with updates handled by their official plugin marketplaces. Skills CLI Cursor, OpenCode, GitHub Copilot, Windsurf, Gemini, Cline, AMP, Factory Droid, Antigravity, Kiro CLI, and other AI coding agents.
路径：插件安装最适合 Claude Code 或 Codex，更新由其官方插件市场处理。Skills CLI 最适合 Cursor、OpenCode、GitHub Copilot、Windsurf、Gemini、Cline、AMP、Factory Droid、Antigravity、Kiro CLI 以及其他 AI 编码代理。

Skills CLI Install all Expo skills with the skills CLI: npx skills@latest add expo/skills --skill '*' This selects every Expo skill without selecting every agent. The CLI will still ask where to install them; to target one agent directly, add --agent <agent>. For most agents, this is the only install command you need. Run it from the project root, then restart or refresh your agent session so it can discover the installed SKILL.md files.
Skills CLI：使用 skills CLI 安装所有 Expo 技能：`npx skills@latest add expo/skills --skill '*'`。这将选择所有 Expo 技能，而无需选择每个代理。CLI 仍会询问安装位置；若要直接针对某个代理，请添加 `--agent <agent>`。对于大多数代理，这是你唯一需要的安装命令。在项目根目录下运行它，然后重启或刷新你的代理会话，以便它能发现已安装的 SKILL.md 文件。

Claude Code Plugin Install from the official Claude Code plugin marketplace: claude plugin install expo@claude-plugins-official You can also run /plugin install expo@claude-plugins-official inside Claude Code.
Claude Code 插件：从官方 Claude Code 插件市场安装：`claude plugin install expo@claude-plugins-official`。你也可以在 Claude Code 内部运行 `/plugin install expo@claude-plugins-official`。

Codex Plugin Install from the OpenAI-curated Codex marketplace: codex plugin add expo@openai-curated You can also open /plugins in Codex and install expo from the OpenAI-curated marketplace.
Codex 插件：从 OpenAI 策划的 Codex 市场安装：`codex plugin add expo@openai-curated`。你也可以在 Codex 中打开 `/plugins` 并从 OpenAI 策划的市场安装 expo。

Updating Claude Code and Codex plugin installs are updated through their official plugin marketplaces. For skills CLI installs, update installed skills with: npx skills@latest update To update a single Expo skill, pass its name: npx skills@latest update expo-router
更新：Claude Code 和 Codex 插件安装通过其官方插件市场进行更新。对于 skills CLI 安装，请使用以下命令更新已安装的技能：`npx skills@latest update`。若要更新单个 Expo 技能，请传入其名称：`npx skills@latest update expo-router`。

Try It After installing, ask your agent Expo-specific questions like: "Build a native-feeling Expo Router screen with tabs, modals, and animations." "Create an EAS workflow that builds previews on pull requests." "Help me upgrade this app to the latest Expo SDK." "Check whether this EAS Update rollout is healthy." Agents choose the right skill from the task context and each skill's description.
尝试一下：安装后，向你的代理询问 Expo 相关的问题，例如：“构建一个具有标签页、模态框和动画的、原生感十足的 Expo Router 屏幕。”、“创建一个在拉取请求时构建预览的 EAS 工作流程。”、“帮我将此应用升级到最新的 Expo SDK。”、“检查此 EAS Update 的发布是否健康。”代理会根据任务上下文和每个技能的描述选择合适的技能。

Skills Included Skills come in two groups so the free vs paid boundary is clear. Each skill's description carries the same label, and every services skill opens with a costs/plan-limits note.
包含的技能：技能分为两组，以便明确免费与付费的界限。每个技能的描述都带有相同的标签，并且每个服务类技能的开头都有关于成本/计划限制的说明。

Start Here Load this first for any Expo/EAS task, then route to the specific skill below. Skill Use it for expo-overview Router and shared setup rules; the entry point when a request is vague or the user hasn't named a specific Expo tool.
从这里开始：对于任何 Expo/EAS 任务，请先加载此项，然后路由到下方的特定技能。技能 `expo-overview`：用于路由和共享设置规则；当请求模糊或用户未指定具体的 Expo 工具时，这是入口点。

Framework (open source) Free, open-source Expo SDK and React Native skills.
框架（开源）：免费、开源的 Expo SDK 和 React Native 技能。

Skill Use it for expo-project-structure Folder structure for a new Expo app: src/ layout, routes-only app/, screens, server code, platform-specific files. expo-router Expo Router navigation: file-based routes, links, native stacks, modals, sheets, native tabs, and headers. expo-animation Polished React Native animations and gestures with Reanimated, Gesture Handler, Expo Router, and expo-haptics. expo-native-ui Native-feeling screen styling, semantic colors, controls, icons, media, and visual effects. expo-design-system In-app design systems: a token theme (color, spacing, typography, radius, shadow, motion), reusable component conventions, and design-system drift audits. expo-ui @expo/ui native components: universal cross-platform first, with SwiftUI and Jetpack Compose for platform-specific needs. expo-data-fetching API calls, React Query, SWR, caching, offline support, and Expo Router data loaders. expo-dom Expo DOM components for gradually using web code in native apps. expo-web-to-native Migrating an existing web/React app (Next.js, Vite, CRA) to a native iOS/Android app with Expo. expo-module Expo native modules and views with Swift, Kotlin, TypeScript, config plugins, and autolinking. expo-brownfield Adding Expo or React Native to an existing iOS or Android app. expo-dev-client Development clients (local builds are free; EAS Build/TestFlight is a paid step). expo-examples The expo/examples repo of with-* integrations to adapt or scaffold a new project from. expo-app-clip iOS App Clip targets, AASA files, associated domains, and Smart App Banners. expo-upgrade Expo SDK upgrades, dependency conflicts, deprecated packages, and cache cleanup.
技能用途：
- `expo-project-structure`：新 Expo 应用的文件夹结构：src/ 布局、仅路由的 app/、屏幕、服务器代码、特定平台文件。
- `expo-router`：Expo Router 导航：基于文件的路由、链接、原生堆栈、模态框、表单页、原生标签页和标题。
- `expo-animation`：使用 Reanimated、Gesture Handler、Expo Router 和 expo-haptics 实现精美的 React Native 动画和手势。
- `expo-native-ui`：原生感的屏幕样式、语义颜色、控件、图标、媒体和视觉效果。
- `expo-design-system`：应用内设计系统：令牌主题（颜色、间距、排版、圆角、阴影、运动）、可重用组件约定和设计系统偏差审计。
- `expo-ui`：@expo/ui 原生组件：优先考虑通用跨平台，并针对特定平台需求提供 SwiftUI 和 Jetpack Compose 支持。
- `expo-data-fetching`：API 调用、React Query、SWR、缓存、离线支持和 Expo Router 数据加载器。
- `expo-dom`：用于在原生应用中逐步使用 Web 代码的 Expo DOM 组件。
- `expo-web-to-native`：将现有的 Web/React 应用（Next.js、Vite、CRA）迁移到使用 Expo 的原生 iOS/Android 应用。
- `expo-module`：使用 Swift、Kotlin、TypeScript、配置插件和自动链接的 Expo 原生模块和视图。
- `expo-brownfield`：将 Expo 或 React Native 添加到现有的 iOS 或 Android 应用中。
- `expo-dev-client`：开发客户端（本地构建免费；EAS Build/TestFlight 是付费步骤）。
- `expo-examples`：expo/examples 仓库，包含用于适配或搭建新项目的 with-* 集成。
- `expo-app-clip`：iOS App Clip 目标、AASA 文件、关联域和智能应用横幅。
- `expo-upgrade`：Expo SDK 升级、依赖冲突、已弃用的包和缓存清理。

Services & paid distribution Skills whose core purpose uses paid Expo Application Services (EAS).
服务与付费分发：核心用途使用付费 Expo Application Services (EAS) 的技能。

Skill Use it for eas-app-stores Build and submit iOS/Android apps: Expo and other React Native projects, plus existing native apps; TestFlight, profiles, versioning, and metadata. eas-hosting Deploying Expo websites and Expo Router API routes to EAS Hosting: secrets, custom domains, Cloudflare Workers. eas-workflows EAS Workflow YAML files and CI/CD automation. eas-observe EAS Observe setup and launch, route, event, and version metrics. eas-update EAS Update setup, OTA publishing, runtime compatibility, testing, and debugging. eas-update-insights EAS Update health, crash rates, launch counts, payload size, and rollout gates. eas-simulator Run and drive your app on a remote iOS simulator or Android emulator on EAS cloud - from the CLI or an agent, with a live browser preview (iOS only).
技能用途：
- `eas-app-stores`：构建并提交 iOS/Android 应用：Expo 和其他 React Native 项目，以及现有的原生应用；TestFlight、配置文件、版本控制和元数据。
- `eas-hosting`：将 Expo 网站和 Expo Router API 路由部署到 EAS Hosting：密钥、自定义域名、Cloudflare Workers。
- `eas-workflows`：EAS Workflow YAML 文件和 CI/CD 自动化。
- `eas-observe`：EAS Observe 设置以及启动、路由、事件和版本指标。
- `eas-update`：EAS Update 设置、OTA 发布、运行时兼容性、测试和调试。
- `eas-update-insights`：EAS Update 健康状况、崩溃率、启动次数、负载大小和发布门控。
- `eas-simulator`：在 EAS 云端的远程 iOS 模拟器或 Android 模拟器上运行和驱动你的应用——通过 CLI 或代理，并提供实时浏览器预览（仅限 iOS）。

Experimental Skills for Expo APIs that are not finalized. Content may change or be retired; skills graduate to the groups above when the underlying API stabilizes. These ship in the separate expo-experiments plugin (install it alongside expo), or individually via the skills CLI.
实验性：针对尚未定稿的 Expo API 的技能。内容可能会更改或被弃用；当底层 API 稳定后，这些技能将升级到上述组别中。它们包含在单独的 `expo-experiments` 插件中（与 expo 一起安装），或通过 skills CLI 单独安装。

技能用途：`expo-migrate-module`：将 Swift Expo 模块从 Modules API 1.0 定义 DSL 迁移到 2.0 宏 API。

**Technical Background: The Three Pillars**
Active learning operates on a simple premise: not all unlabeled samples are equally informative. In a clinical oncology pipeline, you might have 50,000 patients with molecular data but only budget for 500 expert annotations (pathologist time, oncologist review, curated variant interpretation). The question is which 500.

**技术背景：三大支柱**
主动学习基于一个简单的前提：并非所有未标注样本的信息量都是相等的。在临床肿瘤学流程中，你可能有 5 万名患者的分子数据，但预算仅够支持 500 次专家标注（病理学家时间、肿瘤学家审查、精选变异解读）。问题在于选哪 500 个。

The classic strategies I experimented with:
* Uncertainty sampling: pick samples where the model is least confident
* Query-by-committee: pick samples where an ensemble disagrees most
* Core-set / diversity sampling: pick samples that best represent the unlabeled distribution
* Expected model change: pick samples that would most alter the model if labeled

我实验过的经典策略包括：
* 不确定性采样：选择模型最不自信的样本
* 委员会查询：选择集成模型分歧最大的样本
* 核心集/多样性采样：选择最能代表未标注分布的样本
* 预期模型变化：选择如果标注后最能改变模型的样本

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier

def bald_acquisition(ensemble_probs):
    """ 
    Bayesian Active Learning by Disagreement (BALD).
    ensemble_probs: (n_models, n_samples, n_classes)
    Returns mutual information between predictions and model parameters.
    """
    mean_probs = ensemble_probs.mean(axis=0) # (n_samples, n_classes)
    entropy_of_mean = -np.sum(mean_probs * np.log(mean_probs + 1e-12), axis=1)
    mean_of_entropy = -np.mean(
        np.sum(ensemble_probs * np.log(ensemble_probs + 1e-12), axis=2), axis=0
    )
    return entropy_of_mean - mean_of_entropy # higher = more informative
```

While exploring BALD for a lung adenocarcinoma subtyping task, I discovered that pure uncertainty sampling tends to over-query ambiguous, borderline cases—which in oncology are often not the clinically actionable ones. A hybrid approach combining uncertainty with diversity (via a k-center greedy selection on embeddings) consistently outperformed either alone in my experiments.

在为肺腺癌亚型任务探索 BALD 时，我发现纯粹的不确定性采样倾向于过度查询那些模棱两可的边缘案例——而在肿瘤学中，这些案例往往不是临床上可操作的。在我的实验中，结合不确定性和多样性（通过嵌入上的 k-中心贪婪选择）的混合方法始终优于单一方法。

**Differential Privacy: The Math of Plausible Deniability**
Differential privacy (DP) gives a formal guarantee: the output of an algorithm is nearly indistinguishable whether or not any single patient's data was included. The mechanism is elegant—add calibrated noise to the quantity you're releasing. For a function $f$ with sensitivity $\Delta f$ (the max change in output from adding/removing one record), the Laplace mechanism releases: $M(D) = f(D) + \text{Lap}\left(\frac{\Delta f}{\epsilon}\right)$ where $\epsilon$ is the privacy budget. Smaller $\epsilon$ = more privacy = more noise.

**差分隐私：合理推诿的数学**
差分隐私 (DP) 提供了一种正式保证：无论是否包含任何单个患者的数据，算法的输出几乎是无法区分的。其机制很优雅——向你发布的数量中添加校准过的噪声。对于具有敏感度 $\Delta f$（添加/删除一条记录导致输出的最大变化）的函数 $f$，拉普拉斯机制发布：$M(D) = f(D) + \text{Lap}\left(\frac{\Delta f}{\epsilon}\right)$，其中 $\epsilon$ 是隐私预算。$\epsilon$ 越小 = 隐私性越强 = 噪声越大。

```python
import numpy as np

def laplace_mechanism(value, sensitivity, epsilon):
    """Release a DP-protected scalar."""
    scale = sensitivity / epsilon
    noise = np.random.laplace(0, scale)
    return value + noise

def dp_histogram(counts, epsilon, max_contribution=1):
    """DP histogram over clinical categories."""
    sensitivity = max_contribution # one patient contributes at most 1
    noisy = counts + np.random.laplace(0, sensitivity / epsilon, size=counts.shape)
    return np.clip(noisy, 0, None)
```

What took me a while to internalize: DP composes. If you run 100 queries each at $\epsilon=0.1$, you've spent $\epsilon=10$ under basic composition—effectively no privacy. This is the central tension in privacy-preserving active learning, because active learning is inherently iterative, and each query is a privacy expenditure. My first prototype leaked catastrophically because I ignored composition. I still cringe thinking about it.

我花了一段时间才内化的一点是：DP 是可组合的。如果你运行 100 次查询，每次 $\epsilon=0.1$，在基本组合下你已经消耗了 $\epsilon=10$——实际上等于没有隐私。这是隐私保护主动学习中的核心矛盾，因为主动学习本质上是迭代的，而每次查询都是一次隐私支出。我的第一个原型因为忽略了组合性而发生了灾难性的泄露。想到这一点，我至今仍感到难堪。

**Secure Multi-Party Computation and Federated Learning**
Federated learning keeps data local and shares only model updates. But naive federated averaging leaks information through gradients—a well-documented attack vector. Secure aggregation (via secret sharing or homomorphic encryption) closes that gap.

**安全多方计算与联邦学习**
联邦学习将数据保留在本地，仅共享模型更新。但天真的联邦平均算法会通过梯度泄露信息——这是一种有据可查的攻击向量。安全聚合（通过秘密共享或同态加密）弥补了这一差距。

```python
# Sketch: additive secret sharing for secure aggregation
def share_secret(x, n_parties, prime=2**61 - 1):
    """Split x into n additive shares mod prime."""
    shares = [np.random.randint(0, prime, size=x.shape) for _ in range(n_parties - 1)]
    last = (x - sum(shares)) % prime
    return shares + [last]

def reconstruct(shares, prime=2**61 - 1):
    return sum(shares) % prime
```

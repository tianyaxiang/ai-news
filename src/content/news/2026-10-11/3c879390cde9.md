### Cloudflare acquires Deno to improve its Workers programming model

In Brief Posted: 9:25 AM PDT · October 10, 2026 Image Credits:Sundry Photography / Getty Images Anthony Ha Cloudflare acquires Deno to improve its Workers programming model

简讯 发布时间：太平洋夏令时间 2026 年 10 月 10 日上午 9:25 图片来源：Sundry Photography / Getty Images Anthony Ha Cloudflare 收购 Deno 以改进其 Workers 编程模型

Cloudflare announced Friday that it’s acquiring Deno, the startup behind the programming runtime of the same name. According to Cloudflare’s Kenton Varda, Cloudflare will use this acquisition to improve its Workers programming model and platform, which allows customers to build and run software on Cloudflare’s network. (Varda is principal engineer for Cloudflare Workers.)

Cloudflare 周五宣布收购 Deno，这是一家同名编程运行时的初创公司。据 Cloudflare 的 Kenton Varda 称，Cloudflare 将利用此次收购来改进其 Workers 编程模型和平台，该平台允许客户在 Cloudflare 的网络上构建和运行软件。（Varda 是 Cloudflare Workers 的首席工程师。）

Deno — which was co-founded by Bert Belder and Node.js creator Ryan Dahl — recently launched celld, an open source implementation of Workers, which Varda wrote “delighted” the Cloudflare team. Varda argued that contrary to “a popular theory” that the company “made Cloudflare Workers work differently from other cloud platforms in order to create ‘lock-in,’” the company believes “being open source and giving people an escape hatch is good business.”

Deno 由 Bert Belder 和 Node.js 创建者 Ryan Dahl 共同创立，最近推出了 celld，这是 Workers 的一个开源实现，Varda 写道，这让 Cloudflare 团队感到“非常高兴”。Varda 反驳了“一种流行的理论”，即该公司“为了制造‘锁定’而使 Cloudflare Workers 的工作方式与其他云平台不同”，他表示公司认为“开源并为人们提供逃生通道是好的商业模式”。

Dahl, meanwhile, wrote that his team is “joining Cloudflare to make the Workers programming model a mainstream way to build servers.” The financial terms of the acquisition were not disclosed. Deno had raised a total of $26 million, including a Series A led by Sequoia.

与此同时，Dahl 写道，他的团队“加入 Cloudflare 是为了使 Workers 编程模型成为构建服务器的主流方式”。此次收购的财务条款未披露。Deno 此前总共筹集了 2600 万美元，其中包括由红杉资本领投的 A 轮融资。

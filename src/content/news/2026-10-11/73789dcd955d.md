# Talorys – A self-hosted personal AI agent on Cloudflare's free tier

Your personal AI agent. Your own cloud.

您的个人 AI 代理。属于您自己的云端。

Talorys is a free, open-source personal AI assistant that runs entirely inside your own Cloudflare account. It chats with you, remembers what matters, manages tasks, notes and projects, and runs reminders and routines on a schedule — without any server, database or account operated by the Talorys developers.

Talorys 是一款免费、开源的个人 AI 助手，完全运行在您自己的 Cloudflare 账户内。它能与您聊天、记住重要事项、管理任务、笔记和项目，并按计划运行提醒和例程——无需任何由 Talorys 开发人员运营的服务器、数据库或账户。

One person. One Cloudflare account. One command. One personal AI agent.

一个人。一个 Cloudflare 账户。一条命令。一个个人 AI 代理。

More detail: docs/architecture.md.

更多详情：docs/architecture.md。

Talorys does not provision R2, D1, KV, Vectorize, AI Search, Workflows or any paid service.

Talorys 不会配置 R2、D1、KV、Vectorize、AI Search、Workflows 或任何付费服务。

It writes a talorys/ directory containing talorys.json (installation id, account id, resource names, URL — no secrets) and the deployable artifacts. Keep it for updates.

它会创建一个 talorys/ 目录，其中包含 talorys.json（安装 ID、账户 ID、资源名称、URL——不含密钥）以及可部署的制品。请保留此目录以供更新使用。

Interrupted? Run the same command again in the same place. It reconciles what already exists: no duplicate resources, no password re-prompt if the password is already configured, and no data is ever deleted.

中断了？在同一位置再次运行相同的命令即可。它会协调已存在的资源：不会产生重复资源，如果已配置密码则不会再次提示输入，且绝不会删除任何数据。

Non-interactive installs: TALORYS_OWNER_PASSWORD=... npx create-talorys@latest --yes --account-id <id> (with CLOUDFLARE_API_TOKEN set if you are not logged in).

非交互式安装：TALORYS_OWNER_PASSWORD=... npx create-talorys@latest --yes --account-id <id>（如果您未登录，请设置 CLOUDFLARE_API_TOKEN）。

All data is stored in a single SQLite-backed Durable Object (personal-agent) in your Cloudflare account. Talorys has no telemetry, analytics, tracking or advertising code and sends nothing to its developers.

所有数据都存储在您 Cloudflare 账户中一个基于 SQLite 的 Durable Object (personal-agent) 内。Talorys 不包含任何遥测、分析、跟踪或广告代码，也不会向其开发人员发送任何信息。

Cloudflare processes your data to provide its services — including running Workers AI inference on your chat messages and the relevant memories included in each prompt. Review Cloudflare's privacy policy and Workers AI terms.

Cloudflare 会处理您的数据以提供其服务——包括对您的聊天消息以及每个提示中包含的相关记忆运行 Workers AI 推理。请查阅 Cloudflare 的隐私政策和 Workers AI 条款。

Security model and threat mitigations: docs/security.md.

安全模型与威胁缓解措施：docs/security.md。

Talorys is designed to fit the Cloudflare Workers Free plan and never enables paid features on its own. It is not "unlimited free", though:

Talorys 旨在适配 Cloudflare Workers 免费套餐，且绝不会自行启用付费功能。不过，它并非“无限免费”：

Built-in guardrails (adjustable in Settings → AI): max output tokens, max context tokens (older history is summarized), max tool calls and reasoning steps per request, max AI requests per day, and max scheduled AI runs per day. Simple reminders and task digests never use AI. The Usage panel shows local estimates and links to the Cloudflare dashboard for exact Neuron usage.

内置防护机制（可在“设置”→“AI”中调整）：最大输出 Token 数、最大上下文 Token 数（旧历史记录会被摘要）、每次请求的最大工具调用和推理步骤数、每日最大 AI 请求数以及每日最大计划 AI 运行次数。简单的提醒和任务摘要从不使用 AI。使用情况面板显示本地估算值，并提供指向 Cloudflare 仪表板的链接以查看精确的 Neuron 使用量。

Requirements: Node.js 20.18+.

要求：Node.js 20.18+。

npm run dev starts the agent Worker (wrangler dev, port 8787), the Pages Function proxy with its service binding (wrangler pages dev, port 8788) and the Vite UI (http://localhost:5173) in one terminal. It creates apps/agent/.dev.vars with a local password (talorys-dev-password, override with TALORYS_DEV_PASSWORD) and uses the deterministic mock AI provider, so no Cloudflare login is needed. State persists in .wrangler/state.

npm run dev 可在一个终端中启动代理 Worker（wrangler dev，端口 8787）、带有服务绑定的 Pages Function 代理（wrangler pages dev，端口 8788）以及 Vite UI (http://localhost:5173)。它会创建一个包含本地密码（talorys-dev-password，可通过 TALORYS_DEV_PASSWORD 覆盖）的 apps/agent/.dev.vars 文件，并使用确定性的模拟 AI 提供程序，因此无需登录 Cloudflare。状态保存在 .wrangler/state 中。

Other scripts: npm run build, npm test, npm run test:e2e, npm run test:pack, npm run typecheck, npm run lint. See docs/development.md.

其他脚本：npm run build、npm test、npm run test:e2e、npm run test:pack、npm run typecheck、npm run lint。请参阅 docs/development.md。

Settings → Privacy → Download backup produces talorys-backup.json with conversations, memories, tasks, notes, projects, settings and automations (never sessions or credentials). Import validates the file and merges it in one transaction; importing the same backup twice is harmless.

“设置”→“隐私”→“下载备份”会生成 talorys-backup.json，其中包含对话、记忆、任务、笔记、项目、设置和自动化（不含会话或凭据）。导入功能会验证文件并在一个事务中合并；重复导入同一个备份不会造成影响。

Hacktoberfest Open-Source AI Challenge Week 1: Touch Grass Submission 🌿 This is a submission for the Hacktoberfest Open-Source AI Challenge Week 1: Touch Grass What I Built What it does: EdgeEcho is a 100% offline Progressive Web App (PWA) that uses local edge AI to identify 521 environmental sounds, such as specific bird calls or flowing water.

Hacktoberfest 开源 AI 挑战赛第一周：拥抱自然（Touch Grass）参赛作品 🌿 这是 Hacktoberfest 开源 AI 挑战赛第一周的参赛作品。我构建了什么：EdgeEcho 是一款 100% 离线的渐进式 Web 应用（PWA），它利用本地边缘 AI 来识别 521 种环境声音，例如特定的鸟鸣声或流水声。

How it gets people off the screen: It operates hands-free. Users tap "Start Listening," lock their device, and receive text-to-speech audio alerts through their earbuds. There is no visual dashboard to monitor, forcing users to keep their eyes on the environment. Who it is for: Hikers, birdwatchers, and outdoor enthusiasts operating in remote areas with zero cellular connectivity.

它是如何让人们远离屏幕的：它支持免提操作。用户点击“开始聆听”后即可锁定设备，并通过耳机接收语音合成（TTS）音频提醒。由于没有需要监控的可视化仪表板，用户被迫将注意力集中在周围环境中。适用人群：在零蜂窝网络覆盖的偏远地区活动的徒步旅行者、观鸟者和户外爱好者。

How I Built It The AI Stack: Google’s open-weight YAMNet model (3.7MB .tflite mobile architecture) executed via TensorFlow.js (@tensorflow/tfjs-tflite). The Architecture: The app is structurally tethered to local inference. A Service Worker caches the model binary for offline use. The JavaScript strictly formats microphone input to the 16kHz mono buffer YAMNet requires, running the spectrogram analysis and classification entirely in the browser’s local RAM.

我是如何构建它的：AI 技术栈：谷歌的开源权重 YAMNet 模型（3.7MB .tflite 移动架构），通过 TensorFlow.js (@tensorflow/tfjs-tflite) 执行。架构：该应用在结构上绑定了本地推理。Service Worker 会缓存模型二进制文件以供离线使用。JavaScript 会严格将麦克风输入格式化为 YAMNet 所需的 16kHz 单声道缓冲区，并在浏览器的本地内存中完全运行频谱分析和分类。

Why Does Open Innovation Matter? Zero Connectivity / Air-Gapped Use: Closed cloud APIs require active LTE/5G and fail on remote trails. Open-weight models allow the app to function fully in airplane mode. Absolute Privacy: Continuous audio classification requires an always-open microphone. Local inference ensures ambient audio is processed and destroyed on-device, never transmitting data to a corporate server.

为什么开放创新很重要？零连接/物理隔离使用：闭源云 API 需要活跃的 LTE/5G 网络，在偏远步道上无法使用。开源权重模型使应用能够在飞行模式下完全运行。绝对隐私：持续的音频分类需要始终开启麦克风。本地推理确保环境音频在设备上处理并销毁，绝不会将数据传输到企业服务器。

Financial Viability: Streaming continuous audio to a closed API incurs heavy per-minute costs. Running open weights on edge hardware drops the operating cost to zero.

财务可行性：将连续音频流传输到闭源 API 会产生高昂的每分钟费用。在边缘硬件上运行开源权重模型将运营成本降至零。

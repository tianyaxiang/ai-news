# Floci: Locally emulating any cloud service
# Floci：在本地模拟任何云服务

Any cloud. Locally. Run AWS, Azure, GCP, and OCI locally in milliseconds: the fast, credential-free loop your team and its AI agents need to ship faster.
任何云，本地化。在几毫秒内于本地运行 AWS、Azure、GCP 和 OCI：这是您的团队及其 AI 智能体实现快速交付所需的、无需凭证的快速开发闭环。

### GitHub Cloud Emulators
### GitHub 云模拟器

Pick your cloud. Start instantly. Each emulator is a standalone MIT-licensed binary. No auth tokens, no feature gates, no cloud account needed.
选择您的云平台，即刻启动。每个模拟器都是一个独立的、采用 MIT 许可的二进制文件。无需身份验证令牌，没有功能限制，也不需要云账号。

#### AWS floci
Drop-in replacement for LocalStack. Same port 4566, 119 services, native binary. Switch with zero code changes.
LocalStack 的直接替代品。使用相同的 4566 端口，支持 119 项服务，原生二进制运行。无需更改任何代码即可切换。

#### Azure floci-az
Covers Blob, Queue, Table, Functions, App Config, Key Vault, Event Hubs and Service Bus. Native speed, MIT license, no Azure account needed.
涵盖 Blob、Queue、Table、Functions、App Config、Key Vault、Event Hubs 和 Service Bus。原生运行速度，MIT 许可，无需 Azure 账号。

#### GCP floci-gcp
Covers GCS, Pub/Sub, Firestore, Cloud Run, Cloud SQL, GKE and more. All 25 services on one port, native binary. MIT license, no GCP account needed.
涵盖 GCS、Pub/Sub、Firestore、Cloud Run、Cloud SQL、GKE 等。所有 25 项服务均运行于同一端口，原生二进制。MIT 许可，无需 GCP 账号。

#### OCI floci-oci
Covers Object Storage, Identity, Queue, Streaming, KMS, Vault and Functions. All 8 services on one port. MIT license, no Oracle Cloud account needed.
涵盖对象存储 (Object Storage)、身份验证 (Identity)、队列 (Queue)、流处理 (Streaming)、KMS、Vault 和函数 (Functions)。所有 8 项服务均运行于同一端口。MIT 许可，无需 Oracle Cloud 账号。

### Built for AI-assisted development
### 专为 AI 辅助开发而构建

Give your AI agents a cloud they can't break. Coding agents write cloud code faster than ever, but they can't safely run it against a real account. Point them at Floci instead: a local cloud to build, run, and verify against. Instant, free, and credential-free.
给您的 AI 智能体一个“搞不坏”的云环境。编程智能体编写云代码的速度比以往任何时候都快，但它们无法安全地在真实账号上运行代码。改用 Floci 吧：一个用于构建、运行和验证的本地云环境。即时、免费且无需凭证。

*   **0 No credentials to leak.** Agents connect with throwaway keys. No real cloud secrets in the agent's context or sandbox. Nothing to exfiltrate, nothing to bill.
    **0 无需泄露凭证。** 智能体使用一次性密钥连接。智能体的上下文或沙箱中不存在真实的云密钥。没有数据可外泄，也不会产生账单。
*   **24ms Inner-loop fast.** 24 ms cold start, 13 MiB idle. Agents spin up, test, and tear down inside the edit loop instead of waiting on round-trips to a remote account.
    **24ms 内部循环速度。** 24 毫秒冷启动，13 MiB 空闲内存占用。智能体在编辑循环内即可完成启动、测试和销毁，无需等待远程账号的往返通信。
*   **real Real signal, not mock theater.** Lambda, RDS, Redis, and Kafka run for real, so code an agent verifies locally behaves the same in production. No mock-shaped false positives.
    **真实信号，而非模拟表演。** Lambda、RDS、Redis 和 Kafka 均为真实运行，因此智能体在本地验证的代码在生产环境中表现一致。没有模拟带来的误报。
*   **✗ Zero blast radius.** Let agents iterate aggressively. Worst case, they reset a local container, not your staging environment or your cloud bill.
    **✗ 零影响范围。** 让智能体大胆迭代。最坏的情况也只是重置本地容器，而不会影响您的预发布环境或产生云账单。

### Why Floci
### 为什么选择 Floci

*   **$0 MIT Licensed.** Forever free. Fork it, embed it, extend it. No "community edition" sunset, no enterprise feature flags. Every service is available to every developer, always.
    **$0 MIT 许可。** 永久免费。您可以分叉、嵌入或扩展它。没有“社区版”停更，也没有企业版功能锁。每一项服务始终对每一位开发者开放。
*   **✗ No auth token. Ever.** Pull the Docker image and go. No sign-ups, no API keys, no telemetry. LocalStack started requiring an auth token in March 2026. Floci never will.
    **✗ 永远无需身份验证令牌。** 拉取 Docker 镜像即可使用。无需注册、无需 API 密钥、无遥测数据。LocalStack 自 2026 年 3 月起开始要求身份验证令牌，而 Floci 永远不会。
*   **24ms Native binary speed.** Compiled with GraalVM Mandrel. Starts in 24ms, idles at 13 MiB, fast enough for inner-loop iteration. Your CI, your laptop, and your AI agents will all thank you.
    **24ms 原生二进制速度。** 使用 GraalVM Mandrel 编译。24 毫秒启动，13 MiB 空闲占用，速度足以满足内部循环迭代。您的 CI、笔记本电脑和 AI 智能体都会感谢您。
*   **real Real engines, not mocks.** Lambda runs in real Docker containers. RDS uses real PostgreSQL/MySQL. ElastiCache runs real Redis. 100% protocol fidelity, no surprises in production.
    **真实引擎，而非模拟。** Lambda 在真实的 Docker 容器中运行。RDS 使用真实的 PostgreSQL/MySQL。ElastiCache 运行真实的 Redis。100% 协议保真度，生产环境零意外。

### Use Cases
### 使用场景

*   **CI Ephemeral test environments.** Spin up the full stack inside every pipeline job. 24 ms startup adds nothing to the build, each job gets an isolated cloud, and teardown is free.
    **CI 临时测试环境。** 在每个流水线作业中启动完整堆栈。24 毫秒的启动时间几乎不增加构建负担，每个作业都能获得一个隔离的云环境，且销毁过程零成本。
*   **λ Local-first development.** Build against S3, Pub/Sub, or Service Bus on your laptop — offline if you want. No shared dev account to trip over, no credentials to rotate.
    **本地优先开发。** 在您的笔记本电脑上针对 S3、Pub/Sub 或 Service Bus 进行构建——甚至可以离线进行。无需担心共享开发账号的冲突，也无需轮换凭证。
*   **tf Infrastructure-as-code dry runs.** Apply Terraform, OpenTofu, or CloudFormation against localhost first. Catch typos, drift, and bad refactors before they ever touch a real account.
    **基础设施即代码 (IaC) 预演。** 先将 Terraform、OpenTofu 或 CloudFormation 应用于本地主机。在触及真实账号之前，先发现拼写错误、配置漂移和糟糕的重构。
*   **101 Workshops & onboarding.** Teach cloud services with zero billing risk. Every student runs the whole stack on their own machine — no accounts to provision, nothing to clean up.
    **研讨会与入职培训。** 在零账单风险的情况下教授云服务。每位学员都在自己的机器上运行整个堆栈——无需配置账号，也无需清理环境。

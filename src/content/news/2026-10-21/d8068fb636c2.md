OpenBSD 8.0 is here, marking the project’s 61st release and continuing its schedule of semiannual releases dating back to 1996. What started more than 30 years ago as a fork of NetBSD has grown into one of the most security-conscious operating systems in active development.

OpenBSD 8.0 现已发布，这是该项目的第 61 个版本，延续了自 1996 年以来每半年发布一次的计划。这个始于 30 多年前、源自 NetBSD 分支的项目，如今已发展成为目前开发中最注重安全性的操作系统之一。

In a post to the project’s announcements mailing list, OpenBSD founder Theo de Raadt highlights a host of improvements included with the latest version and writes that the project remains “proud of OpenBSD’s record of more than thirty years with only two remote holes in the default install.”

在项目公告邮件列表的一篇帖子中，OpenBSD 创始人 Theo de Raadt 强调了最新版本中包含的诸多改进，并写道，该项目仍然“为 OpenBSD 保持了三十多年来默认安装中仅有两个远程漏洞的记录而感到自豪”。

The latest OpenBSD version brings new features and improvements across the board. These changes, particularly the new Intel Arc support and expanded virtual address space, should improve compatibility with modern graphics cards and allow the system to map more than 4GB of VRAM.

最新的 OpenBSD 版本带来了全面的新功能和改进。这些变化，特别是对 Intel Arc 的新支持和扩展的虚拟地址空间，应能提高与现代显卡的兼容性，并允许系统映射超过 4GB 的显存（VRAM）。

Some of the major updates noted in the release newsletter are as follows: Added support for Intel Arc A-Series (DG2/Alchemist) graphics cards. 512GB kernel virtual address space on AMD64, up from 4GB, allowing VRAM mapping above 4GB. Added hibernation support for ARM64 systems. A new RPKI-to-router daemon: rtrd(8). RISC-V improvements including kernel support for the ‘V’ vector extension and support for Advanced Interrupt Architecture. Wireless network driver additions and improvements, including 802.11n and 40 MHz channels for the qwx(4) wireless driver. Added support for up to 64 virtual CPUs per guest virtual machine. Security and internal improvements for LibreSSL 4.4.0 and OpenSSH 10.6. Improvements to the vmm/vmd virtualization stack.

发布通讯中提到的部分主要更新如下：增加了对 Intel Arc A 系列（DG2/Alchemist）显卡的支持。AMD64 上的内核虚拟地址空间从 4GB 增加到 512GB，允许映射 4GB 以上的显存。增加了对 ARM64 系统的休眠支持。新增了一个 RPKI 到路由器的守护进程：rtrd(8)。RISC-V 的改进包括内核对“V”向量扩展的支持以及对高级中断架构（Advanced Interrupt Architecture）的支持。无线网络驱动程序的增加和改进，包括为 qwx(4) 无线驱动程序提供 802.11n 和 40 MHz 信道支持。增加了每个客户虚拟机最多支持 64 个虚拟 CPU 的功能。LibreSSL 4.4.0 和 OpenSSH 10.6 的安全性和内部改进。对 vmm/vmd 虚拟化堆栈的改进。

The new OpenBSD also retires support for Loongson architecture after the port stopped working with the Clang 22 compiler. If you’re interested in reading over all the changes that come with the new OpenBSD 8.0, you can take a look at the release announcement.

由于 Loongson 架构的移植版本无法再与 Clang 22 编译器协同工作，新版 OpenBSD 也停止了对该架构的支持。如果您有兴趣阅读 OpenBSD 8.0 带来的所有变更，可以查看发布公告。

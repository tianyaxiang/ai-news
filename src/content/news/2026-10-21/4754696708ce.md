针对每种架构的许多预构建软件包：

请参阅镜像站点上的以下文件，以获取有关如何在您的机器上安装 OpenBSD 8.0 的详细信息：

Quick installer information for people familiar with OpenBSD, and the use of the "disklabel -E" command. If you are at all confused when installing OpenBSD, read the relevant INSTALL.* file as listed above!

为熟悉 OpenBSD 的用户提供的快速安装指南，以及关于“disklabel -E”命令的使用说明。如果您在安装 OpenBSD 时有任何困惑，请阅读上述相关的 INSTALL.* 文件！

If your machine can boot from CD, you can write install80.iso or cd80.iso to a CD and boot from it. Refer to INSTALL.alpha for more details.

如果您的机器可以从 CD 启动，您可以将 install80.iso 或 cd80.iso 写入 CD 并从中启动。有关更多详细信息，请参阅 INSTALL.alpha。

If your machine can boot from CD, you can write install80.iso or cd80.iso to a CD and boot from it. You may need to adjust your BIOS options first.

如果您的机器可以从 CD 启动，您可以将 install80.iso 或 cd80.iso 写入 CD 并从中启动。您可能需要先调整 BIOS 选项。

If your machine can boot from USB, you can write install80.img or miniroot80.img to a USB stick and boot from it.

如果您的机器可以从 USB 启动，您可以将 install80.img 或 miniroot80.img 写入 USB 闪存盘并从中启动。

If you can't boot from a CD, floppy disk, or USB, you can install across the network using PXE as described in the included INSTALL.amd64 document.

如果您无法从 CD、软盘或 USB 启动，您可以按照随附的 INSTALL.amd64 文档中的说明，通过 PXE 进行网络安装。

If you are planning to dual boot OpenBSD with another OS, you will need to read INSTALL.amd64.

如果您计划将 OpenBSD 与其他操作系统双启动，则需要阅读 INSTALL.amd64。

Depending on your hardware, you can write install80.iso or cd80.iso to a CD and boot from it, or write a system specific miniroot to an SD card and boot from it after connecting to the serial console. Refer to INSTALL.armv64 for more details.

根据您的硬件情况，您可以将 install80.iso 或 cd80.iso 写入 CD 并从中启动，或者将特定于系统的 miniroot 写入 SD 卡，并在连接到串行控制台后从中启动。有关更多详细信息，请参阅 INSTALL.armv64。

Write a system specific miniroot to an SD card and boot from it after connecting to the serial console. Refer to INSTALL.armv7 for more details.

将特定于系统的 miniroot 写入 SD 卡，并在连接到串行控制台后从中启动。有关更多详细信息，请参阅 INSTALL.armv7。

Boot over the network by following the instructions in INSTALL.hppa or the hppa platform page.

按照 INSTALL.hppa 或 hppa 平台页面中的说明通过网络启动。

If your machine can boot from CD, you can write install80.iso or cd80.iso to a CD and boot from it. You may need to adjust your BIOS options first.

如果您的机器可以从 CD 启动，您可以将 install80.iso 或 cd80.iso 写入 CD 并从中启动。您可能需要先调整 BIOS 选项。

If your machine can boot from USB, you can write install80.img or miniroot80.img to a USB stick and boot from it.

如果您的机器可以从 USB 启动，您可以将 install80.img 或 miniroot80.img 写入 USB 闪存盘并从中启动。

If you can't boot from a CD, floppy disk, or USB, you can install across the network using PXE as described in the included INSTALL.i386 document.

如果您无法从 CD、软盘或 USB 启动，您可以按照随附的 INSTALL.i386 文档中的说明，通过 PXE 进行网络安装。

If you are planning on dual booting OpenBSD with another OS, you will need to read INSTALL.i386.

如果您计划将 OpenBSD 与其他操作系统双启动，则需要阅读 INSTALL.i386。

Write miniroot80.img to the start of the CF or disk, and boot normally.

将 miniroot80.img 写入 CF 卡或磁盘的起始位置，然后正常启动。

Copy 'boot' and 'bsd.rd' to a Mach or UniOS partition, and boot the bootloader from the PROM, and then bsd.rd from the bootloader. Refer to the instructions in INSTALL.luna88k for more details.

将 'boot' 和 'bsd.rd' 复制到 Mach 或 UniOS 分区，从 PROM 启动引导加载程序，然后从引导加载程序启动 bsd.rd。有关更多详细信息，请参阅 INSTALL.luna88k 中的说明。

Burn the install80.iso image from a mirror site to a CDROM, and power on your machine while holding down the C key until the display turns on and shows OpenBSD/macppc boot.

将镜像站点上的 install80.iso 映像刻录到 CDROM，并在按住 C 键的同时打开机器电源，直到显示屏亮起并显示 OpenBSD/macppc 启动界面。

Alternatively, at the Open Firmware prompt, enter boot cd:,ofwboot /8.0/macppc/bsd.rd

或者，在 Open Firmware 提示符下，输入 boot cd:,ofwboot /8.0/macppc/bsd.rd

After connecting a serial port, boot bsd.rd over the network via DHCP/tftp. Refer to the instructions in INSTALL.octeon for more details.

连接串行端口后，通过 DHCP/tftp 通过网络启动 bsd.rd。有关更多详细信息，请参阅 INSTALL.octeon 中的说明。

To install, write install80.img or miniroot80.img to a USB stick, plug it into the machine and choose the OpenBSD install menu item in Petitboot. Refer to the instructions in INSTALL.powerpc64 for more details.

要进行安装，请将 install80.img 或 miniroot80.img 写入 USB 闪存盘，将其插入机器，并在 Petitboot 中选择 OpenBSD 安装菜单项。有关更多详细信息，请参阅 INSTALL.powerpc64 中的说明。

To install, write install80.img or miniroot80.img to a USB stick, and boot with that drive plugged in. Make sure you also have the microSD card plugged in that shipped with the HiFive Unmatched board. Refer to the instructions in INSTALL.riscv64 for more details.

要进行安装，请将 install80.img 或 miniroot80.img 写入 USB 闪存盘，并在插入该驱动器的情况下启动。请确保同时插入了随 HiFive Unmatched 板附带的 microSD 卡。有关更多详细信息，请参阅 INSTALL.riscv64 中的说明。

Burn the image from a mirror site to a CDROM, boot from it, and type boot cdrom.

将镜像站点上的映像刻录到 CDROM，从中启动，然后输入 boot cdrom。

If this doesn't work, or if you don't have a CDROM drive, you can write floppy80.img or floppyB80.img (depending on your machine) to a floppy and boot it with boot floppy. Refer to INSTALL.sparc64 for details.

如果此方法无效，或者您没有 CDROM 驱动器，您可以将 floppy80.img 或 floppyB80.img（取决于您的机器）写入软盘，并使用 boot floppy 启动。有关详细信息，请参阅 INSTALL.sparc64。

Make sure you use a properly formatted floppy with NO BAD BLOCKS or your install will most likely fail.

请确保使用格式正确且没有坏块的软盘，否则您的安装很可能会失败。

You can also write miniroot80.img to the swap partition on the disk and boot with boot disk:b.

您也可以将 miniroot80.img 写入磁盘上的交换分区，并使用 boot disk:b 启动。

If nothing works, you can boot over the network as described in INSTALL.sparc64.

如果以上方法均无效，您可以按照 INSTALL.sparc64 中的说明通过网络启动。

如果您已经拥有 OpenBSD 7.9 系统且不想重新安装，可以在升级指南中找到升级说明和建议。

# AlpineBSD

Welcome to AlpineBSD! AlpineBSD is an operating system based on the NetBSD kernel with a userspace inspired by Alpine Linux and the objective of making it possible to use as little AI-generated software as possible.

欢迎来到 AlpineBSD！AlpineBSD 是一个基于 NetBSD 内核的操作系统，其用户空间受到 Alpine Linux 的启发，旨在尽可能减少对人工智能生成软件的使用。

There is no LLM output included in the base system or main package repository (AlpineBSD AI policy). AlpineBSD is a work in progress. There is currently no installer available. For the adventurous, a very high-level installation guide is available here.

基础系统或主软件包仓库中不包含任何大语言模型（LLM）输出内容（AlpineBSD AI 政策）。AlpineBSD 目前仍处于开发阶段，尚无安装程序可用。对于勇于尝试的用户，此处提供了一份非常简略的安装指南。

Compared to NetBSD AlpineBSD ships the NetBSD kernel, libc, and essential platform-specific tools like mount. NOTICE: The NetBSD kernel has spotty hardware support, much less so than Linux. You cannot necessarily expect AlpineBSD to work on any random computer you have lying around. Consult the NetBSD supported hardware list for more information, particularly for laptops.

与 NetBSD 相比，AlpineBSD 搭载了 NetBSD 内核、libc 以及诸如 mount 等必要的平台特定工具。注意：NetBSD 内核的硬件支持情况参差不齐，远不如 Linux。你不能指望 AlpineBSD 能在随手找来的任何电脑上运行。请查阅 NetBSD 支持的硬件列表以获取更多信息，特别是针对笔记本电脑的部分。

Compared to Alpine Linux AlpineBSD ships with the apk-tools package manager and busybox, and a slightly more GNU-oriented userspace, preferring e.g. GNU make over BSD make. AlpineBSD is not a fork of Alpine Linux, its package collection is original (though many packages are ultimately based on aports). Alpine Linux uses the OpenRC init system. Currently, AlpineBSD uses s6 and we intend to add OpenRC as an alternative.

与 Alpine Linux 相比，AlpineBSD 搭载了 apk-tools 软件包管理器和 busybox，并拥有一个更偏向 GNU 的用户空间，例如更倾向于使用 GNU make 而非 BSD make。AlpineBSD 并非 Alpine Linux 的分支，其软件包集合是原创的（尽管许多软件包最终基于 aports）。Alpine Linux 使用 OpenRC 初始化系统。目前，AlpineBSD 使用 s6，我们计划增加 OpenRC 作为替代方案。

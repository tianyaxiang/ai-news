Today we're excited to release VEKTOR 2.0.10. It lets you install VEKTOR once and find its models and tools already in place, with one list in Config that shows every add-on and keeps each one current after an upgrade.

今天我们很高兴发布 VEKTOR 2.0.10。它允许您在安装一次 VEKTOR 后，即可直接使用其模型和工具。配置界面中有一个列表，显示了所有插件，并在升级后保持每个插件的最新状态。

VEKTOR 2.0.10: detector scores before and after, and the add-ons that install themselves What 2.0.10 changes: detector scores before and after, and the add-ons that install themselves. This release retrains the AI-text detector and averages it with the previous models, so the file stays 82 MB.

VEKTOR 2.0.10：检测器前后的评分，以及自动安装的插件。2.0.10 的变化包括：检测器前后的评分，以及自动安装的插件。此版本重新训练了 AI 文本检测器，并将其与之前的模型进行平均，因此文件大小保持在 82 MB。

On held-out text, with the line set so one human text in twenty is flagged, it now catches about 97% of older machine text and 94% of Claude text. It is also more accurate to real writing: on 99 emails one person wrote before 2023, 4% were flagged, where an earlier build of this model flagged about one in five.

在留出的测试文本上，当阈值设定为每 20 篇人类文本中标记 1 篇时，它现在可以捕获约 97% 的旧机器文本和 94% 的 Claude 文本。它对真实写作的判断也更准确：在某人 2023 年前撰写的 99 封电子邮件中，只有 4% 被标记，而该模型的早期版本标记了约五分之一。

When another model rewrote machine text three times while seeing the detector score, 1% of 87 held-out texts got under the line (8% before). The idea behind both changes is the same: do the preparation once, in the background, so the feature is ready when you open it.

当另一个模型在查看检测器评分的同时对机器文本进行三次重写时，87 篇留出文本中只有 1% 低于阈值（之前为 8%）。这两项改进背后的理念相同：在后台完成一次性准备工作，以便您打开功能时它已准备就绪。

What does it mean that add-ons install themselves? VEKTOR uses a handful of downloaded parts: a video tool, a picture upscaler, a cutout model, a depth model, the grammar checker, the memory-protection scanner, the search models and the AI-text detector. Until now some of them waited for a button press on their own panel.

“插件自动安装”是什么意思？VEKTOR 使用少量下载组件：视频工具、图片放大器、抠图模型、深度模型、语法检查器、内存保护扫描器、搜索模型和 AI 文本检测器。在此之前，其中一些组件需要用户在各自的面板上点击按钮才能安装。

In 2.0.10 the app fetches them in the background after it starts, one at a time, and checks them again after every upgrade.

在 2.0.10 版本中，应用程序会在启动后在后台逐个获取这些组件，并在每次升级后重新检查它们。

Each add-on reports one of four states: ready, working, missing or outdated. A short loop walks the list in order, starts the fix for anything missing or outdated, waits for it to finish and moves to the next.

每个插件报告四种状态之一：就绪、工作中、缺失或过期。一个简短的循环按顺序遍历列表，启动对缺失或过期项的修复，等待其完成后再处理下一项。

A file counts as current only if its size and SHA-256 match the pin shipped with that version of VEKTOR. After an upgrade that changes a pin, the add-on shows as outdated and the same loop fetches the new file.

只有当文件的大小和 SHA-256 与该版本 VEKTOR 附带的固定值匹配时，文件才被视为最新。在更改固定值的升级后，插件会显示为过期，同样的循环会获取新文件。

Each add-on gets two tries per start, so a flaky connection does not turn into a retry storm. You stay in control. In Config, Preferences, "Keep ready automatically" turns the whole thing off, "Check for updates" lists every add-on with its state, and setting VEKTOR_NO_DOWNLOAD=1 stops downloads for machines that must stay offline.

每个插件在每次启动时有两次尝试机会，因此不稳定的连接不会导致重试风暴。您始终拥有控制权。在“配置”的“首选项”中，“自动保持就绪”可关闭整个功能，“检查更新”列出每个插件及其状态，设置 VEKTOR_NO_DOWNLOAD=1 可为必须保持离线的机器停止下载。

The big packs you choose yourself, such as voice, music and picture-generation models, stay on their own panels.

您自行选择的大型包（如语音、音乐和图片生成模型）保留在各自的面板上。

How do you make a detector better without making it bigger? We kept the 82 MB size, running two models side by side would have doubled it. Instead we trained a second model from the first on a wider mix: our Claude, Gemini and web text, ChatGPT-style answers, public sets of mixed domains, and real everyday email.

如何在不增加体积的情况下改进检测器？我们保持了 82 MB 的大小，因为并排运行两个模型会使体积翻倍。相反，我们基于第一个模型，在更广泛的数据集上训练了第二个模型：包括我们的 Claude、Gemini 和网络文本、ChatGPT 风格的回答、公共混合领域数据集以及真实的日常电子邮件。

Then we attacked it the way a user would: a model rewrote machine text three times, saw the detector score after each round, and kept its best rewrite. The rewrites that got through went back into training, and we averaged the weights of three models, which gives one file with the same shape.

然后，我们以用户的方式对其进行攻击：一个模型将机器文本重写了三次，在每一轮后查看检测器评分，并保留其最佳重写版本。通过检测的重写文本被放回训练中，我们将三个模型的权重进行平均，从而得到一个形状相同的文件。

Averaging fine-tunes of one base model is cheap and works because they all start from the same weights and move only a short way. The new model alone caught more but slipped more often under rewrites (6% of the 87 texts); averaged three parts new to one part earlier, it kept the gains and the attack result.

对同一个基础模型的微调进行平均成本低廉且有效，因为它们都从相同的权重开始，且移动距离很短。新模型本身捕获率更高，但在重写攻击下更容易漏检（87 篇文本中的 6%）；通过将三份新模型与一份旧模型平均，它保持了性能提升和抗攻击效果。

One lesson from the email test: the first version looked perfect when we scored it on its own, then flagged one email in five inside the app. The app joins a text's lines into one stream before it scores, and the emails were hard-wrapped, so the model had learned that wrapped lines mean a person.

电子邮件测试的一个教训是：第一个版本在单独评分时看起来很完美，但在应用程序内却标记了五分之一的邮件。应用程序在评分前会将文本行合并为一个流，而电子邮件是硬换行的，因此模型学会了换行意味着是人写的。

We now train on text joined the same way the app joins it, and we judge every candidate through the app's own scoring path. Every number below uses the same rule: the line is set at the 95th percentile of scores on 360 held human texts, so the detector flags about one human text in twenty.

我们现在使用与应用程序相同的合并方式对文本进行训练，并通过应用程序自身的评分路径来评估每个候选对象。下方的每个数字都使用相同的规则：阈值设定在 360 篇留出人类文本评分的第 95 百分位，因此检测器大约标记二十篇人类文本中的一篇。

在两组留出的人类文本集上，人类误报率分别为 4% 和 5%。

单台机器，每组运行一次，一个攻击者模型，攻击行统计了在 1/20 阈值下经过三轮重写后仍被捕获的文本。最后两行是小规模检查，即 31 段文本和 99 封邮件，因此它们显示的是趋势而非精确测量，且邮件来自同一作者。Gemini 的分数下滑了一个百分点，我们保留了它。

Detectors are weakest on very short text, and under about 60 words the score is still noise. The model also downloads by itself now. The Detector shows "downloading the model in the background" while it runs, and retries ten minutes later if the connection drops. Until the file is in place it uses the stock-phrase list alone and says so.

检测器在处理极短文本时最弱，在 60 字左右以下，评分仍属于噪声。该模型现在也可以自动下载。检测器在运行时会显示“正在后台下载模型”，如果连接中断，十分钟后会重试。在文件到位之前，它仅使用常用短语列表并会进行提示。

Where did the converter programs go? The Allow tick boxes for Pandoc, LibreOffice, FFmpeg, ImageMagick, 7-Zip and Poppler used to sit at the bottom of Convert and Compress. They now live in Config, under "Programs for converting", and Convert and Compress end after their own options.

转换程序去哪了？Pandoc、LibreOffice、FFmpeg、ImageMagick、7-Zip 和 Poppler 的“允许”复选框过去位于“转换和压缩”的底部。它们现在位于“配置”下的“转换程序”中，“转换和压缩”界面在显示其自身选项后即结束。

The rule has not changed: only programs you tick run, one at a time, on a private copy of your file in a temporary folder that is deleted afterwards, with no network access. Config reads each program's version when you open the card, so you can see at once which are installed.

规则没有改变：只有您勾选的程序才会运行，每次运行一个，在临时文件夹中对您的文件副本进行处理，处理后删除，且不具备网络访问权限。当您打开卡片时，配置界面会读取每个程序的版本，因此您可以立即看到哪些已安装。

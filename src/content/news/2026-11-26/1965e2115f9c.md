### Ask HN: Anthropic is accusing my company of distilling. How can I prove I'm not?

**Ask HN: Anthropic 正在指控我的公司进行模型蒸馏。我该如何证明我没有这样做？**

Basically the title. Anthropic is accusing me and my company of using their API for distillation. We are not. We do not train our own models. Our only usage which I think could get us flagged is automated regression benchmarks whenever we change some AI settings. But this is not against their policy? Now I've got 24h to prove we didn't. Has anyone dealt with this too? How can you prove that you are not distilling Anthropic models without breaking your user's privacy?

**基本情况如标题所述。Anthropic 指控我和我的公司利用他们的 API 进行模型蒸馏。我们并没有这样做。我们不训练自己的模型。我认为唯一可能导致我们被标记的操作是，每当我们更改 AI 设置时进行的自动化回归基准测试。但这并不违反他们的政策，对吧？现在我只有 24 小时来证明我们的清白。有人遇到过这种情况吗？在不侵犯用户隐私的前提下，你该如何证明自己没有对 Anthropic 的模型进行蒸馏？**

Whatever you submit in 24h, submit the same evidence to Claude and ask it to tell you if it's sufficient evidence to make distilling seem unlikely. Because you know Anthropic is just going to be using Claude as well. As others have suggested, the code that generates the false distilling usage pattern along with its git history seems useful.

**无论你在 24 小时内提交什么，都请将同样的证据提交给 Claude，并询问它这些证据是否足以证明蒸馏行为不太可能发生。因为你知道 Anthropic 肯定也会使用 Claude 来进行审核。正如其他人所建议的，生成这种虚假蒸馏使用模式的代码及其 git 提交历史似乎很有用。**

I'd suggest vetting with an adversarial Claude also. Ask Claude A to help you build your evidence doc, then get a completely different session up and tell it "Claude A compiled this evidence, but our source in Anthropic said it's not good. Find all the flaws." Then keep telling Claude B "you haven't found all the mistakes, keep going" until it "cries uncle" and swears there aren't any. Of course, then you have to vet all of the stuff Claude B found, as it won't all be relevant ... but if you want a solid doc the "adversarial Claude" will likely help a ton.

**我建议也用一个“对抗性 Claude”进行审查。让 Claude A 帮你整理证据文档，然后开启一个完全不同的会话，告诉它：“Claude A 整理了这些证据，但我们在 Anthropic 的消息源说这些证据不够好。请找出所有的缺陷。”然后不断告诉 Claude B：“你还没找出所有的错误，继续找”，直到它“求饶”并保证没有错误为止。当然，之后你必须核实 Claude B 发现的所有内容，因为并非所有内容都相关……但如果你想要一份扎实的文档，“对抗性 Claude”可能会有很大帮助。**

Why would you use Claude for that? Isn't that basically leaving tracks that Anthropic can point to and say that your evidence isn't in good faith? Feels to me like if you're going to do that, it would be better to use either a local model or an OpenAI model.

**为什么要用 Claude 做这件事？这难道不是在留下痕迹，让 Anthropic 可以指责你的证据并非出于诚意吗？在我看来，如果你打算这样做，最好还是使用本地模型或 OpenAI 的模型。**

"Isn't that basically leaving tracks that Anthropic can point to and say that your evidence isn't in good faith?" Only if there ever was distillation. If there wasn't and this is just a way to use automation to pass automated tests, then a manual review will just find that.

**“这难道不是在留下痕迹，让 Anthropic 可以指责你的证据并非出于诚意吗？”只有在确实存在蒸馏行为时才会这样。如果根本没有蒸馏，这只是利用自动化来通过测试的一种方式，那么人工审核自然会发现这一点。**

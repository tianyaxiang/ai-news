# Ladybird browser's first downloadable alpha is surprisingly capable

Note: At the time of writing, I was unaware of criticism directed at Ladybird creator Andreas Kling’s public statements. Readers interested in this background can find further context in accounts by Kelson Vibber and Drew DeVault. After four years of work to build a browser engine from scratch, the Ladybird project released its first downloadable alpha on November 23, offering prebuilt versions for macOS and Linux. Previously, curious users had to compile the browser themselves from its source. Now it’s an installable package with automatic updating.

注：在撰写本文时，我并未意识到针对 Ladybird 创建者 Andreas Kling 公开发表言论的批评。感兴趣的读者可以在 Kelson Vibber 和 Drew DeVault 的文章中找到更多背景信息。经过四年的从零构建浏览器引擎工作，Ladybird 项目于 11 月 23 日发布了首个可下载的 Alpha 版本，提供 macOS 和 Linux 的预构建版本。此前，好奇的用户必须自行从源代码编译该浏览器。现在，它已成为一个支持自动更新的可安装软件包。

Ladybird is most notable for what it isn’t: another browser fork. Where Chrome, Edge, Brave, and Opera all run on Google’s Blink engine, and Firefox depends on Gecko, Ladybird’s rendering engine and its LibJS JavaScript engine were written from scratch. “The engine is our own, built from the ground up, and not a fork,” project lead Andreas Kling wrote in Monday’s announcement. “The browser around it is modest, but functional.”

Ladybird 最引人注目的地方在于它不是什么：它不是另一个浏览器分支。Chrome、Edge、Brave 和 Opera 都运行在 Google 的 Blink 引擎上，而 Firefox 依赖于 Gecko，但 Ladybird 的渲染引擎及其 LibJS JavaScript 引擎均是从零开始编写的。项目负责人 Andreas Kling 在周一的公告中写道：“该引擎是我们自己的，从头构建，并非分支。围绕它构建的浏览器虽然朴素，但功能齐全。”

A fourth engine: Nearly the entire modern web currently runs on three browser engines. There’s WebKit (Safari), Gecko (Firefox), and the biggest of them all, Blink (Chromium). Those limited options mean that web developers often end up optimizing sites for Chromium specifically, since that’s where the majority of traffic is, and as a result, the whole web platform tends to follow suit toward whatever the dominant engine supports.

第四个引擎：目前几乎整个现代网络都运行在三个浏览器引擎上。它们分别是 WebKit (Safari)、Gecko (Firefox) 以及其中最大的 Blink (Chromium)。这些有限的选择意味着 Web 开发人员往往最终会专门针对 Chromium 优化网站，因为那里拥有大部分流量，结果导致整个 Web 平台往往倾向于支持主导引擎所支持的功能。

An independent implementation of web standards has value not just by providing additional competition in the market, but because it can’t help but reveal places where sites depend on Chromium behaviors rather than published specifications. The fact that Ladybird exists isn’t likely to shift the market tides any time soon, but every new browser engine increases the number of implementations that standards can be tested against, which can surface Chromium-specific assumptions and push the ecosystem toward the spec.

独立实现 Web 标准不仅可以通过在市场上提供额外的竞争来体现价值，而且它不可避免地会揭示出哪些网站依赖于 Chromium 的特定行为而非已发布的规范。Ladybird 的存在不太可能在短期内改变市场格局，但每一个新的浏览器引擎都增加了标准可测试的实现数量，这可以暴露出 Chromium 特有的假设，并推动生态系统向规范靠拢。

Some background: The Ladybird project was borne out of Kling’s SerenityOS project, an attempt to develop a new independent OS from scratch, before splitting off as a separate project. Kling formed the Ladybird Browser Initiative, a 501(c)(3) nonprofit funded by sponsorships and donations. The project’s site highlights that there are no sponsored search engine deals supporting the project like many other popular browsers, and sponsoring entities have no say in the project roadmap.

背景：Ladybird 项目源于 Kling 的 SerenityOS 项目（一项从零开始开发全新独立操作系统的尝试），随后作为一个独立项目分离出来。Kling 成立了 Ladybird 浏览器倡议组织，这是一个由赞助和捐款资助的 501(c)(3) 非营利组织。项目网站强调，该项目不像许多其他流行浏览器那样有赞助的搜索引擎交易支持，且赞助实体对项目路线图没有发言权。

The Ladybird alpha is a rolling release channel that updates automatically, and the downloadable package is a huge step to getting the browser onto the PCs of everyday users. “Ladybird improves quickly, and until now you had to build it from source to see that,” Kling wrote. Though the browser began as C++, in keeping with the ethos of SerenityOS, the project has since started shifting toward Rust, starting with its JavaScript engine.

Ladybird Alpha 是一个自动更新的滚动发布渠道，可下载的软件包是让该浏览器进入普通用户电脑的一大步。Kling 写道：“Ladybird 改进迅速，而在此之前，你必须从源代码构建才能看到这一点。”虽然该浏览器最初是用 C++ 编写的，但为了符合 SerenityOS 的精神，该项目已开始转向 Rust，并从其 JavaScript 引擎开始。

While it’s exciting to have a new engine option for browsing, the project leader notes that this is still a very early release. The browser build contains a built-in tool for reporting any websites that fail to render or crash the browser. Kling writes, “We want security nerds to hack it! A new browser gets hacked, over and over, and that’s part of the process, so we make no promises about security today.” Microsoft users are still out in the cold on this one for now. The project says that future support for Windows is planned, but it’s macOS and Linux only for now.

虽然拥有一个新的浏览器引擎选择令人兴奋，但项目负责人指出，这仍是一个非常早期的版本。该浏览器构建版本包含一个内置工具，用于报告任何无法渲染或导致浏览器崩溃的网站。Kling 写道：“我们希望安全极客来破解它！一个新的浏览器被反复破解是过程的一部分，所以我们今天不对安全性做任何承诺。”目前，微软用户暂时无法使用。项目方表示计划在未来支持 Windows，但目前仅支持 macOS 和 Linux。

Impressions: I tested the Ladybird alpha version 2026.47.8 on my AceMagic W1 mini PC AMD Ryzen 7 8745HS with 16GB DDR5 and running Fedora Linux 44 with the new KDE Plasma 6.8.3, and the most surprising thing about the alpha build was how little it feels like alpha software.

印象：我在我的 AceMagic W1 迷你电脑（AMD Ryzen 7 8745HS，16GB DDR5，运行 Fedora Linux 44 和新的 KDE Plasma 6.8.3）上测试了 Ladybird Alpha 2026.47.8 版本，该 Alpha 版本最令人惊讶的是它一点也不像 Alpha 软件。

The browser seemed to handle most anything I threw at it without issue. Day-to-day tabbed browsing mechanics felt snappy and normal. A 50MB test video file downloaded quickly and smoothly. With a dozen tabs open, switching between them was instant, and the browser felt responsive throughout. Options menus were surprisingly fleshed out for a build this young.

该浏览器似乎能毫无问题地处理我交给它的几乎所有任务。日常的标签页浏览机制感觉既灵敏又正常。一个 50MB 的测试视频文件下载得既快又顺畅。打开十几个标签页后，它们之间的切换是瞬间完成的，浏览器全程感觉响应迅速。对于这样一个年轻的版本来说，选项菜单的完善程度令人惊讶。

Google Maps loaded instantly, located me, and handled everything I threw at it: adding and removing layers, zooming out from the Midwest, and dropping into Street View in Alberta, Canada in around three seconds. Everything rendered fast enough that my mini PC’s fan spun up noticeably. GitHub’s site, including repository navigation, worked without a hitch. So did YouTube and the news sites I tried.

Google 地图加载迅速，定位准确，并处理了我交给它的所有操作：添加和删除图层、从中西部缩小地图，以及在大约三秒钟内进入加拿大阿尔伯塔省的街景视图。所有内容的渲染速度都足够快，以至于我迷你电脑的风扇明显转动起来。GitHub 网站（包括仓库导航）运行顺畅。YouTube 和我尝试的新闻网站也是如此。

I could stall the browser, but it took some effort. With about 10 tabs open, I was streaming a 4K test video file from my personal Jellyfin server. Everything worked fine at first, but after skipping around in the file over and over again, the browser eventually got stuck. Mind you, this is an alpha build that I was trying to trip up, not a representation of something inherently broken.

我确实可以让浏览器卡住，但这需要费点劲。在打开大约 10 个标签页的情况下，我从个人的 Jellyfin 服务器流式传输一个 4K 测试视频文件。起初一切正常，但在文件中反复跳转后，浏览器最终卡住了。请注意，这是一个我试图让其出错的 Alpha 版本，并不代表它本身有什么本质上的缺陷。

After spending an evening with Ladybird, I can say that while it won’t be replacing Firefox for me anytime soon, I was genuinely impressed that a scratch-made engine could perform this well in such an early state. Most new browser projects are forks of something that already exists. Ladybird is the rare exception, an engine written from nothing, and the alpha runs well enough that if you have a Mac or Linux PC handy, it’s worth downloading a build and poking around yourself. Just remember Kling’s warning: This is nowhere near trustworthy enough.

在与 Ladybird 共度一个晚上后，我可以肯定地说，虽然它短期内不会取代 Firefox，但我确实对一个从零开始构建的引擎在如此早期的阶段就能有这样的表现感到印象深刻。大多数新的浏览器项目都是现有软件的分支。Ladybird 是一个罕见的例外，一个从无到有编写的引擎，而且这个 Alpha 版本运行得足够好，如果你手头有 Mac 或 Linux 电脑，值得下载一个版本亲自体验一下。但请记住 Kling 的警告：它还远未达到足够可信的程度。

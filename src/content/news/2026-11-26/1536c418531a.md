# AgentOne 1.3.1: Chat Sync Across Your Devices

AgentOne 1.3.1 adds chat sync, so your conversations can follow you across devices and stay backed up in your account. This release also makes extensions easier to set up, adds right-to-left text support, and shrinks the Windows installer.

AgentOne 1.3.1 版本增加了聊天同步功能，让您的对话可以在不同设备间同步，并备份到您的账户中。此版本还简化了扩展程序的设置流程，增加了对从右向左书写文字的支持，并缩小了 Windows 安装包的体积。

Sync Your Chats Your chats can now sync between your devices, which works as a backup too. Chat sync is off by default. Turn it on in Settings > Sync under Sync chats, where you have three choices: Off, All chats, and Only chats I choose. With Only chats I choose, chats stay on your device until you turn on Sync This Chat in a chat's sidebar menu. With All chats, every chat syncs, and you can still stop syncing any single chat from its menu.

同步您的聊天记录：您的聊天记录现在可以在设备间同步，这也起到了备份的作用。聊天同步功能默认处于关闭状态。您可以在“设置”>“同步”下的“同步聊天”中开启它，这里有三个选项：关闭、所有聊天和仅我选择的聊天。选择“仅我选择的聊天”时，聊天记录会保留在本地，直到您在聊天侧边栏菜单中开启“同步此聊天”。选择“所有聊天”时，所有对话都会同步，您仍然可以在单个聊天的菜单中停止同步。

Turning chat sync on opens a dialog that explains the rules: If a chat is changed on two devices before they sync, the most recent version is kept and the other is replaced. Deleting a chat on one device deletes it on your other devices too. Chats in projects stay on the device only and don't sync. Local changes upload a few seconds after you stop changing a chat. Other devices check for new chats when you open or switch back to AgentOne, every 5 minutes while it's open and in front, and every 30 minutes in the background.

开启聊天同步时会弹出一个对话框说明规则：如果一个聊天在同步前在两台设备上都被修改，系统将保留最新版本并覆盖另一个。在一台设备上删除聊天也会在其他设备上将其删除。项目中的聊天记录仅保留在本地，不会同步。本地更改会在您停止编辑聊天几秒钟后上传。当您打开或切换回 AgentOne 时，其他设备会检查新聊天；在应用处于前台打开状态时，每 5 分钟检查一次；在后台运行时，每 30 分钟检查一次。

A chat's menu shows its sync status (Synced, Waiting to Sync, Syncing…, Not Syncing, or Too Large to Sync for very large chats that can't sync), plus which device it was first synced from, which device it was last synced from, and when. You can set a Device name in Account settings instead of the default "This device", and Chats synced in Sync settings shows your progress. Chat sync requires a Pro plan or higher.

聊天菜单会显示其同步状态（已同步、等待同步、正在同步……、未同步，或对于无法同步的超大聊天显示“太大而无法同步”），以及它首次同步的设备、最后一次同步的设备和时间。您可以在“账户设置”中设置设备名称，以取代默认的“此设备”；“同步设置”中的“已同步聊天”会显示进度。聊天同步功能需要 Pro 或更高等级的订阅计划。

Extensions Are Easier to Set Up I smoothed out a few rough spots on the Extensions pages. Extensions that need you to sign in now show a "Sign in to finish setting up" notice with a Sign in button (previously "Connect"). If an extension couldn't connect, its page says "This extension couldn't connect" with a retry button, and tucks the technical error inside a collapsible details section.

扩展程序设置更简单：我优化了扩展程序页面的一些细节。需要登录的扩展程序现在会显示“登录以完成设置”的提示，并配有一个“登录”按钮（之前为“连接”）。如果扩展程序无法连接，页面会显示“此扩展程序无法连接”并提供重试按钮，技术错误信息则被收纳在可折叠的详情部分中。

Extension settings are now organized around a Tools card. Flip one Ask before using tools switch so AgentOne checks with you first each time (except in Auto mode), or choose per tool. This release also fixes extensions signing in twice and stops extensions that failed to start from reloading for no reason. If a local extension crashes or exits, AgentOne now restarts it automatically the next time it uses one of that extension's tools instead of letting the tool fail.

扩展程序设置现在围绕“工具”卡片进行组织。您可以开启“使用工具前询问”开关，让 AgentOne 每次都先征求您的意见（自动模式除外），也可以针对单个工具进行设置。此版本还修复了扩展程序重复登录的问题，并阻止了启动失败的扩展程序无故重新加载。如果本地扩展程序崩溃或退出，AgentOne 现在会在下次使用该扩展程序的工具时自动重启它，而不是直接让工具报错。

Everything Else Better LM Studio detection. AgentOne now uses LM Studio's newer API when fetching models, picking up model names, the loaded model's context length, and vision, tool, and reasoning support automatically instead of guessing. Right-to-left text. Languages like Arabic and Hebrew now display properly in messages, lists, headings, quotes, the message box, and when editing a message.

其他改进：更好的 LM Studio 检测。AgentOne 现在在获取模型时使用 LM Studio 的新版 API，自动识别模型名称、已加载模型的上下文长度，以及视觉、工具和推理支持，无需再进行猜测。支持从右向左书写的文字。阿拉伯语和希伯来语等语言现在可以在消息、列表、标题、引用、消息框以及编辑消息时正常显示。

More reliable Memory and file analysis. The Memory tool now rejects entries that are too long instead of saving them cut off, and gives the AI clearer errors so it can fix the mistake instead of silently saving nothing. File analysis handles newly created files and paths with special characters, URL-encoding, or unusual spaces more reliably. [Beta] account details tool. Ask something like "how many credits do I have left?" and AgentOne can check your plan and remaining credits, after asking for approval first.

更可靠的记忆和文件分析。记忆工具现在会拒绝过长的条目，而不是保存截断的内容，并向 AI 提供更清晰的错误信息，以便它能修正错误，而不是默默地什么都不保存。文件分析功能现在能更可靠地处理新创建的文件，以及包含特殊字符、URL 编码或非常规空格的路径。[测试版] 账户详情工具。询问诸如“我还有多少积分？”之类的问题，AgentOne 在征得您的同意后，可以检查您的订阅计划和剩余积分。

More careful Auto mode. Its default safety prompt now asks before a tool call that edits, overwrites, or deletes something when you only asked for something new to be created, and it reads shell commands more carefully for risky deletes. Smaller Windows installer. It no longer bundles the full Microsoft WebView2 offline installer, making the download much smaller. If a PC is missing WebView2, the installer downloads it.

更谨慎的自动模式。其默认安全提示现在会在工具调用涉及编辑、覆盖或删除操作时进行询问（即使您只是要求创建新内容），并且在读取 Shell 命令时会更仔细地检查风险删除操作。更小的 Windows 安装包。它不再捆绑完整的 Microsoft WebView2 离线安装程序，从而大幅减小了下载体积。如果电脑缺少 WebView2，安装程序会自动下载它。

Drafts stay with their project. An unsent message in a new chat inside a project stays with that project instead of following you to other new chats. Smarter back buttons. Back buttons in Settings, Extensions, and Scheduled Agents now take you to the page you came from instead of always back to the chat. A new animated sine wave loading spinner. The update dialog focuses the Update button automatically, so pressing Enter starts the update. Fixed a glitch in the onboarding splash screen's text animation. Updated app dependencies.

草稿保留在项目中。项目内新聊天中未发送的消息会保留在该项目中，而不会跟随您进入其他新聊天。更智能的返回按钮。设置、扩展程序和定时代理中的返回按钮现在会将您带回上一级页面，而不是总是返回聊天界面。新增了正弦波动画加载图标。更新对话框会自动聚焦“更新”按钮，因此按下回车键即可开始更新。修复了引导启动屏幕文字动画的一个故障。更新了应用依赖项。

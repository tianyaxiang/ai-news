### Objections to .php application being published on ICANN site

ALT.php written in Handel Gothic italic, dark brown text on yellow background. After Automattic's confirmation that they would switch their .vibe application to the replacement string of .php, ICANN has started to publish various objections on the Application Comment Forum (ACF) section of their new gTLD program site. They mostly relate to the confusion and security risk posed by a common filetype (especially in web development) becoming a TLD, similar to the outcry over Google's application for .zip (which was eventually successfully delegated). The other common theme is the objection to a private company effectively trying to claim what is an open-source project.

以 Handel Gothic 斜体书写的 ALT.php，黄色背景上的深棕色文字。在 Automattic 确认将其 .vibe 申请更改为替代字符串 .php 后，ICANN 已开始在其新通用顶级域（gTLD）计划网站的申请评论论坛（ACF）部分发布各种反对意见。这些意见主要涉及将一种常见文件类型（特别是在 Web 开发中）变为顶级域所带来的混淆和安全风险，类似于此前针对谷歌申请 .zip（最终成功授权）所引发的强烈抗议。另一个共同主题是反对一家私营公司试图实际上占有属于开源项目的名称。

The first is by PHP developer Larry Garfield who accused the WordPress parent of "Inappropriate Squatting": PHP is a widely used programming language. It is managed by the PHP project, an informal project at www.php.net. It is also supported by The PHP Foundation, a non-profit organization managed through OpenCollective. No one organization, company, or person owns or controls PHP. Authority within the PHP language and ecosystem is deliberately diffuse.

第一份意见来自 PHP 开发人员 Larry Garfield，他指责 WordPress 的母公司存在“不当抢注”行为：PHP 是一种广泛使用的编程语言。它由 PHP 项目管理，这是一个位于 www.php.net 的非正式项目。它还得到通过 OpenCollective 管理的非营利组织 PHP 基金会的支持。没有任何组织、公司或个人拥有或控制 PHP。PHP 语言和生态系统内的权力是刻意分散的。

Automattic, the company that has attempted to register .php as a TLD, is the owner/author of the WordPress blogging software. WordPress is itself written in PHP and Javascript. However, Automattic has no ownership or control over the PHP language itself. In fact, Automattic and its employees are conspicuously absent from contribution to the PHP project itself, aside from in recent years becoming a large passive donor to The PHP Foundation.

试图注册 .php 作为顶级域的公司 Automattic 是 WordPress 博客软件的所有者/作者。WordPress 本身是用 PHP 和 Javascript 编写的。然而，Automattic 对 PHP 语言本身没有任何所有权或控制权。事实上，除了近年来成为 PHP 基金会的大额被动捐赠者外，Automattic 及其员工在对 PHP 项目本身的贡献方面明显缺席。

For Automattic, or any other company that operates in the PHP space, to try and lay claim to .php as a TLD is grossly inappropriate. There are dozens of other companies, projects, and interested parties that have just as much if not more claim to the name. PHP is a far larger ecosystem than just Automattic. It would be equivalent to Microsoft registering .rust (they use a lot of Rust now, but did not originate the language), or Hashicorp registering .golang, or IBM registering .java. None of those would be reasonable or appropriate, and neither is any one organization owning .php.

对于 Automattic 或任何其他在 PHP 领域运营的公司来说，试图将 .php 占为己有作为顶级域是极其不恰当的。还有数十家其他公司、项目和利益相关方对该名称拥有同样多甚至更多的权利。PHP 是一个比 Automattic 大得多的生态系统。这相当于微软注册 .rust（他们现在使用很多 Rust，但并非该语言的创始者），或者 Hashicorp 注册 .golang，又或是 IBM 注册 .java。这些做法都不合理也不恰当，任何单一组织拥有 .php 也是如此。

One company owning .php would be significantly harmful to the PHP ecosystem, as it would give control over a significant branding and marketing channel to one company that is not engaged in the ecosystem, leading to market confusion and an easily exploitable way for that company to claim more authority and ownership than it actually has. The only organization that has any legitimate claim to register .php would be The PHP Foundation, but they have made no such attempt. The application for .php should be rejected outright as inappropriate "domain squatting." Its approval would be detrimental to a major software ecosystem, and establish a dangerous precedent for one company claiming an entire ecosystem's name without cause.

一家公司拥有 .php 将对 PHP 生态系统造成重大损害，因为它会将一个重要的品牌和营销渠道的控制权交给一家未参与该生态系统的公司，导致市场混乱，并为该公司提供了一种易于利用的方式，使其能够声称拥有比实际更多的权威和所有权。唯一有权注册 .php 的合法组织应该是 PHP 基金会，但他们并未做出此类尝试。对 .php 的申请应作为不当的“域名抢注”予以直接拒绝。其批准将对一个主要的软件生态系统造成损害，并为一家公司无故占有整个生态系统的名称开创一个危险的先例。

WordPress contributor Jamie VanRaalte objected on the grounds of "Part of a pattern - .php should not go to one company" and also said the .wordpress application was a similarly inappropriate power grab of another open-source project: I agree with the comments already made here about .php. [I've been building commercial software in PHP for X years.] PHP is run by the PHP project and supported by The PHP Foundation, and no company owns it.

WordPress 贡献者 Jamie VanRaalte 以“属于某种模式的一部分——.php 不应归于一家公司”为由表示反对，并称 .wordpress 的申请同样是对另一个开源项目不恰当的权力攫取：我同意这里已经提出的关于 .php 的评论。[我使用 PHP 构建商业软件已经 X 年了。] PHP 由 PHP 项目运行并由 PHP 基金会支持，没有任何公司拥有它。

I want to add one thing that's easy to miss when this application is looked at on its own. Knock Knock WHOIS There, LLC is a subsidiary of Automattic, and it has also applied for .wordpress. WordPress is an open source project too, and its trademark is held by the WordPress Foundation, not Automattic. So this is one company applying for the names of two open source ecosystems that it takes part in but does not govern.

我想补充一点，当单独看待这个申请时很容易被忽略。Knock Knock WHOIS There, LLC 是 Automattic 的子公司，它也申请了 .wordpress。WordPress 也是一个开源项目，其商标由 WordPress 基金会持有，而非 Automattic。因此，这是一家公司在申请两个它参与但并不管理的开源生态系统的名称。

Automattic does use PHP heavily, but so do millions of other developers and companies. Using a language doesn't give a company any claim to its name. If .php goes to Automattic, it would decide who can register under the name of a language that belongs to everyone who uses it. If .php should exist at all, it should be held by The PHP Foundation or another neutral body accountable to the PHP community. This application, and the one for .wordpress, should both be rejected.

Automattic 确实大量使用 PHP，但数以百万计的其他开发人员和公司也是如此。使用一种语言并不能赋予公司对其名称的任何权利。如果 .php 归 Automattic 所有，它将决定谁可以在属于所有使用者的语言名称下进行注册。如果 .php 确实应该存在，它应该由 PHP 基金会或其他对 PHP 社区负责的中立机构持有。这个申请以及 .wordpress 的申请都应该被拒绝。

Web developer Ryan Maietta highlighted the "File Extension Confusion and Security Risks" of using an established filetype as a TLD and the risk of people confusing websites using this domain as being officially endorsed by the PHP project: I oppose the proposed .php top-level domain because .php already has a widely recognized meaning as the extension for PHP files. I work in web development and sometimes use the open-source WordPress software. The .php extension appears throughout websites, source code, documentation, development tools and technical discussions. If .php becomes a top-level domain, the same text could identify either a PHP file or a registered domain name.

Web 开发人员 Ryan Maietta 强调了将既定文件类型用作顶级域所带来的“文件扩展名混淆和安全风险”，以及人们将使用该域名的网站误认为是 PHP 项目官方认可的风险：我反对提议的 .php 顶级域，因为 .php 作为 PHP 文件的扩展名已经具有广泛认可的含义。我从事 Web 开发工作，有时会使用开源的 WordPress 软件。.php 扩展名出现在整个网站、源代码、文档、开发工具和技术讨论中。如果 .php 成为顶级域，相同的文本既可以标识 PHP 文件，也可以标识注册的域名。

For example, wp-login.php is the standard WordPress login script. If .php is approved and the name is available for registration, wp-login.php could also be a domain owned by someone with no connection to WordPress. A link shared in a message or technical discussion could appear familiar while sending someone to an unrelated website. Software that automatically turns text into links could make this confusion worse.

例如，wp-login.php 是标准的 WordPress 登录脚本。如果 .php 获得批准且该名称可供注册，wp-login.php 也可能成为由与 WordPress 无关的人拥有的域名。在消息或技术讨论中共享的链接可能看起来很熟悉，但却会将人引导至不相关的网站。自动将文本转换为链接的软件可能会加剧这种混淆。

The concern extends beyond WordPress. Someone could register domains that resemble PHP scripts or development resources and use them for phishing or impersonation. People may also mistake a .php website for an official resource endorsed by the PHP project. These risks are another reason I oppose the application. The applicant is an Automattic company. Automattic has a significant role in the WordPress ecosystem, but PHP is an independent, open-source language used by developers and organizations around the world. The interests of the broader PHP community deserve consideration. I ask ICANN to reject this application. The security risks are my most important concern.

这种担忧不仅限于 WordPress。有人可能会注册类似于 PHP 脚本或开发资源的域名，并将其用于网络钓鱼或冒充。人们也可能将 .php 网站误认为是 PHP 项目认可的官方资源。这些风险是我反对该申请的另一个原因。申请人是一家 Automattic 公司。Automattic 在 WordPress 生态系统中扮演着重要角色，但 PHP 是一种由全球开发人员和组织使用的独立开源语言。更广泛的 PHP 社区的利益值得考虑。我请求 ICANN 拒绝此申请。安全风险是我最关心的问题。

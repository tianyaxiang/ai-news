# Vim Classic 8.3.1 released

Vim Classic 8.3.1 发布 [2026-11-20] 我很自豪地宣布 Vim Classic 的第二个版本 Vim Classic 8.3.1，这是一个稳定且长期支持的文本编辑器分支，其维护过程未使用任何生成式人工智能工具。有关此分支动机的更多信息，请阅读这篇博客文章。

Vim Classic 8.3.1 released [2026-11-20] I'm proud to announce the second release of Vim Classic, Vim Classic 8.3.1, a stable, long-term support fork of the ubiquitous text editor, maintained without the assistance of generative AI tools. For more information about the motivations for this fork, please read this blog post.

此版本包含了截至 Vim 8.2.3237 的所有适用补丁，包括大量的错误修复、次要功能以及对 Vim 插件的兼容性改进。此版本还移除了 Vim Classic 对 Python 2 的支持。

This release includes applicable Vim patches up to Vim 8.2.3237, including numerous bug fixes, minor features, and compatibility improvements for Vim plugins. This release also removes Python 2 support from Vim Classic.

Vim Classic 和 Vim 一样属于慈善软件（charityware），我们很高兴能继续支持 Bram 为乌干达贫困儿童提供资助的热忱。从 Vim 切换到 Vim Classic 对您来说是一个捐款的好时机！

Vim Classic is charityware, much like Vim, and we are happy to continue supporting Bram's passion of providing for children in need in Uganda. Switching from Vim to Vim Classic would be an opportune moment for you to make a donation!

You can download Vim Classic from SourceHut: .tar.gz vim-classic-v8.3.1.tar.gz .tar.gz.sig vim-classic-v8.3.1.tar.gz.sig This release is signed with my PGP public key. Please subscribe to vim-classic-announce to be notified of important (actionable) news and releases in the future.

最后但同样重要的是，我要向每一位热情参与测试 Vim Classic、提供反馈并贡献了大量补丁和反向移植以促成此次发布的人表示衷心的感谢！祝编辑愉快！—— Drew DeVault

Last, but not least, let me extend a big "thanks!" to everyone who jumped in to enthusiastically test Vim Classic, provide feedback, and contribute many patches and backports to get this release done. Happy editing! — Drew DeVault

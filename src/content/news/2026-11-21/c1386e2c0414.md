What is new with Inkling 2 Mini? Inkling 2 Mini is a mixture-of-experts model with 24 decoder layers, but the 12 middle layers run three times in a loop. Therefore, the model acts as if it had 48 (6+ 3*12 + 6) logical layers with just 24 physical ones. Similar to Inkling 2 Small, Inkling 2 Mini executes 48 layer visits per token. The hidden size is 2,304 instead of 4,608. At each layer visit, both variants route the token to 8 experts, but Mini selects them from among 128 experts per layer, while Small selects from 384. The decoder runs layers 0–5 once, layers 6–17 three times, and layers 18–23 once. All three passes through layers 6–17 reuse the same weights. Architectures such as Nanbeige have explored looping before. But Inkling 2 Mini explores an interesting approach. Every pass through the looped core (layers 6–17) starts from the same inputs which is the output of the first six layers. Information moves between passes through cross-pass messages. Each looped layer reads a message from the previous pass's outputs with its own learned query (one message for its query, key, value and MLP inputs). A small gating controller then looks at both the layer's current input and the message. It decides how much of the current input to forget and how much of the message to add. Each pass therefore refines what the previous one computed.

Inkling 2 Mini 有什么新功能？Inkling 2 Mini 是一个拥有 24 个解码器层的混合专家模型，但中间的 12 层会循环运行三次。因此，该模型在仅有 24 个物理层的情况下，表现得如同拥有 48 个（6 + 3*12 + 6）逻辑层。与 Inkling 2 Small 类似，Inkling 2 Mini 每个 token 执行 48 次层访问。其隐藏层大小为 2,304 而非 4,608。在每次层访问时，两个版本都会将 token 路由到 8 个专家，但 Mini 是从每层 128 个专家中选择，而 Small 是从 384 个中选择。解码器运行第 0-5 层一次，第 6-17 层三次，第 18-23 层一次。所有三次通过第 6-17 层的过程都重用了相同的权重。Nanbeige 等架构之前已经探索过循环机制，但 Inkling 2 Mini 探索了一种有趣的方法。每次通过循环核心（第 6-17 层）时，都从相同输入开始，即前六层的输出。信息通过跨通道消息在各次通过之间传递。每个循环层通过其自身学习到的查询从前一次通过的输出中读取一条消息（一条用于其查询、键、值和 MLP 输入的消息）。一个小型的门控控制器随后会查看该层的当前输入和消息，决定忘记多少当前输入并添加多少消息。因此，每一次通过都会优化前一次的计算结果。

Each six-layer block has five sliding-window layers and one full-attention layer. The local window holds up to 1,024 tokens. Attention uses 24 query heads and eight KV heads. It uses learned relative position logits, a learned sink, and an output gate. Full-attention layers use dynamic key and value convolutions. The router selects eight of 128 SwiGLU experts for each token. It normalizes the selected scores and scales the weights by 8. During passes 2 and 3, each core layer attends over two residual blocks from the previous pass. Four rank-64 gates mix separate messages into the query, key, value, and MoE inputs. Text decoder width is 2,304, and the intermediate width of each expert is 1,152. Reusing core weights reduces the number of distinct layers the checkpoint stores. The model still executes all 48 visits, and each visit keeps its own KV and short-convolution state. In addition to the flagship Inkling 2 Mini model, a research artifact has also been released. It shares the same architecture, but this variant was trained to accept a variable number of passes through the loop 🤯. Setting 1 or 2 passes instead of 3 will make inference run a lot faster, but generations may be of slightly lower quality. We tested this variant, and it works, but we haven’t evaluated it in depth.

每个六层模块包含五个滑动窗口层和一个全注意力层。本地窗口最多可容纳 1,024 个 token。注意力机制使用 24 个查询头和 8 个 KV 头。它使用学习到的相对位置 Logits、一个学习到的 Sink 以及一个输出门。全注意力层使用动态键和值卷积。路由器为每个 token 从 128 个 SwiGLU 专家中选择 8 个。它会对选定的分数进行归一化，并将权重缩放 8 倍。在第 2 次和第 3 次通过期间，每个核心层都会关注前一次通过的两个残差块。四个秩为 64 的门将独立消息混合到查询、键、值和 MoE 输入中。文本解码器宽度为 2,304，每个专家的中间宽度为 1,152。重用核心权重减少了检查点存储的不同层数。该模型仍然执行所有 48 次访问，并且每次访问都保留其自己的 KV 和短卷积状态。除了旗舰版 Inkling 2 Mini 模型外，还发布了一个研究工件。它共享相同的架构，但该变体经过训练，可以接受可变次数的循环通过 🤯。将通过次数设置为 1 或 2 而非 3 会使推理速度快得多，但生成质量可能会略有下降。我们测试了这个变体，它确实有效，但我们尚未对其进行深入评估。

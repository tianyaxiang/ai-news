# zed-industries / zed

Zed Welcome to Zed, a high-performance, multiplayer code editor from the creators of Atom and Tree-sitter.

Zed 欢迎来到 Zed，这是一款由 Atom 和 Tree-sitter 的创作者开发的高性能多人代码编辑器。

Installation On macOS, Linux, and Windows you can download Zed directly or install Zed via your local package manager (macOS/Linux/Windows). Other platforms are not yet available: Web (tracking discussion)

安装：在 macOS、Linux 和 Windows 上，您可以直接下载 Zed 或通过本地包管理器（macOS/Linux/Windows）安装 Zed。其他平台暂不可用：Web（正在跟踪讨论）。

Licensing Zed source code is licensed primarily under GPL-3.0-or-later, with Apache-2.0 components where marked. License information for third party dependencies must be correctly provided for CI to pass. We use cargo-about to automatically comply with open source licenses.

许可：Zed 源代码主要在 GPL-3.0-or-later 下授权，并在标记处包含 Apache-2.0 组件。必须正确提供第三方依赖项的许可信息，以便通过持续集成（CI）。我们使用 cargo-about 来自动遵守开源许可。

If CI is failing, check the following: Is it showing a no license specified error for a crate you've created? If so, add publish = false under [package] in your crate's Cargo.toml. Is the error failed to satisfy license requirements for a dependency? If so, first determine what license the project has and whether this system is sufficient to comply with this license's requirements. If you're unsure, ask a lawyer. Once you've verified that this system is acceptable add the license's SPDX identifier to the accepted array in script/licenses/zed-licenses.toml. Is cargo-about unable to find the license for a dependency? If so, add a clarification field at the end of script/licenses/zed-licenses.toml, as specified in the cargo-about book.

如果 CI 失败，请检查以下内容：是否显示了您创建的 crate 未指定许可的错误？如果是，请在您的 crate 的 Cargo.toml 中的 [package] 下添加 publish = false。错误是否为无法满足依赖项的许可要求？如果是，请先确定该项目拥有什么许可，以及此系统是否足以满足该许可的要求。如果您不确定，请咨询律师。一旦确认此系统可接受，请将该许可的 SPDX 标识符添加到 script/licenses/zed-licenses.toml 中的 accepted 数组中。cargo-about 是否无法找到某个依赖项的许可？如果是，请按照 cargo-about 手册中的说明，在 script/licenses/zed-licenses.toml 的末尾添加一个 clarification 字段。

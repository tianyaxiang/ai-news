Symfony is a PHP framework for web and console applications and a set of reusable PHP components. Symfony is used by thousands of web applications and most of the popular PHP projects.

Symfony 是一个用于 Web 和控制台应用程序的 PHP 框架，也是一套可重用的 PHP 组件。Symfony 被数以千计的 Web 应用程序和大多数流行的 PHP 项目所使用。

Installation Install Symfony with Composer (see requirements details). Symfony follows the semantic versioning strictly, publishes "Long Term Support" (LTS) versions and has a release process that is predictable and business-friendly.

安装：使用 Composer 安装 Symfony（查看详细要求）。Symfony 严格遵循语义化版本控制，发布“长期支持”（LTS）版本，并拥有可预测且对商业友好的发布流程。

赞助：Symfony 8.2 正在寻找支持者。通过赞助其开发来帮助 Symfony！

Documentation Read the Getting Started guide if you are new to Symfony. Try the Symfony Demo application to learn Symfony in practice. Discover Symfony ecosystem in detail with Symfony The Fast Track. Master Symfony with the Guides and Tutorials, the Components docs and the Best Practices reference.

文档：如果您是 Symfony 的新手，请阅读入门指南。尝试使用 Symfony 演示应用程序来实践学习 Symfony。通过《Symfony 快速通道》详细了解 Symfony 生态系统。通过指南和教程、组件文档以及最佳实践参考来掌握 Symfony。

Community Join the Symfony Community and meet other members at the Symfony events. Get Symfony support on GitHub Discussions, Slack, etc. Follow us on GitHub, Twitter and Facebook. Read our Code of Conduct and meet the CARE Team.

社区：加入 Symfony 社区，并在 Symfony 活动中结识其他成员。通过 GitHub Discussions、Slack 等渠道获取 Symfony 支持。在 GitHub、Twitter 和 Facebook 上关注我们。阅读我们的行为准则并了解 CARE 团队。

Contributing Symfony is an Open Source, community-driven project with thousands of contributors. Join them contributing code or contributing documentation.

贡献：Symfony 是一个由社区驱动的开源项目，拥有数以千计的贡献者。加入他们，贡献代码或文档。

Security Issues If you discover a security vulnerability within Symfony, please follow our disclosure procedure.

安全问题：如果您发现 Symfony 中存在安全漏洞，请遵循我们的披露程序。

About Us Symfony development is led by the Symfony Core Team and supported by Symfony contributors.

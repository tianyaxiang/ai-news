Distinguished Engineer Brian is a Principal Software Engineer working on the storage and core services that power all repository interactions on GitHub.

杰出工程师 Brian 是一位首席软件工程师，致力于开发为 GitHub 上所有存储库交互提供支持的存储和核心服务。

Architecture & optimization The bridge to agent-scale Git infrastructure We moved a copy of 99.99999% of GitHub’s repositories to Azure. Here’s how per-reference quorums will bring over the rest, and how object storage lets reads scale independently.

架构与优化：通往代理级 Git 基础设施的桥梁。我们将 GitHub 99.99999% 的存储库副本迁移到了 Azure。以下是基于引用的法定人数（per-reference quorums）如何迁移剩余部分，以及对象存储如何实现读取操作的独立扩展。

Engineering Staying Evergreen: How we automated secure access and repo hygiene in a shared org Put native GitHub features to work to review outside collaborator access and archive stale repositories.

工程：保持常青：我们如何在共享组织中实现安全访问和存储库清理的自动化。利用 GitHub 原生功能来审查外部协作者的访问权限并归档陈旧的存储库。

Architecture & optimization From 2,500 requests to 24: Rebuilding star history without the stargazers Our new repo star history API now provides trends without returning individual identities or requiring unbounded database work. These are the engineering tradeoffs we made.

架构与优化：从 2,500 次请求到 24 次：在不获取点赞者信息的情况下重建星标历史。我们新的存储库星标历史 API 现在可以提供趋势分析，而无需返回个人身份信息或进行无限制的数据库操作。这些就是我们所做的工程权衡。

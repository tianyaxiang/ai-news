# Robust Stream Classification using Time Neutralising Decision Trees

Computer Science > Machine Learning arXiv:2611.06991 (cs) [Submitted on 4 Nov 2026] Title: Robust Stream Classification using Time Neutralising Decision Trees Authors: Brandon Gower-Winter, Georg Krempl.

计算机科学 > 机器学习 arXiv:2611.06991 (cs) [提交于 2026 年 11 月 4 日] 标题：使用时间中和决策树的稳健流分类 作者：Brandon Gower-Winter, Georg Krempl。

Abstract: Data Streams are characterised as a potentially infinite source of data subject to non-stationarity. This non-stationarity, also called Concept Drift, often results in deployed predictive models having to be perpetually retrained as the underlying data generating process of the stream changes over time.

摘要：数据流的特征是潜在的无限数据源，且具有非平稳性。这种非平稳性（也称为概念漂移）通常导致已部署的预测模型必须不断进行重新训练，因为流的底层数据生成过程会随时间发生变化。

Drift Detectors are a class of methods used to identify these changes, triggering these retraining procedures. Historically, Stream Learning has operated under the assumption that instances are only seen once, and cannot be stored for later use. Contemporary work relaxes this assumption, yet drift detection and simple resetting procedures are still ubiquitous.

漂移检测器是一类用于识别这些变化并触发重新训练过程的方法。从历史上看，流学习是在假设实例仅被查看一次且无法存储以供后续使用的情况下运行的。当代研究放宽了这一假设，但漂移检测和简单的重置程序仍然无处不在。

Building on related work which has shown that traditional Batch Learning algorithms often outperform Stream Learning algorithms when instances can be stored, we introduce Time Neutralising Trees (TNT), a Decision Tree architecture that enables robust stream classification in settings with Concept Drift.

基于相关研究表明在可以存储实例时传统批处理学习算法通常优于流学习算法，我们引入了时间中和树 (TNT)，这是一种在存在概念漂移的环境中实现稳健流分类的决策树架构。

During training, TNT will filter out ("neutralise") old training samples that are no longer relevant given the current context of the stream. If those instances become relevant again, TNT will then re-include them. We evaluate TNT, and related algorithms on 24 real and semi-real classification data streams from the USP DS repository.

在训练过程中，TNT 会过滤掉（“中和”）在当前流上下文中不再相关的旧训练样本。如果这些实例再次变得相关，TNT 将重新包含它们。我们在来自 USP DS 存储库的 24 个真实和半真实分类数据流上评估了 TNT 及相关算法。

Results show strong evidence that TNT achieves best-in-class performance on a wide-range of data streams with varying concept drift types.

结果有力地证明了 TNT 在具有不同概念漂移类型的广泛数据流上实现了同类最佳性能。

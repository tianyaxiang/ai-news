It's free, open source, built in Rust, and it ships its own MCP server so AI agents like Claude Code can edit video. 简而言之：Concat 在 3.9 秒内将一个 76 MB 的视频压缩到了 3 MB，在运行过程中我记录了所有的网络请求：我的视频没有 1 字节上传到云端。它是免费、开源的，基于 Rust 构建，并自带 MCP 服务器，因此像 Claude Code 这样的 AI 代理可以进行视频编辑。但它目前仍是一个发布 10 周的测试版（v0.2.9），且有 200 多个待解决的问题。▶ 完整视频：https://youtu.be/KWJw3RQHElU

What is Concat? Concat is a desktop video editor that wants to replace CapCut. Everything runs on your own machine. Free and open source (AGPL-3.0), no account, no watermark, and the site says there is no paid tier. Built in Rust: about 159,000 lines, first release in September 2026. Runs on Mac, Windows, Linux, Android and iPhone. Fast growth: 14,000+ GitHub stars and about 440,000 downloads in ten weeks. Needs 4 GB of RAM (16 GB recommended for 4K). The layout will feel familiar if you've used CapCut: library on the left, preview in the middle, inspector on the right, timeline at the bottom. Every panel can be swapped, split or dragged.

什么是 Concat？Concat 是一款旨在取代 CapCut 的桌面视频编辑器。所有操作都在本地机器上运行。它免费且开源（AGPL-3.0），无需账户，没有水印，网站声明不存在付费层级。它由 Rust 构建，代码量约 15.9 万行，于 2026 年 9 月首次发布。支持 Mac、Windows、Linux、Android 和 iPhone。增长迅速：十周内获得了 14,000 多颗 GitHub 星标和约 440,000 次下载。需要 4 GB 内存（4K 视频建议 16 GB）。如果你用过 CapCut，会觉得布局很熟悉：左侧是素材库，中间是预览，右侧是检查器，底部是时间轴。每个面板都可以交换、拆分或拖动。

Test 1: Compress a video (the one I ran myself) Concat has free tools that run right in the browser. I tried Compress a video in Chrome on my Mac: Input: 76 MB stock clip, 20 seconds of 1080p H.264 Settings: Balanced quality, 720p, MP4 Result: 3.0 MB (96% smaller) in 3.9 seconds It encodes on your own GPU, with no server in between. I recorded every network request during the run: 0 bytes of the video were uploaded. The honest flaw: the page still loads Google ads.

测试 1：视频压缩（我亲自运行的测试）Concat 提供直接在浏览器中运行的免费工具。我在 Mac 上的 Chrome 浏览器中尝试了“压缩视频”功能：输入：76 MB 的素材片段，20 秒 1080p H.264 格式；设置：平衡质量，720p，MP4；结果：3.0 MB（缩小了 96%），耗时 3.9 秒。它在你的 GPU 上进行编码，中间没有经过服务器。我记录了运行期间的每一个网络请求：视频上传量为 0 字节。诚实的缺点：页面仍然会加载谷歌广告。

Test 2: Auto captions Captions are one button (the T on the timeline). You pick a Whisper model; the base English one is a 148 MB download, and after that it transcribes fully offline. You get one title per phrase on the timeline, you can restyle all of them at once, and it imports and exports SRT. Their own guide has a section called "why a word is wrong", so expect to fix a few words.

测试 2：自动字幕 字幕只需一个按钮（时间轴上的 T）。你需要选择一个 Whisper 模型；基础英语模型下载大小为 148 MB，之后即可完全离线转录。时间轴上每个短语对应一个标题，你可以一次性重新设置所有标题的样式，并支持 SRT 格式的导入和导出。他们自己的指南中有一个名为“为什么单词会出错”的章节，所以请做好手动修正个别单词的准备。

Test 3: Text to speech, voice cloning, background removal Type a script, pick a voice, and the read lands on your timeline. Voice cloning from a few seconds of audio (small model 98 MB, studio model about 1 GB). Background removal for people or objects, plus a smart brush. The person model is 15 MB. No green screen. Downside: on phones, the built-in voice is still coming.

测试 3：文本转语音、语音克隆、背景移除 输入脚本，选择声音，朗读内容就会出现在你的时间轴上。通过几秒钟的音频即可进行语音克隆（小型模型 98 MB，录音室模型约 1 GB）。支持人物或物体的背景移除，以及智能画笔功能。人物模型大小为 15 MB。无需绿幕。缺点：在手机端，内置语音功能尚未上线。

Test 4: 4K export and the MCP server Export H.264, HEVC or AV1 up to 4K 60 fps, 10-bit, no watermark at any resolution. This week's update made 4K exports about 2.4x faster. The part developers will care about: Concat ships its own MCP server. An AI agent like Claude Code gets tools for clips, titles, keyframes, effects and export, the same commands the editor itself uses. Setup is one line in the terminal; the steps are in the repo's docs/MCP.md. So "cut the silences, add captions, export 1080p" can be a prompt instead of an afternoon.

测试 4：4K 导出和 MCP 服务器 支持导出 H.264、HEVC 或 AV1 格式，最高支持 4K 60 fps、10-bit，任何分辨率下均无水印。本周的更新使 4K 导出速度提升了约 2.4 倍。开发者会关心的部分：Concat 自带 MCP 服务器。像 Claude Code 这样的 AI 代理可以获得用于剪辑、标题、关键帧、特效和导出的工具，这些命令与编辑器本身使用的命令相同。设置只需在终端输入一行代码；步骤在仓库的 docs/MCP.md 中。因此，“剪掉静音片段、添加字幕、导出 1080p”可以变成一个提示词，而不是一下午的工作。

The catch Beta: v0.2.9 with 200+ open issues on GitHub. Windows builds aren't code-signed yet, so SmartScreen will warn you. Phones: no built-in voice yet.

局限性 测试版：v0.2.9，GitHub 上有 200 多个待解决的问题。Windows 版本尚未进行代码签名，因此 SmartScreen 会发出警告。手机端：暂无内置语音功能。

Verdict If you edit for clients with deadlines, not yet. If you're a student, a Linux user, a small creator, or a developer who wants an editor an agent can drive, it's already useful, and it's free. Nothing uploads, which also makes it a good fit for private footage. Would you let an AI agent cut your videos through MCP? I'm curious what you'd automate first.

结论 如果你是为有截止日期的客户进行剪辑，目前还不推荐。如果你是学生、Linux 用户、小型创作者，或者想要一个能由 AI 代理驱动的编辑器的开发者，它已经很有用，而且是免费的。没有任何内容会上传，这也使其非常适合处理私人素材。你会让 AI 代理通过 MCP 来剪辑你的视频吗？我很好奇你会优先自动化哪些操作。

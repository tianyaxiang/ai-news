# StackCircuit365 - Catch Vercel & GitHub deployment issues and auto-rollback before users notice
# StackCircuit365 - 在用户察觉前捕获 Vercel 和 GitHub 部署问题并自动回滚

StackCircuit365 is a 100% free npm package that is built to watch your Github and Vercel deployments for deployment issues and automatically brings back the last verified healthy version.
StackCircuit365 是一个完全免费的 npm 包，旨在监控您的 GitHub 和 Vercel 部署是否存在问题，并自动恢复到上一个经过验证的健康版本。

With 3 distinct modes; Observe: In this mode StackCircuit365 will detect incidents and write an impact report. It alerts you to the problem but doesn't change anything.
它提供三种不同的模式：观察模式（Observe）：在此模式下，StackCircuit365 会检测事故并编写影响报告。它会向您发出问题警报，但不会进行任何更改。

Approval: StackCircuit365 detects an early regression and sends a recommendation on the best next steps. You approve it in the dashboard or through your connected Slack.
批准模式（Approval）：StackCircuit365 会检测到早期的回归问题，并发送关于最佳后续步骤的建议。您可以在仪表板或通过已连接的 Slack 进行批准。

Auto-Recover: StackCircuit365 performs a rollback on it own, but only when every strict safety layer is passed. Off until you turn it on and only after real testing.
自动恢复模式（Auto-Recover）：StackCircuit365 会自行执行回滚，但前提是必须通过每一层严格的安全检查。该功能默认关闭，仅在您开启且经过实际测试后才会生效。

The AI reads evidence, diagnoses issues, and offer or executes solutions autonomously. It stops at auth change, billing path, or on sensitive data it is not sure about.
AI 会读取证据、诊断问题，并自主提供或执行解决方案。如果遇到身份验证更改、计费路径或不确定的敏感数据，它会停止操作。

立即尝试 StackCircuit365，欢迎随时提供反馈！
